# IDCM v11.0 — Reality-Architecture

**Information Dynamics Cosmology Model — 11th Generation**

> v11.0 的職責是收束，不是擴張：把 v10.0 遺留命題逐條歸類為「結構」「標籤」「否證」，只保留可追源至 𝒯 = K_Chain ⊗ K_Tree 譜結構者。

## 緣起

v10.0 產出大量結果，其中一部分以結構標籤命名——分支閉合、轉移矩陣不變量、對稱性論證——追源後發現只有數值接軌而無算子推導。標籤一旦被當成推導，錯誤會累積而無法察覺，因為每個標籤都「看起來」有結構理由。

v11.0 因此不做新物理，只做三件事：

1. **重推**：把標籤換成算子，由 𝒯 的譜、標籤與投影重新導出
2. **證偽**：把湊數結果標 FAIL、封存、寫入禁區，唔重推
3. **立規**：令新結果無法再以密度命中冒充結構

驗收標準：一個結果只有在能回答「算子身份是甚麼」時才通過。能寫出公式但講不出算子，一律當標籤。

## 方法

1. **追源**：每條公式必須落到 𝒯 = K_Chain ⊗ K_Tree 的譜、標籤或投影
2. **分類**：結構／標籤／否證，三類互斥，不設灰色地帶
3. **盲測**：先寫死預言再對數據；禁止看到目標後凑算子
4. **封存**：已否證路線保留 FAIL 原文＋校正 tag，唔重推
5. **隔離**：每問題獨立目錄（README＋01_problem_record＋SESSION_START）
6. **立規**：三鐵律——L1 可證偽、L2 可預言、L3 自由度能砸
