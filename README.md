## 緣起

v10.0 產出大量結果，其中一部分以結構標籤命名——分支閉合、轉移矩陣不變量、對稱性論證——追源後發現只有數值接軌而無算子推導。

標籤一旦被當成推導，錯誤會累積而無法察覺，因為每個標籤都「看起來」有結構理由。判別方法只有一個：**能不能回答「算子身份是甚麼」。**

v11.0 因此不做新物理，只做三件事：

1. **重推**：把標籤換成算子，由 𝒯 的譜、標籤與投影重新導出
2. **證偽**：把湊數結果標 FAIL、封存、寫入禁區，唔重推
3. **立規**：令新結果無法再以密度命中冒充結構

驗收標準：一個結果只有在能回答「算子身份是甚麼」時才通過。能寫出公式但講不出算子，一律當標籤。

## 驗證紀律

IDCM 的嚴謹性分六層：入場券 → 結構審計 → 獨立性審計 → 數字紀律 → 記錄紀律 → 路徑紀律。任一層不過，結果只停留「數值候選」。

### 一、入場券：4 Hard Tests

| 測試 | 要求 | 失敗處置 |
|---|---|---|
| ① 零參數自由度 | dof = 0；每加一個可調參數即扣一級 | 有自由參數 ⟹ 不准稱閉合 |
| ② MC null | 10⁷ 次隨機對照，5σ | 未過 ⟹ 標「候選」 |
| ③ 樣本外盲測 | 預言先寫死，數據後開 | 事後調整 ⟹ 作廢 |
| ④ 結構剛性 | 擾動任一參數，結論必須崩 | 不崩 ⟹ 係恆等式或凑數 |

### 二、結構審計：三鐵律

- **L1 能證偽**：預言必須零寬度或可被更精確測量殺。禁「約 X%」寫法。
- **L2 能預言**：至少一個**獨立**樣本外預言；同義反覆不算。
- **L3 自由度能砸**：dof = 0。禁「枚舉 N 個候選揀中 1 個」——隱藏 dof = N。

> 三律缺一 ⟹ 降級為數值候選，不得升格為結構解。

### 三、獨立性審計：五反模式

1. **同義反覆** — 計放大因子 `δy/y ÷ δx/x`；若對所有候選同一常數，則 `y = f(x)` 為單調變換 ⟹ 同一信息，唔算兩個判據
2. **循環** — 預言公式內含被解釋量
3. **範疇錯** — 樹級 vs RG running、on-shell vs MS-bar、M_Z vs 統一標度
4. **枚舉即隱藏 dof** — 掃 N 個組合揀中 1 個 ⟹ dof = N
5. **密度家族依賴** — 家族越小統計力越弱；報密度必須同時報家族大小與定義

### 四、數字紀律

- **密度基準分位數**：任何「命中」必須擊敗同族隨機分佈並報出百分位
- **反硬編碼**：關鍵常數須三源一致（結構推導／獨立觀測／數值重算）；只有一源 ⟹ 標「未驗」
- **禁區**：φ-power fitting、見 target 後凑算子、事後選窗
- **跨版本引用**：先核歸一化——版本公式不相通

### 五、記錄紀律
