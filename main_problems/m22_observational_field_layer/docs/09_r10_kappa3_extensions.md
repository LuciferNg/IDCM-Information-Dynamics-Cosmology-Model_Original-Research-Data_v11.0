## §一 (a) 跨 ℓ `κ₃(ℓ,ℓ′)`：選擇律封死大半

```
I₃^{ℓℓℓ′} = Σ_{m₁+m₂+m₃=0} (ℓℓℓ′|m₁m₂m₃) a^ℓ a^ℓ a^{ℓ′}
κ₃^{ℓℓℓ′} = I₃ / (I₁^ℓ · √I₁^{ℓ′})        免框架、免振幅（c²c′）
```

**選擇律**：`3j(ℓ,ℓ,ℓ′) ≠ 0` 只當 `|ℓ−ℓ′| ≤ ℓ ≤ ℓ+ℓ′`。實測 9 對之中：

## §二 (b) 四次不變量 `κ₄^{(L=2)}` ≡ 0（結構性，非 bug）

```
I₄^{L} = Σ (ℓℓL|m₁m₂M)(ℓℓL|m₃m₄−M) a₁a₂a₃a₄ ，  M = −m₁−m₂
κ₄ = I₄^{L=2}/I₁²
結果：13/13 ℓ 全部 = 0（|κ₄| < 1e−9）
陽性對照：同一估計量於「一般實場」給 |κ₄| = 1e−4 ≠ 0 ⟹ **唔係 code bug**
```

### §2.1 原因（新結構定理）

```
全部 13 個 I_ℓ：|a_{ℓm}|² ≠ 0 只於 **m 偶**
⟹ I_ℓ 係鏡像 S = diag(1,−1,1) 之本徵態：
     偶 ℓ：純 cos 級數（m 偶）⟹ 本徵值 +1
     奇 ℓ：純 sin 級數（m 偶）⟹ 本徵值 −1
   統一寫法：本徵值 = (−1)^ℓ
⟹ L=2 之 4-點收縮只餘 B₀ 項，而 B₀ 於鏡像本徵態上恆零
```
