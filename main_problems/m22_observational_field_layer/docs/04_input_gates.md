## §一 CQ2 — 原初譜 IR 端

### §1.1 輸入門答案（指名常數 ＋ 為何係佢）

```
常數：𝒟 = {ℓ : m_ℓ ≥ 1}，m_ℓ = dim Hom_{A₅}(1, H_ℓ) —— 即 A₅ 在球諧上之不變譜支撐
為何係佢：v11 中唯一作用於 S² 之結構係 A₅（經其**唯一** 3 維 irrep 嵌入 SO(3)）；
          而鏈側 A₅ 作用平凡（5 ∤ 88）⟹ 等變投影之像必落在不變子空間（docs/02 §三）
可算預言：ℓ = 1,2,3,4,5 之功率**恰零**（非「小」）；等價地 f ≡ 0（docs/03 §二）
```

### §1.2 預言 ＋ 閾值（事前可算）

```
f = Σ_{ℓ=2..5}(2ℓ+1)C_ℓ / Σ_{ℓ=2..27}(2ℓ+1)C_ℓ       模型值 = 0
GRF null 10⁷（非 permutation）：
  SW 權重  ：f_crit(Bonferroni α=0.05/22) = 0.21659 ；f_crit(5σ) = 0.11432
  平 C_ℓ   ：f_crit(Bonferroni)          = 0.01809 ；f_crit(5σ) = 0.00878
```
**此門檻與振幅完全無關**（模型值恰 0，任何 `A` 皆同）。

### §1.3 M17 之 CQ2 判準所需之「S_{1/2} 與 C(π)」

| 量 | 可預言？ | 依據 |
|:--|:--:|:--|
| `f` | ✅ | 恰零；門檻見上 |
| `S_{1/2}` | 🔴 | 帶 `221…1376`（comb）、`S_{1/2}/σ⁴` 帶跨 7.5× ⟹ 無點預言 |
| `C(π)` | 🔴 | 帶 `−90.5…+442.4`；`C(π)/σ²` 帶 `−0.35…+0.99` ⟹ 跨符號 |

⟹ **CQ2 之輸入門：以 `f` 之形式通過；`S_{1/2}`／`C(π)` 之數值預言不通過。**
M17 若堅持以 `S_{1/2}`／`C(π)` 為判準，則 CQ2 須記「無預言」。

## §二 CQ3 — 宇稱／手性

### §2.1 算子存在性（✅）

```
𝒟_odd = {15, 21, 25, 27, …}      ⟹ 奇宇稱不變度存在，ℓ_odd^min = 15
A₅ = I（手性）：400 個 det = −1 元素，**0 個** normalise A₅（scripts/05 P1）
   ⟹ 群階若雙倍（I_h，120）則存在反射；實測冇 ⟹ 手性屬**群層結構**
宇稱分級：𝒟_even(≤27) = {6,10,12,16,18,20,22,24,26}（9 個，Σ(2ℓ+1) = 317）
          𝒟_odd(≤27)  = {15,21,25,27}（4 個，Σ(2ℓ+1) = 180）
```
⟹ 答案：**有宇稱分級（算子層面存在）**，且最低奇度 = 15（唔係 2/3）。

### §2.2 觀測簽名（🟡 —— 兩條路皆空）

```text
路 A（R^27 型宇稱比）：C_ℓ 對鏡像**全盲** —— S = diag(1,1,−1) 作用只改相位
   a_{ℓm} ↦ (−1)^{ℓ+m} conj(a_{ℓ,−m}) ⟹ |a_{ℓm}|² 之集合不變 ⟹ C_ℓ 不變（scripts/05 P2）
   ⟹ R^27 對「模型 vs 其鏡像」零判別力；且 R^27 數值帶 [0.40, 102] ⟹ 無預言

路 B（跨 ℓ 圖樣）：以 ℓ=6 定框架後，偶 ℓ 之鏡像殘差 = 0（I_ℓ∘S = D^ℓ(R_z(π))I_ℓ 恆等）；
   奇 ℓ 殘差 ≈ 0.27–0.36 ⟹ 鏡像 = c_ℓ → −c_ℓ（奇 ℓ）。
   但 c_ℓ 係自由實數，24 種子中正/負皆現（ℓ=6：14/10；ℓ=15：11/13；ℓ=21：10/14）
   ⟹ 鏡像落在同一 amplitude 族內 ⟹ **手性無觀測簽名**
```

### §2.3 判詞

**CQ3 輸入門 = 🟡：算子存在（宇稱分級 ＋ 手性群），但「事前可算、事後可證偽」之統計量不存在**
（在 `c_ℓ` 自由之下）。M17 若要以 CQ3 判死／判生，須先有一個**固定 `c_ℓ` 符號**之結構理由 —— 本 M 冇。
**R^27 不得作判準**（帶跨 2 個數量級）。

## §三 CQ4 — 低方差 `σ²_16`

### §3.1 `dof = 1` 能否給 `σ²_16`？（答案分兩半）

```
✅ 半：dof_scale = 1 ⟹ **冇**自由變異度 dof（隨機場之 variance 係第二個連續參數，被 dof=1 排除）
        ⟹ `σ²_16` 係**結構決定量**，唔係自由參數 —— 呢點係明確答案（M6 B2 之直接後果）
🔴 半：但「決定」需要一條 `質量標度 → ΔT/T` 之通道；v11 冇
        （現有量：γ 譜／M₀ 屬質量標度；Ω 比例屬無量綱；CMB 溫度 T₀ = 2.7255 K 屬外部錨）
        ⟹ 絕對值須**外部振幅歸一** ⟹ 章程 §二 T4 明文判 🔴
```

### §3.2 可交之無量綱內容（🟡）

```
ℓ ≤ 5 恰零 ⟹ σ²_16 相對「填回 ℓ≤5」之抑制度 = 2.28% … 9.10%
σ²_16 / σ²_total = 0.831442 … 0.905908（帶窄 ±4%）
```
（`σ²_16` 用 `healpy.pixwin(16)`，`ℓ ≤ 47`；`σ²_total` 為 `ℓ ≤ 40` 之無窗總和。）

### §3.3 判詞

**CQ4 輸入門 = 🔴（絕對值）／🟡（帶窄之比值）。** 判死／判生須由 M17 決定是否接受「只以無量綱比值為判準」。
