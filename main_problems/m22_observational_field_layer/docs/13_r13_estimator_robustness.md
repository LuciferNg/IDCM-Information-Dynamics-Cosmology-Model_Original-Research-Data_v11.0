# M22 docs/13 — R13：κ₃ 估計量之公約穩健性自檢（交 M17 前最後一關）

> **腳本**: `scripts/17`（5/5 PASS，20s）｜**一句**: **κ₃ 可由「單 ℓ 地圖之立方積分」直接量出（無 3j 求和），兩條公約無關路徑一致至 1e−14 —— M17 唔會因公約踩雷。**

---

## §一 風險

M17 若用不同公約（實／複基底、Condon–Shortley 相位、3j 呼叫次序、網格 vs 求積），`κ₃` 之值可能偏 ⟹ 判死會誤。

## §二 三重交叉核（公約無關）

| 核 | 內容 | 機器結果 |
|:--|:--|:--|
| C1 | 實基底（cos/sin 係數）重建 `f(θ,φ)` vs 複基底 `Σ a_m Y_{ℓm}` | `max|f_real − Re f_complex| = 7.77e−16` |
| C2 | 直接球面求積 `∫f³dΩ` vs 3j 收縮 `I₃` | 比值全等於 `√((2ℓ+1)³/4π)·(ℓℓℓ|000)`（9/9 偶 ℓ）|
| C3 | 奇 ℓ：`∫f³` 應 ≡ 0 | 4/4 皆 ~1e−18（與 `(ℓℓℓ|000)=0`、`I₃≡0` 三重一致）|
| C4 | 求積解析度獨立性（NG 120 vs 200）| `max 相對差 = 1.75e−13` |
| C5 | `κ₃` 兩路徑（求積 vs 3j 收縮）| `max 差 = 1.06e−14`（9 個偶 ℓ）|

## §三 交付：**無 3j 求和之 κ₃ 實作**（交 M17）

```
由 (C2)：∫Y_{ℓm₁}Y_{ℓm₂}Y_{ℓm₃}dΩ = √((2ℓ+1)³/4π)·(ℓℓℓ|000)·(ℓℓℓ|m₁m₂m₃)
⟹ ∫ f_ℓ³ dΩ = C_ℓ · I₃ ,   C_ℓ ≡ √((2ℓ+1)³/4π)·(ℓℓℓ|000)

故   κ₃(ℓ) = [∫ f_ℓ³ dΩ] / [ C_ℓ · I₁^{3/2} ] ,   I₁ = Σ_m |a_{ℓm}|²

實作（healpy，三步，零 3j 求和）：
  ① 取該 ℓ 之 a_{ℓm}（其餘設 0）→ alm2map → f_ℓ（單 ℓ 地圖）
  ② ∫f_ℓ³dΩ = Σ_pix f_ℓ³ · Ω_pix（HEALPix 等面積；或用 ud_grade 至 Nside 256+ 減離散誤差）
  ③ κ₃ = 上式；C_ℓ = √((2ℓ+1)³/4π)·(ℓℓℓ|000)（C_ℓ 可用 sympy 一次算好，見下表）
```
