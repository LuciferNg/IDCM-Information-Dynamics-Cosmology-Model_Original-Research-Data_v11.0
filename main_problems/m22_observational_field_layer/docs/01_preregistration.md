### §1.4 等變性要求（P 之唯一性來源）

```
P 必須 A₅-等變：P(g·ρ) = g·P(ρ)
鏈側 A₅ 作用 = 平凡（5 ∤ 88 ⟹ A₅ 冇任何非平凡作用可保 C₈₈ 之環結構）
⟹ 對任何鏈側量 ρ（∈ 平凡表示）必有 P(ρ) ∈ 天空側之平凡等型分量
```
本條係 §三「形狀定理」之唯一來源；若鏈側存在非平凡 A₅ 作用，本定理即失效（見 §五 剛性測試）。

## §二 四統計量之凍結定義（對齊 Planck／文獻）

```
C(θ)     = Σ_ℓ (2ℓ+1)/(4π) · C_ℓ · P_ℓ(cos θ)
S_{1/2}  = ∫_{−1}^{1/2} [C(θ)]² d(cos θ)                    （Copi–Huterer–Schwarz–Starkman）
C(π)     = Σ_ℓ (−1)^ℓ (2ℓ+1)/(4π) C_ℓ  = C(θ=180°)
R^27     = D⁺ / D⁻ ,  D^± = (1/ℓ^±_tot) Σ_{ℓ∈{2..27}, even/odd} ℓ(ℓ+1)/(2π) C_ℓ
           （Planck XVI／Muir et al. 2018 §；**even/odd**；觀測異常 = odd>even ⟹ R^27 < 1）
σ²_16    = Var(unmasked pixels of Nside = 16 map)            （Planck 2018 VII §5；Muir §4）
```
`C_ℓ = (1/(2ℓ+1)) Σ_m |a_{ℓm}|²`；本 M 一律用**實**球諧基底，`C_ℓ` 與基底無關。

### §3.1 判準之量（機械可數）

```
m_ℓ        = dim Hom_{A₅}(1, H_ℓ) = (1/|G|) Σ_g χ_ℓ(θ_g)          （精確，須 ∈ ℤ≥0）
𝒟          = { ℓ : m_ℓ ≥ 1 }
𝒟_even/odd = 𝒟 ∩ {ℓ even} / {ℓ odd}
ℓ_min      = min 𝒟 \ {0}   ｜  ℓ_odd^min = min 𝒟_odd
N_fix(ℓ_max)= Σ_{ℓ≤ℓ_max} (2ℓ+1 − m_ℓ)      ← 投影「釘死」之實自由度数（信息量）
```
`N_fix` 係「全域場 vs 60 dof 硬牆」之判別量（P4 docs/73 §4.1 GF1 之量化答覆）：全域場模型若 `N_fix > 60`，則模型資訊量超過節點直讀上限。

