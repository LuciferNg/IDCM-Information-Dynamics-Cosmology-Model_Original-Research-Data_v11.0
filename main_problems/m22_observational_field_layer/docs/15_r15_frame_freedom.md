# M22 docs/15 — R15：框架自由定理 —— 方向／子空間統計量之判死力**恰為零**

> **腳本**: `scripts/19`（4/4 PASS）｜**一句**: **M22 從未推導天空取向 ⟹ 框架自由 ⟹ 一切「方向／子空間投影」統計量之判死力**恰為零**（`max_S u ≡ 1`）；有判死力者**只限**旋轉不變泛函。**

---

## §一 定理 F

```
設 a ∈ H_ℓ（ℓ 之 2ℓ+1 維係數空間），S = 取向參數（A₅ 嵌入 sky 之取向，3 dof，未由結構定）
定義 u(a;S) ≡ |P_S a|² / |a|² ，P_S = 該取向下之 m_ℓ 維不變投影

定理 F：框架自由（S 可取遍 SO(3)）⟹ max_S u(a;S) = 1  對**任意** a
證明：SO(3) 在 H_ℓ 之單位球上傳遞 ⟹ ∃S 使 P_S 之像含 a ⟹ |P_S a|² = |a|²。

機器核（200 個隨機 a，ℓ = 6,12,26）：max_S u = 1.000000000000（偏離 0.00e+00）
對照：隨機取向之 u 均值 = 0.0759 / 0.0405 / 0.0185（= 1/(2ℓ+1)）
```

## §二 推論

```
F1（通道 4 死）：形狀方向之「對齊後殘差」最小化後恆 0
     機器核：殘差均值 1.18e−16、max 4.75e−16（ℓ=6,12 × 100 實現）
F2（通道 5 死）：子空間投影 u 同理（§一 已含 m ≥ 2 情形，因 P_S 之像可含 a）
F3（生者清單）：判死力僅存於**旋轉不變泛函**
     ✓ C_ℓ 支援（整 ℓ 之選擇）
     ✓ f（ℓ 帶功率分數）
     ✓ T（ℓ 帶集中度 —— 因為係「整 ℓ 帶」選擇，非子空間）
     ✓ κ₃ = ∫f³/C_ℓ（SO(3) 純量）
     ✗ 形狀方向、子空間投影 u、任何逐模指派
```

## §三 若硬要掃框架：代價量化

```
N_rot = 200 個取向：u_max 均值 = 0.5314（q95 = 0.6831），未掃 = 0.0769 ⟹ 膨脹 6.9×
隨 N_rot → ∞，u_max → 1 ⟹ 判死力 → 0（與定理 F 一致）
```

⟹ 掃框架**唔會**救回判死力，只會令統計量失真；掃得越密，越接近「必然通過」。

## §五 例外條件（何時通道 4/5 復活）

```
若且唯若某**獨立**機制固定天空取向（例如：結構性錨定軸／預註冊之外部軸），
則 S 縮至 2 dof 或 1 dof ⟹ 通道 4/5 之判死力重新出現。
但：以數據本身定取向（如「令冷斑對節點」）＝後驗 ⟹ 不得作判死依據
⟹ 本 M 內無任何結構性取向來源（MR0/B1 只給 arena，不給 sky 取向）
```
