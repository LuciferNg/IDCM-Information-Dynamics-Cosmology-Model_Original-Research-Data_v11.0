## §三 `m_ℓ ≥ 2` 之不變子空間上，κ₃ 之可達集 = 窄區間

```
ℓ = 30（m=2）：κ₃ ∈ [−0.00141, +0.00141]｜寬 0.00281｜寬/外推 sd = 0.58
ℓ = 36（m=2）：κ₃ ∈ [−0.00046, +0.00046]｜寬 0.00092｜寬/外推 sd = 0.16
ℓ = 40（m=2）：κ₃ ∈ [−0.00071, +0.00071]｜寬 0.00141｜寬/外推 sd = 0.30
（sd 外推 ∝ 1/√(2ℓ+1)，錨 ℓ=26 之 0.00592）
```

**關鍵**：`κ₃` 係 SO(3) 純量 ⟹ 對任意 realisation（任意共軛嵌入）取**同值**
⟹ 即使形狀唔唯一（`m_ℓ ≥ 2`），`κ₃` 之預言仍**免框架**：由「點」退化為「窄帶」。
⟹ 判別力唔會全失（寬 < 1× 外推 sd）。
