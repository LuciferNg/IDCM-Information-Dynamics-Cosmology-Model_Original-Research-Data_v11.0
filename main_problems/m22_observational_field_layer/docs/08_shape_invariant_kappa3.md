## §二 構造：κ₃

```
κ₃(ℓ) ≡ I₃ / I₁^{3/2} ,    I₁ = Σ_m |a_{ℓm}|² ,    I₃ = Σ_{m₁+m₂+m₃=0} (ℓℓℓ|m₁m₂m₃) a_{ℓm₁}a_{ℓm₂}a_{ℓm₃}
```

| 性質 | 理由 |
|:--|:--|
| SO(3) 純量（**免框架**）| 3j 符號為 SO(3) 不變張量之分量收縮 |
| 尺度不變（**免 B2**）| `a ↦ c·a` ⟹ `I₃ ↦ c³I₃`、`I₁ ↦ c²I₁` ⟹ `κ₃` 不變 |
| 由 `I_ℓ` 唯一確定 | 模型 `a_ℓ = c_ℓ I_ℓ` ⟹ `κ₃ = κ₃(I_ℓ)`（與 `c_ℓ` 無關）|
| 仍依賴 **B1** | `I_ℓ` 由 A₅ ⊂ SO(3) 之嵌入定 |

## §三 結構定理（新）：奇 ℓ ⟹ `I₃ ≡ 0`（**恆零，非「小」**）

```
① 3j 對 m ↔ −m： (ℓℓℓ|−m₁−m₂−m₃) = (−1)^{3ℓ}(ℓℓℓ|m₁m₂m₃) = (−1)^ℓ ⋯
② 實性：a_{ℓ,−m} = (−1)^m conj(a_{ℓm})，且 m₁+m₂+m₃ = 0
   ⟹ I₃ = (−1)^ℓ conj(I₃)          （奇 ℓ ⟹ 純虛）
③ 3j 對 m₁ ↔ m₂：for l₁=l₂=l₃，(ℓℓℓ|m₂m₁m₃) = (−1)^ℓ (ℓℓℓ|m₁m₂m₃)
   而求和中 m₁ ↔ m₂ 係重命名（a 之積對稱、約束 m₃ = −m₁−m₂ 對稱）
   ⟹ 奇 ℓ：I₃ = −I₃ ⟹ **I₃ ≡ 0**
```
機器核：奇 ℓ（15,21,25,27）之 `Re I₃` 與 `|I₃|` 皆 = 0；GRF null 之 sd = 0.00000（零方差 ⟹ 恆零）。
⟹ **κ₃ 只在偶 ℓ 有效**（9 個：6,10,12,16,18,20,22,24,26）。
