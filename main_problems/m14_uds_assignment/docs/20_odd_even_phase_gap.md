# docs/20 — ★ 拍頻空間中 `/88` 與 `/90` 之相位差：odd/even 產生什麼

**日期**: 2026-10-31
**腳本**: `scripts/21_odd_even_phase_gap.py`（log `data/run_21_phase_gap.log`，dps = 60，判定閾 `1e−40`）
**性質**: 回答調律者提問。**零觀測量**，`N_trials = 0`，全部精確（`max|dev| ≤ 5e−61`）。

**問**：`γ_n = 4sin²(nπ/x)`，`x = 88` 與 `90` 之間存在相位差；呢個 odd/even 相位差**產生嘅係什麼**？

---

## 一、相位差本體（精確）

```
θ^(x)_n = nπ/x  ⟹  Δθ_n = θ^(88)_n − θ^(90)_n = nπ(1/88 − 1/90) = **nπ / 3960**
                                                              （3960 = 44·90 = 88·45）

cos 差化積（cos A − cos B = −2sin((A+B)/2) sin((A−B)/2)）：
  Δγ_n ≡ γ^(88)_n − γ^(90)_n = **4 · sin(89nπ/3960) · sin(nπ/3960)**      （max|dev| = 4.96e−61）

Δγ_n > 0 對全部 n = 1..44 ⟹ **/88 之譜逐模嚴格高於 /90**（44/44）
Δγ_1 = 2.238713e−4（最細）；max Δγ = 0.08175568
Δγ_44 = γ^(90)_1 = 4.87189948e−3（精確；因 γ^(88)_44 = 4 = Nyquist）
```

## 二、★★ 產生嘅核心：**88 與 90 之互換（週期 ↔ 能量預算）**

```
已知恆等式 Σ_{n=1}^{M} cos(nπ/M) = −1 ⟹
    環（n = 1..M，半週期 2M）        ⟹ Σγ = 2M + 2
    Dirichlet（n = 1..M−1，半週期 2M）⟹ Σγ = 2M − 2
（掃 M = 2..60 兩條閉式：違例 **0**）

本題：
    環 /44（半週期 88，44 模）        ⟹ Σγ = **90**
    Dirichlet /45（半週期 90，44 站）  ⟹ Σγ = **88 = 2N_d**
    Σ Δγ = 90 − 88 = **2**（精確）
```

> **相位差所產生嘅，係「88」與「90」兩個 canonical 整數之角色對調**：
> 環/44 之下 **90 係能量預算、88 係週期**；
> Dirichlet/45 之下 **88 係能量預算、90 係週期**。

⚠ **慣例陷阱（本輪新發現，須記錄）**：已註冊之 `Σγ = B(N_d+1)/2 = 90`（O211／M7）
係**環 /88（44 模）**之陳述；**Dirichlet /90（44 站）之預算係 88**，不是 90。
凡引「Σγ=90」必須同時標明係環或 Dirichlet。

## 三、相位差之幾何身份 = **一位點平移 = parity flip**

```
/88：γ_n + γ_(44−n) = 4      補償模 c_88(n) = 44 − n
/90：γ_n + γ_(45−n) = 4      補償模 c_90(n) = 45 − n = (44 − n) + 1

宇稱：c_88(n) ≡ n (mod 2) 之模數 = **44/44** ⟹ 保宇稱
      c_90(n) ≡ n (mod 2) 之模數 = **0/44** ⟹ **flip 宇稱**
```

⟹ `/90` 之反射 = `/88` 之反射**再一位點平移**；一位點平移 = 二分格換邊 = **宇稱翻轉**。
⟹ **odd/even 相位差之幾何身份 = 單位點平移（half-cell shift）**。

## 四、產生之第一件事：**和頻價對之宇稱 grade 翻轉**

| 鏈 | 和頻族 | 對數 | 同 parity | grade |
|:--|:--|--:|--:|:--|
| `/88` | `a+b = 44`（偶） | 21 | **21/21** | **+1** |
| `/90` | `a+b = 45`（奇） | 22 | **0/22** | **−1** |

⟹ 和頻合成物之宇稱 grade **由 `x` 之奇偶直接決定**：`x` 偶 ⟹ 同 parity；`x` 奇 ⟹ 異 parity。
（此即 `44` 與 `45` 之唯一結構差異：`45` 為奇 ⟹ 反射必然換邊。）

## 五、產生之第二件事：**和頻（反物質）通道關閉**

```
/88：和頻 m = a+b 命中 **21**（落點 m = 44 = Nyquist，γ = 4）
/90：和頻 m = a+b 命中 **0**（落點須 m = 45，係 Dirichlet 邊界節點，非模）
拍頻 m = b−a：兩鏈皆 **0**（能量層；與 docs/12 之頻率 no-go 一致）
```

⟹ **`/88` 有「物質＋反物質」兩側；`/90` 只有物質側（beat 側）。**
⟹ 亦解釋 `docs/15` 之 3 個三元組為何全屬「場型」而無一屬和頻型。

## 六、兩譜永不相交

```
γ^(88)_n = γ^(90)_(n′) ⟹ 45n = 44n′ ⟹ n = 44t, n′ = 45t ⟹ t = 0（出界）
⟹ 交叉退化 = **0**；最小間隙 = Δγ_1 = 2.238713e−4
⟹ 兩載體**不可互換**，必須由外部原則裁決（此即 docs/15 之慣例閘之深層理由）
```

## 七、odd/even 兩半唔同構

```
γ^(88)_(2k) ≡ 4sin²(kπ/44)   ⟹ 偶子格 = /44 鏈（22 模）
γ^(90)_(2k) ≡ 4sin²(kπ/45)   ⟹ 偶子格 = /45 鏈（44 模）
（兩者 max|dev| = 0）
```

⟹ 折疊（`n ↦ 2k`）**唔保載體類型**：一條變 22 模環、一條變 44 模 Dirichlet。

## 八、判定

```
✅ 相位差 = nπ/3960，及 Δγ_n = 4 sin(89nπ/3960) sin(nπ/3960) > 0（44/44）
✅ 幾何身份 = 單位點平移 ⟹ parity flip（44−n 保、45−n 反）
✅ 產生①：和頻價對之宇稱 grade 翻轉（+1 → −1）
✅ 產生②：和頻（反物質）通道由 21 對變 **0** 對（Dirichlet 邊界封閉）
✅ 產生③：**88 與 90 互換角色**（環/44 ⟹ Σγ=90；Dirichlet/45 ⟹ Σγ=88）
✅ 產生④：兩譜零交叉退化（最小間隙 2.24e−4）＋ odd/even 兩半唔同構
⚠ 物理讀法（和頻 = 反物質）來自 docs/12 之定向機制；本 docs 只證結構，不宣稱觀測後果。
```
