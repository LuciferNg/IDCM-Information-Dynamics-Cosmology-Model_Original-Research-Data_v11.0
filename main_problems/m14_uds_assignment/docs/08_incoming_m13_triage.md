## 三、交辦「`√B` 之出處」之答覆

**問題**（`docs/11 §六`）：世代權重比 = `2`，已註冊分枝 `B = 4` ⟹ 為何取 `√B` 而非 `B`？
三種同值讀法（`√B`／`log₂B`／`|ℤ₂|`）在 `B = 2²` 下塌縮為 `B = |ℤ₂|²`，該恆等式 v11 未註冊。

**答**（`scripts/07 §四`）：

```
√B = 2.0 ✓   log₂B = 2.0 ✓   |ℤ₂| = 2.0 ✓   N_gen−1 = 2.0 ✓  （四者同值）
B = |ℤ₂|² ？ 4 = 2² ⟹ 成立（純算術）
```

⟹ 🔴 **不可由本 M 給出，且其結構價值為 0**，理由三：

1. **算術 ≠ 算子身份**（`docs/11 §〇` 自訂之標準）：四讀法同值 ⟹ 塌縮為恆等式
   ⟹ 屬「**算術巧合**」型，與禁區 3（小分母凑數／`φ`-power）**同型**。湊出底數 `2` 不能給出
   算子身份；反而 `N_gen−1 = 2` 亦可同值 ⟹ 候選解釋空間**增大**而非收窄。
2. **即使給出亦只定比值，不定次序**：本 M `docs/04 §二` 已證結構之輸出係
   **無味名之比值多集**；「邊個味得 `1`、邊個得 `2`」= 指派本身（`0 bit`，`docs/02 §三`）。
3. **即使給出亦不可裁決**：1σ 窗內有 3 個 `(1/3)ℤ` 格候選（`4`、`11/3`、`7/2`），
   而 `11/3` 之 `|z| = 0.125 < 0.636`（`4` 之 `|z|`）⟹ 推得 `r = 4` 亦**不優於**已被否證之對手。

⟹ 故「`√B` 之出處」係**下游**於一個未註冊輸入之問題：先須有「α 屬幾何族」之結構理由，
而該理由本身即 `docs/11` 所判「標籤級」。**問題次序錯置**。
