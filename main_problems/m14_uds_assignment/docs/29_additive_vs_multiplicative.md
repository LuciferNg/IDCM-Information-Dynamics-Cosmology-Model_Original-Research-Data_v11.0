## 二、`/88` 之 `ℚ(√2)` 階梯：等差，公差 `√2`

```
γ11 = 2−√2 = 0.5857864376269
γ22 = 2
γ33 = 2+√2 = 3.4142135623731

AP 檢定：γ22−γ11 = γ33−γ22 = √2        |d1−d2| = 3.11e−61，|d1−√2| = 1.56e−61
GP 檢定：γ22² − γ11·γ33 = 2.0 ≠ 0       ⟹ **非等比**
比值：1 : 3.41421356 : 5.82842712（= 1 : 2+√2 : 3+2√2）
```

## 三、`/90` 之 `ℚ(√5)` 三元組：等比，比 `φ²`

```
γ9  = (3−√5)/2 = 0.381966011250105
γ15 = 1
γ27 = (3+√5)/2 = 2.618033988749895

GP 檢定：γ15² − γ9·γ27 = −2.33e−61   ⟹ **等比**，r = 2.618033988749895 = φ²（|偏差| = 0）
AP 檢定：(γ15−γ9) − (γ27−γ15) = −1.0  ⟹ **非等差**
```

## 四、★ 結構根源：AP 係恆等，GP 係偶然

```
對任何子鏈 /M（M 偶）：γ_n + γ_(M−n) = 4 = 2·γ_(M/2)
⟹ 取 n, M/2, M−n ⟹ **恆成 AP**，中心 = 2，公差 = 2 − γ_n
   /8：公差 = 2 − (2−√2) = √2
⟹ /88 之 21 個 AP 全部係此恆等之後果（零自由度、零資訊）

而 /90 之 3 個 GP **不**來自 γ_n + γ_(45−n) = 4 之恆等 ⟹ 屬偶然簡併，
   須逐例驗證（本輪已驗：γ_b² − γ_a·γ_c < 1e−40）
```

> ⟹ **/88 只有加性結構（能量守恆／AP）；`/90` 方有乘性結構（GP／φ-冪）。**
> 與 `docs/28` 之域論結論同源：`√5 ∉ ℚ(ζ_88)` ⟹ `φ` 缺席 ⟹ 無乘性階梯。
