## 三、三項記錄（皆為 append-only；不改上游）

### 3.1 `R7 CONV`：`σ(δ_c)` 之慣例差

`δ_c` 之中值**逐位吻合**（`1.100 − 1.382 = −0.282`）。`σ` 之差（`0.2614` vs `0.2830`）源於
M12 未列明 `Σc⁺`（PDG 非對稱 `+0.22/−0.16`）之取法：取 `0.22` 則得 `0.2840`，取平均 `0.19` 則 `0.2614`。

⟹ 記 `CONV`（慣例差），**非 FAIL**，**不改上游**；本 M 凡用 `δ_c` 一律附 σ 值並標來源。
⟹ 此差**不影響任何判詞**：`δ_c` 在本 M 只作「與 0 相容」之定性檢定（`z = −1.08`／`−0.99`，兩值皆 <1.3σ）。

### 3.2 ★ 本輪踩過之坑：`Δ_n` 之定義（錯則與 M13 對不上數）

初版以 **固定** `Δ_n = φ_n(3) − φ_n(2)` 掃描三元組，得 `A₂⊕1 = 24 / 392`、`A₂ 塊 = 13 / 112`
—— 與 M13 `docs/05 §S1` 之 **44 / 112**、**87 / 112** 不符。

正確定義：`Δ_n` 係**該三元組自身**之 `u↔d` 交換向量

```
Δ_n = φ_n(p_d) − φ_n(p_u)          （(p_u,p_d)=(2,3) 時退化為 φ_n(3)−φ_n(2)，與 M13 一致）
```

改用後：三元組計 **112**（`p_u<p_d<p_s`、`p_u≤7、p_d≤8、p_s≤10`）、`A₂⊕1 = 44/112`、
`A₂ 塊 = 87/112` —— **三數與 M13 逐位吻合**。

⟹ 記錄：`Δ` 隨三元組變；凡掃描 A₂ 類必以此式，否則偏差達 5 倍（24 vs 44 之型）。
