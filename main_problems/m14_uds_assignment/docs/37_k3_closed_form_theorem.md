```

  χ³_{abm} = C/4 · ∏_{cyc} sin(πa/45) / ∏_{±} sin(π(±a±b±m)/90)
```

## 二、四步證明鏈

```
(1) 積化和
    sin A sin B sin C = ¼[sin(A+B−C) + sin(A−B+C) + sin(−A+B+C) − sin(A+B+C)]

(2) 鏈和（N = 45）
    S(k) ≡ Σ_{j=1}^{44} sin(πkj/45) = 0（k 偶）｜cot(πk/90)（k 奇）
    ⟹ χ³ = C/4 · [S(k₁)+S(k₂)+S(k₃)−S(k₄)]，k = (a+b−m, a−b+m, −a+b+m, a+b+m)

(3) cot 併項（x_i ≡ πk_i/90）
    cot x₁ + cot x₂ = sin(x₁+x₂)/(sin x₁ sin x₂) = sin(πa/45)/(sin x₁ sin x₂)
    cot x₃ − cot x₄ = sin(x₄−x₃)/(sin x₃ sin x₄) = sin(πa/45)/(sin x₃ sin x₄)

(4) 再積化和
    sin x₁ sin x₂ + sin x₃ sin x₄
      = ½[cos(π(b−m)/45) − cos(πa/45)] + ½[cos(πa/45) − cos(π(b+m)/45)]
      = ½[cos(π(b−m)/45) − cos(π(b+m)/45)]
      = sin(πb/45) sin(πm/45)

⟹ Φ := cot x₁+cot x₂+cot x₃−cot x₄ = ∏_{cyc} sin(πa/45) / ∏_{±} sin(π(±a±b±m)/90)   ∎(閉式)
```

**非零性（純算術，無枚舉）**：

```
分子：1 ≤ a,b,m ≤ 44 ⟹ πa/45 ∈ (0,π) 且 a ≠ 45 ⟹ sin ≠ 0
分母：a+b+m 奇 ⟹ 四個 k_i 全奇（k_i ≡ a+b+m mod 2）
      k_i = 0 ⟹ 對應之兩指標和等於第三指標 ⟹ a+b+m 為偶（與奇和矛盾）
      |k_i| ≤ 132 < 180 且奇 ⟹ k_i ∉ 90ℤ ⟹ sin(πk_i/90) ≠ 0
⟹ Φ ≠ 0 ⟹ χ³ ≠ 0
```

## 四、副產品一：最小點之**簡併**（修正 `docs/35`）

`docs/35` 記「最小 `1.609741784646e−6` 於 `(1,2,44)`」—— 該值係**不同指標**三元組之最小。容許重複時：

```
(1,1,43)：k = (−41, 43, 43, 45)       χ³ = −1.60974178464637539e−6
(1,2,44)：k = (−41, 43, 45, 47)       χ³ = −1.60974178464637539e−6   ← 完全相同（20 位）
```

原因（閉式直接給出）：

```
分子：sin²(π/45)·sin(43π/45) = sin²(π/45)sin(2π/45) = sin(π/45)sin(2π/45)sin(44π/45)
分母：sin(43π/90) = sin(47π/90) = cos(π/45)   ⟹ 分母相同
⟹ 兩者 χ³ 相等
```

**一般機制**：`Φ` 之每個因子滿足 `sin(πk/90) = sin(π(90−k)/90)`，即**反射對稱 `k ↦ 90 − k`**；`43 ↦ 47`、`45 ↦ 45` 即此反射。故閉式把「數值巧合」升格為結構必然。

## 七、附註：為何先前誤判為 Conway–Jones 型

先前只掌握「cot 和」形式 `Φ = Σ cot(...)`，此形式下非零性需要四項 cot 之相消分析（看似屬超越數論）。真正之瓶頸係**未做 cot 併項**：一旦用 `cot p ± cot q = sin(·)/(sin p sin q)` 兩兩併，`sin(πa/45)` 公因子立現，餘下之和再由積化和坍縮成 `sin(πb/45)sin(πm/45)`。

**方法教訓**：判「超越數論」之前，先問「此和是否為乘積比」——若代數結構中存在公因子，非零性即純算術。
