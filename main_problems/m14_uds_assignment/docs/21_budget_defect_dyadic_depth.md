## 一、★ 三分律：`δ ≡ Σγ − x ∈ {+2, −2, 0}`

```
ring（x 偶，M = x/2）           Σγ = x + 2   ⟹ δ = **+2**（與 x 無關）
Dirichlet（x 偶，M = x/2 − 1）  Σγ = x − 2   ⟹ δ = **−2**
Dirichlet（x 奇，M = (x−1)/2）  Σγ = x       ⟹ δ = **0**

掃 x = 3..200 三類全掃：**違例 0**
```

⟹ `δ` **由（邊界類型, `x` 之奇偶）完全決定**：
ring 恆 `+2`；Dirichlet 則 `x` 偶為 `−2`、`x` 奇為 `0`
⟹ **跨 odd/even 界線時，`δ` 由 `−2` 跳 `0`**。

## 二、本題兩載體

```
/88 ring        x=88  M=44  Σγ=90  δ = +2
/90 Dirichlet   x=90  M=44  Σγ=88  δ = −2
⟹ δ 相隔 **4 = 2B**
```

⟹ 已註冊之 `Σγ = 90` 正是 `/88` 之 `x + 2`；`/90` 之 `88` 正是 `x − 2`（`docs/20 §二` 之另一表述）。

## 三、★ 2-adic 折疊鏈（odd/even 之迭代結構）

| 鏈 | 折疊 | 層數 | odd core |
|:--|:--|--:|--:|
| `/88` ring | `88(44) → 44(22) → 22(11)`（`max|dev| = 0`） | **3** | `11`（質數） |
| `/90` Dirichlet | `90(44) → 45(22)`（`max|dev| = 0`） | **2** | `45 = 4·11 + 1` |

**折疊條件 ≡ `x mod 4`**（掃 `x = 6..200`，違例 0）：

```
ring 可摺 ⟺ x ≡ 0 (mod 4)        （因 M = x/2 需偶）
Dirichlet 可摺 ⟺ x ≡ 2 (mod 4)    （因 M = x/2 − 1 需偶）
⟹ 兩者之可摺性**恰好相反**
```

> ⟹ **相位差之最深不可約形式：`88 ≡ 0 (mod 4)`（ring，可摺 2 次）對 `90 ≡ 2 (mod 4)`（Dirichlet，可摺 1 次）。**
> ⟹ `v₂(88) = 3`、`v₂(90) = 1`；層數 3 vs 2。

## 四、各層能量預算序列

```
/88：90(x=88) → 46(x=44) → 24(x=22)      δ 恆 +2
/90：88(x=90) → 45(x=45)                 δ = −2 然後 0（x=45 奇）
共同層（M=22）：46 vs 45 ⟹ 差 **1**（上一層差 2，故每上一層差翻倍）
```

## 五、判定

```
① 三分律成立（違例 0）：δ ∈ {+2, −2, 0}，由（邊界類型, x 奇偶）唯一決定。
   ⟹ **odd/even 相位差之最簡不可約內容 = 呢個 ±2／0 缺陷分類。**
② 本題：/88 為 +2、/90 為 −2 ⟹ 相隔 4 = 2B（與 B=4 一致，但此處只是數值相等，未證因果）。
③ 折疊：/88 三層（odd core 11）、/90 兩層（odd core 45 = 4·11 + 1）；
   可摺性由 x mod 4 決定，而兩載體之 mod 4 類**相反**（0 vs 2）。
④ ⚠ **「3 層」是否即 `N_gen = 3`：不作主張。** 依 `docs/19` 單標籤定理，3 只能係**計數**；
   本輪只記錄新計數身份 `v₂(88) = 3`（層數 3），與世代之對應須**先凍結映射再盲測**。
⑤ 已記錄之新計數身份（不裁決）：`88 = 2³·11` ⟹ 折疊 2 次／3 層；
   `90 = 2·3²·5` ⟹ 折疊 1 次／2 層。
```
