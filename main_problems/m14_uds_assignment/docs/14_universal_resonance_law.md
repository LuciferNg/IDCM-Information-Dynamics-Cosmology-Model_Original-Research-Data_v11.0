# docs/14 — 通用共振定律（N-無關）：活價對 = (N−1)＋⌊(N−1)/2⌋

**日期**: 2026-10-31
**腳本**: `scripts/15_general_resonance_law.py`（log `data/run_15_general_law.log`，dps = 40，閾 `1e−30`，**掃盡**）
**性質**: 兩條鏈（N=44、N=88）全掃 `(a,b,m)`（44-鏈 41,624 格；88-鏈 336,864 格）。`N_trials = 0`。**零觀測量**。

## 一、定律

鏈長 `N`，`γ_n = 4sin²(nπ/(2N))`，`n = 1..N`（`N = 44` 為 44-站鏈；`N = 88` 為雙鏈）。
價對 `a < b ≤ N`：

> **sum 通道在殼 ⟺ `a + b = N`**（落 `m = N`，`γ = 4` = Nyquist）
> **beat 通道在殼 ⟺ `b = N`**（落 `m = N − a`）
> **兩者互斥**（`a ≥ 1` ⟹ `b = N` 與 `a + b = N` 不可同真）

**證明（一行）**：由 `γ_n + γ_(N−n) = 4 = γ_N`
(i) `a+b = N` ⟹ `γ_a + γ_b = γ_a + γ_(N−a) = 4 = γ_N`；
(ii) `b = N` ⟹ `γ_N − γ_a = 4 − γ_a = γ_(N−a)`。
兩者皆**零新常數**，全部由已註冊恆等式逼出。

## 二、掃盡核對（非抽樣，非擬合）

| N | 價對 | 三格 | sum 精確解 | beat 精確解 | 定律預測 | 相符 | 活價對 |
|--:|--:|--:|--:|--:|:--|:--:|--:|
| **44** | 946 | 41,624 | **21**（全落 `m=44`） | **43** | 21 / 43 | ✅ / ✅ | **64**（882 全 off-shell） |

`γ_n + γ_(N−n) = 4` 之數值核對：`max|dev| = 9.18e−41`（44/88-鏈同值）。

⟹ 定律**與 `N` 無關** ⟹ 唔係 44-鏈之巧合。註：`(N−1) + ⌊(N−1)/2⌋` = `43+21 = 64`（N=44）、`87+43 = 130`（N=88）。

## 三、推論

1. **44-鏈活價對 = 88-鏈活價對之「偶 × 偶」子集**（`a,b` 皆偶 ⟹ 即 44-鏈模）。此與 `O218` 之 `γ'_(2n) = γ_n` 遷移一致。
2. **Nyquist 模 `n = N` 係 beat 共振之必要成分**（`b = N` 唯一）—— 呢個模係 `v_g = 0` 之駐波。
3. sum 共振落於 `γ = 4`（能量上界）；beat 共振落於鏡像能量 `γ_(N−a)`。
4. 活價對佔比：`64/946 = 0.0677`（N=44）；`130/3828 = 0.0340`（N=88）⟹ 隨 `N` 趨近 `2/N`（稀疏）。
5. **定向**（`docs/12 §四`）：`b = N` 型 = beat 在殼 = 物質；`a+b = N` 型 = sum 在殼 = 反物質。零參數、唔用宇稱。

## 四、方法陷阱（實測，兩次）

1. `float64` 預篩 `|resid| < 1e−9` 掃 88-鏈時**漏掉 `(21,67,88)`**（真解，殘餘略高於閾）。
2. N=176 首跑時 beat 檢定被 sum 分支之 `continue` 一齊跳過 ⟹ 誤得 `|D| = 0`。
   修正後 `|D| = 175`，與定律相符。

⟹ 共振類檢定**必須高精度全掃**，且 sum／beat 兩支不可共用同一 early-exit。
