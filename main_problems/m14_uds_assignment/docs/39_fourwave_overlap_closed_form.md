# docs/39 — 四波重疊之精確閉式（`χ⁴ = W/90`）＋ `p` 模宇稱定理

**日期**: 2026-11-02
**腳本**: `scripts/40_fourwave_overlap_theorem.py`（log `data/run_40_fourwave_overlap.log`，dps = 60）
**性質**: `docs/18 §六 MR1`（四波之動能學）之**前置**：先定四波頂點振幅之精確值與選擇律。零觀測量。
**慣例**: `N = 45`、`φ_n(j) = √(2/45) sin(πnj/45)`、`j = 1..44`（Dirichlet 44 站）。

---

## 一、★ 定理一：任意模數之宇稱律

```
設 χ⁽ᵖ⁾_{n₁…n_p} = Σ_{j=1}^{44} ∏_{i=1}^{p} φ_{n_i}(j)。則

  χ⁽ᵖ⁾ = 0   除非  Σ n_i ≡ p (mod 2)

證：反射 j ↦ 45−j，φ_n(45−j) = (−1)^{n+1} φ_n(j)
    ⟹ χ⁽ᵖ⁾ = Σ_j ∏φ_{n_i}(45−j) = (−1)^{Σ n_i + p} χ⁽ᵖ⁾
    ⟹ 若 Σ n_i + p 為奇，χ⁽ᵖ⁾ = −χ⁽ᵖ⁾ ⟹ χ⁽ᵖ⁾ = 0 ∎
```

`p = 3` 即 `docs/37` 之 `K3` 前半（`a+b+m` 奇才可能非零）；`p = 4` 給「和偶才可能非零」。
**注意單向性**：宇稱容許**唔保證**非零 —— `p = 4` 另有 `W = 0` 之額外零（§三）。

## 二、★ 定理二：四波重疊之閉式

```
χ⁴_{abcd} = 0                                        若 a+b+c+d 奇
χ⁴_{abcd} = W/90                                     若 a+b+c+d 偶

W ≡ Σ_{ε} c_ε · [ k_ε ≡ 0 (mod 90) ]  ∈ ℤ
k_ε ∈ { ±a±b±c±d }（八個帶號和），c_ε = ( + + − − − − + + )
```

**非零判準**：`χ⁴ ≠ 0 ⟺ W ≠ 0 ⟺ 存在一個帶號和 ∈ {0, ±90}`
**例（數值落地）**：

```
(1,2,3,4)：帶號和含 1−2−3+4 = 0 ⟹ W = 1 ⟹ χ⁴ = 1/90   = 0.0111111111111
(1,1,1,1)：三個帶號和為 0 ⟹ W = 3          ⟹ χ⁴ = 3/90   = 0.0333333333333
(1,2,44,43)：0 與 90 各一 ⟹ W = 2          ⟹ χ⁴ = 2/90   = 0.0222222222222
(9,15,18,20)：八個帶號和皆 ≠ 0, ±90 ⟹ W = 0 ⟹ χ⁴ = 0
```
（`|k_ε| ≤ 176` 且偶 ⟹ 只可能 `0` 或 `±90`）

### 證明鏈

```
(1) 鏈和：Σ_{j=1}^{44} cos(πkj/45) = 44（k ≡ 0 mod 90）｜−1（k 偶，非 90 倍）｜0（k 奇）
(2) 四正弦展開：
    sinA sinB sinC sinD = (1/8)[ +cos(A−B−C+D) +cos(A−B+C−D)
                                −cos(A−B−C−D) −cos(A−B+C+D)
                                −cos(A+B−C+D) −cos(A+B+C−D)
                                +cos(A+B−C−D) +cos(A+B+C+D) ]
(3) 和偶 ⟹ 八個 k_ε 全偶 ⟹ 每個 Σcos ∈ {44, −1}；而八個係數和 = 0
    ⟹ 常量項 −1 全消，只剩 k_ε ≡ 0 (mod 90) 之項：
    χ⁴ = (2/45)² · (1/8) · 45 · W = W/90
```

## 四、結構後果

```
① 振幅量化：χ⁴ ∈ (1/90)ℤ —— 四波耦合**唔係連續可調**，只取值 W/90
② 選擇律：非零 ⟺ 某帶號和 ∈ {0, ±90}（一個純算術條件，無自由參數）
③ 與 docs/18 §六⑥ 之關係：該處記「四波頂點常數 −(2/45)² 全等 ⟹ 仍無荷差異」
   —— 該常數只係**歸一化因子**；真正之振幅係 W/90，隨四元組跳變 ⟹ 差異確實存在
   但屬**振幅**層，未達「荷」層（荷仍需扇區→荷映射，見 docs/09）
④ 對 MR1 之意義：四波頂點振幅已封；**散射截面**仍未（需動能學／守恆律，另屬場論層）
```

## 六、與 `K3`（`docs/37`）之關係

```
兩者共用同一機器：
  K3   ：p = 3，鏈和用**正弦**（Σ sin = cot），故得乘積比
  χ⁴   ：p = 4，鏈和用**餘弦**（Σ cos ∈ {44, −1, 0}），故得**整數/90**
⟹ 奇 p 得 cot 型（超越外觀，實為乘積比）；偶 p 得有理型（1/90 網格）
```
