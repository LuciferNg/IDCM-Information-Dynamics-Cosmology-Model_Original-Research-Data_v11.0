## 一、3↔5 耦合律（本文件新增，`docs/44` M1 之推廣）

Fock 矩陣元律 `⟨T'|H/g₄|T⟩ = [Σ_{R⊂T,|R|=p}(#emb)·p!·q!·χ⁴(R∪A)]/√(n_T n_T')`，取 `|T|=3`、`|T'|=5`：

```
p = (3+4−5)/2 = 1，q = 3  ⟹ 去 1 添 3，權重 p!q! = 6
χ⁴(去1 ∪ 添3) 恰 4 個 index ⟹ 宇稱律 Σn ≡ 4 (mod 2) 直接適用
```

**由 Q 側枚舉（440 候選／quint）**：取 `S ⊂ Q`（2 模多重集，10 種）× 餘模 `r0 ∈ 1..44`：

```
V_{Q,T} = 6·emb·wgt·χ⁴(r0, a₀,a₁,a₂)/(90·√(n_T n_Q))，a = Q − S
wgt = c_S(r0) + 1        ← 位置重複權重（T = S∪{r0} 之位置選擇數）
n_T = n_S·(c_S(r0)+1)    ← r0 ∈ S 時階乘升一級
```

## 六、★ 完整四階之比值檢（修正 `docs/45` §五b）

```
A2_n = Σ_T b_T²/(γ_n − E_T)（定義式重算）

ρ_n := (|A4^full/T_n|)/(|T_n/A2_n|)
```

```
ρ：min 0.100104｜中位 13.138972｜max 437.465196｜落 [0.1,10] 之模數 = 18/44
```

**判（推翻 `docs/45` §五b 之「ρ ≈ O(1)」）**：

```
ρ 中位 13.14 > 2 ⟹ **超幾何（相鄰階比遞增）** ⟹ 級數係**漸近級數**，非幾何發散

```
