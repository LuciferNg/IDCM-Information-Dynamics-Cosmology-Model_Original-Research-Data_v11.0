## 一、★ 結構門檻：模式數可達性（原有模式 `Δ|T| ∈ {0, ±2}`）

由 `|n⟩`（1 模）出發，逐頂點模式數變化 `Δ ∈ {0,±2}`，要求末態回 1：

```
E_2（2 頂點）→ 最大 3 模 ｜鏈例 (1→3→1)
E_3（3 頂點）→ 最大 3 模 ｜鏈例 (1→1→3→1)
E_4（4 頂點）→ 最大 5 模 ｜鏈例 (1→3→5→3→1)
E_5（5 頂點）→ 最大 5 模 ｜鏈例 (1→1→3→5→3→1)
E_6（6 頂點）→ 最大 7 模 ｜鏈例 (1→3→5→7→5→3→1)
```

⟹ **四階在原有模式下已完整**（三模鏈 ＋ 五模扇區），`docs/46` 之「不得稱完整四階」保留語可撤；
**7 模扇區屬 `E_6`，不屬 `E_4`**。五階同樣只需三模 ＋ 五模兩個空間。

> ⚠ 此結論只在原有模式成立。若容許 `Δ = ±4`（`p=0`／`p=4` 通道），`E_4` 最大可達 9 模 ——
> 該通道本腳本**未含**，屬凍結項（見 §七）。

## 二、新增算子：`5 ↔ 5`（`p = 2`、`q = 2`）

```
律：⟨Q'|H/g₄|Q⟩ = [Σ_{去 2} (#位置選擇)·4·χ⁴(去二 ∪ 添二)·emb]/√(n_Q n_Q')
    權重 p!q! = 4；emb = ∏_m C(c_{Q'}(m), c_S(m))（S = 三倖存模）
```

**閘（對稱核，10 個固定樣本、4 個非零）**：表值 vs 獨立直算 `max|差| = 0.000e+00`。

`3 ↔ 5`（`p=1`、`q=3`）沿用 `docs/46` 已驗之律，本文件以**由 T 側直算**重新核對：
`max|表 − 直算| = 0.000e+00`。建構結果：**3↔5 非零元 = 58442310**（每 trio 均值 3850）。
