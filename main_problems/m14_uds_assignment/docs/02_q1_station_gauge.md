## 一、L1 比值層：`ρ_x` 只依 `α`

四個 `α` 候選，逐一在 **44 個 `A₂⊕1` 三元組**上比對閉式
`ρ_u = (2α_u−α_d)/(2α_s)`、`ρ_d = (2α_d−α_u)/(2α_s)`：

| `α` | `ρ_u` 閉式 | `ρ_d` 閉式 | `max|Δρ_u|` | `max|Δρ_d|` |
|:--|--:|--:|--:|--:|
| `(1,2,1)` | `0` | `1.5` | `6.4e−61` | `1.4e−60` |
| `(1,2,3)` | `0` | `0.5` | `4.2e−61` | `6.2e−61` |
| `(1,2,4)` | `0` | `3/8` | `4.0e−61` | `6.6e−61` |
| `(1,1,1)` | `0.5` | `0.5` | `7.0e−61` | `6.2e−61` |

⟹ **定理（重現，M13 `docs/05 §S2`）**：於 `A₂⊕1` 族內，`(ρ_u, ρ_d)` **只依 `α`**，與三元組無關
（偏差 `1.4e−60`，機器精度級）。
⟹ 判：**比值層 ⟹ 站指派 = gauge**。範圍 = `{有限集：44 個 A₂⊕1 三元組}`。

## 二、L2 絕對層：`δ_x`（非比值）**亦**不可固定

M13 只證過比值層。本輪補測絕對值：

```
M_uu 之 44 個值：min = 0.02222…（= 2/90）  max = 0.06666…（= 6/90）   max/min = 3.0
δ_u/δ_s 之 44 個值：極差 = 7.8e−61（≡ 0，同 L1）
```

⟹ `M` 之**形狀**固定為 `(c/90)(A₂⊕1)`，只餘一個整體標度 `c ∈ [1, 3]`。

**但該標度唔係結構量**：
`v_x = φ(p_x)·Δ` 之歸一化係**慣例**（取 `φ_n(j)=√(2/45)sin(πnj/45)` 使 `Σφ²=1`）；
`M`（因而 `δ_x`）之絕對值隨該慣例整體縮放 ⟹ **絕對值本身不含物理信息**。
物理內容只在比值（L1），而 `α` 之整體標度係 M13 自己承認之 `dof = 1`（`docs/03 §四`）。

⟹ 判：**絕對層同樣不可固定**站指派。「絕對 `δ` 值」**不構成**第二類觀測量
⟹ 此即對 record `R1` 所問「絕對值？quality？`C_f`？」之直接答覆：**皆不行**。

## 三、L3 算子層：`𝒜` 對味標籤置換**精確不變**（/88 慣例）

`𝒜 = { E = M₀ Σ_n σ_n γ_n + Σ_{i<j} g(|n_i−n_j|) }`（`γ_n = 4sin²(πn/88)`，配對 `44−n`）

`E` 只依「佔用模之多集」與「模距之多集」⟹ 味標籤置換係 `𝒜` 之**精確對稱**。
null MC：`N = 10⁷` 組態 × 隨機 6-標籤置換，三種核：

| `g(d)` | `max|ΔE|` | bit-identical |
|:--|--:|:--|
| `cos(2πd/88)` | `0.000e+00` | ✅ |
| `exp(−d/8)` | `0.000e+00` | ✅ |
| `1/(1+d)` | `0.000e+00` | ✅ |

⟹ **任何 `𝒜`-觀測量對「邊個味住邊個站」= 0 bit**。
⟹ 此為 M7 `docs/28` 味盲定理之**獨立重現**（本輪不引用其數值，以自算為準）。

### 4.1 「換什麼觀測量才可固定」之答覆（record `R1` 要求；三層已窮盡）

| # | 觀測類 | 可否固定 | 理由 |
|:-:|:--|:--:|:--|
| ① | `𝒜`-內任何量（含絕對值、`C_f`、quality） | 🔴 **否** | L3 定理級：置換係精確對稱 ⟹ `0 bit` |
| ② | 比值層以外之絕對量 | 🔴 **否** | L2：標度屬歸一化約定，非結構量 |
| ③ | `𝒜` 外之味相關項 `c·(δ_{f,u}−δ_{f,d})` | 🟡 可，但**違規** | `dof +1`（違 A3）；且該項對任何味對差恰給 `Δ0 = c`（違 A2 循環） |

⟹ **站指派之地位 = 外部輸入**（與 M7 `A_eff = 4.4492 MeV` 同級），非可導出量。
⟹ 此結論與 M7 `docs/20 §七`「u/d 扇區指派 = NO-GO」**同源且互證**（本輪獨立重現其實驗基礎）。
