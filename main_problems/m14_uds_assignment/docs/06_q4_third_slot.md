## 三、耦合塊之**身份**：係 `(u,d)` 對，非世代結構

依構造 `v_x(n) = φ_n(p_x)·Δ_n`，而 **`Δ_n = φ_n(p_d) − φ_n(p_u)`** ⟹ `Δ` 只含 `u`、`d` 兩站
⟹ 交叉項 `M_xy = Σ_n φ(p_x)φ(p_y)Δ²/γ_n` 之非零結構**恆由 `(u,d)` 對承載**。

```
實例 p=(2,3,4)：M_ud/M_uu = −0.5（A₂ Cartan 之非對角）
                M_us/M_uu = 2.1e−51（≡ 0）
```

⟹ `rank = 2` 之來歷 = **isospin 對 `(u,d)`**，非「世代數」。
⟹ `rank` 不含任何關於 `N` 之信息；`N` 係**輸入站數**。
⟹ 「槽數 = `rank(A₂)+1`」之內容 = 「`N = 2 + (N−2)`」= **恆等式**。

### 6.1 判詞一句

`N_gen = rank(耦合塊)+1` 係 **`3 = 2 + 1` 之重述**：
其「`2`」= isospin 對之秩（由 `Δ = φ(p_d)−φ(p_u)` 之**定義**而來）；
其「`1`」= `s` 站與 `u,d` 正交（僅 `44/112` 之子集性質）。
⟹ **`N_gen = 3` 在現有結構中仍是輸入，而非結論。**

### 6.2 正面保留（不作死）

`A₂⊕1` 之形式（耦合塊秩 2 ＋ 恰一單態，`44/112`）係**真結構事實**，可作**該三元組之描述**；
只是不可反推 `N_gen`。此點與 M13 `docs/10 §二` 之「第 4 味不可外推」相容 ——
本輪補上者係：**「3」本身亦不可由該結構**推得**。
