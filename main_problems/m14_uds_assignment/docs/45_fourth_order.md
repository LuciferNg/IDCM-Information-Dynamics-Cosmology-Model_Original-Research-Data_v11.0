## 一、方法：RS 遞歸（免閉式公式之記憶風險）

```
|φ_p⟩ = R( V|φ_{p−1}⟩ − Σ_{q=1}^{p−1} E_q|φ_{p−q}⟩ ),  R = Q(E_n − H₀)⁻¹Q,  E_p = ⟨n|V|φ_{p−1}⟩
E_1 = ⟨n|V|n⟩ = 0（docs/44 M4）
```

**引擎自校（S1）**：對隨機 Hermitian 矩陣，比較「四階級數」與「精確對角化」：

```
12 個隨機 6×6（λ = 1e−3）：max|級數 − 精確| = 1.554e−15
λ = 0.01 ：殘差 = 2.7688e−11，殘差/λ⁵ = 0.2769
λ = 0.001：殘差 = 2.7092e−16，殘差/λ⁵ = 0.2709
λ = 1e−4 ：殘差 = 2.7148e−21，殘差/λ⁵ = 0.2715
⟹ 比值恆定（0.2709–0.2769）⟹ 殘差 ∝ λ⁵ ⟹ **四階級數正確**
```

## 五、★ 收斂半徑：塌窗係真、極點非假象

```
[1/1] Padé：A2 g² + T g³ ≈ A2 g²/(1 − (T/A2) g) ⟹ 極點 g* = A2/T
⟹ |g*| = |A2|/|T| ≡ docs/44 §五 之界（**同一物件**，非兩個獨立結論）

[2/1] Padé：q = 1 + b1 g，p = a0 + a1 g + a2 g²
  A2 = a0、T = a1 + a0 b1、A4 = a2 + a1 b1 ⟹ **餘一自由度** ⟹ 三係數不足以定 [2/1] 極點
```

**★ §五b 比值檢（d'Alembert）** —— 用四階回答「[1/1] 極點是否假象」：

```
ρ_n := (|A4/T|)/(|T/A2|)   〔相鄰階比之比值〕
ρ 之 min = 0.001651｜中位 = 0.690538｜max = 1.861989
落在 [0.1, 10] 之模數 = 43 / 44
樣本：n = 43｜|T/A2| = 2.248561e+03｜|A4/T| = 2.566810e+03｜ρ = 1.1415
      n = 1 ｜|T/A2| = 1.272985e+01｜|A4/T| = 1.508871e+01｜ρ = 1.1853
```

**判**：相鄰階比近似恆定（`ρ ≈ O(1)`）⟹ 級數係**幾何式發散**，非「極點位置漂移」⟹
`[1/1]` 極點**非假象**，半徑 `~|A2/T|` 為真。最靠前者 `n = 39`：`|g*| = 2.252170338306e−04`。

⚠ **仍非收斂性證明**：此係數值比值證據，非嚴格解析證明。
