### 精確證明（`ℚ(√5)/8`，`Fraction` 算術，零誤差）

```
sin²18° = (3−√5)/8    sin²30° = 2/8      sin²36° = (5−√5)/8
sin²54° = (3+√5)/8    sin²60° = 6/8      sin²72° = (5+√5)/8

(i)   sin²18° + sin²30° = (5−√5)/8 = sin²36°   ✅
(ii)  sin²18° + sin²54° = 6/8     = sin²60°   ✅
(iii) sin²30° + sin²54° = (5+√5)/8 = sin²72°   ✅
```

等價於三條三角恆等式：

```
(i)   cos36° − cos72° = cos60° = ½                 （黃金比例基本恆等式）
(ii)  cos36° + cos108° = ½                         （= (i)，因 cos108° = −cos72°）
(iii) cos60° + cos108° = 1 + cos144°               （另一條）
```

## 三、三個三元組之結構

```
聯集 = {9, 15, 18, 27, 30, 36}（6 個模）
兩兩交：T1∩T2 = {9}   T1∩T3 = {15}   T2∩T3 = {27}   ⟹ 兩兩恰共用一模
「合成模」（sum 之後件）：18、30、36
γ 值：γ_18 = (5−√5)/2 = 1+φ⁻² ≈ 1.38197 ； γ_30 = 3（精確） ； γ_36 = (5+√5)/2 = 1+φ² ≈ 3.61803
     ⟹ γ_18 + γ_36 = 5（精確）、γ_18·γ_36 = 5 ⟹ 兩者係 x²−5x+5=0 之兩根
     ⟹ γ_18 + γ_30 + γ_36 = 8 = 2B
```

## 四、為何只有 3 個

```
C 鏈之角度 = 2n°（n = 1..44）⟹ 偶數度。共振條件（精確）：
    cos(2(a+b)°) · cos(2(a−b)°) = cos²(2m°)
解集全部落於 6 個角度 {18°,30°,36°,54°,60°,72°}，其 sin² 值只有 6 個（上表）。
三波共振 = 呢 6 個值之間之加法關係；逐對窮盡得 3 條，掃盡（41,624 格，dps=60）確認無第四。
⟹ 非擬合、非選取：係 `ℚ(√5)` 加法表之**逼出**結果。
```
