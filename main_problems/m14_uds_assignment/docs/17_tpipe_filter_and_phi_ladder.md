## 四、★ 共用模之振幅 = φ-階梯（精確）

```
A_9  = 2sin18° = (√5−1)/2 = **φ⁻¹** = 0.61803398875
A_15 = 2sin30° = **1**    = φ⁰
A_27 = 2sin54° = (1+√5)/2 = **φ**   = 1.61803398875
數值核：max|A − φ^(−1,0,1)| = 2.3e−41
```

⟹ 三個共用模（每個各參與兩個三元組）之振幅**恰為等比 `φ`**：`φ⁻¹ : 1 : φ`。

合成模之能量（`γ`）：

```
γ_18 = 3 − φ      γ_30 = 3（精確）      γ_36 = 2 + φ
γ_18 + γ_36 = 5（精確）        γ_18 + γ_30 + γ_36 = 8 = 2B
```

## 五、★ 即時算死：「振幅 = 質量」

若 `A_n ∝ m`，則相鄰世代質量比 = `φ = 1.618`。
觀測：輕子 `m_μ/m_e ≈ 2.07×10²`、`m_τ/m_μ ≈ 1.68×10¹`（量級），兩者皆**遠離** `1.618`。

```
⟹ **「A_n = 質量比」讀法即時死**（唔需等新數據；量級已差 1–2 個數量級）。
⟹ φ-階梯只可能係**耦合振幅**（或投影係數），唔係質量譜。
⟹ 且 φ 幂質量主張屬本項目**已知禁區**（`userskills-idcm-phi-power-trap`）：本輪**不**作此主張。
```
