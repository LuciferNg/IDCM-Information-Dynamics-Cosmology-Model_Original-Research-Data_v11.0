## 一、定義（零參數）

```
δγ_n := (g₄²/8100) · Σ_{b≤c≤d} m(b,c,d) · W(n;b,c,d)² / (γ_n − γ_b − γ_c − γ_d)
   m = 3!/(multinomial)（相異排序數）｜W = 90·χ⁴（docs/39 之閉式）
   只取 **1→3 tadpole 支**；2→2 bubble 支未算（見 §六）
```

## 二、★ 極點屏蔽定理

```
運動學極點（分母 = 0）恰 1 個：(n; b,c,d) = (30; 15,15,15)
喺該點：和 = 30+15+15+15 = 75 為**奇** ⟹ χ⁴ = 0（docs/39 宇稱律）⟹ W = 0
⟹ **真極點 = 0** —— 微擾論無極點，一階求解安全
```

**結構意義**：`30 → 15+15+15` 係唯一之四波衰變通道（`docs/41 §二`），而佢之耦合恰為零。即係：**唯一運動學奇異點被宇稱律精確屏蔽** —— 唔係「碰巧冇」，而係宇稱令耦合恆零。

## 三、★ 二階頻移：44 個值全相異

```
S_n := 8100·δγ_n/g₄²
  n = 1：−3913.79403031      n = 10：−22573.3904714
  n = 3：−35850.9898577（最負）… max S = 23852.714
相異值 = 44 / 44  ⟹ 無任何簡併
```

**對照 `docs/41 §四`**：一階之不透明度**完全均勻**（每模恰 21 條），二階頻移**完全相異**（44/44 互異）。同一相互作用，兩個通道給出相反之對稱性 —— 均勻性屬**計數**（組合恆等），差異性屬**動力學**（分母含 `γ` 差）。

## 四、微擾有效性界

```
要求 |δγ_n| < γ_n/2（半級寬）對所有 n：
   g₄² < min_n 8100·γ_n/(2|S_n|) = 0.004937225855088783（最小者 n = 3）
   ⟹ |g₄| < 0.070265395858052
```

## 五、level crossing（頻級翻轉）

```
相鄰級翻轉之正臨界 c = g₄²/8100 共 24 個；最小：
   級 42 ↔ 43：c = 4.473284021755663e−7  ⟹ g₄ = 0.060194352373143
   級  2 ↔  3：c = 7.662261481471659e−7  ⟹ g₄ = 0.078780910124167

⟹ g₄ ≳ 0.0602 時頻譜次序開始翻轉（先 42↔43）；此值**低於**微擾界 0.0702654
⟹ 存在一個窗口 g₄ ∈ (0.0602, 0.0703)：微擾仍收斂，但次序已非 γ 之次序
```
