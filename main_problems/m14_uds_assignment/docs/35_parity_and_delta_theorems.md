## 一、`K3` 前半（**代數證明**）：`a+b+m` 偶 ⟹ `χ³ = 0`

```
反射 j ↦ 45−j（{1..44} 之雙射）：
  φ_n(45−j) = √(2/45)·sin(πn − πnj/45) = (−1)^(n+1) φ_n(j)

⟹ χ³ = Σ_j φ_a(45−j)φ_b(45−j)φ_m(45−j)   （僅重排）
      = (−1)^(a+b+m+3) χ³

a+b+m 偶 ⟹ a+b+m+3 奇 ⟹ χ³ = −χ³ ⟹ **χ³ = 0**  ∎
```

核：`φ_n(45−j) = (−1)^(n+1)φ_n(j)` 之 44×44 = **1936 對全核，違例 0**；偶和三元組 **6622** 個之 `max|χ³| = 1.36e−60`（dps 60 噪底）。

核心數值（明文）：最小 |χ³| = 1.609741784646e-6（於 (1,2,44)）；偶和三元組 6622 個；反射對 1936 對。

## 二、`K3` 後半（閉式 ＋ 窮舉）：`a+b+m` 奇 ⟹ `χ³ ≠ 0`

```
4 sinA sinB sinM = sin(A+B−M) + sin(A−B+M) + sin(−A+B+M) − sin(A+B+M)
Σ_{j=1}^{44} sin(πkj/45) = cot(πk/90)（k 奇）／0（k 偶）

a+b+m 奇 ⟹ 四個 k 全奇 ⟹
χ³ = (2/45)^{3/2}/4 · [ cot(π(a+b−m)/90) + cot(π(a−b+m)/90)
                       + cot(π(−a+b+m)/90) − cot(π(a+b+m)/90) ]
```

| 核 | 值 |
|:--|:--|
| 奇和三元組數 | **6622** |
| 閉式 vs 直接求和之不符 | **0** |
| 最小 `\|χ³\|` | **1.60974178465e−6**（於 `(1,2,44)`） |
| 全非零 | **是** |

```
⟹ 判定：K3 兩半成立 —— 前半為代數定理；後半為「閉式 ＋ 6622 例窮舉非零」。
🔴 明示邊界：「奇 ⟹ ≠0」無一般數論證明（cot 之和能否精確相消屬代數關係問題，
   等同 Conway–Jones 型；本 M 不假裝此半為定理）。
```

## 三、`Q4` ✅ `δ` 三分律之**完全代數證明**

```
起點：Σγ = Σ_{n=1}^{M} 4sin²(πn/x) = 2M − 2Σ_{n=1}^{M} cos(2πn/x)

關鍵和（兩條皆為標準恆等式）：
  (a) x 偶：Σ_{n=1}^{x/2−1} cos(2πn/x) = 0      ← 配對 n ↔ x−n，且 Σ_{n=1}^{x−1} = −1
            cos(π) = −1  ⟹  Σ_{n=1}^{x/2} cos = −1
  (b) x 奇：Σ_{n=1}^{(x−1)/2} cos(2πn/x) = −1/2

三類代回：
  ring（x 偶，M = x/2）         Σγ = 2(x/2) − 2(−1)   = x + 2  ⟹ δ = **+2**
  Dirichlet（x 偶，M = x/2−1）  Σγ = 2(x/2−1) − 0     = x − 2  ⟹ δ = **−2**
  Dirichlet（x 奇，M = (x−1)/2）Σγ = (x−1) − 2(−1/2)  = x      ⟹ δ = **0**  ∎
```

數值核（`x = 3..200` 三類全掃，**違例 0**）；關鍵和獨立核：`x=88` 之 `Σ_{1..x/2−1}cos = 1.5e−60`、`Σ_{1..x/2}cos = −1.0`；`x=45` 之 `Σ = −0.5`。

⟹ `δ` 三分律由「掃描歸納」升格為**定理**（`docs/21` 之 `Q4` 結案）。
