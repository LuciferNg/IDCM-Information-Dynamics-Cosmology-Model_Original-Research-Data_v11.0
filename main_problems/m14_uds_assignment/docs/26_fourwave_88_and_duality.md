## 一、`U1` 得答：兩鏈四波譜完整算得

| 鏈 | 價對 | 等值類 | 單元類 | 雙元類 | 最大類 | 四波共振 `C(k,2)` |
|:--|--:|--:|--:|--:|--:|--:|
| **`/88`** | 946 | **926** | 925 | **0** | **21**（`a+b=44`，`S=4`） | **210** = `C(21,2)` |
| **`/90`** | 946 | **913** | 900 | **12** | **22**（`a+b=45`，`S=4`） | **243** = 231 + 12 |

```
/88：926 = 925 + 1 ；四波共振 210 全部來自單一類（a+b=44 之 21 對）
/90：913 = 900 + 12 + 1 ；四波共振 243 = C(22,2)=231（大類） + 12（12 個雙元類）
```

★ **結構差異**：`/88` **零意外簡併**（除補償族外全部唯一）；`/90` 有 **12** 個雙元類
（`docs/18` 已證 12/12 全在 `n ≡ 0 (mod 3)`）⟹ `/88` 之譜處於「一般位置」，`/90` 則有系統性二次簡併。

## 二、★ 對偶 `S ↦ 8 − S`（兩鏈同型，統一成因）

```
c(n) = N_c − n，N_c = 44（/88）或 45（/90）
S(a,b) + S(c(a),c(b)) = 8        兩鏈 max|dev| = 1.24e−60（全價對）
固定線 a + b = N_c ⟹ S = 4 = 8/2 ⟹ 自對偶
  /88：21 對（a<b，44 偶 ⟹ 中點 22 不成對）
  /90：22 對（45 奇 ⟹ 無中點）
```

⟹ 四波共振之**統一成因** = 補償對之能量互補至 `8 = 2γ_max`，
非各鏈各自巧合。此亦解釋為何 `/88` 大類 21 對而 `/90` 大類 22 對 —— 純由 `N_c` 奇偶決定。

## 三、`U2` 得答（否定式）：兩個「11」非同一結構

```
(a) 奇模扇區組數 = |{a 奇 : a < 44/2}| = 44/4 = 11
(b) /88 折疊 odd core = 88/2³ = 11
(c) 兩者皆 = 88/8 = 11（因 v₂(88) = 3 ⟹ 8 | 88）
```

⟹ **數值同位，無結構同一**：一個數「價對之奇數半區」，一個數「2-adic 約化後之奇核」。
要稱同一結構，須給出與動力學交換之自然雙射（載體上不存在；`docs/21 §五` 已立此紀律）。
**判定：算術巧合（`88 = 8×11` 之後果），不作結構宣稱。**
