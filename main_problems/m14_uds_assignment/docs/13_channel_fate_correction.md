## 二、錯在哪

`Σ = a+b` 係**動量指數**，唔係頻率指數。非線性色散 `ω_n = 2sin(nπ/88)` 之下
「動量指數落喺 1..44」**唔等於**「該頻率係鏈上嘅模」。故用 `Σ` 相對 44 分「帶內／帶外」
係把兩個空間混為一談。

`scripts/14` 之真實頻率掃描：`ω_a ± ω_b = ω_m` **0 / 83,248**（並有 `m = Σ`、`m = Δ` 之代數 no-go）。
⟹ 以頻率言，**三類全部 off-shell**，I 與 III 無分別。

## 三、更正後之正確結構

```
II（Σ = 44，21 對）  ⟹ γ_a + γ_b = γ_a + γ_{44−a} = 4 = γ_44  ⟹ **sum 真在殼**（落 m = 44）✅
I 與 III             ⟹ sum 皆 off-shell；且兩者之 beat 亦 off-shell（除非 b = 44）
```

⟹ 三分**塌縮**為：

```
① 在殼／唔在殼（二分）
② 若在殼：B 型（b = 44 ⟹ beat 在殼，43 對）或 S 型（a+b = 44 ⟹ sum 在殼，21 對）
③ S 型 ≡ 原 II 類 ⟹ scripts/13 之 II 類**係真**，但理由唔係「Nyquist」，而係 γ 恆等式
```
