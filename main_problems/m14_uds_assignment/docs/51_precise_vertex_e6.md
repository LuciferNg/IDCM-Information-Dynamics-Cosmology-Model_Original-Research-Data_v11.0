## 一、為何 7 模態就夠

模式數 BFS（`Δ|T| ∈ {0,±2}`，由 `|n⟩` 出發、末態回 1 模）：

```
E_1 → 1 模      E_2 → 3 模      E_3 → 3 模      E_4 → 5 模
E_5 → 5 模      E_6 → 7 模（1→3→5→7→5→3→1）      E_7 → 9 模
```

⟹ **`E_6` 於 7 模態即閉合**（毋須 9 模）。所需新通道只有兩條：

```
V^{5→7}：去 1 添 3      V^{7→5}：去 3 添 1
（7↔7 屬 E_7 才需要，本文不建）
```

## 二、7 模態之表示（不落地 1e8 表）

```
C(50,7) = 99,884,400 態；全表 7 欄 int32 = 2,667 MiB > 卡可用記憶體
⟹ 以 combinadic rank 即時 unrank（GPU 內），rank = Σ_j C(a_j + j − 1, j+1)
   還原：a_j = max{ n : C(n, j+1) ≤ r }，v_j = a_j − j + 1
```

能量分母亦以 kernel 即時計算（`den7`：`v_i /= (γ_n − Σγ)`）。
