## 一、`Q1` ✅：`δ` = Nyquist 本徵值之半（結構身份，非凑數）

```
起點（docs/35 §三）：Σγ = 2M − 2C，C ≡ Σ_{n=1}^{M} cos(2πn/x)
⟹ δ ≡ Σγ − x = (2M − x) − 2C

三類代回：
  ring（x 偶, M = x/2）          2M−x = 0   ⟹ δ = −2(−1) = **+2**
  Dirichlet（x 偶, M = x/2−1）   2M−x = −2  ⟹ δ = −2 − 0 = **−2**
  Dirichlet（x 奇, M = (x−1)/2） 2M−x = −1  ⟹ δ = −1 − 2(−1/2) = **0**

⟹ **δ = ε · γ_max/2**（γ_max = 4）
   ε = +1：Nyquist 在譜內（ring）
   ε = −1：x 偶但 Nyquist 被排除（Dirichlet）
   ε =  0：x 奇，無 Nyquist 可言
```

核：`x = 4..200` 三類全掃，**違例 0**。

**候選否決**：

| 候選 | 值 | 判 |
|:--|:--|:--|
| (a) `\|ℤ₂\|·\|B−2\|` | `2·2 = 4` | 🔴 **否**（≠2；且 `B−2` 無獨立出處） |
| (b) sync 項 | — | 🔴 無證據（`docs/21` 原文只列為猜測，本 M 從未建 sync 量與 `δ` 之連結） |
| **(c) `ε·γ_max/2`** | `±2`／`0` | ✅ **得答** |

⟹ `δ` 唔係 neu 常數，而係**唯一攜帶邊界資訊之本徵值（Nyquist）的半值**；符號即「Nyquist 是否在譜內」。這同時解釋了 `docs/21 §四` 之「每上一層差翻倍」（層間差 = 2 的冪 ⟹ 來自 Nyquist 半值之逐層折疊）。

## 二、`MR2` ✅（結構側）：14 模子晶格 ≅ `/30` 半譜

```
子晶格 n = 3k（k = 1..14）：{3, 6, 9, 12, 15, 18, 21, 24, 27, 30, 33, 36, 39, 42}
max|γ^(90)_(3k) − γ^(30)_k| = 3.11e−61   （k = 1..14）
⟹ **精確譜同構**（n ↦ 3n），非近似
k = 15 ⟹ n = 45 = /90 之鏈 Nyquist，不在 44 模集內（故子晶格止於 14 模）
```

⟹ `MR2` 之**結構側**得答：14 模子晶格 = `/30` 鏈之像（同一個算子、不同標籤）。
⟹ **物理側**（「是否即味活性扇區」）屬跨載體，本 M 不裁（依紀律只可 register 發還）。

## 三、`MR3` 🟡 部分：`k` 和 = 14 與 `T_pipe` 重合，但唔係必然

```
① /90 mod-3 子晶格內之三波共振恰 **3** 個：
     n = 9,15,18   ⟹ k = (3,5,6)   k 和 = 14   ← 唯一 k 和 = 14
     n = 9,27,30   ⟹ k = (3,9,10)  k 和 = 22
     n = 15,27,36  ⟹ k = (5,9,12)  k 和 = 26

② T_pipe（n* = 27 ⟹ k* = 9）：只有 {9,15,18} 全在窗內
   ⟹ 「k 和 = 14」與「T_pipe 存活」**在本扇區完全重合**（集合相等 = True）

③ 忠實跨鏈類比（N = 8..200，Dirichlet 44 模公約，321 個 (N,d) 子晶格）：
     「子晶格內三波共振且 Σk == K」共 **4 例**，全部係 k = (3,5,6)、K = 14：
       N=90,d=3 ｜ N=120,d=4 ｜ N=150,d=5 ｜ N=180,d=6
     四者皆 N/d = 30 ⟹ **同一個 /30 鏈**（非四個獨立事件）
```

**判讀（誠實分兩層）**：

```
結構層（真）：T_pipe 窗 k ≤ 9 與「Σk = K」同向偏愛**最低**的三元組，
              而 /30 鏈唯一最低共振即 (3,5,6) ⟹ 兩判準必然相關（單調性）
算術層（巧合）：Σk = 3+5+6 = 14 = K 本身**無數論必然性**；
              跨鏈掃描只給出「/30 鏈具有此性質」，未給出「為何 K=14 恰好等於該和」
⟹ MR3 判：**重合成立、必然不成立**（範圍：本載體 /90 mod-3 扇區）
```

## 九、精度更正（2026-11-02，append-only）

`§一` 寫「**δ = ε · γ_max/2**（`γ_max = 4`）」—— 恆等式無誤，但 `γ_max` 之**身份**須精確化：

```
Nyquist 值 ≡ 4
  /88 ring：γ_44 = 4（精確，Nyquist 模在 44 模集內）
  /90 Dirichlet：譜內最大 γ_44 = 3.99512810052 < 4；Nyquist 模 n = 45 **不在** 44 模集

⟹ δ = ±2 之「2」用 Nyquist 值 4 之半，**唔係** /90 譜內最大之半（後者 = 1.99756405026）
⟹ 恆等式對所有 x 成立（scripts/38 逐 x 以 gam(x, x//2) 算，即用各鏈自身之 Nyquist 值）
```

`docs/34 §二`（`8 = 2γ_Nyquist`）同屬此類：`8` 精確，來源係 Nyquist 值 4 而非 /90 譜內最大（`2 × 3.99512810052 = 7.99025620104`）。
