## 一、`L3` ✅：`γ18+γ30+γ36 = 8` 係恆等後果，非巧合

```
γ18 = 4sin²36° = 1.3819660112501 = 3−φ        |dev| = 0
γ30 = 4sin²60° = 3.0
γ36 = 4sin²72° = 3.6180339887499 = 2+φ        |dev| = 0
和 = 8.0                                      |dev| = 0

機制：γ18 + γ36 = (3−φ) + (2+φ) = 5      ← **φ 相消**
      5 + γ30(=3) = 8 = 2γ_Nyquist
等價 sin² 恆等：sin²(π/5) + sin²(2π/5) + sin²(π/3) = 2      （與 N 無關）
```

**全檢**：`N ≤ 400`、`15 | N` 之 13 個 N（取 `(N/5, N/3, 2N/5)`），和**全為 8**。

⟹ `8` 之來源係「有理角 sin² 之 `15|N` 恆等式」，非新結構常數；`2B` 之 B 即 `γ_Nyquist = 4`，故 `8 = 2γ_Nyquist` 屬**尺度無關**之必然。

## 二、`Q3` ✅：odd core `11`／`45` = 二次域扇區之開關

```
/88  = 8·11   ⟹ odd core 11，質因子 {11}
/90  = 2·45   ⟹ odd core 45 = 3²·5，質因子 {3,5}
Kronecker–Weber：ℚ(√d) ⊂ ℚ(ζ_N) ⟺ cond(d) | N
```

| 域 | cond | \|88 | \|90 | \|176 |
|:--|--:|:--:|:--:|:--:|
| `√−11` | 11 | ✓ | ✗ | ✓ |
| `√5` | 5 | ✗ | ✓ | ✗ |
| `√2` | 8 | ✓ | ✗ | ✓ |
| `√−3` | 3 | ✗ | ✓ | ✗ |
| `i` | 4 | ✓ | ✗ | ✓ |
| `√13` | 13 | ✗ | ✗ | ✗ |

⟹ **odd core 之質因子集完全決定奇 conductor 扇區**：`/88` 只開 `11`（`√−11`）；`/90` 開 `3`、`5`（`√−3`、`√5`）。`√2` 之 conductor `8 = 2³` 屬 2-進部分，故 `/88`（`2³·11`）專屬、`/90`（`2·45`）全無。
⟹ `Q3` 得答：`11`／`45` 非神秘數 —— 它們就是 `N` 之奇部，而奇部決定「本載體能看見哪幾個二次域」。

## 三、`K4` ✅：三模互異之要求**幾乎無成本**

| 鏈 | 互異三波 | 允許重複（`2γ_a=γ_c`）新增 | 內容 |
|:--|--:|--:|:--|
| `/88` | 21 | **1** | `(22,22,44)`：`2γ22 = 2·2 = 4 = γ44` |
| `/90` | 3 | **0** | 無 |

⟹ 唯一被互異條件排除者係 `/88` 之 `(22,22,44)`，即**同模計兩次**之平凡退化（`γ44 = 2γ22`）。無任何非平凡共振因「互異」而被排除 ⟹ 互異要求**不損結構**，可安全保留。

## 四、`P1` ✅：`3960 = lcm(88,90) = 88·90/2` —— 強制之相位公分母

```
gcd(88,90) = 2；lcm(88,90) = 3960；88·90 = 7920
『44·90 = 3960』只是同一數之另一寫法（因 44·2 = 88）
對照：lcm(86,88)=3784、lcm(90,92)=4140、lcm(44,46)=1012 —— 皆 = ab/gcd
```

⟹ `3960` 係兩鏈相位之**共同週期**（`Δθ_n = nπ/3960`，`7920` 步一週期），屬 `lcm` 之必然，**唔係** `L_ring·(N_d+1)` 型獨立結構數。`44·90` 之形式純屬 `gcd=2` 之算術巧合。

## 五、`J1` ✅：「恰 6 個 `ℚ(√5)` 角」= `ℚ(√5)` 值集，共振係域內封閉之後果

```
γ_n ∈ ℚ(√5) 之模（n = 1..44）恰 **6** 個：
  n=9  γ = 3/2 − √5/2 = 0.3819660112501
  n=15 γ = 1
  n=18 γ = 5/2 − √5/2 = 1.3819660112501
  n=27 γ = 3/2 + √5/2 = 2.6180339887499
  n=30 γ = 3
  n=36 γ = 5/2 + √5/2 = 3.6180339887499

集內加法封閉之共振恰 **3** 個：{9,15,18}、{9,27,30}、{15,27,36}   ← 與 docs/12 完全一致
```

⟹ `J1` 之 Galois 理由：因 `5 | 90`，`ℚ(√5) = ℚ(ζ_5)^+` 為 `ℚ(ζ_90)` 之實子域；凡 `γ_n` 落此子域者恰為上述 6 模；而**同域相加不出域** ⟹ 共振只能在集內找，故解集恰 3 個、恰落此 6 角。**唔需要**額外機制解釋「為何係此 6 角」。
