## 一、bubble 支之定義與零分母分類

```
δγ_n^B := (g₄²/8100) · Σ_{m} Σ_{p≤q} mult(p,q) · W(n,m;p,q)² / (γ_n + γ_m − γ_p − γ_q)
```

| 類 | 數（每模） | 處置 |
|:--|--:|:--|
| 自收縮 `{p,q} = {n,m}` | **44**（每個 `m` 一個） | 正規序移除（同一頂點自我收縮） |
| 零分母且 `W ≠ 0` | **21**（全部模相同） | 實中間態 ⟹ 實部取主值、虛部 = `−Γ_n/2` |
| 零分母但 `W = 0`（宇稱殺） | **0 / 3 / 6** | 無虛部；只因運動學巧合 |
| 運動學零分母合計 | 21 / 24 / 27 | 非均勻（因宇稱類別各異） |

**關鍵區分**：運動學零點非均勻（`21/24/27`），但**有振幅者恰 21**（均勻）⟹
虛部 `Im δγ_n = −Γ_n/2` **完全均勻**（`Γ_n = 21 × 2π/2025`，見 `docs/41 §四`）。
即係 `docs/42` 之「tadpole 全相異」與「虛部完全均勻」可以並存 —— 差異全在 `W = 0` 那幾條。

## 二、★★ 定理：bubble 主值之鏡像反號

```
PV_n := Σ_{m,p≤q, den≠0} mult(p,q) W(n,m;p,q)²/(γ_n+γ_m−γ_p−γ_q)

  PV_n = −PV_{45−n}       （精確；數值 max|PV_n + PV_{45−n}| = 1.712e−43）
```

### 證明

```
(1) 譜之鏡像恆等：γ_{45−n} = 2 − 2cos(π(45−n)/45) = 2 + 2cos(πn/45) = 4 − γ_n
(2) 態之鏡像：φ_{45−n}(j) = sin(πj − πnj/45) = (−1)^{j+1} φ_n(j)
    ⟹ 四點重疊 χ⁴_{45−n,45−m,45−p,45−q} = ∏(−1)^{j+1} χ⁴_{n,m,p,q} = χ⁴（四次 ⟹ 符號消）
    ⟹ W 不變
(3) 對 (m,p,q) 同步取鏡像（雙射）：分母
    (4−γ_n)+(4−γ_m)−(4−γ_p)−(4−γ_q) = −(γ_n+γ_m−γ_p−γ_q)
    ⟹ PV_{45−n} = Σ W²/(−den) = −PV_n ∎
```

**推論**：`Σ_n PV_n = 0`（44 個配成 22 對，每對反號）。
**例外之美**：`n = 15`（`γ = 1`）與 `n = 30`（`γ = 3`）之 `PV = ∓2018.25`（精確有理 = `∓8073/4`）。

## 三、tadpole 符號：非結構量

```
S_n > 0 之模 = {17, 30, 33, 35, 39, 41}（6 / 44）
按 γ 升序之符號序列轉換 **12** 次 ⟹ 閾值假說（S_n > 0 ⟺ γ_n > θ）**否證**
主導項診斷：n = 17 之最大單項 triple (4,6,15)，分母 = 0.00040112033；
            n = 44 之最大單項 triple (2,2,42)，分母 = −9.4825982e−5
⟹ 符號由 ~1e−4 級近簡併分母之抵消決定 ⟹ **非結構量**，不可作選擇律或量子數
```

## 四、MR1 四節合觀

| 通道 | 分佈性質 | 值 |
|:--|:--|:--|
| 一階速率 `Γ_n` | **完全均勻** | 每模 21 條 × `2π/2025` |
| 二階虛部 `Im δγ_n` | **完全均勻** | `−Γ_n/2`（同上，反號縮半） |
| 二階實部（tadpole） | **完全相異** | 44/44；`|g₄| < 0.070265395858052` |
| 二階實部（bubble） | **鏡像反號** | `PV_n = −PV_{45−n}`；44/44 相異；`Σ PV = 0` |

```
⟹ 三個層次、三種對稱性：
   計數（一階／虛部）⟹ 均勻（組合恆等）
   實部逐模 ⟹ 全異（分母含 γ 差）
   實部全域 ⟹ 鏡像反號（γ 鏡像 + W 四點不變）
```
