## 一、模態數更正（推翻 `docs/51 §一` 之末行）

模式數上界：由 `|n⟩`（1 模）出發，經 `k−1` 個頂點回 3 模，`Δ|T| ∈ {0,±2}`：

```
1 + 2·(#up − #down) = 3  ⟹  #up − #down = 1
#up + #down + #zero = k − 1
⟹ #up ≤ (k−1)/2 + 1/2 ⟹ 1 + 2#up ≤ 1 + (k−1) + 1 = k + 1
```

| `k` | `k−1` 頂點 | 最大 #up | 最大模態數 |
|:--:|:--:|:--:|:--:|
| 6 | 5 | 3 | 7 |
| 7 | 6 | 3 | **7** |
| 8 | 7 | 4 | **9** |

⟹ **`E_7` 只需 7 模態**（`1+2·3`）；**9 模屬 `E_8`**。
`docs/51 §一` 之「`E_7` → 9 模」為誤標，本文以本節取代。

故 `E_7` 只需一個新算子 `V^{7→7}`（`na=2, cre=2`），其餘通道（`3↔3`、`3→5`、`5→3`、`5↔5`、`5→7`、`7→5`）已存在。

## 二、通用四波算子

```
amp(Q|T) = (W/90) · √( noA · noC ) · φ(T) / ( fpA · fpC · mulpos )
  A = 被湮滅之多重集（na 個）        C = 被創造之多重集（ncre 個）
  c_T(v) = T 中 v 之重數             c_S(v) = 倖存部分 S 中 v 之重數
  noA  = ∏_{v∈A}(c_T − t_v)          noC = ∏_{v∈C}∏_{u=1}^{q_v}(c_S + u)
  fpA  = ∏ c_A!   fpC = ∏ c_C!       mulpos = ∏_{v∈A distinct} C(c_T(v), t_v)
  W    = χ⁴(A ∪ C)（八個帶號和 ≡ 0 mod 90 之加權計數）
```

`χ⁴` 以查表實現（`WT13`／`WT22`／`WT31`，皆 ≤2 MB）；先取 `W ≠ 0`（非零率 8.5%）再對倖存者排序取 rank ⟹ 較逐點版快 3×。
