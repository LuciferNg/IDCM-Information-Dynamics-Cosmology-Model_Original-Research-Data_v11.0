**性質**: 承接 `docs/26 §五` 之 `V1`。**零觀測量**，`N_trials = 0`。
**判準（跑前凍結）**：R1 步 `d` 取 `n = dk`、`M = N/d ∈ ℤ`；R2 成鏈 ⟺ `K = ⌊M/2⌋`；R3 Σγ 直接求和並核 `Σ_{k=1}^{M−1} 4sin²(kπ/M) = 2M`。

---

## 一、★ 判準：`mod-m` 子晶格存在 ⟺ `m | N`

```
步 d 取 n = dk  ⟹  γ_n = 4sin²(dkπ/N) = 4sin²(kπ/(N/d))
⟹ 子晶格落在 /M 鏈上（M = N/d）⟺ d | N
```

## 二、兩鏈之子晶格清單

| 鏈 | 非空子晶格 | 步 `d` | 成鏈（`K=⌊M/2⌋`） |
|:--|--:|:--|:--|
| **`/88`** | **6** | 2, 4, 8, 11, 22, 44 | **6**（`/44`,`/22`,`/11`,`/8`,`/4`,`/2`） |
| **`/90`** | **9** | 2, 3, 5, 6, 9, 10, 15, 18, 30 | 5（`/45`,`/15`,`/9`,`/5`,`/3`） |

```
3 | 90  而  3 ∤ 88
⟹ /88 **冇** mod-3 子晶格（3kπ/88 不能寫成 kπ/M，M ∈ ℤ）
⟹ /90 之「14 模 /30 鏈」係 3 | 90 之**算術專屬後果**，不可移植
⟹ /88 之最細模數為 11（88 = 8×11）⟹ d=11 給出 /8 鏈（4 模）
```

## 三、`/90` 之 14 模 `/30`：**完整半譜**，非截斷（修正我先前的說法）

```
γ^(90)_(3k) = 4sin²(kπ/30)，k = 1..14        max|dev| = 3.11e−61
/30 全譜（k=1..29）：Σγ = 2M = 60            （Σ_{k=1}^{M−1} 4sin²(kπ/M) = 2M）
/30 半譜（k=1..14，排除 Nyquist）：Σγ = (2M−4)/2 = **28**  ⟵ 與本子晶格 Σγ 精確相符
Nyquist（k=15 ⟹ n=45）落於 /90 模域（n ≤ 44）之外
```

> ⟹ 本子晶格係 `/30` 之**除 Nyquist 外之完整半譜**。
> 與 `docs/20 §三`「和頻通道在 `/90` 關閉（落點 `m = 45` 為邊界節點）」**互為同一事實之兩面**。
> ★ 我先後兩版曾寫成「殘缺」／「低頻截斷」—— 兩者皆錯：缺的是**鏡像半譜**，非高頻段。
