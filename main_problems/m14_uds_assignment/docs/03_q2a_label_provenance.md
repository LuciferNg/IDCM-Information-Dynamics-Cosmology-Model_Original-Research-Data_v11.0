## 三、範疇檢定：`d ∈ {3,2,0}` **不可能是 ℤ₂ 分級**

```
G-分級 = 映射 φ: 模集 → G ，φ 為群同態
G = ℤ₂ = {0,1}  ⟹  |image φ| ≤ |G| = 2
v9 要求 |image| = 3（且以 len(set)==3 為驗證條件）
⟹ 3 > 2 ⟹ d **不可能**係任何 ℤ₂ 分級之值
```

⟹ 「`Z₂` grading `d={3,2,0}`」係**範疇錯置**：`ℤ₂` 只能給 2 類，不能給 3 個扇區。
⟹ v9 對 `ℤ₂` 之**唯一**正確用法 = 宇稱選擇（`expansion_plan.md` L43：88 節點中一半 = 44 個
carry chiral modes）—— 該用法只給 2 類，**亦不能**給 3 個世代替換。
