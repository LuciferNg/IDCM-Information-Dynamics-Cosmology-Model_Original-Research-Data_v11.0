## 二、結構輸出之標籤結構：係「無味名之多集」

```
α = (1,2,4)、M = (1/90)(A₂⊕1) ⟹ δ = Mα = (0, 0.03333, 0.08889)
⟹ 結構所能說者 = 「三個讀出值之比 = 0 : 3/8 : 1」——一個**無味名之多集**
```

`δ` 之三分量按**槽位**索引，而「槽位 ↔ 味名」正是待定者。
⟹ 把 `0` 認作 `δ_u`、`3/8` 認作 `δ_d`，係**對號步驟**，不在結構之內。

## 四、存活者係由結構抑或由觀測選出？（A2 之形式化）

```
結構之全部內容 = 比值多集 {0, 3/8, 1}（不含味名）
觀測 = (ρ_u, ρ_d) = (−0.025888, +0.403504)（帶味名）
對號所需 = 決定「0 ↔ ρ_u」「3/8 ↔ ρ_d」⟹ 用「誰最接近 0」
   0 與 |ρ_u| 之距 = 0.02589 ； 3/8 與 ρ_d 之距 = 0.02850
⟹ 對號判據 = 觀測值本身 ⟹ A2（以觀測反解）
```

⟹ 結構對「哪一個對應」之貢獻 = **0 bit**；6 個對應之篩選**全由數據完成**。
⟹ 故 §三 之 `1/6` 命中係**後驗對號**，不得作結構結果（可標記為後驗，但 Q2② 之問法係
「只用結構砍」⟹ 答案為**否**）。

「u/d 扇區指派 = NO-GO」同源（本輪以 `𝒜` 味盲定理給出其**結構根源**）。
