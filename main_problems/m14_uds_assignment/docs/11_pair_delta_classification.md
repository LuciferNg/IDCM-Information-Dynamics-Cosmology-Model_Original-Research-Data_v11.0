## 一、主結果

```
旋轉 ℤ_88 作用 σ_s(a,b) = (a+s, b+s)：軌道數 = **43**
加反射 τ(a,b) = (88−b, 88−a)：      軌道數 = **43**（反射保 Δ ⟹ 不再細分）

每軌之 Δ = b − a 互異，範圍 1..43 ⟹ **Δ 係完備不變量**（每軌唯一 Δ）
軌道大小 = 44…86（因 fold a ↔ 88−a 而變；Σ = 946 ✅）
```

### 定理（價對分類）

> 價對空間 `{(a,b) : 1 ≤ a < b ≤ 44}` 在物理對稱群 `D_88` 之下之軌道分解，
> 與 `Δ = b − a ∈ {1,…,43}` **一一對應**；`Σ = a + b` 係軌道內座標（orbital coordinate）。

**讀法**：`Δ` 正是 beat（差頻）指數——即 `docs/09 §五` 所定「matter = 差頻」之**同一個**
`Δ`。「味對住邊個站」係範疇錯，正確講法係「味對住邊個 **Δ**」；站位置（`Σ`）係軌道內自由度。
⟹ M12 `docs/16 §九` 所要求之「階 2、有向價對 × 扇區」對象，座標系到此**定義閉合**：
`(Δ, Σ)`，其中 `Δ` 分類、`Σ` 係扇區。

**但**：類數 = 43 ≠ 3 ⟹ 「3 個味」**唔喺價對層**。

## 二、`3 | 27` 缺口：封

```
γ_n 在 n = 1..27 嚴格遞增（γ_1 = 0.0050957708 … γ_27 = 2.6989284）⟹ γ 全相異
⟹ 任何「保 γ」之模置換必為恆等 ⟹ 段內無非平凡對稱群
段內 mod-27 平移保 γ者（非恆等）：**無**
n mod 3 之三類 γ 和 = 10.634555 / 8.7898673 / 9.6910408（**不相等**）⟹ 非對稱扇區
```

⟹ `3 | 27` 只給**算術可能**，不給結構分割。`mod 3` 係外加著色（`ℤ/27` 上可定義，但
γ 不對稱）⟹ **`docs/10` 之 T1 缺口亦封**。

## 四、這意味着咩（不改既有判詞）

1. 「3 個世代／3 個味」在 IDCM 載體上係**計數事實**（`B−1`、`9 = N_gen²`、`L₆ = 18`、`27 = 3³`），
   **唔係**任何對稱或週期結構之扇區數。
2. 故「味分類」之正確形式**唔係**「4 個站 → 3 個味」，而係：
   **味對 = 一個 `Δ ∈ 1..43`；世代標籤 = 該 `Δ` 帶何種量子數**。3 之出現須由**計數**（`B−1`）或
   **載體係數**（`docs/09 §五` 第 7 條：係數由載體唯一決定）給出，而**唔可以**由「切 3 份」給出。
3. 此結論**不**推翻 `docs/09` 之更正（Q1 仍 ill-posed、Q2② 條件性）；它係把「未分類」
   推進為「**分類已定位、且 3 類不可能**」——即把 no-go 由「對象錯」升級為「**結構已封**」，
   並且係喺**正確對象**（價對層）上封，非再次類型錯。
