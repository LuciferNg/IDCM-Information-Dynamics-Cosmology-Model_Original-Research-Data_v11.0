## 一、問題設定：兩個守恒量唔可以混

`cos(ω_a t)cos(ω_b t) = ½[cos((ω_b−ω_a)t) + cos((ω_a+ω_b)t)]`
—— beat（差頻）與 sum（和頻）要被視為**載體之合法模**，須有一條通道**在殼（on-shell）**：

```
頻率守恒：  ω_a ± ω_b = ω_m        （ω_n = 2 sin(nπ/88)，色散）
能量守恒：  γ_a ± γ_b = γ_m        （γ_n = 4 sin²(nπ/88) = ω_n²，能量量子）
```

IDCM 之能量預算 `Σγ = 90` 係用 `γ`；`γ` 就係能量量子 ⟹ **能量守恒用 `γ`**。兩者結果**完全不同**，見下。

## 二、頻率守恒：0 / 83,248（附代數 no-go）

```
sum  ω_a+ω_b = ω_m ：精確解 0 / 83,248 ；最小頻隙 1.578e−4  at (a,b,m)=(1,33,52)
     （其中 721 / 946 對之 ω_a+ω_b > 2 = 帶頂 ⟹ 自動不可能）
beat ω_b−ω_a = ω_m ：精確解 0 / 83,248 ；最小頻隙 9.097e−5  at (a,b,m)=(1,2,87)
```

**代數 no-go（特例 `m = Σ`、`m = Δ`，可完全證明）**：取 `u = π/88`，

```
sin(au) + sin(bu) − sin((a+b)u) = 2 sin(Σu/2)[cos(Δu/2) − cos(Σu/2)]
= 0 ⟺ sin(Σu/2)=0（⟹ Σ ≥ 176 ✗）  或  Δ = ±Σ + 352n
     Δ = Σ ⟹ a = 0 ✗ ；  Δ = −Σ+352n ⟹ 2b = 352n ⟹ b = 176n ≥ 176 ✗
```

數值核對分解式：`max|LHS − RHS| = 3.11e−61`（946 對）。

⟹ **頻率層永不共振**。故「beat／sum = 模」在頻率意義下**唔可以**字面成立。

## 三、能量守恒：恰 64 / 946 對有一條通道在殼

```
sum  γ_a+γ_b = γ_m ：精確解 21 ；命中 m 之集合 = {44}（γ=4 = Nyquist）
                     ⟺ a + b = 44（21 對）
beat γ_b−γ_a = γ_m ：精確解 86 = 43 對 × 2 個 m；涉及之 b 值 = {44} 唯一
                     ⟺ b = 44（43 對），落 m = 44−a 或 m = 44+a（γ_{88−m}=γ_m ⟹ 同一 γ）
```

### 根源 = 一條**已註冊**恆等式（零新常數）

```
γ_n + γ_(44−n) = 4 = γ_44        max|dev| = 6.22e−61（n = 1..43）
  (i)  Σ = 44 ⟹ γ_a + γ_b = γ_a + γ_{44−a} = 4 = γ_44  ⟹ sum 在殼，落 m = 44
  (ii) b = 44 ⟹ γ_44 − γ_a = 4 − γ_a = γ_{44−a}       ⟹ beat 在殼，落 m = 44−a
```

⟹ 兩條選擇規則**係同一條恆等式嘅兩個讀法**。
