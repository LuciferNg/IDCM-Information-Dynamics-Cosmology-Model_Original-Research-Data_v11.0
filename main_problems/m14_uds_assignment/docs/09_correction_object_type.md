### 1.3 判據層：量詞偷換（真正的邏輯錯）

我 `docs/02 §三`／`final_result.md` 之原句係：

> 「`𝒜`（一體＋兩體）對味標籤置換**精確不變** ⟹ 結構支應 **0 bit**」

形式化：`𝒜` 味盲 ⟹ `𝒜`-觀測量對味一無所知。此為**真**。
但由此跳到「**u,d,s 之站指派不可由結構推出**」，係把 `𝒜` 換成「結構」——**量詞偷換**：

```
已證：  ¬∃ O ∈ 𝒜  :  O 分辨味
未證：  ¬∃ O ∈（結構全體）: O 分辨味
而研究綱領之前提正是：味之載體 ∉ 𝒜（M12 全線即此）
```

⟹ **Q1 之 0-bit「定理」係 M7 `docs/28` 之逐字重述**，對「味可否被推出」**零增量**。
⟹ 其唯一新增內容係「在『味＝外掛名、站＝自由指標』之編碼下，指派不可推」——而該編碼本身
已**預設**味未分類，即預設咗要證嘅結論。**循環**。

### 1.4 一句

```
不是「結構推不出來」，係「我拿一個已知不含味嘅算子集，去證明味推不出來」。
```
