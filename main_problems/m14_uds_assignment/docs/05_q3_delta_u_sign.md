## 一、`𝒜` 層：`δ_x ≡ 0` **精確**

`docs/02 §三` 已證 `𝒜` 之任一算子只依「佔用模之多集」與「模距之多集」
⟹ 任何味對差之期望值 `≡ 0`（`10⁷` null，bit-identical）。

⟹ 於 `𝒜` 內，`ρ_u` 之結構值 `= 0` 對**任何** `α` 皆成立（不限 `ω₂` 方向）。
⟹ **`δ_u < 0` 於 `𝒜` 內不可生成**（`0` 無符號）。

## 二、`α`-模型層：`ρ_d = 3/8` 與 `ρ_u = 0` 係**同一條件的兩面**

族 `α = (1, x, x²)`（M13 `docs/09 §四` 之家族；`x=2` 唯一雙通）：

```
ρ_u(x) = (2−x)/(2x²)        ρ_d(x) = (2x−1)/(2x²)
解 ρ_d = 3/8 ： (2x−1)/(2x²) = 3/8 ⟹ 16x − 8 = 6x² ⟹ 3x² − 8x + 4 = 0
⟹ x = 2   ⟹ ρ_u = 0      （精確）
⟹ x = 2/3 ⟹ ρ_u = +3/2   ⟹ z_u = 45.4σ ⟹ 已死
```

⟹ 族內 `ρ_d = 3/8` 只有 **兩個根**；唯一存活者（`x=2`）**同時**給 `ρ_u = 0` 精確。
⟹ **代數**：`ρ_u < 0 ⟺ x > 2`（因 `2−x<0`、分母恆正）⟹ 此時 `ρ_d(x) < 3/8` 嚴格。
⟹ 故 **「`δ_u < 0`」與「`ρ_d = 3/8`」在族內精確互斥**（無同時解）。

| `x` | `ρ_u`（`z_u`） | `ρ_d`（`z_d`） |
|--:|--:|--:|
| `2.10` | `−0.01134`（`+0.43`） | `0.36281`（`−0.91`） |
| `2.27`（`x*`） | `−0.02589`（`0.00`，恰等觀測） | `0.34395`（`−1.33`） |
| `2.50` | `−0.04000`（`−0.42`） | `0.32000`（`−1.86`） |
| `3.00` | `−0.05556`（`−0.88`） | `0.27778`（`−2.81`） |

⟹ 欲得觀測之負 `ρ_u`（`x* = 2.2658`），須 `ρ_d` 降至 `0.3440`，即 `z_d = −1.33σ`。

## 三、觀測層：數據對「符號」**無判別力**

`χ²(x)` profile（`x ∈ [1,7]`，步長 `1e−3`）：

```
x̂ = 2.045   χ²_min = 0.9515（2 dof ⟹ p = 0.621）
x̂ > 2 ？是（數據微偏負 ρ_u）
Δχ² ≤ 1 ⟹ x ∈ [1.860, 2.293]；  Δχ² ≤ 4 ⟹ x ∈ [1.715, 2.635]
x = 2（ρ_u ≡ 0）之 χ² = 0.9993 ⟹ 距最小僅 Δχ² = 0.048
強制 ρ_u = 觀測（x = x*）之 χ² = 1.768 ⟹ Δχ² = 0.817（< 1 ⟹ 不可裁決）
```

⟹ `x̂ = 2.045` 只微偏負側（`Δχ² = 0.048`），**統計上完全不可分**。
⟹ 若欲以 3σ 確立負號，需 `σ(δ_u) ≲ 0.0296 MeV`（現 `0.1124`，**需改善 3.8×**）。

### 4.1 語言層判定（record 之原問）

> 「本語言（`A₂` 方向 `ω₂`）結構上只能給 `0`，負號屬**語言外殘餘**」

⟹ **成立**。本語言只能給 `ρ_u = 0` 精確；負號（若真實）之地位與 M7 `A_eff = 4.4492 MeV` 同級
—— 即**外部輸入（Type-3：語言不適用）**，非可由現有算子生成。

### 4.2 兩條禁區（本輪明示拒絕）

1. **不得**為容納負號而加 `c·sgn(δ)` 型自由參數：`dof +1` ⟹ 違 A3；且對任何味對差恰給
   `Δ0 = c` ⟹ 等於把答案當參數（違 A2）。
2. **不得**改 `ω₂` 條件以求命中：`ρ_u` 與 `0` 相容 `0.771σ` 係結構成果，不可丟
   （M13 `docs/04 §六` 已立此禁）。
