# docs/30 — ★★ `Y3` 之否證與取代：`AP ⟺ 4|N`、`GP ⟺ 12|N 或 30|N`

**日期**: 2026-11-02

**性質**: 承接 `docs/29 §六` 之 `Y3`。**零觀測量**，`N_trials = 0`。
**判準（跑前凍結）**：U1 鏈 `γ_n = 4sin²(nπ/N)`，n = 1..K；主掃 `K = N/2`（Nyquist 在內），穩健掃 `K = N/2−1`（Nyquist 在外）；U2 容差 `1e−30`。

## 一、★ 先否證我自己上一輪之表述

`docs/29 §五` 我寫：
> 「`/88` 只有加性結構、`/90` 方有乘性結構」；並歸因於「`√5` 缺席 ⟹ `φ` 缺席 ⟹ 乘性階梯缺席」。

**兩處錯**：

```
(a) /88 與 /90 用**同一** γ_n = 4sin²(nπ/N) ⟹ 無「加性載體 vs 乘性載體」之類型分別
(b) 「√5 缺席 ⟹ 無乘性階梯」不成立為因果：
    N = 12 有 GP（2 個）而 5 ∤ 12；N = 30 有 GP（3 個）而 4 ∤ 30 ⟹ √5 既非必要亦非充分
```

反例最直接者 = **`/90` 本身**（同一 γ 公式，卻有 3 個 GP）。

## 二、★ 取代命題（掃 `N = 8..200`，偶，97 個；**0 違例**）

```
AP（加性階梯）存在 ⟺ 4 | N        違例 0/97 ✅
  AP 族可證：(a, N/4, N/2−a)，因 γ_a + γ_(N/2−a) = 4 = 2·γ_(N/4)
  ⟹ 需 N/4 ∈ ℤ ⟹ 4|N；數目 = N/4 − 1 + [12|N]

GP（乘性階梯）數 = 2·[12|N] + 3·[30|N]       （Nyquist 在內，K = N/2）      違例 0/97 ✅
                 = 1·[12|N] + 3·[30|N]       （Nyquist 在外，K = N/2−1）    違例 0/97 ✅
  兩式之差恰為 [12|N] ⟹ Nyquist 模（γ=4）參與一個 GP 三元組，僅當 12 | N
```

## 三、套用至 `/88` 與 `/90`

| 鏈 | `N` | `4|N` | `12|N` | `30|N` | AP | GP |
|:--|--:|:--:|:--:|:--:|--:|--:|
| **`/88`** | `2³·11` | ✓ | ✗ | ✗ | **21** `= 88/4−1` ✓ | **0** ✓ |
| **`/90`** | `2·3²·5` | ✗ | ✗ | ✓ | **0** ✓ | **3** `= 3·[30|90]` ✓ |

⟹ **兩鏈之差完全由 `88`／`90` 之算術決定**，與「載體類型」無關。

## 四、`docs/28` 之保留與限定

```
✅ 保留：√5 ∉ ℚ(ζ_88)（conductor 5 ∤ 88）；pslq 核實 /88 譜在 ℚ(√2)、/90 譜在 ℚ(√5)
❌ 撤回：由此推「/88 無乘性階梯」之**因果** ——
        正確理由係 12 ∤ 88 且 30 ∤ 88（算術），非數域
```

## 五、對 M14 之意義（收束）

```
「乘性質量階梯」若要存在，載體之 N 必須 ∈ 12ℤ ∪ 30ℤ。
N = 88 = 2³·11 ⟹ 兩者皆非 ⟹ 對 /88 載體**必然**無乘性階梯。
⟹ φ-冪質量路線在 /88 上之失敗，係 88 之算術必然，而非模型或載體設計之缺陷。
```

## 六、判定

```
❌ Y3 原表述（「加性載體不可承載乘性階梯」）**否證** —— 無此類型，反例 = /90
✅ 取代命題（實測 0/97 違例）：AP ⟺ 4|N；GP 數 = 2[12|N]+3[30|N]（環）／[12|N]+3[30|N]（Dirichlet）
✅ 對 88／90 之套用精確吻合（21/0、0/3）
🔴 未證：GP 判準之數論證明；「4∤N ⟹ 無其他 AP 族」之證明
```
