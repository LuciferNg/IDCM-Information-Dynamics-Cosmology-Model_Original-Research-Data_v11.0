# docs/18 — 四波（W⁴）共振結構 ＋ 共振扇區 = mod-3 子晶格（14 模 `/30` 鏈）

**日期**: 2026-10-31
**腳本**: `scripts/19_four_wave_and_mod3.py`（log `data/run_19_four_wave.log`，dps = 80，等值判定閾 `1e−50`）
**性質**: 掃盡 `C(44,2) = 946` 個價對之 `γ`-和等值類；並給出 χ³／χ⁴ 選擇規則。
`N_trials = 0`。**零觀測量**。

**動機**：IDCM 之自耦合係 `V(W) = ½φW² + (ε/2)W⁴`（已註冊）⟹ **物理頂點係四波**。
而 `docs/16` 已證三波 χ³ 對三個共振三元組全為 0 ⟹ 必須查四波。

---

## 一、pair-sum 譜（四波能量守恒之等值類）

```
946 個價對之 γ_a+γ_b ⟹ 913 個等值類
類大小分佈 = {1: 900, 2: 12, 22: 1}
四波共振（同和、不同對）數 = Σ_k C(size,2) = **243**
```

## 二、22 類 = **對稱恆等式**（非場巧合）

```
γ_n = 2 − 2cos(4n°) ⟹ γ_a + γ_b = 4 ⟺ cos4a° + cos4b° = 0
                            ⟺ 4(a+b) ≡ 180 (mod 360) ⟺ a + b = 45（a+b ≤ 87 ⟹ 唯一解）
⟹ 恰 22 對：(1,44),(2,43),…,(22,23)    全部 γ_a+γ_b = 4（核：max|dev| < 1e−60）
⟹ 對**所有** a 成立 ⟹ 係 cosθ + cos(180°−θ) = 0 之**對稱恆等式**。
```

## 三、12 個雙元類 = **非平凡場重合**，全部在 mod-3 子晶格

```
(3,15)=(9,12)   (6,24)=(15,18)   (15,21)=(6,27)   (6,30)=(18,21)
(3,33)=(9,30)   (3,36)=(12,30)   (9,42)=(15,33)   (15,36)=(12,42)
(15,39)=(24,27) (18,39)=(24,30)  (21,39)=(27,30)  (33,36)=(30,42)
```

- **12/12 四個模全部 ≡ 0 (mod 3)** ⟹ 非平凡重合只發生於 `n = 3k`。
- 子晶格 = `3ℤ ∩ [1,44]` = `{3,6,…,42}`（**14 個模**）；子晶格價對 `C(14,2) = 91`，其中 24 對構成上述 12 個雙元類。
- 對照：**22 類（`a+b=45`）不受 mod-3 限制** —— 因為佢係對稱恆等式，唔係場重合。

## 四、子晶格約化：`γ_(3k) = 4sin²(kπ/30)` ⟹ **14 模 `/30` 鏈**

```
max|γ_(3k) − 4sin²(kπ/30)| = 8.43e−81（k = 1..14）
⟹ 共振活性扇區 ≡ 一條半週期 30 之鏈（k = 1..14；第 15 點係 Dirichlet 邊界節點，非模）
⟹ 該鏈之互補恆等式 γ_k + γ_(15−k) = 4 在 k = 1..7 內可實現（7 對）
⟹ 依 docs/14 之定律，該鏈之「規律型」三波共振須 a+b = 15 ⟹ 但 m = 15 超出 k ≤ 14
   ⟹ **規律型全部被 Dirichlet 邊界切斷**；餘下者即 docs/15 之 3 個「場型」三元組
```

⟹ **三個三元組之所以只有 3 個，係「鏈短一格」之結果**：`N = 44 = 45 − 1`。

## 五、χ³／χ⁴ 選擇規則（互補）

```
χ³ = Σ_p φ_aφ_bφ_m ：四項 k 同 parity ；S(k) = cot(kπ/90)（奇）/ 0（偶）
                  ⟹ **χ³ ≠ 0 ⟺ a+b+m 奇**
χ⁴ = Σ_p φ_aφ_bφ_cφ_d：八項 k 同 parity ；Σ_{p=1}^{44}cos(kπp/45) = 0（奇）/ −1（偶）
                  ⟹ **χ⁴ ≠ 0 ⟺ a+b+c+d 偶**  （值 = −(2/45)²，對所有允許者**相等**）
```

三個共振三元組 `a+b+m` 皆偶 ⟹ **χ³ 暗、χ⁴ 亮**。
物理解讀：IDCM 之頂點係 `W⁴` ⟹「三波暗」係**自然**（三波本非物理頂點），四波則允許。

## 六、一個未驗證之觀察（明示為觀察，非結論）

其中唯一**索引和 = 14**（= 子晶格模數）者係 {3,5,6} ⟺ n 空間 {9,15,18}
而 {9,15,18} 正是 docs/17 中**唯一完整落於 T_pipe 接收窗**之三元組。
⟹ 兩件事重合，但**未證**其必然關係（可能係 14 = 3+5+6 之算術巧合）。

## 七、判定

```
① 四波譜：913 類 / 243 個四波共振；22 類係對稱恆等式（a+b=45），12 雙元類係場重合。
② 非平凡共振**只**在 mod-3 子晶格（12/12），且子晶格 ≡ 14 模 /30 鏈（精確）。
③ χ³ 需奇和、χ⁴ 需偶和 ⟹ 互補；三元組「三波暗、四波亮」，與 W⁴ 頂點一致。
④ 三個三元組之數目 = Dirichlet 截斷（N=44 = 45−1）之結果，唔係獨立自由度。
⑤ 「3」之身份仍未定：現有三個候選（3 三元組／3 共用模／3 合成模），全部無觀測支持。
⑥ 未決：14 模子晶格是否即「味活性扇區」；四波頂點常數 `−(2/45)²` 全等 ⟹ 仍無荷差異。
```
