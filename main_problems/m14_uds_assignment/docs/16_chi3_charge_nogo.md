# docs/16 — 荷係數（χ³）：能量共振與宇稱禁戒**互斥**

**日期**: 2026-10-31
**腳本**: `scripts/17_chi3_charge_coefficient.py`（log `data/run_17_chi3.log`，dps = 40）
**性質**: 檢定 `docs/09 §五` 第 7 條（「係數由載體唯一決定」）在**三模頂點**定義下是否給出非平凡荷。
`N_trials = 0`。**零觀測量**。

## 一、候選定義（canonical，零參數）

```
C(a,b,m) = Σ_{p=1}^{44} φ_a(p) φ_b(p) φ_m(p)      φ_n(p) = √(2/45) sin(nπp/45)
```

閉式（`4 sinA sinB sinC = sin(A+B−C)+sin(A−B+C)+sin(−A+B+C)−sin(A+B+C)`）：

```
C = (2/45)^{3/2}/4 · [ S(a+b−m) + S(a−b+m) + S(−a+b+m) − S(a+b+m) ]
S(k) = Σ_{p=1}^{44} sin(kπp/45) = cot(kπ/90)（k 奇）／ **0**（k 偶）
```

**宇稱選擇規則**（數值核：`k` 奇 45 個 `max|Σ−cot| = 1.14e−38`；`k` 偶 44 個 `max|Σ| = 9.67e−39`）：
四項 `k` 之 parity 全部 `≡ a+b+m (mod 2)` ⟹ **`C ≠ 0` 要求 `a+b+m` 為奇**。

## 二、結果：三個共振三元組**全部** `C = 0`

| 三元組 | 四項 `k` | `a+b+m` | `C` |
|:--|:--|--:|:--|
| `{9,15,18}` | `6, 12, 24, 42` 全偶 | 42（偶） | **0**（`1.9e−42`） |
| `{9,27,30}` | `6, 12, 48, 66` 全偶 | 66（偶） | **0**（`1.1e−41`） |
| `{15,27,36}` | `6, 24, 48, 78` 全偶 | 78（偶） | **0**（`1.5e−42`） |

## 三、定理：能量允許 ⟺ 宇稱禁戒

```
三模互異（無序）三元組總數 = C(44,3) = 13,244
其中 C ≠ 0（a+b+m 奇）        = 6,622
能量共振集                     = 3 個 → {9,15,18}, {9,27,30}, {15,27,36}
交集                           = ∅     （全掃確認，無例外）
```

> **在 `/90` Dirichlet 載體上，冇任何三元組同時「能量共振」與「χ³ 耦合非零」。**

此為一條**雙重禁戒**：能量允許者耦合為零；耦合非零者能量不守。故三模頂點在本載體上
**永不**成為味對之載體。

## 四、對照：`/88` 環（平面波）

```
φ_k(p) = e^{2πikp/88}/√88 ⟹ C = (1/88^{3/2})·88·[a ± b ∓ m ≡ 0 (mod 88)]
⟹ 耦合 = 動量守恒 delta，滿足者**全部等值**（1/√88）⟹ 64 活價對等權，無荷差異。
```

## 五、判定（對 `docs/09 §五` 第 7 條之答覆）

```
① /90：三個共振三元組之 χ³ 全 0 ⟹ 荷係數 = 0（宇稱禁戒）
② /88：64 活價對之 χ³ 全等 ⟹ 荷係數 = 常數（無差異）
③ ⟹ 在 **三模頂點** 之定義下，「係數由載體唯一決定」給出的是 **0 或常數**，
     兩者皆**非平凡荷**。故此路不通。
④ 後果：味對之荷若要非平凡，載體須為
     (a) **二階**結構（質量矩陣／Gram，非三模頂點），或
     (b) **觀察者讀數**（`T_pipe` 投影 σ_n·A_n），或
     (c) 兩者之合成。
   此為下一步（未做）。
```
