## 三、對上游診斷之三條實質修正（本記錄新增，M4 可採納或反駁）

1. **「攻堅點＝矩陣元（波函數重疊）」把兩個不同物件混為一談**。本記錄判：
   - 可攻堅、且有外部錨者 = **`⟨O⟩_ch ≡ ∂M_h/∂(m_d−m_u)`**（isovector scalar density matrix element，即 M4 `docs/28` 之定義），5 錨：π 0（Dashen）／N 1.1263(185)／Σ 1.9090(158)／Ξ 2.1719(104)／K 2.4213(101)。
   - 無載體者 = **`⟨1/r_ij⟩`**（em 核之重疊期望，M4 `B3`）—— M5 已判零參數 `ψ(0)`／`(a₀,t)` 不可識別。
   ⟹ 兩者係**兩個缺口**，非一個。em 通道之可即時攻堅面在 `⟨O⟩_ch` 側（有 lattice 錨），`⟨1/r_ij⟩` 側現時無路。此為對 U5 之內容級修正。
2. **`E_ch` 之「混合量」性質可升級為定理級陳述**：不限於「混入強 IB 殘餘」，而是「在此算子類內 8 條中 5 條不可能」。M4 `docs/17/18` 之四族排除結論**不變**（其對象本來就是混合量），但命名宜由「em operator」改為「**IB 算子**」。
3. **歸一法警告（跨記錄引用風險）**：M4 `docs/28` 之 `⟨O⟩` 用 BMW lattice total 歸一；本記錄用「實驗 `Δm` − lattice QED」。兩法差 N +26.5%／Σ +27.4%／Ξ −5.3%（`docs/01 §四 C2`）。任何跨 M 引用必須註歸一法，否則等於換咗目標量。
