## 五、結論報告

1. **輸入層乾淨**（C1 PASS）：8 條 `Δm`、`E_ch` 由 PDG2024 質量獨立重現，`max|Δ| = 3.1e-5 MeV`。`docs/18` 表可作本記錄之上游輸入使用，但**只限 central value**（`σ_E` 誤差集未能完全反推，見 §七 B）。
2. **`E_ch` 不可作 `Ô` 之目標（🔴 本輪最硬判詞）**：在「兩體、正核、`S,P ∈ (0,1]`」算子類內，8 條中 **5 條不可行**，其中 `K⁺−K⁰`（em 必為正、數據為負）與 `Σ⁰−Σ⁺`（em 必為負、數據為正）屬**符號類**，與任何標度 `k₀` 無關 —— 即任何正核兩體算子、任何 a₀，皆不可能。此與 M4 `docs/27` 同判，但**路徑不同**：`docs/27` 係統計式（14.6σ），本輪係零統計之精確可行性。
3. **目標已釘死（C2）**：`⟨O⟩_ch = ∂M_h/∂(m_d−m_u)`，5 個外部錨值 ＝ **π 0（Dashen，恰零）｜N 1.1263(185)｜Σ 1.9090(158)｜Ξ 2.1719(104)｜K 2.4213(101)**。`⟨O⟩ = 1` 之偏差由 −100% 到 +142% ⟹ 上游 `X` 之「代數係數 = 1」假設在 8 條中無一條成立（除 π 之 0 屬另一機制）。
4. **存在性問題之可證偽形式（C4）**：`rank_ℚ = 13/16`、核維 3 ⟹ 只要求「重現 8 條 Δm」之任何 `Ô` 都可被 3 維平移吸收，問題**空泛**。可證偽形式 = `Ô` 須同時（i）給出 5 個錨值、（ii）定出 3 條自由通道之 `(⟨O⟩, em)` 分割（out-of-sample）。
5. **尺度診斷（C11，條件式）**：`k_req/k₀` 由 0.507 到 2.367（4.7×）⟹ **無單一兩體尺度可覆蓋 8 條**；且 `Σ⁻−Σ⁺` 需 2.37×、`Ξ` 需 1.72× ⟹ 兩體 Coulomb 即使放大亦不足。此為 M5 側「一體 EM 自能必需」之**獨立支持**（兩側路徑不同：M5 走束縛能上界，本輪走箱可行性）。
6. **結構讀數（定性，留 R2 用）**：`⟨O⟩` 隨奇異數上升 —— N（0 s）1.126 → Σ（1 s）1.909 → Ξ（2 s）2.172；但 K（1 s̄，meson）2.421 **高於** Ξ ⟹ `⟨O⟩` 非單純奇異數函數，meson／baryon 之分類亦入；π 恰 0（G-parity ⟹ 強 IB 分量消失）。此三特徵係 R2 之首要定性靶。

## 七、誠實標記（限制與已知弱點）

- **A｜C1 係 reconstruction，非獨立量度**：質量值取自 PDG2024（`docs/18` 宣告之來源），本輪只驗內部算術一致，不構成對 PDG 之獨立核實。
- **B｜`σ_E` 未能完全復現**：`Σ⁻−Σ⁰` 0.1015 vs 0.1010、`Ξ` 0.2318 vs 0.2301、`D` 0.1176 vs 0.1172、`K` 0.0962 vs 0.0963 ⟹ `docs/18` 之誤差集未明載，反推有 ≤0.8% 差。本輪結論（C4／C9）**不依賴** `σ_E`；C2 之 `σ⟨O⟩` 用本輪自算值。
- **C｜C9 之條件**：依賴 H2 之分解（自重項與對項共用歸一化重疊 `S,P`）＋正核＋`S,P ≤ 1`。符號類判詞**不依** `k₀`／`a₀`，但**仍依** H2 之分解假設；若放棄分解（改為逐對權重），符號仍受「`Δ(q_iq_j) > 0` ⟹ 該對貢獻為正」之逐項約束，但不再有單一 `P`。此為 R2 必須處理之接口。
- **D｜`k₀` 之身份**：`k₀ = α ħc/a₀` 含 M5 之現象學輸入 `a₀`（`ħc/a₀ = 0.514 GeV`）⟹ 幅度類判詞（π 1.08×、Σ⁻−Σ⁺ 2.37×、Ξ 1.72×）標「條件式」；π 之 1.08× 落於 `a₀` 不確定帶內，只 Ξ／Σ⁻−Σ⁺ 為穩健超界。
- **E｜BMW 錨之通道指派**：BMW TABLE I 之「Σ」本記錄取 `Σ⁻−Σ⁰`，「Ξ」取 `Ξ⁻−Ξ⁰`；若原表取向不同，N/Σ/Ξ 之 `⟨O⟩` 需重算（`Σ` 一項影響最大，σ 亦最寬）。
- **F｜Dashen 只到 leading order**：`⟨O⟩_π = 0` 係 `O(δm)` 陳述，非精確零；π 之錨因此屬「結構性錨」，不計入統計自由度。
- **G｜`docs/28` 數值不可直引**：兩套歸一法差 +26.5%／+27.4%／−5.3%；引用時必須註明歸一法。
