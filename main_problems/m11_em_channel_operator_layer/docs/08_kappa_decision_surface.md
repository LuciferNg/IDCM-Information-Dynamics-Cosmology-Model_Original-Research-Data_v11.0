## 一、問題定性

κ 在 M5 形狀族中係「**鏈扇區佔 D 接觸振幅之份額**」：`A_D = A(a,t) + κ·g(7)·q_C`、`c(a,t) = C_D`。每個 κ 都**精確重現 D 兩數**（殘差 < 1e−9），只係 (a, t) 隨之變 ⟹ **κ 完全未被 D 約束**。故「κ 正典」不是文獻裁決問題，而是「**用邊個第三約束去釘死它**」之問題。

而 M11 每一條判詞都經 `k₀ = α·ħc/a₀` 依賴 a₀ ⟹ κ 之未定直接污染 M11 全部定量結論。

## 五、κ 之三條釘死路線（依強度排）

### A｜K 兩數最小 χ²（可用、純 M5 數據、對 M11 為盲）

```
κ = 0.300     χ² = 4.163（dof = 1）⟹ 2.04σ
Δχ² ≤ 1 帶：κ ∈ [0.2975, 0.3050] ⟹ a₀ ∈ [0.18424, 0.18955] fm、k₀ ∈ [7.597, 7.816] MeV
該帶：K 束縛 ✓（d_peak = 2）、接觸 ≥ 0 ✓、M11 判詞 R1 3/8、A/B/C/D 全 0/3 失敗
```
- 與 M5 `docs/19` T5（`χ² = 4.163 @ κ = 0.300`、2.04σ）**獨立重現一致**。
- 殘差之來源係 `z₂ ≈ −2.01` 且**與 κ 無關** ⟹ 係模型對 K 之結構性張力，非 κ 可修。
- **代價**：用 K 釘 κ ⟹ K 不再是盲測（1 參數、dof=1）。

### B｜生產約定 κ = 0（M5 `docs/13`）

`a₀ = 0.377422 fm`。**無推導支撐**——它只是「不加鏈份額」之約定；M11 現行全部判詞只在這一點成立。

### C｜結構判準（未做，唯一零參數路線）

若鏈扇區與接觸扇區源自**同一算子**（IDCM 單算子立場），則兩項係數比應由譜結構定 ⟹ κ 應**算出**而非擬合。需 M5／M7 給出兩項之 operator identity（M7 `docs/10` 之 weight 約定 `N_d v²` vs `v²` 係**同一自由度之另一面**，須一併釘）。
