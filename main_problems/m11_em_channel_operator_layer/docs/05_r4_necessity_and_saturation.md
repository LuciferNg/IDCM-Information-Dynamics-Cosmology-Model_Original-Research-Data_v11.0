## 五、判詞與必要性定理

**T-N1（I2 必需，🔴 已立）**：無 iso-breaking 頂點 ⟹ `∂M/∂(m_d−m_u) ≡ 0`（`m_k = M₀γ_k` flavour-blind；M5 `docs/43 ④`／`docs/45 ③`）⟹ `⟨O⟩ ≡ 0`，與 4 錨（1.13–2.42，最低者亦 6.1σ 遠離 0）矛盾。

**T-N2（I3 必需，🔴）**：通道無關模型 A ⟹ 錨層 `z = 5.71` 判死，且盲測箱再失敗 1/3。即：`⟨O⟩_ch` **唔可以**只是「被替換夸克」之函數。

**T-N3（`ns` 依賴必需，🔴）**：只記 `n_q` 之模型 B ⟹ 錨層 `z = 4.56` 判死，盲測箱再失敗 1/3（`D⁺−D⁰` 越界）。

**T-N4（`n_q` 依賴，🟡）**：只記 `ns` 之模型 C 錨層僅 `z = 2.74`（TENSION，**未達** 3σ），但盲測箱 2/3 不可行 ⟹ OUT。惟越界幅度邊際（`S0-S+` 只超界 1.8%）⟹ 此判詞標 🟡，不得當硬否證。

**T-N5（飽和定理，⚫ 關鍵）**：唯一存活者 D 之 4 個類別 `(3,0) (3,1) (3,2) (2,1)` **各吃一個錨** ⟹ `dof = 0`。
⟹ **錨集已耗盡**：D 唔係「被證實」，而係「無殘餘自由度可被檢驗」。任何比 `(n_q, ns)` 更細之結構（模波函數權重、譜重疊、通道權重）**在現有數據下不可鑑別**。

**系定理（對 `⟨O⟩` 身份之裁定）**：`⟨O⟩_ch` 必須係**強子量子數 `(n_q, ns)` 之函數**，而唔係「被替換夸克」之函數。故 `docs/03 §六` 之 I3 應正名為「**通道狀態依賴**」，而非「通道權重」——權重屬 D 之下層，已被 N5 判為不可鑑別。

## 七、誠實標記

- **A｜盲測箱係「必要條件」非充分條件**：箱由 `k₀ = 3.7508 MeV` 與 `ΔΣq², ΔΣqq` 構成（`data/01` C9），只係包絡。通過箱 ⟹ 未被排除，唔等於正確。

- **C｜`k₀` 之粗細**：`k₀` 取自 C9 之譜估計，若 `k₀` 上調 5%，C 之兩條越界會縮至 ~0.646／0.903（前者變可行）⟹ C 之排除對 `k₀` 敏感。
- **D｜「無預言」亦係結果**：D 飽和 ⟹ 其兩條 Σ 預言只是「類別內插」，非由結構算出。不得宣稱 M11 已推導出 `⟨O⟩`。
