## 四、發現

**F1（定義，最重要）** `E_ch` **唔係純 em**。以 lattice 錨 `em(K⁺−K⁰) = +2.26459` 核：`E_ch(K) = −1.3740` ⟹ 強 IB 殘餘 `= −3.639 MeV`，**大於** em 本身（2.265）。故 M4 `docs/17/18` 四族排除係**以混合量為對象**之測試；其結論不變，但「em operator」之名需更正為「**IB 算子**（強 IB ＋ em 兩項）」。

**F2（QN 盲，獨立再證 O124）** QN 差矩陣 rank = 2（僅 ΔQ、ΔI₃；ΔB/ΔS/ΔC 全零）。同 (ΔQ=−1, ΔI₃=0) 群：K −1.374、Σ⁻−Σ⁰ +2.247、Σ⁰−Σ⁺ +0.712、Ξ⁻−Ξ⁰ +4.290 ⟹ 盲區 **5.664 MeV**。QN-only 算子在結構上不可能。

**F3（pairwise 環核之成績與失敗模式）** 混合對象上 5/7 符號對、χ² = 1184；但**純 em 側**（K 通道，單位耦合、零擬合）**−11.1%** 命中 ⟹ 環核作為 em 部分**有理**。兩處反號（K、Σ⁰−Σ⁺）恰好係「被替換之輕夸克緊鄰最重 spectator」者 ⟹ 反號源自**缺強 IB 項**，非核形狀本身。

**F4（強 IB 非普適）** `R/X ∈ [−1.32, +1.36]`，spread 2.68 ⟹ 單一 `⟨O⟩` 因子不可行（**獨立再證** M4 `docs/13` 之 `⟨O⟩` 死因，而唔需引用其 16σ 結果）；且 \|R\|max/\|E\|max = 0.81 ⟹ 強 IB 主導。

**F5（算子結構推論）** 可行算子 = **兩項**：
```
E_ch = em[環核 g(d), 單位耦合] + strong-IB[非普適因子 f(ch)]
```
第二項之非普適性 ⟹ `f` 必須 state-dependent ⟹ 仍需 mode-level 佔用資訊。U5 由「一個未建立算子」細化為「**兩項結構 ＋ 一個非普適因子**」——攻堅面收窄，且 `em` 項已有零參數、−11% 級之立足點。
