## 四、判詞

### 4.1 溯源缺陷（🔴 已定，非本輪引入）

M11 之 `ħc/a₀ = 0.514 GeV` 係 **M5 校準值的四捨五入繼承**（真值 0.522 828 GeV）。兩個後果：

1. `k₀` 低 1.69%（3.7508 vs 3.8153）⟹ R4 之 `t` 值全部偏高 1.7%。〔**溯源更正**：514.0 MeV 並非 522.828 之四捨五入，而係 M5 **v2 `docs/28`（`ħc/a₀ = 0.5136262 GeV`）** 之四捨五入；v2 已被 `docs/13` 重校取代（見 §八）〕
2. 但**不足以翻轉任何判詞**：`C` 之約束通道需 `k₀ ≥ 5.3358`，距 3.8153 仍差 40%。故 R4 結果穩健。**惟溯源須更正**（見 §六 建議）。

### 4.2 零參數性：`k₀` 屬「中間標度缺口」（🔴）

存貨內長度只有三個數量級：宇宙（`R_world`、`r_d`、`λ_sync`，10²¹–10²³ fm）、電弱（`ħc/v_SM`，10⁻⁴ fm）、Planck（10⁻²⁰ fm）。
唯一落 fm 數量級者 = `ħc/Λ_IDCM = 4.357 fm`，距所需 0.384 fm **11.35×**，且該比值非任何已註冊結構整數。

⟹ **v11 存貨內不存在 0.1–1 fm 之結構長度**；`a₀` 只能由 M5 之 D 通道兩參數 `(a₀, t)` 校準 ⟹ **`k₀` 非零參數**，與 O38 `M₀` 之標度缺口同族（同一類「中間標度缺失」）。

**禁**：以「4.36 fm 與 0.38 fm 同屬 fm 級」宣告推導（R5-4）；以 `11.35 ≈ 2π×1.8` 之類凑數。

### 4.3 靈敏度定理（本輪主結果，✅）

- **錨層判詞完全與 `k₀` 無關**（`⟨O⟩` 只用質量差，不含 `a`）⟹ `T-N2`（`z=5.71`）與 `T-N3`（`z=4.56`）係**硬判**，不受 `a₀` 不確定性影響。A／B 於所有 `a` 支皆「錨死」。
- **盲測箱是唯一含 `k₀` 之閘**，且只在其「幅度」面；「符號」面（`em` 之正負）與 `k₀` 無關。
- `k₀^crit` 排序：`D 2.5425 < A 4.0730 < B 4.1358 < C 5.3358`（MeV）。`k₀` 越大（`a` 越小），越多模型能過箱。
- **全局門檻**：`k₀ ≥ 5.3358 MeV`（`a ≤ 0.26987 fm`）時**四模型全部**通過盲測箱 ⟹ **箱之鑑別力歸零**。

## 五、誠實標記

- **A｜`a` 之兩支皆非定論**：`a = 0.377422`（M5 κ=0 主校準）與 `a = 0.243274`（κ=0.215 天花板）皆在 M4 `docs/26` 之窗內／窗外判詞中出現，本輪**不裁定**哪支為正典（屬 M5 問題域）。故 T-N4 之最終判詞須待 M5 定 `κ`。
- **B｜箱本身係必要條件**：`k₀^crit` 只是一條界，過箱不等於正確（`docs/05 §七 A`）。
- **C｜`X` 之 1σ 已掃（§三 E）**：`k₀^crit(C)` = 4.6949／5.3358／5.9767 MeV（X−1σ／X／X+1σ）⟹ `a^crit` = 0.30671／0.26987／0.24093 fm（±12%）。
  `κ=0`、`M11`、`窗界` 三支在整個 X±1σ 帶內**皆被排除**；`κ=0.215` 支在 X 與 X−1σ 存活，但 **X+1σ 時被排除**（`a=0.24327` vs 界 `0.24093`，邊際 **1%**）⟹ `κ=0.215` 支之判詞對 `X` 敏感。
- **D｜`ħc/Λ_IDCM` 之 11.35× 不作任何解釋**：只作「存貨內無 fm 級結構量」之證據列示。
