## 一、OA1 —— 逐粒子命名算子：已註冊標籤下**不存在**

### 定理 M19-N1

```
命名算子 = f : 粒子側標籤 tuple → M9，要求雙射（9 粒子 ↦ 9 模式）
雙射可行 ⟺ |image(f)| = 9 ⟹ 需 ≥ 9 個可區分粒子類
```

### 實算：已註冊標籤之可區分類數

| 標籤子集 | 類數 | 內容 |
|:--|:-:|:--|
| `{χ}` | **2** | `{1}`（e,μ,τ,u,c,t）／`{3}`（d,s,b） |
| `{Q}` | **3** | `{−1}`／`{+2/3}`／`{−1/3}` |
| `{B−L}` | **3** | `{−1}`／`{+1/3}`／`{−1/3}` |
| `{χ,Q}`／`{χ,B−L}`／`{Q,B−L}` | **3** | 三者互為冗餘（χ 由 B−L 定） |
| `{χ,Q,B−L}` | **3** | 最強組合仍只 3 類 |

```
max = 3 < 9  ⟹  任何以已註冊標籤定義之命名算子，image ≤ 3
             ⟹  雙射命名算子**不存在**（鴿籠；枚舉核亦 0）
```

### ★ 救命條件（唯一）

```
加入「世代」標籤（3 值）⟹ 類數 = 3 × 3 = 9 = |M9|  ⟹ 恰好可行
```

但世代標籤 `d ∈ {3,2,0}` 已被 **M14 `docs/03`** 判：
① **範疇錯置**（ℤ₂ 只給 2 類，不可能給 3 個世代）；② AST 追溯為**純字面值**（v9 六處硬編碼，零上游推導）。
⟹ 世代標籤**未註冊**，且其原形式已判死；要救活須以**新結構**重新導出世代（屬 M13／M14 上游）。

**判（OA1）**：🔴 **不存在命名算子**；阻塞點精確 = 「世代標籤未註冊」。此判與 `docs/03` 之「值層 = 質量 rank 輸入」互為獨立印證（兩條不同路線，同一結論）。

## 二、OA2 —— 容許矩陣權重比：**非獨立信息**

### 實算

```
A[quark][≡1 欄]   = 3!·5!      = 720
A[quark][非 ≡1]   = 4·3!·5!    = 2880
比                = 1 : 4  = 1/#{≡1 槽} = 1/4        （精確 Fraction）
```

### 關鍵檢定：條件化 vs 不條件化

| 先驗 | quark-at-≡1 | quark-at-非≡1 | 比 |
|:--|:-:|:-:|:-:|
| 均勻 over **admissible**（S1 條件化） | 720/17,280 = **1/24** | 2880/17,280 = **1/6** | **1:4** |
| 均勻 over **全部 9!**（不條件化） | **1/9** | **1/9** | **1:1** |

**⟹ 1:4 完全由「條件化於 S1」產生，唔係獨立信息。**

用該比去「支持」某指派 = 用 S1 之條件化去支持 S1（循環）。要令它變成證據，須有一個**生成指派的動力學**（physical prior）；本輪掃全 `main_problems`（排除本 M）之「指派動力學／生成律／轉移」關鍵詞：**零命中** ⟹ v11 無此物件。

**判（OA2）**：🔴 **不可作弱判別**（現有結構下）；與 `docs/04` §二 D6「720 vs 2880 係計數效應」一致。
