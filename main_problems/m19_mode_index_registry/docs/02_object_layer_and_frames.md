## 二、F1 / F2 之精確關係：同一物件嘅兩個方向

```
C3  F2 = F1 ∘ (9 模式集反序)          —— 逐位核對 PASS
    e13 u11 d9 s7 μ5 c4 τ3 b2 t1  ⟵ F1_rev（腳本實印）
C4a F1 與質量升序逐位相同：e u d s μ c τ b t
C4b F2 與質量降序逐位相同：t b τ c μ s d u e
C7  ⟹ 兩者只差 **1 bit（方向）**，其餘完全相同
```

**★ 由此立一條硬事實**：`F1` 與 `F2` 唔係兩個互相競爭嘅「理論」，而係**同一個次序嵌入之兩種取向**。任何「F1 對 / F2 錯」之裁決，其全部內容 = 決定邊一端為重。

## 三、F3 唔係同一層物件（C5）

```
F3 之 n 值 = {1,1,1,7,14,20,33,34,44}
  ⟹ 重複：n = 1 出現 3 次（e, u, d 同模）
  ⟹ 9 個粒子中 5 個落喺 9 模式集外（τ20, s14, c34, b33, t44）
⟹ F3 唔可能係「粒子 ↦ 模式」之雙射
```

F3 屬 **M1/M2 之帳本編碼層**：`m = M₀ Σ_n σ_n γ_n`（`σ ∈ [0,1]^44`），一個粒子一般係多模支撐；`C_f` 只係把殘餘吸收落 `n` 該模。此層**唔需要、亦唔可能**有單一 `k_q`。

**⟹ 層分離（本 M 第一個結構結論）**：

```
索引層（Layer A）：粒子 ↦ 單一模式 n          ← F1 / F2 住喺此層
支撐層（Layer B）：粒子 ↦ σ ∈ [0,1]^44       ← F3 住喺此層；M1/M2 正典
```

`k_q` 只喺 Layer A 有意義；講 `k_q` 而未聲明層位，等於偷渡「單模支撐」假設（見 §五）。

## 五、★ 前提審計：`k_q` 本身預設咗「單模支撐」

```
k_q 存在 ⟺ 粒子之 σ 支撐 = 單一模式
但 Layer B（正典）容許任意 σ ∈ [0,1]^44
⟹ 「k_q」唔係 Layer B 之導出量，而係加插一個**支撐坍縮假設**（σ = C_f · e_n）
```

該坍縮假設在 v11 **無任何記錄**（M1 只做格式層；M2 之泛函係多模）。故 `k_q` 之身份 = **輸入（假設）＋ 排序規則**，唔係譜結構量。
