## 二、殘量與位元（B1–B7）

```
ρ_struct = 4（≡1 四槽中取三給輕子）× 3!（輕子次序）× 6!（其餘 6 粒子）
         = 17,280 = 9! / 21                          [實跑：17,280 ✓]

結構位元 = log₂(9!/17,280) = log₂21      = 4.392317 bit
輸入位元 = log₂17,280                    = 14.076816 bit
合計                                    = 18.469133 bit = log₂9!
```

**★ 21 = 9!/4!·3!·6! 之倒數比**（`362880/17280 = 21`）—— 即結構只砍走 21 分之一。

## 四、位元分解之意義

```
4.392 bit（結構）：唯一來源 = T3 槽定理（χ 類 ↔ n mod 4 類）
                  —— 且係「類別」級，唔係「值」級
14.077 bit（輸入）：全部係類內次序，只能由觀測質量 rank 給
```

**反事實閘（B7）**：若 T3 槽定理被撤回 ⟹ `ρ_struct = 9!` ⟹ **結構位元 = 0** ⟹ `k_q` 全部 18.43 bit 皆輸入。

## 五、★ T1 判（k_q 結構 vs 輸入）

| 層 | 內容 | 判 |
|:--|:--|:--|
| 模式**集** `{1,2,3,4,5,7,9,11,13}` | A₅ chiral 60-orbit 動差準則（奇 n≤13、偶 n≤4） | ✅ 結構（v10 O136 `docs/19`；v11 未註冊 ⟹ 本 M 登記引用） |
| **類別分割** {e,μ,τ} ⊂ {1,5,9,13} | T3 槽定理 × 群層 iso `Φ: Ŝ↦z`（🟡⁺，common measure 永久 no-go 為其正確上限） | ✅ 結構（4.392 bit） |
| **值**（邊個粒子落邊個模式） | 質量 rank（γ 升序 ⟹ 質量升序，`docs/01` §二 定理） | 🔴 **輸入**（14.077 bit，dof = 9 − 0 結構自由度在值層） |

**結論**：`k_q` 唔係「結構量抑或輸入」之單選題，係**混合量**：**類別 = 結構（4.392 bit）；值 = 輸入（14.077 bit）**。任何把 `k_q` 當零參數結構量使用之數值評估，實際上有 14.077 bit 係由觀測（質量次序）餵入。

## 六、判

- T1 **判為「混合」**，唔係原假設之二元。原命題 `k_q = γ_n 譜上之某結構標記`：
  - 若「標記」指模式**集**或**類別** → ✅ 成立；
  - 若指**逐粒子之 n 值** → 🔴 不成立（值層由質量 rank 定，屬後驗輸入）。
- 禁區遵守：本輪**零**由質量反解指數；質量只用於「排序」與「C_f 展示」，且已標輸入。
