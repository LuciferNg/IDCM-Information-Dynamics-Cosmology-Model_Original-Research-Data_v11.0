## 二、譜定理（本輪新增，恆等式級）

```
γ_{n+1} − γ_n = 4 · sin(π/88) · sin((2n+1)π/88)          （sin²A − sin²B = sin(A+B)sin(A−B)）
n = 1..43 :  兩個正弦因子皆 > 0  ⟹  Δγ_n > 0 恆成立
```

實算核對：43/43 逐點與恆等式差值 `|Δγ − 恆等式| < 1e−50`；最小值落喺 `n = 43`（`γ₄₄ − γ₄₃ = 0.005095770779`）。

**推論（本 M 全部結論之基石）**：

```
γ 喺 n = 1..43 嚴格遞增  ⟹  γ_n 之次序 = n 之次序
⟹ 任何「依質量由細到大排」嘅映射，落 9 模式集上，其像之次序被 γ 次序**唯一鎖死**
   ⟹ 次序嵌入（order embedding）唯一：第 r 輕 ⟹ 第 r 小模式
```

即：`k_q` 若由質量次序定，佢唔係「由譜推出嘅身份」，而係「質量次序嘅重新編碼」。此點於 `docs/03` 量化。
