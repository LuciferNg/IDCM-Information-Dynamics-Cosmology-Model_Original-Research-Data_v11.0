## 一、T2：`s` 三讀 {4, 5, 7} 之結構判別力 = 0

**凍結判準（record §二 T2）**：「若三讀皆可容 ⟹ 零判別力，🔴」——本輪觸發。

```
s→4 : 2,880 個 S1 可行雙射
s→5 :   720
s→7 : 2,880
```

三讀皆 > 0 ⟹ **結構唔排除任何一讀**。原因：`s` 係夸克（`B−L ∉ ℤ`），T3 對夸克唔施加 ⟹ 夸克支撐 = 全 9 模式（`docs/03` §三）。

**逐讀判**：

| 讀 | 結構可容？ | 值層地位 |
|:-:|:-:|:--|
| **4** | ✅（2,880） | 質量 rank：`u<d<s<c<b` ⟹ 模式 `2<3<4<7<11` ⟹ `s = 4`（**輸入**） |
| **5** | ✅（720） | `s` 佔 ≡1 槽 ⟹ 需輕子遷出該槽；與 F1 衝突（`μ` 被擠）⟹ 純排序上不成立 |
| **7** | ✅（2,880） | 需與 `c` 對調 ⟹ 違反類內質量次序（`s < c`）⟹ 純排序上不成立 |

**判**：`s = 4` 係**正典值**，但其地位 = **輸入（質量 rank）**，唔係結構推導。
與 M12 `docs/17` §四之「R4-O4 三讀全死」並無矛盾：彼處「死」係指形狀族 `δ_x` 測試全部不中；本輪指出**更深一層**原因 —— 三讀本來就冇結構判別力。
