
## §2 定理 M16-1（歸約；覆蓋所有階，無上界）

```
C(G)  ⟺  DNT(G) = {3,4,5}  ∧  |G| = 60
```

**證**：`docs/01 §2` L2+L3 給 `⟹`（8 個 Σ=12 候選集，只有 {3,4,5} 過 `∏ > Σd²`）；`⟸` 直接。

## §4 度集 `{3,4,5}` 之來源：鏈波段指數（上游，唔在本 O 重推）

```

```

⟹ **群選擇問題 = 「三個扇區數之帶指數」呢個對應**，而唔係「揀群」。
一旦 `{33,44,55}` 與 `420` 釘死，群已被逼為 A₅（定理 M16-1 + 階 60 之 13 群完備枚舉，見 `docs/04 §2`）。

| 群 | DNT | Σ | ∏ | 需要嘅扇區（×L₅） | 實際家族成員 |
