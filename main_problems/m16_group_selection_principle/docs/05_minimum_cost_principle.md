## §2 Q2：**唔係「非唯一、但最低成本」—— 係嚴格最小、唯一解**

```
DNT ⊇ {3,4,5} 之群（階 ≤ 500）        = 24 個
其中 |G| 不被 60 整除者                = 0     （度必整除群階 ⟹ 3,4,5 | |G| ⟹ 60 | |G|）
min |G|                                = 60
達到者                                 = 1 個 = A₅（SmallGroup(60,5)）
```

⟹ 最小值由**整除性硬逼**，唔係靠比較得嚟；且 A₅ 達到 ⟹ **零 tie、零 tie-break**。
「非唯一性」之前提不成立：在度集約束下，最低成本 = 唯一解。

## §5 Q1：邊啲成本函數先有嚴格最小

在 11 群族上逐個試（argmin 是否唯一）：

| 成本 | min | argmin |
|:--|--:|:--|
| **\|G\| = Σd² = 預算分母**（狀態數） | 60 | **★唯一 = A₅** |
| **類數**（irrep 數／通道數） | 5 | **★唯一 = A₅** |
| **k = \|G:G'\|**（未區分通道） | 1 | **★唯一 = A₅** |
| max 維數（最大單扇區） | 5 | tie 11（全部 5） |
| #DNT（相異扇區數） | 3 | tie 11（全部 3） |
| Σ_{DNT} d（和） | 12 | tie 11（恆 12） |

⟹ **總量型成本**（數盡所有狀態／通道）有嚴格最小；**形狀型成本**（只看度集統計）對 abelian 膨脹**全盲**，11 群平手。
物理上「運行成本」只能係總量型（運行 60 個狀態 vs 120 個狀態係有分別；扇區形狀一樣冇用）。
而總量型成本 = `|G|` = `Σd²` = **預算分母本身** ⟹ 成本唔係外加概念，佢就係 60。
