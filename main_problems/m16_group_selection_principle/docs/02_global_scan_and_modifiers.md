## §4 ★ look-elsewhere（R4）

### §4.1 常數掃描（這是最直接嘅量度）

固定 `∏(DNT) = |G|`，掃 `Σ(DNT) = c`，`c = 1..40`：

```
有命中者：c ∈ {12, 15, 17, 19, 21}        （其餘 35 個 c 全空）
唯一命中 A₅：c = 12                        ← ★
c = 15 → 8 群（∌A₅）；c = 17 → 4 群；c = 19 → 2 群；c = 21 → 1 群（非 A₅）
```

★ 誠實：`15 = N_gen·F₅` 亦係 IDCM 結構數（O171 `final_result.md:223`），且 `15 = Σ(DNT)` 正是 **S₅**。
準則取 12 而唔取 15，代價 = 以下游戲：40 個常數中 5 個有命中、1 個命中 A₅ ⟹ **粗略 look-elsewhere 1/5**。
但 12 並非自由：`12 = Σ{3,4,5}` = 三個鏈波段指數之和（見 `docs/03 §4`），係由扇區數 33/44/55 反推，唔係揀出嚟。

### §4.2 準則族（selector × feature × target）

```
|F| = 434 條（selector ∈ {DNT, NT, DALL, ALL} × feature ∈ {∏, Σ, Σd², #}
              × target ∈ {|G|} ∪ {1..30}）
單條即唯一命中 A₅：0 條（A₅ 從不由單條選出）
含 A₅ 之單條     ：10 條
兩條聯合：可測 45 對（兩條皆含 A₅ 者），其中恰好唯一命中 A₅ = 17 對
⟹ look-elsewhere 率 = 17/45 = 37.8%
```

★ 解讀（誠實）：37.8% **唔等於**「準則係亂揀」。17 對之中大部分彼此**邏輯等價**（同一個 A₅ 維數多重集之唔同寫法：
`NT.sum=15`、`ALL.sum=16`、`DALL.sum=13`、`DALL.count=4` 全係 A₅ 度集 [1,3,3,4,5] 之重述）。
真正嘅信息係：**準則之「形式」冇特權，其「內容」= A₅ 之度多重集才有特權**。
⟹ 本 O 之正確表述唔係「兩條條件聯合選出 A₅」，而係「兩條條件**同義於**一個度集」；
「為何係嗰個度集」= 上游問題（`docs/03 §4`）。
