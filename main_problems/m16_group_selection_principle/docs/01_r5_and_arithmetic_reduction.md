## §2 四條引理

**L1（Burnside）** 對任何有限群 `G`：`Σ_{χ∈Irr(G)} χ(1)² = |G|`。
⟹ 單獨使用零鑑別力（`SESSION_START` 陷阱① 正確，但需精確化：**單獨**零鑑別力）。

**L2（乘性-加性夾逼）** 設 `DNT = {d₁,…,d_r}`（相異、≥2）。每個 `d∈DNT` 至少出現一次，且 trivial 特徵標貢獻 `1²`：

```
|G| = Σ_{χ} χ(1)² ≥ 1 + Σ_{d∈DNT} d²  >  Σ_{d∈DNT} d²
而準則第一條要求 |G| = ∏_{d∈DNT} d
⟹ 必要條件：  ∏_{d∈DNT} d  >  Σ_{d∈DNT} d²          （★ 本 O 之殺手）
```

**L3（Σ=12 之窮盡）** 相異整數（≥2）和為 12 之集合**恰好 8 個**：

| S | ∏ | Σd² | L2 |
|:--|--:|--:|:--:|
| {12} | 12 | 144 | ✗ |
| {2,10} | 20 | 104 | ✗ |
| {3,9} | 27 | 90 | ✗ |
| {4,8} | 32 | 80 | ✗ |
| {5,7} | 35 | 74 | ✗ |
| {2,3,7} | 42 | 62 | ✗ |
| {2,4,6} | 48 | 56 | ✗ |
| **{3,4,5}** | **60** | **50** | **✓（唯一）** |

⟹ **`|G| = 60` 被逼**，且 `DNT = {3,4,5}`。**冇用任何群表、冇用任何階上界**。

**L4（重數閉合）** `|G| = 60`、`DNT = {3,4,5}`，寫重數 `a,b,c ≥ 1`、線性特徵標數 `k = |G:G'| ≥ 1`：

```
k + 9a + 16b + 25c = 60   ⟹   只有兩解
   (a,b,c,k) = (1,1,1,10)    |G'| = 6
   (a,b,c,k) = (2,1,1, 1)    |G'| = 60   ← A₅
```

即：度集 `{3,4,5}` 之下，容許之群**只有兩種多重度型**；第二型 = 完備群（`G=G'`）。

## §4 附帶發現：`Σ = 12` 與 `B(B−1)` 之算術鎖

設 `DNT = {B−1, B, B+1}`（以 Nyquist `B = γ_max` 為中位），則 `Σ = 3B`；
IDCM 之計數要求 `Σ = γ_max(B−1) = B(B−1)`：

```
3B = B(B−1)  ⟹  B = 4（唯一解）
⟹ 唯一自洽之 (B, DNT) = (4, {3,4,5})，∏ = 3·4·5 = 60
```

`B = γ_max = 4`（Nyquist，M15 `docs/17` 精確鎖死）、`B−1 = 3`（階 4 分支群之非平凡特徵標數）
⟹ 12 = 4·3 有上游身份。**但「Σ_{DNT} d 必須 = B(B−1)」本身仍係一條額外陳述**（見 `docs/03` §3）。
