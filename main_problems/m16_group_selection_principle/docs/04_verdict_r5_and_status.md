## §2 A₅ 之終局地位

```
A₅ = 輸入？                         ❌ 否
A₅ = 事後凑數？                     ❌ 否（度集由三個獨立扇區數供給）
A₅ = 條件導出（零額外自由度）        ✅ 是
```

形式陳述：

```
已知（上游，已計代價）
  S1  三個表層扇區數 33 = K_tree、44 = N_d、55 = F₁₀            🟢
  S2  鏈波段律 #{γ_k ≤ γ_{nR}} = nR  ⟹ 帶指數 = (33,44,55)/11 = (3,4,5)   🟢 為算術
      （帶指數之選擇代價 1/C(8,3) = 1.79%，O171 docs/09 R1b）  🔴 來源遺留 → MR3
  S3  表層 = 單一 irrep 維數 × L₅；深層 = |G| × L₄              🟡 型別識別 → MR1
  S4  深層 420 = L₄·60  ⟹ |G| = 60                             🟡 識別循環 → MR2
────────────────────────────────────────────────
推出（本 O，零假設）
  T1  C(G) ⟺ DNT(G) = {3,4,5} ∧ |G| = 60                       ✅ 定理（docs/01）
  T2  |G| = 60 之 13 群中唯一符合者 = A₅                        ✅ 定理（GAP 完備枚舉）
  ⟹  G ≅ A₅，自由度 0，新增假設 0
```

**判詞**：`A₅ = 條件導出`。剩餘缺口全部係上游 `O171` 之 `MR1/MR2/MR3`，**唔在群選擇**。
「為何係 A₅」之最終答案 = 「因為三個扇區數落喺帶 3,4,5，而階 60 之群中只有 A₅ 之相異非平凡維數恰為 3,4,5」。
