> **狀態**: ⚪ **已註冊、未開推**（本 session 只建三件套；待其他 session 承接）

## 1. 問題陳述

`M15 docs/25` 證：A₅ 之不可約表示維數 `d = [1,3,3,4,5]` 滿足

```
Σd² = 60（分母）｜Σd = 16（DM 分子）｜Σd(d−1) = 44（N_d）
⟹ Σd² = Σd + Σd(d−1)  ⟺  60 = 16 + 44        （同一 irrep 清單之一條恆等式）
```

⟹ 預算分母之分解**唔再係凑數**。但下一步立即撞牆：

> **為何係 A₅ 而唔係其他群？**

呢個唔係計算缺口 —— 係**公理層缺口**：需要一條「群選擇原理」（selection principle），
而 corpus 現時冇。

## 2. 已核事實（本 session 即場重算）

```
A₅：dims [1,3,3,4,5] ⟹ 相異非平凡 {3,4,5}：∏ = 60 = |A₅| ✓｜Σ = 12 ✓
S₅：dims [1,1,4,4,5,5,6] ⟹ {4,5,6}：∏ = 120 = |S₅| ✓｜Σ = 15 ✗
Σ = 12 且 ∏ = 60 之整數三元組：**唯一 (3,4,5)**
```

⟹ v10 舊有準則（見 §6 `O171`）**算術正確**，且會唯一挑出 `{3,4,5}`。

## 3. 缺口清單

| # | 缺口 | 具體問法 |
|:-:|:--|:--|
| **R1** | 準則之來源 | 「`∏` 相異非平凡 irrep 維數 = `|G|`」與「`Σ = 12 = B·N_gen`」兩條件**各自**之結構理由？為何係積與和，唔係平方和（`Σd² = |G|` 恆真、無鑑別力）？ |
| **R2** | 全域唯一性 | 所有階 `≤ 500` 之群，同時滿足兩條件者是否**只有** A₅？（現時只測過 S₅ 一例） |
| **R3** | 修飾詞之必要性 | 「**相異**」與「**非平凡**」兩個限定是否必要？去掉任何一個會否選出其他群？→ 若會，則準則之自由度 ≥ 2 |
| **R4** | 事後性 | 準則係**見到 A₅ 之後**寫出（v10 `O171` 文件時序）抑或事前可指定？若事後 ⟹ 須做 look-elsewhere 校正 |
| **R5** | 與 `60 = |A₅|` 之關係 | `M3` 已立「分母 `60 = |A₅|` 🟢」；而 `Σd² = |G|` 係恆真 ⟹ 兩者係同一陳述抑或兩條？若同一，`M3` 之 🟢 須降級為「恆真」 |

## 4. 判準（接受標準）

1. 準則**事前**指定（先寫判準，後掃群；不得見解後補）。
2. **全域掃描**：階 `≤ 500` 之全部群（GAP 或標準表），列出所有滿足者。
3. **look-elsewhere 校正**：候選準則族（積／和／平方和／類數 之各種組合）之命中率。
4. 判死**亦算結果**：若「群選擇」不可由結構決定 ⟹ 明寫「A₅ = 輸入」，並撤回任何「A₅ 係推導所得」之表述。
