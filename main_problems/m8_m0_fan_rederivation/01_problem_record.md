# M8 — M₀ 重新推導：標度 = 江恩角度線反向交疊？

## 一、問題陳述（凍結）

**核心問題**：M₀（及其唯一無量綱搭檔 4.095e38 = ω_M0/ω_site）能否由一個**角度扇（fan）＋ 其反向（鏡射）交疊**嘅結構導出，而唔需假設「標度 = 一連串離散點 anchor^k」？

三條子問題：

- **Q1（結構）**：扇／反向／交疊 三個詞嘅精確定義係咩？邊個係**強迫**（structurally necessary），邊個只係**容許**（admissible）？
- **Q2（可推性）**：扇結構能否定一個**絕對**標度？抑或自對偶（反向對稱）令佢**尺度不變** ⟹ 只可定比值？
- **Q3（識別）**：4.095e38 可否由扇結構**首選**生成（唔係 78 生成集之一、唔係事後凑）？

## 九、校正記錄（append-only，2026-10-26；原文不動）

**觸發**：調律者指出 M8 起手式對其表達有理解錯誤。原文逐字見 `docs/03 §0`。

**誤讀本體**（六點對照見 `docs/03 §1`）：
舊本檔 §一 把「標度」一律讀成 **M₀ 之絕對量值**，把「江恩角度線反向交疊」讀成
**數生成器假說**（去搜「邊個扇生成 4.095e38」）⟹ R3 路線。
調律者原意係 **三層結構**：微觀端 = 讀數投影（π²=π）、映射層 = 按比例之標度（λ）、
宏觀端 = 本徵值映射；「10^38」並非存在之標度，而係**兩圖卡之間的座標差**；
「非線性交接點」= 兩圖卡唯一可交接處（角度反向交疊之不動點）。

**本輪成果**（詳見 `docs/04`）：

1. **映射層 = γ 之 odds 圖卡**：`tan²(πn/88) ≡ γ_n/(4−γ_n)`（符號恆等）；
   鏡射 = **已證** `γ_n + γ_{44−n} = 4`（非新假設）。
2. **交接點唯一**：`θ*=π/4 ⟺ n*=22 ⟺ γ*=2 ⟺ s*=1 ⟺ t*=0`；並係 `dγ/dθ` 極大（=4=γ₄₄）
   與 `dt/dγ` 極小（=1/2）之同一點。
3. **非線性交接係必然**：鏡射奇仿射膠合 `a(θ−π/4)` 與乘法膠合 `λ·ln tan θ` **互斥**。
4. **10^38 no-go**：圖卡內跨距 2.894 decade，目標 38.612 decade，差 35.72 decade；
   T₁ 需 13.34 次迭代（非整數）⟹ **唔係任何圖卡之標度**。
5. **dof = 1 重新定位**：λ 住映射層，係「單位」非「量值」（與 M6 T2 不矛盾）。

### 十七·3 為何一輪審計捉唔到、二輪捉到

一輪（`scripts/09 §D2`）只重算文檔內**源頭式**（decade／dev 表／比值）；「78.55」係由源頭式**再換算**一層之
二階值，而一輪比對嘅係 `μ·det = 0.01257`（正確）——文檔寫其倒數，方向一轉即無交叉點。
二輪 L2 **由原始輸入獨立重算**並直接生成期望值 ⟹ 一擊命中。

⟹ **制度**：倍數／倒數類數字，期望值必須由 L2 生成，唔可以同層互檢。
