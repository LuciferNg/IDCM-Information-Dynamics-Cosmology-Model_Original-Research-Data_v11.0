## §1 誤讀診斷（六點逐句對照）

| # | 原話 | 舊 M8 讀成 | 校正後（本檔採用） |
|:-:|:--|:--|:--|
| 1 | M₀ 標度本身未必有意義 | 「M₀ 絕對值仍是一個未閉合數值」＝O38 G1/G2 缺口延續 | M₀ **作為標度不存在** ⟹ 唔係「缺口未閉合」，係**問題對象錯置**（dissolve，非 solve） |
| 2 | 微觀端是讀數讀取產生的投影 | 微觀＝質量譜低端 `m_n = M₀√γ_n/2`（一串小質量） | 微觀＝**投影算子之像**（投影 ⟹ 冪等 ⟹ `im π = Fix π`）；讀數係「一次投影」，唔係「一個值」 ⟹ 微觀端**無獨立標度 dof** |
| 3 | 大尺度宏觀端是本徵數值的映射 | 宏觀＝「10^38 咁大嘅數要生成」 | 宏觀＝本徵值 γ 經**映射**出去（`γ ↦ 4−γ ↦ odds ↦ log`）；大數係**座標**，唔係實體 |
| 4 | 未必存在一個跨越 10^38 的標度 | 「要搵邊個結構式生出 4.095e38」（＝R3 原定路線） | 10^38 **不存在**：圖卡內跨距只有 **2.89 decade**（J5.1）⟹ 唔應該搵生成式；R3 應撤 |
| 5 | 映射層可能存在一個按比例的標度 | 未處理（舊 M8 把「標度」一律等同 M₀） | 標度住喺**映射層**，形態係**比例**（odds／λ），唔係量值 ⟹ dof = 1 係「**單位**」唔係「**大小**」 |
| 6 | 角度反向交疊後的非線性交接點 | 「江恩 fan（斜率 1/n）＋鏡射」⟹ 測 20 個候選數生成式 | 「反向交疊」＝**已證** `γ_n + γ_{44−n} = 4` 之鏡射；「非線性交接點」＝兩圖卡**唯一**可交接點 `θ=π/4`（n=22, γ=2）；非線性**必然**（J4：仿射膠合 ⊥ 乘法膠合） |

**核心錯置**：舊 M8 把「**唔存在嘅標度**」當成「**未生成嘅大數**」去搜 ⟹ 必然零命中（R1 盲測 0/20 係正確嘅數學，
但佢測錯對象）。R1 嘅 P1–P5 與 0/20 **不變有效**，本檔不動 `docs/01`、`docs/02`。

## §2 三層結構（形式化）

```
L_micro   微觀端 ：讀數投影  π : Θ → Θ,  π² = π        （冪等 ⟹ 無標度 dof）
                     im π = Fix π = 44 rung；γ_n = 4sin²(πn/88) ∈ [0,4]  有界
L_map     映射層 ：比例圖卡  s = tan θ ≡ √(γ/(4−γ))    （odds／logit；唯一投影座標，J2）
                     標度自由度 = 1（λ），只作整體縮放 ⟹ 只定「單位」不定「大小」
L_macro   宏觀端 ：本徵映射  t = ln s = λ·ln tan θ     （加法圖卡；本徵值經映射出去）
                     鏡射 θ↦π/2−θ ⟺ s↦1/s ⟺ t↦−t     （J2.3，與已證 γ 鏡射同一）
J         交接點 ：θ* = π/4 ⟺ n* = 22 ⟺ γ* = 2 ⟺ s* = 1 ⟺ t* = 0      （唯一，J3）
```

**「反向交疊」唔係新假設**：`γ_n + γ_{44−n} = 4`（M6 docs/01 A3 已證）⟺ `γ ↦ 4−γ` 鏡射
⟺ 在 odds 圖卡上正好係 `s ↦ 1/s`。即調律者所講嘅「角度反向交疊」在 IDCM 內部**已經兌現**，
缺嘅只係把它讀成「圖卡交接」而唔係「數生成器」。

## §3 命題陳述（J1–J7；結果見 `docs/04`）

| # | 命題 | 類型 |

| **J1** | 投影 ⟹ 冪等 ⟹ 微觀端 = 不動點集，無獨立標度 dof | 定義級 |
| **J2** | 映射層唯一投影座標 = `tan θ`（交比歸一化唯一）；反向 ⟺ `s↦1/s` | 可證（符號） |

| **J6** | 標度 dof 計數 = 1（λ），住喺映射層 ⟹ M6 `dof_scale = 1` 之重新解讀：一個單位，非一個量值 | 一致性 |
| **J7** | 與譜接合：`tan²θ ≡ γ/(4−γ)`（odds 恆等）；`dt/dγ = 2/(γ(4−γ))` 於 γ=2 極小 = 1/2 ⟹ 交接點在 γ 座標亦係最平緩（非線性最強）之點 | 可證（精確） |
