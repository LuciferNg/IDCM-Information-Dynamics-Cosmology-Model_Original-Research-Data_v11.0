## §2 ★ 主判別：讀法 A 與 B **不相容**（P5）

```
讀法 A（江恩原義：有理斜率 s ∈ {1/n}）  vs  讀法 B（IDCM 現行角度扇 θ_n = πn/88）

P5：tan(πn/88) 有理 ⟺ n = 22（值 = 1）
⟹ 88 鏈上「有江恩線」嘅 rung 只有 1 個（n = 22 = 45° = 1×1）
⟹ 想喺 88 鏈上佈滿江恩角度線（1×2、1×3、2×1…），必須**放棄角度均勻**
⟹ 反之，保留角度均勻，就只能保留一條江恩線（1×1）
```

**判決**：兩者唔可以同時成立。所以「江恩角度線反向交疊」若要入 IDCM，
只有兩條互斥路線：

| 路線 | 內容 | 代價 |
|:--|:--|:--|
| **A′** 放棄角度均勻 | 重建 `{1/n}` 斜率扇譜，`γ` 族（Σ=90、rank 20）**唔再適用** | 要由零重推整條質量譜 |
| **C′** 保留角度均勻 | 「江恩線」= **鏡射對偶**（θ↦π/2−θ），即 P2＋P3 | 無新譜；只兌現已證恆等式 |

## §3 反向交疊嘅真實產物：**常數，唔係標度**

三個已證事實合起來講同一件事：

1. **乘積坍縮**：鏡射配對令 `tanθ · cotθ = 1` ⟹ 全扇乘積 = 1（P4）。
2. **和為常數**：`γ_n + γ_{44−n} = 4` ⟹ 對和恆定（P3）。
3. **唯一不動點**：`n = 22`，`γ = 2`（P2）——一個 O(1) 數。

⟹ 「反向交疊三角函數」嘅天然不變量係 **1、2、4、90、272、1247** 呢類 O(1) 純數，
**冇任何一個係 10^38 量級**。要用扇造出 4.095e38，必須經過**指數化**（k^m），
而指數化已經唔係扇嘅不變量，係組合計數。

> 「標度 = 江恩角度線反向交疊三角函數」——
