## §1 本輪問題

前三輪把 7 類橋樑「打死」。但打死嘅**強度**從未量度過。本輪問：
**每個 null 到底有幾多判別力？** 並補試唯一未試之族（前因子族 `μ = A·e^{−S}`）。

方法：**目標平移對照（target-shift control）**——把目標值隨機平移 ±1 dex 共 200 次，數同一族喺同樣 0.1% 窗內嘅平均命中數 ρ。
ρ 就係「該族對隨機目標嘅覆蓋率」，亦即該族嘅判別力量度。

## §2 H1 — 結構對 μ 完全免疫（分類證明）

8 個無量綱預測之積木：

| 類 | 例 | 數 |
|:--|:--|--:|
| 計數比 | `Ω_Λ = 41/60`、`Ω_m = 19/60`、`Ω_b = 1/45`、`Ω_dm/Ω_b = 16/3` | 4 |
| 譜跡 | `Σγ = 90`、`γ₂₂ = 2`、`γ₄₄ = 4`、`Σtan² = 1247` | 4 |

兩類積木**皆無質量單位** ⟹ 任何 `f(γ, 計數)` 皆 μ-免疫；μ 只能經 `M₀` 進入（`scripts/03` A3 實測 0/8 依賴）。

## §3 H2 — 參數計數：1 錨 ＋ 1 無量綱參數

| 項 | 值 | 來源 |
|:--|:--|:--|
| 標度 dof | 1 | O212 步驟1（`c = R·ω_ring` 恆等 ⟹ 三量只帶 1 標度） |
| 無量綱自由參數 | **1 = μ** | H1：其餘無量綱預言皆 μ-免疫 |

⟹ **「推導 μ」≡「令模型零自由無量綱參數」**（同一件事，非兩件）。
⟹ 質量 ∝ `M₀`（A3：指數 +1、單一均勻）⟹ 量一個質量即定 μ，其餘質量皆預言。

## §4 H3 — 一致性不能定 μ

任何內部一致性條件皆由結構積木構成 ⟹ 對 μ 鈍感 ⟹ **不能「解出」μ**。
唯一能定 μ 之形式 = identity `μ = f(結構)`，且 `f` 須完全被強迫（零自由係數）。
⟹ **「一致性檢驗」路線永久封閉**（新禁區）。

## §6 ★★ 自我更正（撤回 docs/06 / docs/07 之措辭）

### 原文（作廢）

- `docs/06 §5`：「0.1% 窗之期望 = 0.17 < 1 ⟹ **該窗有資訊**；命中 0 ⟹ **有效否證**」
- `docs/06 §9`、`docs/07 §5.3`：「1% 級 = 噪音地板；0.1% 級 = 有效否證」

### 錯在何處

「期望命中 < 1」**唔係**「該窗有資訊」，而係**該族太稀疏**：
若目標係隨機，0 命中嘅機率 = **0.99** ⟹ 觀察到 0 命中幾乎必然發生 ⟹ **null 無法區分「族錯」與「族唔夠密」**。

正確方向：
- **ρ ≪ 1（稀疏族）**：**命中**才有判別力；null 近乎必然 ⟹ 無資訊。← F1、F2 屬此
- **ρ ≫ 1（稠密族）**：**null** 才有判別力；命中係噪音。← F3 屬此

### 更正後之現狀

| 舊宣稱 | 新宣稱 |
|:--|:--|
| E5：`X₀` 非半整數冪 = **空集（否證）** | 126 個候選無一命中，但 ρ=0.025 ⟹ **無候選，非否證** |
| G4：指數族 = **有效否證** | ρ=0.070 ⟹ **無候選，非否證**（撤回） |
| R1 / O38 之 0/20、0/75 | 同型稀疏族 ⟹ null 資訊量同樣有限（其 look-elsewhere 只保證「唔係碰巧撞中」，**唔**證明「族外無結構」） |
| （新）F3 前因子族 | ρ=4.0、0 命中 ⟹ **唯一有效之 null**：前因子族**不含** μ（p ≈ 0.02–0.09）|

⚠️ F3 之排除只針對**該離散化**（A 取 24 個結構數之局部式、S 取 8 個整數），**不**否證「前因子」概念本身。

## §7 ★ 功率判準（新方法論規則）

```
null 可作證據  ⟺  ρ ≥ 3      （稠密族）
命中 可作證據  ⟺  ρ ≤ 0.1    （稀疏族）
```

兩者**不可兼得** ⟹ **一個族只能回答一個方向**。

### 推論（數字掃描之證據上限）

對**單一目標值**，任何有限離散族只有兩種結局：含目標或不含。而：
- 稀疏族嘅「不含」近乎必然 ⟹ 無資訊；
- 稠密族嘅「含」係噪音 ⟹ 無資訊。

⟹ **單目標數字掃描嘅證據上限 ≈ 1 bit，且不可跨族累加**（累加只增加 look-elsewhere，唔增加證據）。
⟹ 唯一能突破上限嘅做法：**用「零自由係數之強迫族」**——此類族每個結構只產生**一個**候選，ρ 無意義，
   命中即成立、唔命中即精確否證（因為候選係事前唯一確定）。

## §8 對「盲掃法」方向之意涵（記錄，非裁決）

調律者 2026-10-10 提出「Ramanujan Machine 盲掃法」構想。本輪結果直接相關：

| 掃法 | 證據上限 | 建議 |
|:--|:--|:--|
| 大族盲掃（多候選、單目標） | 1 bit、不可累加 | 只可作**發現**用途（hit ⟹ 再過四 Hard Tests），不可作**判別**用途 |
| 強迫族（零自由係數） | 單候選 ⟹ 命中/否證皆精確 | ✅ 應作為主路線 |

⟹ 掃法本身唔錯，但**必須以強迫性（零自由度）而非以族大小為設計目標**。

## §9 判決

1. `μ` 係模型**唯一**自由無量綱參數（H2）；推導 μ ≡ 零參數化。
2. 一致性路線永久封閉（H3）。
3. identity 路線之既有掃描**全部功率不足**（ρ ≪ 1）⟹ 現狀係「**無候選**」，唔係「已否證」。
4. 唯一有功率之 null：前因子族不含 μ（p ≈ 0.02–0.09，只限該離散化）。
5. 維持 **🟡，不 close**。close 觸發器 = **強迫型 identity 命中**（單一候選、零自由係數、dev < 1e−10）。
