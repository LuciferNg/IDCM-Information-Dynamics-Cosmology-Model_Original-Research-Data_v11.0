## §5 ★ 對 docs/04 §4 之更正（append-only；原推論作廢）

**docs/04 §4 原文推論**：「4.095e38 …係兩圖卡之間的座標差，數值由 λ 決定 ⟹ **不可觀測為結構**」
＋「舊 R3 撤銷：其前提（該標度存在）已被 J5 否定」。

**更正**：

1. J5 之**圖卡命題本身有效**（圖卡內跨距 2.894 dex，目標 38.612 dex；T₁ 唔係 on-chart 比值）——不變。
2. 但「**不可觀測為結構 ⟹ 唔使推**」**錯**。T₁ = f_M0·f_R/44，兩因子皆係既有、獨立、仍未閉合之
   **無量綱預言缺口**（O212 表列 2.29e−21 與 7.88e60）。T₁ 係**兩缺口之積**，唔係「非對象」。
3. 因此 **R3 之撤銷理由錯**：唔係「前提被否定」，而係「**目標錯配**」——搜「積」而非分別搜「因子」。
   正確目標 = f_M0（質量層級）與 f_R（宇宙尺度）**各自**。
