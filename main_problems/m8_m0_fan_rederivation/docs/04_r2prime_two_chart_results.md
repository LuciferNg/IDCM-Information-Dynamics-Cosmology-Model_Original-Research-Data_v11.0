## §2 主結果一：映射層＝odds 圖卡（非假設，係已證結構的必然）

```
γ_n = 4sin²(πn/88)                     ← 已證譜（Σγ=90, rank 20, 核 24）
γ_n + γ_{44−n} = 4                     ← 已證（M6 docs/01 A3）  ⟹ 鏡射 γ ↦ 4−γ
s² = γ/(4−γ) = tan²(πn/88)             ← J7.1 恆等（符號 = 0）
t  = ln s = ½ln(γ/(4−γ))               ← 加法／本徵映射圖卡
t_n + t_{44−n} = 0                     ← J7.2（2.5e−60）
```

⟹ 調律者所講「**映射層**」＝ γ 嘅 **odds（logit）圖卡**；「**按比例**」＝ odds 係比值（`γ:(4−γ)`）；
「**反向交疊**」＝ `γ ↦ 4−γ`，即**已證**之 `n ↦ 44−n`。三者全部落在既有已證結構內，
冇引入任何新常數、新譜、新可調參數。

## §3 主結果二：「非線性交接」係必然，唔係選項（J4）

```
膠合要求 (i) 鏡射奇對稱 t(π/2−θ) = −t(θ)
         (ii) 比例性（乘法同態）t(s₁s₂) = t(s₁) + t(s₂)

(i)  ⟹ t = a(θ − π/4)         唯一（仿射）
(ii) ⟹ t = λ·ln tan θ         唯一（連續特徵標定理）

J4.2：仿射解違反 (ii)（實測 |Δ| = 0.104 ≠ 0）
J4.3：乘法解自動滿足 (i)
⟹ (i) 與 (ii) 不可兼得 ⟹ 交接必為非線性（linear–log 型）
```

**交接點**：兩膠合唯一共同歸零點 `θ* = π/4` ⟺ `n* = 22` ⟺ `γ* = 2` ⟺ `s* = 1` ⟺ `t* = 0`。
並在 γ 座標亦係**最平緩點**（`dt/dγ` 極小 = 1/2，J7.3）——即「讀數投影 ↔ 本徵映射」響應最弱、
非線性最強之唯一點。**呢個就係「角度反向交疊後的非線性交接點」嘅精確內容。**


| 類 | 定義 | 檢驗 |

`Λ_IDCM = ρ√λ_max·M₀`（O142）、`r_d = πR_world/88`（O127）、真空能 `41/60`（O39）。

1. 本輪**冇**推出 M₀ 或 λ 嘅數值；亦**冇**聲稱已閉合 O38 G2。
2. 主命題（M₀ 非標度）**未過 §8 殺手檢定** ⟹ 現階段級別 = 🟡（結構自洽，未排他）。

4. 「fan 交點格」讀法未測；不得引用為結果。
5. **投影座標之冪次（m 歧義）**：`s = tan^m θ` 與 `s² = γ/(4−γ)` 兩讀法皆鏡射互反。
   取 m = 1 之理由 = 投影座標（交比）唯一性（J2.1）；但 m 之選擇**只令 t 整體乘 m**，
   即被 λ 完全吸收 ⟹ 交接點（J3）、no-go 比值（J5）、dof 計數（J6）**全部 m-不變**。
   ⟹ m 歧義不影響任何結論，只影響 λ 之數值（而 λ 本輪未推）。
6. **新穎性界定**：`tan²θ = γ/(4−γ)` 本身係 `γ = 4sin²θ` 之代數推論（初等，非新）；
   本輪新增內容 = ①把它讀成「兩圖卡交接」 ②J4 互斥定理 ③J5 之定量 no-go ④dof=1 之重新定位。
   RAG 掃描未見 corpus 有同型圖卡論述（`idcm_rag_search` 兩查零命中）——但「零命中」只表示未見，
   非證明未有，故不宣稱首創。
7. 本輪**未**做 MC null（②）與樣本外盲測（③）——因為冇「命中」可測（no-go 屬結構性）。
