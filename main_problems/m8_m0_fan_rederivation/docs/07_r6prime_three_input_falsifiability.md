## §1 本輪目的

`docs/06 E7` 已排除「兩標度冪律橋」。調律者指示在 M8 內直接續推 ⟹ 問：
**加入第三個無量綱結構輸入 S，能否救回 μ 之推導？**

答案分三層，全部可檢定。

## §2 G1 — 欠定定理：三輸入冪律族**零預言內容**

```
μ = r^p · S^q          （r = ħω_ring/M_Pl = 1.2682908e−61）
```

2 未知（p, q）、1 約束 ⟹ **1 參數族**。實測：固定 q = 1，對任何 S 反解 p，皆精確重現 μ（7/7，dev < 1e−25）：

| S | 反解 p（q=1） |
|:--|--:|
| 44 | 0.3659390588 |
| 88 | 0.3708823413 |
| 90 | 0.3710426099 |
| 1247 | 0.3897894783 |
| 291.5 | 0.3794239404 |
| 61.5 | 0.3683270740 |
| 3 | 0.3467864632 |

⟹ **加入無量綱第三輸入不恢復可證偽性**（每個 S 都「中」，等於冇中）。
⟹ 第三輸入只有以**非冪**方式（加性／對數／指數）進入方有內容。

## §3 G2 — `p` 之有理近似：唔優於隨機

`p = 0.338951545726743`。`limit_denominator` 掃描（q ≤ 500）最佳 = **161/475**，`dev = 1.232e−05`。
但隨機基準 `1/(2q²) = 2.216e−06` ⟹ **`dev/基準 = 5.56`**，即比隨機**更差** 5.6 倍 ⟹ 無異常、無結構身份。

⟹ `p` 不升格（亦不作禁區斷言，只記錄「無有理身份」）。

## §4 G3 — 只有指數類能在無精調下給 10^−21

| 非冪類 | 上限 | 判 |
|:--|:--|:--:|
| 加性（M2：`m/M₀ = Σγ_n`） | `Σγ = 90` ⟹ O(10²) | ✗ 造唔到 10^−21 之比 |
| 對數（M8 圖卡 `t = λ·ln tanθ`） | 圖卡內跨距 2.894 dex | ✗ 唔夠 |
| 指數（O86：`Λ_eff = 8πM_Pl²e^{−V_Λ}`） | `e^{−S}`，S ~ O(10²) 已足 | ✅ 量級合理 |

⟹ 目標量 **`S* = ln(1/μ) = 47.5277926827`**（若 μ = e^{−S}）。

## §5 ★ G4 — 局部密度量度（本輪核心）

「幾多個簡單結構式落喺目標附近？」——用 `R = {2,3,8,11,22,36,44,45,55,60,88,89,90,98,123,135,137,176,272,1247,33.75,61.5,291.5,784.96}` 生成
一元運算（`id, ×2, ×3, /2, /3, sq, √, ±1, ±2`）＋ 二元運算（`+, −, ×, ÷`）＋ 二層（`×2, /2, ×3, /3`），只留落喺局部 ±30% 帶內者。

局部帶 [33.27, 61.79]，表達式數 **52**。

⟹ 0.1% 窗之期望 = 0.17 < 1 ⟹ **該窗有資訊**；命中 0 ⟹ **有效否證**：

### §5.3 密度量度之意義

- **0.1% 級在本題係「有資訊」窗**（期望 < 1）⟹ 0 命中＝真否證。
- **1% 級係噪音地板**（期望 1.7 / 1.1）⟹ 1% 級任何配對**永久無資訊**（與 M4/M5 之 0.1% 規則一致，並給出量化理由）。

## §6 橋樑類窮盡表（累積：E7 ＋ G1–G4）

| # | 類 | 判決 | 依據 |
|:-:|:--|:--:|:--|

## §7 破牆規格（凍結；G5）

1. `S` 須以鏈／樹既有量**獨立定義**（定義中不得出現 `μ, M₀, M_Pl, ω_ring, R_world`）。
2. `S` 與 `ln(1/μ)` 須 **identity-level** 相符（dev < 1e−10；受輸入 8 s.f. 限制，實際下限 ~1e−8）。
3. `S` 須為閉式（有限項 γ 多項式／整數計數／對數），**不得含自由係數**。
4. 若 `S` 含新常數 ⟹ 須先過四 Hard Tests（dof 成本／10⁷ null／樣本外盲測／結構剛性）。

## §8 ⚠️ 候選解讀（未識別，不得當結果）

若 μ = e^{−S}，則 `S* = 47.5278 nats = 68.586 bits`。可讀作「微觀讀數資訊量」之候選 —
但 §5.1 已示 0.1% 窗零命中 ⟹ **現有結構式造唔出**，此解讀純屬方向假設，不得引用為證據。

## §9 判決

1. 兩標度冪律（E7）與指數類（G4）皆已被**有效否證**；三輸入冪律（G1）**不可證偽**。
2. ⟹ `μ = M₀/M_Pl` 在 v11.0 已註冊結構內**無解**，且**可證明係結構性缺口**（非算術缺口）。
3. 依 O238 教訓（推盡≠結論）⟹ 維持 🟡，**不 close**；close 觸發器 = 出現符合 §7 規格之新算子。
4. 本輪**未**引入任何新常數、未升格任何候選。

## §11 ⚠️ 同日更正（2026-10-26 第五輪；見 `docs/08` §6）

**原文作廢**：§5.3「0.1% 級在本題係『有資訊』窗」、§6 表第 6/7 列「✗ **有效否證**」、§9 第 1 點。

**更正後**：
