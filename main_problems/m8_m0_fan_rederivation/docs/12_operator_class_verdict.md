## §1 兩類物件（先分清，避免誤殺）

| 類 | 定義 | 維度 | 出自 |

| **A** | **歸一化映射**：`∃(α,β,π) 使 α·s_c + β = d_{π(c)}`（鏈側 ℤ₄ 分級測度 `s` ↔ 算子側 `dim` 測度 `d`） | `4 → 4`（ℤ₄ 級） | v10 `O210 docs/11 §1` |

**判定：A ≠ B。** `A` 係兩個**既有**分級之間嘅**數值歸一化**；`B` 係**動力學算子**、其譜定義比率。

## §2 B2 定理（電腦核）：抽樣式粗粒化 ⇒ 投影 ⇒ 譜 ⊆ {0,1}

任何**抽樣式** decimation（`A: V_88 → V_m` 為區塊平均、其後以 pseudo-inverse 重建）
其合成 `P = Aᵀ(A Aᵀ)⁻¹A` 必為**正交投影**（`P² = P`、`Pᵀ = P`）⟹ 譜 **⊆ {0,1}**。

實測（`scripts/15 §1`）——塊 2／4／8 × 均勻／非均勻權重，全部：

```
譜 = {1}^44 ∪ {0}^44（或對應維度），**冇任何 r ∉ {0,1}**
```

⟹ 自然 decimation **不可能**供 `r ≠ 1` ⟹ **decimation 版本之門 (C) 不存在**。

## §3 B3：`[P,K] ≠ 0` 與「有標度」無關

```
‖[P,K]‖_F = 6.557439   （塊 2 均勻；確實非交換）
spec(P)   = {0, 1}      （確實冇 r ∉ {0,1}）
```

⟹ M20 `A2`（`Φ ∉ Comm(K)`）只保證「非 K 之函數」，**唔保證有標度**。
Gemini 把兩件事當同一件 —— 本輪以數值釘死：**非交換 ≠ 有標度**。

## §4 B1：一般 `C` 對**任何** `r` 皆可構造 ⟹ 該公理零約束

構造：`C = S · diag(r, 1, …, 1) · S⁻¹`（`S` 一般可逆）⟹ 譜含唯一 `r ≠ 1`、且 `[C,K] ≠ 0` 一般成立。

實測（`§3`，`S = I + 0.05·Gaussian`）：

| 目標 `r` | 非 1 特徵值數 | `‖[C,K]‖_F` |
|:--|:-:|--:|
| `1e5` | 1 | 1.87e5 |
| `3.7` | 1 | 4.89 |
| `2.2852930605e−21`（＝μ） | 1 | 1.9 |

⟹ **對任何目標（含 μ 本身）都可造出合條件之 `C`** ⟹ 該公理**不篩選任何東西**
⟹ `dof` = 1 連續（`r`）＋ 1 整數（`N`）＝ **2**，預言數 = 0 ⟹ **不可證偽**。

★ 對照 4 Hard Tests：① 自由度成本 = **2**（要求 0）⟹ 直接不過。
