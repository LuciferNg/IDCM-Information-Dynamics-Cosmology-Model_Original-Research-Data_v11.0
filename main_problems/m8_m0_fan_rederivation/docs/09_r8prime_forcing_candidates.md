## §2 ★ J1 — 交接點之第三重表徵：(1 − K/2) 之精確零模

```
γ_n ≡ 2(1 − cos(πn/44))          （恆等，44/44 成立）
⟹ 1 − γ_n/2 = cos(πn/44)
⟹ n = 22 時 cos(π/2) = 0        ⟹ γ₂₂ = 2 **精確**
```

⟹ 交接點（`n*=22, θ*=π/4, γ*=2, s*=1, t*=0`）同時係算子 **(1 − K/2) 之零模**。
⟹ **三重獨立表徵**：

| 表徵 | 來源 | 獨立性 |
|:--|:--|:--|
| 鏡射中點 `γ_n+γ_{44−n}=4 ⟹ γ₂₂=2` | 譜對稱（doc 04） | — |
| 圖卡 `t=0 ⟺ s=1 ⟺ n=22` | odds 圖卡 `tan²θ=γ/(4−γ)`（doc 04） | 依賴圖卡 |
| **`(1−K/2)` 零模** | 本輪 J1 | **不依賴圖卡** |

⟹ 交接點**唔係**圖卡之 artefact，係譜結構強迫點。
