## §1 定義（三個詞嘅精確化）

```
扇 F(S)    : 由原點出發、斜率 s ∈ S ⊆ ℝ_{>0} 之射線族；θ = arctan s
反向 R     : θ ↦ π/2 − θ   ⟺   s ↦ 1/s        （對 45° 線鏡射）
交疊 F ⊔ R(F) : 扇併其鏡射；自對偶 ⟺ R(S) = S
角度扇 B   : S_θ = {tan(πn/88) : n = 1..44}（IDCM 44-mode 鏈；n=44 為 pole）
斜率扇 A   : S_s = {1/n : n ∈ ℕ}（江恩原義 1×n / n×1）
```

**關鍵**：A 均勻於**斜率**，B 均勻於**角度**。兩者唔等價，亦唔可以當同一族測。

## §2 五個命題（P1–P5）

| # | 命題 | 類型 |
|:-:|:--|:--|
| **P1** | `F(S)` 鏡射自對偶 ⟺ `S` 對 `s ↦ 1/s` 封閉。`S = {1/n}` **唔**自對偶；其自對偶閉包 = `{n} ∪ {1/n}`（雙扇） | 定義級（可證） |
| **P2** | 鏡射唯一不動射線 `θ = π/4`（`s = 1`）。喺 88 鏈上 `πn/88 = π/4 ⟺ n = 22` ⟹ **唯一鏡射不動 rung = n = 22 = N_d/2 = 88/4**，且 `γ₂₂ = 4sin²(π/4) = 2`（唯一有理非平凡 rung） | 可證（精確） |
| **P3** | 鏡射喺 88 鏈上嘅軌道和恆為常數：`γ_n + γ_{44−n} = 4`（n=1..43），`2γ₂₂ = γ₄₄ = 4`。即「反向交疊」= `sin²+cos²=1` 之縮放，**產生常數和，唔產生標度** | 已證（M6 docs/01 A3） |
| **P4** | 自對偶扇之乘積坍縮：`Π_{n=1}^{43} tan(πn/88) = 1`（配對 `tanθ·cotθ = 1` 逐對消去） | 可證（本輪） |
| **P5** | **讀法 A 與 B 不相容**：`tan(πn/88) ∈ ℚ` 只可能 `n ∈ {22, 44}`（`tan = 1`、pole）；其餘 42 個 rung 全部無理（Niven 型） ⟹ 江恩「有理斜率」扇**唔可能**同時係角度均勻 88 鏈 | 可證 → **判別定理** |

**P5 為本輪主判別**：若「江恩角度線」= 有理斜率（A），則佢**唔屬於**現行已證譜；
若保留現行譜（B），則「江恩線」只能解作 **鏡射對偶**（C），而 C 已由 P3 兌現。

## §3 三個讀法之地位

| 讀法 | 內容 | 與已證結構之關係 | 地位 |
|:--|:--|:--|:--|
| **A** 有理斜率扇 | `s ∈ {1/n}` | 與 `Σγ=90`／`γ_n+γ_{44−n}=4` **無關**（P5）；需另建譜 | 🟡 可並存，但非現行譜 |
| **B** 角度扇 | `θ_n = πn/88` | 現行 44-mode 鏈全部結論 | 🟢 已證 |
| **C** 鏡射交疊 | `θ ↦ π/2−θ` | P3（常數和）＋ P2（n=22 不動點） | 🟢 已證（即 B 之對偶結構） |

## §4 「標度」問題之收窄

`M₀` 本身有量綱 ⟹ **任何**純幾何扇（純數）都不可能單獨定其 MeV 值（量綱論證；
與 M6 dof=1、O38 G1 一致）。所以 Q2/Q3 只可能問：

> 扇結構可否定出**無量綱**目標：`ω_M0/ω_site = 4.095e38` 或 `M_Pl/M₀ = 4.3758064e20`？

`§5` 即針對此二目標之預註冊測試。

## §5 ★ 預註冊候選族（清單凍結，測試前寫定）

**規則**：每個候選必須係「由扇／88 鏈結構**定義**出嘅純數」，不得含可調參數；
命中判準 `|Δlog₁₀| ≤ 0.002`（0.5%，純計數級命中應近乎精確）。
目標：`T₁ = 4.095e38`（`log₁₀ = 38.6123`）、`T₂ = M_Pl/M₀ = 4.3758064e20`（`log₁₀ = 20.6411`）。

**Look-elsewhere 披露**：20 個候選 × 2 個目標 = 40 次比較；命中門檻 0.5%
⟹ 隨機命中期望 ≈ 40 × 0.01 = 0.4（因為 0.5% 對應 log 窗寬 0.004/ (log 域全範圍 ~10) 約 4e-4 每目標… 見 §6）。

## §6 統計判準（事前）

對每個候選計算 `d = log₁₀(K) − log₁₀(T)`；若 `|d| ≤ 0.002` ⟹ 記「命中」。
隨機對照：於 `[log₁₀T − 1, log₁₀T + 1]` 均勻抽 10⁶ 個數，計落入 ±0.002 之比例 `p₀`
⟹ 期望假命中 = 40·p₀；實際命中數須顯著多於此才可稱為結構生成（並逐個查算子身份）。
