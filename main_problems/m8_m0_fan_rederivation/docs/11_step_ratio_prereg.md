## §2 判據（先驗）

| 項 | 內容 |
|:--|:--|
| 形式 | `N(r) = ln μ / ln r` |
| **主判據（唯一可作證據）** | `N` 必須**精確**落在特權整數集 `I` 上：`∃ n ∈ I, |N − n| ≤ 1e−6` |
| `I`（凍結，23 個） | `{3,4,5,7,9,11,13,16,18,20,22,24,29,33,36,41,44,45,47,55,60,88,90}` |
| 容差理由 | `μ` 相對精度 ~`1e−9` ⟹ `|δ ln μ| ≤ 1e−9`；`r` 為精確代數 ⟹ `|δN| ≈ 1e−9/|ln r|`。取 `1e−6` 為保守上界（≈ 1000× 餘裕） |
| 診斷級（**不作證據**） | `|N−n| ≤ 1e−4 / 1e−3 / 1e−2` 只報數字，並與空模型比較 |
| **空模型（target-shift，明示 MC）** | `M = 10⁵` 個隨機目標 `log₁₀ μ′ ~ U[−25, −15]`；對每個目標計同一 `r` 族之近整數數目；`λ(tol)` = 每目標期望數 |
| **判詞規則** | **N**（主級 0 命中）／**H**（主級命中 ∧ `λ(1e−6) ≤ 0.01` ∧ 該 `r` 屬「唯一被結構強迫」者）／**C**（其餘命中 = 巧合） |

★ **為何要「精確」而非「接近」**：離散 RG 錨聲稱 `μ = r^N` **恆等**；「差 0.03%」唔係恆等（`docs/10` 之 `γ₁^{N/2}` 案例：`N = 18.005187` 距 18 僅 0.0288%，但代入 `N=18` 得 **dev 1.3788%** ⟹ 已判死）。
