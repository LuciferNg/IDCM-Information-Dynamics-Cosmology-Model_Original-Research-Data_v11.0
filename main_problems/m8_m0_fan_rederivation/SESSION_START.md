# M8 起手式（v2）

## §0′ 調律者原意（逐字，2026-10-26 校正）

```
「M8起手式創造時對我的表達有理解錯誤，我的意思是
  M_0標度本身未必有意義，
  微觀端是讀數讀取產生的投影，
  大尺度宏觀端是本徵數值的映射,
  本身就未必存在一個跨越10^38的標度，
  但映射層可能存在一個按比例的標度，
  這個標度可能是一個角度反向交疊後的非線性交接點」
```

**三層結構**（本 M 唯一工作框架）：

```
L_micro  微觀端 ：讀數投影  π² = π ⟹ im π = Fix π = 44 rung ⟹ 無獨立標度 dof
L_map    映射層 ：按比例之標度 s = tan θ ≡ √(γ/(4−γ))（odds／logit 圖卡）
L_macro  宏觀端 ：本徵映射 t = λ·ln tan θ（加法圖卡；γ_n+γ_{44−n}=4 之鏡射 ⟺ t ↦ −t）
J        交接點 ：θ*=π/4 ⟺ n*=22 ⟺ γ*=2 ⟺ s*=1 ⟺ t*=0（唯一）
```

⟹ **「10^38」唔係標度，而係兩圖卡之間的座標差**；「M₀ 標度」唔存在，
但映射層仍有一個**按比例**之標度（λ）——即 M6 `dof_scale = 1` 之真正所在。

## §一 本 M 只做一件事

判決 **M₀ 究竟係「標度」抑或「映射層單位」**，並找出該單位住喺邊一層。

- 若 M₀ 係標度 ⟹ dof_scale = 2 ⟹ 與 M6 T2 矛盾 ⟹ 需第二標度出口。
- 若 M₀ 係單位 ⟹ M₀ 必為錨（ω_ring／G／M_Pl）之導出量 ⟹ **O38 G1/G2 之「缺口」係偽命題**（dissolve，非 solve）。
- **證偽判準**：R3′（§四）——任一絕對入口若證 M₀ 為獨立第二標度 ⟹ 本 M 主命題被否證。
