## §2 Chandrasekhar 顯式核對

```
M_Ch = 1.457 M_⊙ = 1.624947e60 MeV
M_Pl³/m_p² = 2.067150e60 MeV
⟹ M_Ch = ω · M_Pl³/m_p²,  ω = 0.786081（O(1) 純數）
⟹ anchor 指數 k = 1；無量綱因子 = ω(M_Pl/m_p)² = 1.330953e38（N 之冪）
```

⟹ **冇反例**：emergent 尺度 = 錨^1 ×（N 之冪 × O(1)），屬同一 dof 之冪次，唔係新標度。
（若 ω 係新標度，anchor 指數唔會恰為 1——呢個係判別點。）


## §4 ★ 子集和匹配嘅鑑別力（方法論，本輪實測）

**先算分佈**：Σγ = 90、Σγ² = 272 ⟹ Var(Σσγ) = Σγ²/4 = 68，σ = **8.25**。
⟹ 子集和集中喺 μ = 45 ± 8.2，**尾部稀疏** ⟹「均勻密度 5.1e-12」論證**唔成立**，
必須逐目標精確計數（meet-in-the-middle，S1 × S2 各 2²²，two-pointer 精確數）。

| 目標 | λ | δ_rel=1e−6 命中 | δ_rel=1e−9 命中 |
|:--|--:|--:|--:|
| m_p | 33.6287 | 22,545,093 | 19,231 |
| m_K± | 17.6939 | 98,562 | 45 |
| m_π± | 5.00236 | 3 | **0** |
| m_μ | 3.78691 | 1 | **0** |

（總組合 2⁴⁴ = 17,592,186,044,416）

**兩種失效模式同時存在**

1. **bulk 目標太易**：λ ≈ 45 附近，1e−9 級命中仍上萬 ⟹ 命中零證據力。
2. **尾部目標完全不可**：λ ≪ 45 之輕質量，1e−9 級命中 **0** ⟹
   **單量子子集和模型結構上唔可能解釋 m_π / m_μ**。
3. **命中態唔穩定**：m_p 之最佳態（S1#325148, S2#468597）目標動 1e-7 即換成
   (S1#2312647, S2#401767) ⟹「貼近」≠「識別」。

**判決**：任何「質量 = Σγ 子集」型命中必須
(i) **事前**指定子集（由算子身份導出）；
(ii) 計 look-elsewhere（2⁴⁴ 組合）；
(iii) 命中態對目標末位數字穩定。
缺任一項 = O200 分類 (c) 池子匹配陷阱，唔算證據。
