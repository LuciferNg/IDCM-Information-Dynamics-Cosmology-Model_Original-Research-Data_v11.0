## §2 路線① 對稱（Galois 軌道）— **本輪實測**

```
作用群 G = (ℤ/88)^* / ±1（因 γ_n = γ_{88−n}），|G| = 20
作用於 44 個 mode 類 ⟹ 軌道分解（實測）：
   大小 [20, 10, 5, 5, 2, 1, 1]  ⟹ **7 個軌道**
Galois 一致性：7/7 軌道大小 == deg γ_n = φ(88/gcd(n,88))/2  ✅
```

**真定理（副產品，可用）**：`γ_n` 與 `γ_m` 同軌道 ⟺ Galois 共軛。
任何 **ℚ-定義**（有理係數）之質量泛函必須對同軌道 mode **等權**。

**判決**：
- 對稱強迫「一個標度」**只在每個軌道內部**成立 ⟹ sector 標度自由度上界 = **7**，唔係 1。
- 即：對稱把問題由「44 個 mode 各自可有標度」收窄到 **7 個 sector**，
  但 **7 → 1 仍需額外公設**（例如「所有軌道共享同一歸一化」——呢個就係 T1 現時默默假設嘅東西）。
- ⚠️ 修正記錄：本輪起初誤預期「軌道數 = 20 = rank」；實測係 **7 個軌道**，而
  `rank_ℚ{γ_n} = 20` 係**最大軌道大小**（= 一般 mode 之代數度），兩者係唔同量。

**否證條件**：若證得某兩個軌道必然共享標度（例如由交換律強制），則上界由 7 降到 6…1；
若證得 7 個 sector 各自可有獨立標度，則 T2 之「單一」**被否證**（會變 dof = 7）。
