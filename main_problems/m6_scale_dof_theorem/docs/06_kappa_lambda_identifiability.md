## §3 判決

| 命題 | 判決 | 依據 |
|:--|:--:|:--|
| κ 係單 mode 質量？ | **🔴 排除** | 0 命中（最近差 1.3%） |
| κ 係 2-mode 和？ | **🟡 容許但唔唯一** | 10 個同格候選 |
| 可由晶格識別 λ_κ？ | **🔴 唔可以** | 2-mode 10 個 + 全支撐 1,817 個 ⟹ 多義 |
| 可排除 λ_κ？ | 🔴 亦唔可以 | 窗內有態 ⟹ 晶格**唔排除** κ |

**判決一句**：λ_κ 落喺晶格嘅**5.15σ 尾部**——命中雖然少（1,817 / 1.76e13），但**唔唯一**，
所以任何「κ = M₀(γ_i + γ_j)」式主張都係從 10 個（或 1,817 個）候選中**揀一個**，
屬 M6 `docs/03 §4` 同型之池子匹配陷阱，**零證據力**。

## §4 對 M5 之回覆（更新版）

M6 `docs/04 §2` 已答：`dof = 1` **不能**固定 κ 之 MeV 值（結構原因）。
本節補上定量版：

```
1. 標度層：唔可以定 κ（docs/04 §2）
2. 晶格層：唔可以識別 λ_κ（本節；2-mode 10 個、全支撐 1,817 個）
⟹ κ 之身份只能在**算子層**（M4/M5 之 ⟨1/r⟩ 核／D 通道）由算子結構定，
   唔可以從質量晶格反推。若 M5 有一條算子路徑給出 λ_κ，
   本節可用作「事後核對」：該值必須落喺窗內，但**窗內符合唔等於證明**。
```

## §5 副產品（可重用）

- 「可識別」嘅判據必須係**唯一性**（恰好 1 個），唔係「有冇命中」：
  0 個 = 排除；1 個 = 可識別；>1 = 多義。本輪首跑誤用「= 0」做判據（設計錯，已修）。
- 尾部窗（≫3σ）雖然命中率極低，仍然可以有 O(10)–O(10³) 個候選 ⟹
  **「稀有」唔等於「唯一」**。
