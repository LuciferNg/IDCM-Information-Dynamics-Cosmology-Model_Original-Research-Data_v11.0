## §1 定義（本輪凍結）

```
標度自由度 dof_scale := 參數空間中「令所有有量綱預言同步伸縮」嘅方向維數
                        （mod 整體單位 rescaling；即物理可分辨嘅獨立標度方向）
```

關鍵：**dof 係全模型共享嘅參數**。逐個 claim 各有一個可調數 = 擬合，唔算 dof。

## §2 定理

```
T2: dof_scale = 1，且唯一方向 = M₀/M_Pl（⇔ M_Pl/M₀ = N）。
```

### 上界（dof ≤ 1）— 由 T1 ＋ O212

1. T1（docs/01）：任何質量 m_i = M₀·λ_i，λ_i ∈ ℚ(ζ₈₈)⁺ ⟹ **任何質量比 M₀-free**。
2. O212 §二：任一有量綱量 q = 錨^k × 無量綱數；生成元 (M₀, c, ħ) 之下 22/22 量之指數**唯一解出**；
   c, h, e, k_B 係 SI 2019 精確定義（換算因子，非可調參數）。
3. ⟹ Jacobian ∂ln q_i/∂ln M₀ = a_i 係**單列** ⟹ rank = 1 ⟹ 全譜只用 1 個有量綱輸入。

### 下界（dof ≥ 1）— 由 O38

```
M_Pl/M₀ = 4.3758064e20（本輪輸入；O38 docs/15 §4 記 4.3758067e20，差 7e-8 = M_Pl 取值差異）
log₁₀ = 20.6411  ← 穹頂空洞 20.6 dex（O38 docs/28 §3）
```
框架內**冇**結構式定此比值（O38 G1 已裁決「M₀ 數值可推」= 偽命題並關閉；14 輪零命中）
⟹ 至少 1 個未定標度數 ⟹ dof ≥ 1。

⟹ **dof_scale = 1**（兩邊夾死，符號級）。

## §3 中間層無新 dof

| 論證 | 內容 |
|:--|:--|
| 複合 | m(X) = Σ parts = M₀ λ_X（T1）⟹ X 之標度係 M₀ 之代數倍 ⟹ 導出量，非參數 |
| 非加性修正 | 任何修正只改 λ（無量綱）⟹ 唔入標度軸（示例 δ = ±0.05 ⟹ λ 變、m 仍 = M₀×數） |
| 逐 claim 插值 | L(t) = A^{1−t}B^{t}：四個已註冊中間量之 t = 0.3936 / 0.4447 / 0.9285 / 0.9543，散佈 0.561 ⟹ **冇單一共享 t** ⟹ 逐 claim 一個 t 屬擬合 |
| 空洞 | 中間 30.9 dex（O38 docs/28 §2）⟹ 一個 t 可自由滑過 ⟹ 零預言力 |

## §5 剛性測試（4 Hard Test ④）

- 二元 sector：σ ∈ {0,1} ⟹ σ^{1+ε} ≡ σ ⟹ 43 個 mode 對連續旋鈕**零靈敏**（離散剛性）。
- 唯一連續量 = 瓶頸 f_proj；∂m/∂f_proj = M₀γ₂₇ = **75.3026 MeV** ⟹ 質量精度 1e−6 MeV 即封 |ε| < 1.33e−8。
- f_proj 由兩錨解出：f_proj = (28.5 − S₂₆)/γ₂₇ = **0.771960195963**（復現 M2 記載），E_proj = 28.500000000000 ⟹ 非自由參數。

## §6 ★ 未定數分類（誠實邊界）

| 項 | 類型 | 狀態 |
|:--|:--|:--|
| M₀ 之絕對數值（MeV） | scale | 單位制 artifact（O38 docs/15 §4）⟹ 非結構對象 |
| **M₀/M_Pl** | **scale** | **未閉合 ⟹ 唯一標度 dof** |
| f_proj | dimensionless | 由兩錨解出 ⟹ 已定 |
| 質量比 λ_i/λ_j | dimensionless | ∈ ℚ(ζ₈₈)⁺（離散）⟹ 已定 |
| Ω_Λ, Ω_m, Ω_b | dimensionless | 41/60, 19/60, 1/45 ⟹ 已定 |

> 但確實係未閉合項——兩者唔可以混講。
