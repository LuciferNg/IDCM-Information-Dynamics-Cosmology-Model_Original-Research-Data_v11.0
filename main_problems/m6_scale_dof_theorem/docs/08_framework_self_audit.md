## §1 A：T1（加性）測咗咩？

同一套 9100 次隨機分割檢查，換三組數據重跑：

| 數據 | 違反數 |
|:--|--:|
| 真 γ 譜（Σ = 90） | 0 / 9100 |
| 隨機正數（3 seeds，U(0.001,4)） | 0 / 9100 |
| 隨機**正負**數（U(−4,4)） | 0 / 9100 |

⟹ **任何 44 個數都「通過」**。T1 之加性檢查（`scripts/01` A6–A8）只驗證分配律
`Σ_k Σ_{n∈S_k} = Σ_n`，**零鑑別力**——與 γ 譜、與 IDCM、與物理全部無關。

**但**（重要區分）：`scripts/01` 之 A2–A5、A9、A10 **有**內容——
`Σγ = 90`、`γ_n+γ_{44−n} = 4`、`rank = 20`、`|image| ≤ 3²¹·4` 係 88 邊形嘅**真代數事實**，
並非定義性。問題只在於：佢們係**數學事實**，未係物理證據。

## §2 B：T2（dof_scale = 1）係定理抑或定義？

100 個玩具模型（`m_i = M₀·u_i`，`u_i` 任意 U(0.01,100)，12 個質量）：

```
rank(∂ln m_i/∂ln M₀) = 1  ← 100/100
```

⟹ **任何「只有一個有量綱輸入」嘅模型都得 dof_scale = 1**。
所以 T2 唔係對 IDCM 結構嘅發現，而係「IDCM 只有一個有量綱輸入」嘅**重述**。

T2 之**下界**（dof ≥ 1）亦唔係定理：佢建基於 O38 G1 之**負面搜索**（14 輪、生成集 75、
譜跡/路徑/熱核全零命中）——負面搜索 ≠ 非存在證明。

**因此 T2 嘅正確地位**：一個**歸約**（把「階層問題」歸約為「一個數值問題」），
唔係「尺度自由度定理」。原標題**過強**。

## §3 C：M6 框架唯一**非定義性**嘅物理預言

```
rank_ℚ{γ_n} = 20 ⟹ 一切 λ = m/M₀ 落在 20 維 ℚ-向量空間 V
（單量子 = 子集和；多量子 = 整數倍 ⟹ 仍在 V 內）
⟹ 任何 21 個質量必有整數關係 Σ c_i m_i = 0（M₀ 自動消去，不須先知 M₀）
```

呢個係**真預言**（唔靠 M₀ 值、唔靠算子身份、唔靠任何擬合）。判死力取決於精度：

| 相對精度 δ | 偽關係可達係數上界 H = δ^(−1/21) |
|--:|--:|
| 1e−4 | 1.55（係數須 ≤ 1 ⟹ 無判死力） |
| 1e−6 | 1.93（無） |
| 1e−8 | 2.40（弱） |
| 1e−10 | 2.99（弱） |
| 1e−12 | 3.73（弱） |

**現時不可判**：≤1e−8 精度嘅質量只有 4 個（m_e、m_p、m_n、m_μ），距 21 個甚遠。
（提升數量比提升精度更有效：30 個質量 ⟹ H = δ^(−1/30)，1e−10 時 ≈ 2.15。）

## §4 三處真正的問題（唔係修辭）

### 問題 1｜與 M5 束縛能之張力（最嚴重）
T1 之加性 = **定義上**交叉項 κ = 0（複合係各部分之和）。但 M5 嘅主題正正係**強子束縛態**
（⟨1/r⟩ 核、D 通道）——束縛能存在 ⟹ 強子質量 ≠ 組成部分質量之和。
M6 從未用強子數據檢驗加性（A8 僅以 M2 帳本作「獨立實例」）。
若強子層有束縛能，T1 在該層**為假**；「mode」若唔係組成部分，加性可以成立但需要
明確講清楚 mode 嘅本體地位——本 M 未講。

### 問題 2｜「身份」代理係選擇，唔係定理（item 4）
用「支撐數」量化身份，係一個**可操作代理**。換代理（對稱性、算子不變量）
會改密度曲線；T1′ 之線性界（λ ≤ 4k）不變，但「隱藏 = 身份枯竭」之**強度**依賴代理選擇。

### 問題 3｜item 3 之「不可識別」講嘅係晶格，唔係 κ
窗內 10（2-mode）／1,817（全支撐）只證明 **γ 晶格唔夠疏** 去識別 λ_κ；
佢同時**唔排除** κ。所以「κ 身份屬算子層」係**分工陳述**，唔係對 κ 之約束。

## §6 若要修正框架，四步

1. **降格 T2**：改稱「單一有量綱輸入之歸約（dof 計數）」，唔叫定理。
2. **加性與束縛能對賬**：用 M5 嘅 bound-state kernel 檢驗強子層；mode 之本体地位要寫明。
3. **升級預言**：把「質量 = 子集和」換成「質量 ∈ 20 維 ℚ 空間」＋
   21 質量整數關係測試（預註冊；目標 δ ≤ 1e−10 × 21 個，或 30 個 × 1e−8）。
4. **常規自檢**：每個「PASS」要附「換隨機數據是否同樣 PASS」——本節 A 即為模板。

## §7 一句話

> M6 框架**冇邏輯錯誤**，但**有一處真錯位**：它把「定義嘅推論」（T1 加性、T2 dof = 1）
> 當成「結構嘅發現」。真正有內容嘅係三類：88 邊形嘅代數事實、一組不可識別性（負面）結果、
> 以及一個**尚未可判**嘅物理預言。所以 —— M6 **冇錯**，係**被高估**；
> 而佢唯一可以判死嘅預言，要等 21 個 1e−10 精度嘅質量。
