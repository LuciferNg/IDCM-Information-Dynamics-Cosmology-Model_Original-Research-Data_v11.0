## §1 定理（PG：Scale-Generation No-Go）

**假設**
- **P1**：IDCM 三點頂點恆零：`3g = 0`（O124 §3 判決 B：標準 `(11/3)C_A` 冇 IDCM 來源）。
- **P2**：IDCM running 係**繞數計數**，非圈積分：`Δα⁻¹ = N_gen² = (B−1)² = 9`（整數，O139 §1）。
- **P3**：無鬼場（連結場係離散全局對稱，冇 gauge fixing）。

**定理**
> Dimensional transmutation 需要 `Λ = μ·exp(−∫dg/β(g))`，即需 **(i) 連續耦合**、**(ii) 非零 β**。
> P1 + P2 令 (ii) 不存在（無 bubble 源、無連續 running），P3 排除鬼場圈補充
> ⟹ **IDCM 結構內冇標度生成通道** ⟹ 唔可能由量子效應誘發第二標度。

**推論（與 T2′ 合併）**
```

⟹ 「中間層無新標度」由 bookkeeping 變成**動力學陳述**：唔係「冇見到」，而係「生不出」。
```

## §2 b₀ 之地位釐清（本節最重要之分野）

```
Tr(Q^B) = L_B（Lucas）對 B = 1..7 精確成立：
    B=1..7 : Tr = 1, 3, 4, 7, 11, 18, 29  ==  L_1..L_7      ✅ 7/7
Q = [[1,1],[1,0]]（Fibonacci 矩陣）
```

⟹ **`b₀ = L₄ = 7` 係「跡身份／閉走道計數」，唔係跑動係數。**
因此唔可以（亦冇需要）用它去證 β；相反，正因為冇 β，`b₀` 只能以結構身份存在。
呢個釐清消除 O124 舊表述中「3g = 0 對 b₀ = 7 之 1-loop 一致性」之 ill-posed 陷阱。
