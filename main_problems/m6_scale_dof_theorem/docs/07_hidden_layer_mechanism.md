## §1 T1′ 支撐定理（精確，44/44）

```
γ_n = 4sin²(πn/88) 喺 n ≤ 44 嚴格遞增
支撐 ≤ k 之最大質量：λ_max(k) = Σ_{n=45−k}^{44} γ_n

用配對和 γ_j + γ_{44−j} = 4（M6 docs/01 A3）逐項代換：
    λ_max(k) = 4k − Σ_{j=1}^{k−1} γ_j        （閉式，偏差 < 1e−40，44/44 全過）
```

| k | λ_max | log₁₀ |
|:-:|--:|--:|
| 1 | 4.000000 | 0.602060 |
| 2 | 7.994904 | 0.902813 |
| 3 | 11.974547 | 1.078259 |
| 4 | 15.928841 | 1.202184 |
| 8 | 31.296348 | 1.495494 |
| 12 | 45.505650 | 1.658065 |
| 22 | 72.999369 | 1.863319 |
| 44 | 90.000000 | 1.954243 |

**推論（關鍵）**：`λ_max(k) < 4k` ⟹ **支撐每增 1 個 mode，質量上界只升 ~4 M₀**。
即：質量對「支撐數」係**線性**嘅，唔係指數嘅。

## §4 T3′ 層數定理：加法 vs 乘法（本項核心）

```
目標 D = log₁₀(M_Pl/M₀) = 20.641058 dex

乘法分層（每層 ×Σγ = 90 ⟹ 1.954240 dex/層）：需 10.5622 層
加法量子（每量子 +90 M₀，高 λ 處 0.0 dex）：需 4.86201e18 量子
⟹ 相差 4.60e17 倍
```

**判決**：

1. **T1 已證複合係加法**（M6 docs/01：任意分割 dev = 0，域內恆等式）⟹
   要用「幾十層對數階梯」解釋穹頂，**必須放棄 T1 加法**，改乘法／對數分層。
2. 但乘法／扇式分層已由 **M8 R1**（docs/02 §3）證為只生**常數**（`Πtan = 1`、`γ_n+γ_{44−n} = 4`），
   **唔生標度** ⟹ 對數階梯唔可以提供中間標度。
3. 所以「中間幾十層隱藏」呢個圖像與 T1 不相容；由 T1 導出嘅正確圖像係：
   **中間 = 連續量子計數區**（每量子 1.954 dex 內連續），要到 M_Pl 需 4.86e18 量子，
   而其中冇任何量子數被結構單獨標記 ⟹ 中間層之所以隱藏，係因為**冇身份**，唔係因為被壓縮。

## §5 可證偽點

| 觀測預言 | 否證條件 |
|:--|:--|
| 單量子區 `[γ₁, Σγ] = [0.0051, 90] M₀`（4.25 dex）之外，任何質量都**必須**係多量子 | 若發現一個質量 `m` 有 `m/M₀ ∈ (90, 4.4e20)` 而可證為**單量子**（即某子集和）⟹ T1′/T2′ 錯 |
| 低支撐（≤2）上限 < 8 M₀ | 若能給出一個 > 8 M₀ 之質量 = 兩個 mode 之和 ⟹ 支撐定理錯（本輪 946 值全掃，無反例） |
| 中間層數 = 4.86e18（加法）而非 ~11（乘法） | 若能構造一條乘法分層嘅標度律且**唔放棄 T1** ⟹ T3′ 錯 |

## §6 邊界（誠實）

- 🟡 本節講「**質量標度**」嘅層結構；若宇宙另有非質量標度（如能量密度、時標）之層級，
  其層數須另算，唔可以套用本節結論。
- 🟡 「身份」用「支撐數」量化係一個**可操作代理**（proxy），唔係唯一可能定義；
  用其他代理（如對稱性、算子不變量）會得出唔同密度曲線，但 T1′ 線性界不變。
