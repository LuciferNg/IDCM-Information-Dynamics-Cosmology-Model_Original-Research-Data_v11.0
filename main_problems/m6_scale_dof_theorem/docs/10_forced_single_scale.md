## §1 定理（T2′：兩界夾出 dof_scale = 1）

**假設**
- **H1（Galois 協變）**：質量泛涵係 ℚ-定義 ⟹ `w_{g(n)} = g(w_n)`，`g ∈ Gal(ℚ(ζ₈₈)⁺/ℚ)`。
- **H2（關係保持）**：晶格之全部 ℚ-關係在質量上仍成立：
  `Σ_n c_n γ_n = 0 ⟹ Σ_n c_n w_n = 0`（25 條，秩 24 = 核維，**張滿核**）。
- **H3（軌道標度形式）**：`w_n = μ_{orb(n)} γ_n`，`μ ∈ ℚ`（H1 強制 μ 為有理，見 §3）。

**結論**
```
(上界 ≤ 1)  H1 + H2 + H3  ⟹  μ_1 = μ_2 = … = μ_7  ⟹  只剩整體倍率 (1 維)
(下界 ≥ 1)  齊次性（docs/12）⟹ 整體倍率不可由任何結構性質固定
────────────────────────────────────────────────────────────
            ⟹  dof_scale = 1  **恰**（兩界齊全）
```

## §3 為何 H1 會強制 μ 為有理

若 `μ_g ∈ ℚ(u)\ℚ`，則對 `g ∈ Gal`：`w_{g(n)} = g(μ_g) g(γ_n) ≠ μ_g g(γ_n) = g(w_n)`
（因 `g(μ) ≠ μ`）⟹ 協變破裂。故 **H1 ⟹ μ_g ∈ ℚ**，與 §2 第二列一致。

## §4 反例案（誠實記錄）

**場值標度（6 個自由）** 之所以存活，機制明確：
```
μ_a γ_n + μ_b γ_{44−n} = μ_c γ₄₄ ，而 γ_{44−n} = 4 − γ_n
⟹ (μ_a − μ_b)γ_n + 4(μ_b − μ_c) = 0
⟹ 在場中可由 (μ_a − μ_b) = −4(μ_b − μ_c)/γ_n ≠ 0 滿足（**唔需要** μ_a = μ_b）
```
即：**只有當標度被限制為有理數時，關係保持才咬得住。**
