## §1 問題

`dof_scale = 1` 只講**標度軸**。M6 `docs/02 §6` 已標明：dimensionless 未定數（如 p）唔佔標度軸，但**確實未閉合**。
本節要答三件事：

- **A** p 會唔會偷偷吸收標度軸（即「p 同 M₀ 係同一個自由度嘅兩種寫法」）？
- **B** p 未定時，速率預言仲有冇鑑別力？
- **C** 全模型自由度總帳點寫，才唔會誤導？

## §2 A：量綱（精確指數運算）

```
M2 §9：dm/dt = p·(M₀γ_n)/Δt = p·M₀·γ_n·R_max

dim(dm/dt) = (1,0,−1)  [MeV/Gyr]
dim(M₀)    = (1,0, 0)
dim(R_max) = (0,0,−1)  [Gyr⁻¹]
⟹ dim p = (1,0,−1) − (1,0,0) − (0,0,−1) = (0,0,0)  ✅
```

（對照：若漏掉 `M₀γ` 因子會誤得 `(1,0,0)` = 質量維。本輪首跑正正犯此錯，已修並記錄——屬**腳本錯**，非物理錯。）

## §3 B：獨立性（Jacobian，非冪律比對）

```
觀測映射 (ln M₀, ln p) → (ln m, ln rate)：
    m    ∝ M₀           （p 無關）
    rate ∝ p·M₀·γ·R_max

J = [[∂ln m/∂ln M₀,    ∂ln m/∂ln p   ]] = [[1, 0],
     [∂ln rate/∂ln M₀, ∂ln rate/∂ln p]]   [1, 1]

det J = 1 ≠ 0 ⟹ rank = 2 ⟹ (M₀, p) 係兩個**獨立**自由度
```

⟹ **冇任何重定義可以令 p 同 M₀ 合併**：p 改速率唔改質量，M₀ 改全部質量（比率不變）。

> ⚠️ 方法註記：本輪首跑用「`p^a = M₀^b` 有無解」做判準，**係錯嘅**——p 無量綱 ⟹
> 任何 `b = 0` 都自動「解得」，退化。已改用 Jacobian（真判準）。

## §4 C：預言力（量化 M2 §9 之 conditional no-go）

```
R_max = 1.0397344 Gyr⁻¹（零參數上界；tick = T_ring/88 = 0.96178409 Gyr）
rate = p·R_max
```

| p | dm/dt (Gyr⁻¹) |
|:--|--:|
| 0.001 | 0.001040 |
| 0.01 | 0.010397 |
| 1/88（禁區凑數） | 0.011815 |
| 19/41（禁區凑數） | 0.481828 |
| 0.9 | 0.935761 |
| 1.0 | 1.039734 |

**覆蓋率 = 100%**：任何 `r ∈ (0, R_max]` 都存在唯一 `p = r/R_max ∈ (0,1]` 解釋。
⟹ 速率**預言零鑑別力**；宣稱「量到 r」只會被翻譯成「p = r/R_max」，唔構成對 p 之預言。
⟹ 反過來講：**只有當觀測給出 `r > R_max = 1.0397344 Gyr⁻¹`，交換律才被否證**。此為本軸唯一可證偽點。

## §6 判決

| 命題 | 判決 |
|:--|:--:|
| p 佔標度軸？ | **🔴 否**——dim p = 0，Jacobian rank 2 |
| p 與 M₀ 可互換？ | **🔴 否**——det J = 1 |
| p 未定 ⟹ 速率預言有效？ | **🔴 零鑑別力**（覆蓋 100%） |
| 速率軸唯一可證偽點 | `r > 1.0397344 Gyr⁻¹` ⟹ 交換律否證 |
| M6 可唔可以定 p？ | **🔴 唔可以**（無結構必需性；任何揀值都係 M2 §9 明文禁止之凑數） |

**給 M2 之回覆**：M6 確認 p 係**真獨立**嘅 dimensionless dof（唔係標度自由度之偽裝），
所以 M2 之 conditional no-go 係**結構性**而唔係「未搵到」；要開，需一條能從躍遷計數
（而非擬合）給出概率嘅機制。M6 唔越界代推。

## 附註更正（2026-10-26，append-only；原文不改）

> 觸發：`docs/10` 之 Galois 軌道結構（7 軌道）＋ 尺度軸／速率軸不對稱分析。

本節 §3「自由度總帳」原寫「dimensionless 自由數 **1**（p）」。**惟該數字在未加

        若額外假設 p_g ≡ p（mode-blind 均勻）⟹ 1 個自由（= 本節原帳）

**修正後帳本**：尺度軸 **1（被迫）**（`docs/10` T2′）＋ 速率軸 **≤6（自由，未被迫）**。
