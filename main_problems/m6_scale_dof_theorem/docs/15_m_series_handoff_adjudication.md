## §1 H1（M5）κ 之絕對值：dof=1 **唔**能固定

**問**：dof=1 定理能否把 κ 之 MeV 值固定？

**答**：**不能，且可精確界定它能定到哪裡**。

```
κ/M₀ ∈ [2.457611, 2.529465]     （M5 H4b 號解窗 ÷ M₀）
⟹ dof=1 所固定嘅係「κ 屬 M₀ 標度（= c_κ·M₀）」呢件事，唔係 c_κ 本身
```
- **標度層（已閉）**：κ 無獨立 MeV 標度 ⟹ 帳本尺度 dof 仍 **1**。
- **數值層（無身份）**：`scripts/15` §2 掃描 `c_κ` 兩端點 ＋ `κ_crit = 0.00455132`：**嚴格命中 0｜隨機期望 0**
  （71 原子、67 166 候選值、rtol 1e−9、20000 隨機目標）⟹ 判「**標度已閉、數值無算子身份**」，`c_κ` 入超越槽。
- dof=1 嘅正確表述：**任何有量綱量 = M₀ × (純數)**；純數是否有身份係另一問題（B3）。

## §7 H7（M15）FORCE_44 ＋ dof 張力：⚖️ **裁定「兩賬分立」，dof=2 不成立**

**M15 之問題**：`N_d = 44` 若係第二個獨立錨 ⟹ O212「dof = 1」需修訂為 2。

**裁定**：**兩個 dof 賬，唔可以相加。**

| 賬 | 內容 | 現值 | N_d = 44 之地位 |
|:--|:--|:--|:--|
| **連續尺度賬**（O212） | 有量綱標度自由度 | **1**（錨 `G ≡ ω_ring ≡ M_Pl`） | **不入此賬**：`N_d` 係無量綱整數 |
| **無量綱賬**（本記錄 B3） | 超越槽（連續自由數） | 速率 ≤6 ＋ 強子形狀 2 ⟹ **≤9** | 不入此賬（非超越） |
| **離散錨賬**（本節新增） | 整數結構錨（不可互推） | `{N_d = 44, N = 88 = 2N_d, B = 4}` | **在此賬 +1** |

**理由（三句）**：
1. 連續 dof 之定義係「有量綱標度嘅獨立個數」；`N_d` 係**純計數**（88 站之半），唔帶量綱 ⟹ 加它不會產生第二個 MeV 尺度。
2. M15 FORCE_44 四閘全中 ⟹ `N_d = 44` 確係**錨**（不可由 corpus 推出）⟹ 它構成一個**離散**自由度，須明列，唔可以假裝它係結構推導結果。
3. 兩賬相加 = 類別錯誤（同「把質數個數加入長度自由度」）。O212 之 `dof = 1` **無需修訂**；需修訂嘅係「帳本要明列離散錨」。

**對 M15 之要求（一件）**：其 dof 表述改為「連續 dof = 1；離散錨集另列」。

★ 附：`N_d = 44` 之錨地位與本記錄 `docs/14` B2 相容 —— B2 只需要「錨恰一」作用於**尺度**；離散錨多寡唔影響 B2。

## §9 H9（M18）MA6 `ħc/a₀ = 522.83 MeV` 之算子身份：🔴 **no-go（附結構理由）**

**判**：**無算子身份；判 no-go。** 兩層理由：

**(a) 機器核（本輪）**：`T_A` 兩約定皆 **0 嚴格命中**（隨機期望 1／0）；候選集 = 71 原子（γ₁…γ₄₄、Σγ=90、N_d=44、N=88、B=4、φ、π、√2、√5、ln2、cot(π/88)、M0/M_Pl、1/44…）× ≤3 項積 ＋ 二項商 = **67 166 值**。

**(b) 結構理由（比掃描更硬）**：
1. B1（`docs/14`）證明：**晶格譜 ℚ-多項式** ⟹ 落 `ℚ(ζ₈₈)` ⟹ 代數、零連續自由度。`a₀` 唔屬此類 —— 它係**束縛態求解器之長度輸入**（M5 唯一校準點 D 通道匹配所得），唔係譜之函數。
2. 要 `a₀` 有身份，須存在「結構數 × (M₀ 或 ħc 之 ℚ-多項式組合)」；`ħc/a₀` 之無量綱比 `T_A` 就係該純數。掃描 0 命中 ⟹ 現行算子集**唔含**該數。
3. 因此 `ħc/a₀` 落 **B3 超越槽**：法律上可以有一個身份，但**唔可以係現有算子之組合**（B1 封閉性 ⟹ 任何 `ℚ(ζ₈₈)` 元素已可判別；掃描 0 命中即判別結果）。
**範圍**：no-go 僅對「以 γ 譜 ＋ 已註冊結構整數之 ≤3 項組合」成立；若引入**新算子類**（例：束縛態 eigenvalue 本身），則屬另一問題，唔係本 no-go 之範圍。M18 要求嘅「判 no-go 並給結構理由」已達。
