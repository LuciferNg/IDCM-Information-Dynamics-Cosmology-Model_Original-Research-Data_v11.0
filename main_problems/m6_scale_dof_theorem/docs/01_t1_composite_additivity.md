## §1 算子定義

```
M̂ : 2^{1..44} → ℝ,      M(S) = M₀ Σ_{n∈S} γ_n,   γ_n = 4sin²(πn/88) ∈ ℚ(ζ₈₈)⁺
```

1. **算子 well-defined**：複合質量 = 子集和；m(S)/M₀ ∈ ℚ(ζ₈₈)⁺。
2. **加性 = 域內恆等式**：任意分割 dev 恰 0（9100 次）；交叉項 κ = 0（獨立實例核對）。
