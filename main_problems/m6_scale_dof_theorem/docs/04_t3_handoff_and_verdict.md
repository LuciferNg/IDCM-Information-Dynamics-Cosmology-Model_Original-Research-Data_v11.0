## §2 M5→M6 入站 handoff 之答覆

> κ（鏈耦合常數）之絕對值／hadronic scale 識別，M5 層不可推——M5 之 ⟨1/r⟩ 核只定比值。
> 問：dof=1 定理能否把 κ 之 MeV 值固定？

**答（結構性，非資料不足）**：

```
1. 由 T2：κ 唔係第二標度 ⟹ κ = M₀ × λ，λ 無量綱
   視窗 [68.5696, 70.5744] MeV ⟹ λ ∈ [2.457611, 2.529465]（窗寬 0.071854）
2. 密度檢定：小有理數池（a,b ≤ 40）落入此窗 **3 個**；命名結構候選 2 個
   （5/2 = 2.5 ⟹ κ = 69.7523 MeV；√(88/14) = 2.507133 ⟹ κ = 69.9513 MeV）
   ⟹ 視窗對候選**無鑑別力**
3. ⟹ dof=1 定理【不能】固定 κ 之 MeV 值——係結構原因，唔係量度不足
4. 定理能做嘅：把「κ 未知」降為「κ = M₀ × 無量綱數」 ⟹ 減少一個 unknown，
   而唔係定值；λ 之識別屬**算子身份層**（M4/M5 之 ⟨1/r⟩ 核／D 通道），
   唔屬標度層。
5. 附帶：M5 之兩個 κ（0.2150／0.26986，無量綱，D 兩數定）與此處 MeV 級 κ 係
   不同對象（符號碰撞）——λ 之身份必須由 M5 內部算子導出，唔可以跨層套用。
```

**⟹ 對 M5 之回覆要點**：唔可以靠本 M 收窄 κ；但可以刪去「κ 係獨立標度參數」呢個可能性
（呢個係真進展：M5 唔需要為 κ 另設標度自由度）。
