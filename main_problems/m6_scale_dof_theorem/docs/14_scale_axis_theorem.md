## §1 B1 代數剛性（定理 ＋ 機器核）

### 1.1 陳述

> **定理 B1**：設晶格譜 `γ_n = 4 sin²(πn/88) ∈ ℚ(ζ₈₈)⁺`（ζ₈₈ = e^{2πi/88}）。
> 任何由 `{γ_n}` 經**有限 ℚ-多項式**（加、乘、有理係數）得到之結構常數 `F`
> ⟹ `F ∈ ℚ(ζ₈₈)` ⟹ **F 為代數數 ⟹ 完全確定、零連續自由度**。

### 1.2 證明（三行）

1. `γ_n = 2 − (ζ^n + ζ^{−n})`，故 `γ_n ∈ ℚ(ζ₈₈)⁺`（`ζ` 之代數整數組合）。
2. ℚ-多項式在體上封閉 ⟹ `F ∈ ℚ(ζ₈₈)`；其共軛為 `σ_m(F) = F(σ_m(γ))`，`σ_m(γ_n) = γ_{mn mod 88}`，`m ∈ (ℤ/88)^×`（|·| = 40）—— **全部由整數決定**。
3. 代數數由有限個有理數確定 ⟹ **冇任何可調連續參數**。（離散自由度仍可存在 ⟹ 由 21 質量 ℤ-關係測試管，見 §6。）

### 1.3 ★ 關鍵分野：**「不變」≠「確定」**

早期版本（及 `docs/10`）要求「Galois 協變」作為**假設**。本節機器核顯示：

| 類型 | 例子 | 環項數 | 判 |
|:--|:--|--:|:--|
| **有理（不變）** | `Σγ = 90`、`γ₄₄ = 4`、`γ₂₂ = 2`、`(γ₀+γ₄₄)/2 = 2` | 1 | 40 個共軛全同 |
| **代數（有共軛、仍確定）** | `γ₇·γ₃₇ = 0.9187183650888048`、`γ₁²−γ₄₃² = −15.95923383376406` | 3 / 11 | 共軛互異，但**逐個由整數決定** |
| | `Σn·γ_n/44 = 63.84010601005435`（環項數 39）、`γ₂³/8 = 1.0545296187456e−6` | 39 / 19 | 同上 |

⟹ **B1 比 `docs/10` 更強**：唔需要「關係保持」、唔需要假設協變；只需要 F 係 ℚ-多項式。
⟹ 強子層質量**唔**屬此類（束縛態是 eigenvalue，非 ℚ-多項式）⟹ 強子層**唔**受 B1 保護 —— 但**亦唔需要**（尺度軸靠 §2）。

### 1.4 機器核（精確分圓環，非浮點）

`Φ₈₈(x) = Φ₁₁(−x⁴) = Σ_{j=0..10} (−1)^j x^{4j}`（度 40；已用 `sympy.cyclotomic_poly(88)` 核對 **match = True**）。

## §2 B2 適足性（定理）

### 2.1 陳述

> **定理 B2**：設理論有 `d` 個獨立有量綱輸入，而**錨恰一**（O212：`G ≡ ω_ring ≡ M_Pl` 為唯一測量）。
> 則：`d = 1` ⟺ 全部標度比（`Λ_i/Λ_j`）皆可預言；`d ≥ 2` ⟹ 剩 `d−1` 維參數族**無任何預言**。

### 2.2 證明

`d` 個獨立標度 ⇒ 物理只依賴 `d−1` 個比值；一錨只定一個標度 ⇒ 剩 `d−1` 個比值無約束。`d=1` 時零剩餘比值 ⇒ 全部標度由錨固定。 ∎

### 2.3 實例（實測）

```
H₀(pred) = 67.4071（c = R_world·ω_ring 錨，非自由）
Planck 2020: 67.36 ± 0.54   ⟹ z = 0.087σ
```
若 `d = 2`，`H₀` 係自由數 ⟹ 呢個 0.087σ 巧合無意義。⟹ **dof=1 有預言力，並且被兌現**。

★ 地位變化：`dof_scale = 1` 由「表示法事實」升為**適足性條件**（可證偽，見 §6）。
