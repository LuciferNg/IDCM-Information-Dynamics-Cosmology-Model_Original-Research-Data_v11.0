## §二 判定

### (i) 一致規則（同一規則供三讀數）

```
catalog 251 ｜ |z_d|<1 ∧ |z_u|<1 = 0 / 251 ｜ |z|<3 = 10 / 251 = 3.98%
min χ = 2.1688087 @ (ρ_d, ρ_u) = (39/82, −2/41)
       該三元組由 **T1(2,4) 與 T1x(c2/c4)** 兩條規則共用 ⟹ 地板點無結構身份
```

### (ii) 每讀數自選規則（已註冊，但組合係後驗選取）

```
值集：δ_s 177 ｜ δ_d 79 ｜ δ_u 97  ⟹ 選擇空間 = 1,356,351 ⟹ **20.371 bit**
最優：ρ_d = 21/52、ρ_u = −1/39 ⟹ χ = 0.0123
```

⟹ 「每讀數自選」可以貼到 0.01σ —— 但代價 20.37 bit ∣ 依 `§七①`＋look-elsewhere **零判別力**。

### (iii) 三族互不包含

```
覆蓋之三元組數：T1 166 ｜ T1x 88 ｜ T1p 9 ｜ 總 251
只由單一類覆蓋者 = 240 / 251
```

⟹ 三族**互相有新值**（非嵌套）⟹ 分開跑並非重複計算；合併後結論仍係 0 個 1σ。
