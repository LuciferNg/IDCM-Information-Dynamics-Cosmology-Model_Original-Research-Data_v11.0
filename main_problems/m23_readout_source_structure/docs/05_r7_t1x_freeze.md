## §〇 覆蓋缺口（自捕，誠實記錄）

`docs/01 §二` 三型實際定義：

| 型 | 定義 | 源對與 `x` 之關係 |
|:-:|:--|:--|
| T1 | `δ_x = D_{a,b}[G](k_x)` | 一對，**與 `x` 無關** |
| T2 | `ρ_x = D_{a₁,b₁}[G](k_x) / D_{a₂,b₂}[G](k_s)` | **分子／分母**兩對，與 `x` 之身份無關 |
| T3 | 由配對幾何（Gram／`G` 比值）直接給 `ρ` | **唔係場差** |

⟹ **缺一格**：`δ` 仍係場差，但**源對隨 `x` 走**（`p = p(x)`）。此即 `Q1` 第二問之直接形式，
亦係「源站本身就係物件」之最自然實現。首輪三型**未算此格** ⟹ 本輪補齊，並擴充 NG1 之範圍。

## §一 語法（T1x）

```text
p : {u,d,s} → { (i,j) : 1 ≤ i < j ≤ 44 }
δ_x ≡ D_{p(x)}[G](k_x) = G(b_x, k_x) − G(a_x, k_x)          p(x) = (a_x, b_x)
ρ_x ≡ δ_x / δ_s
```

兩族（**預註冊**）：

| 族 | 內容 | 自由整數 |
|:-:|:--|:-:|
| **F-F1** | `p(x) = (f₁(k_x), f₂(k_x))` —— **同一對映射**供三個讀數（「隨站但族內一致」） | `f₁,f₂` 若由結構固定 ⟹ **0** |
| **F-F2** | `p(u), p(d), p(s)` 三對**獨立**（「每讀數自選源」） | 6 個整數 − 1 標度 ⟹ **有效 5** |

★ `F-F1` 係本輪**主判對象**：唯一可能保有零參數地位者。`F-F2` 只作參數代價披露。

## §二 映射集 `M`（**只准入已註冊關係**，跑前凍結）

```text
M ≡ { 1, 2, 3, 4 }                              （鏈起點 ＋ 味站集，M14）
  ∪ { k_x + d  :  d ∈ {−2,−1,0,1,2} }           （自身／鏈鄰接／次近鄰：P₄₄ 邊結構）
  ∪ { 45 − (k_x + d) : d ∈ {−2,−1,0,1,2} }      （模反射 45−k 之平移合成；R25 恆等 γ_{45−n}=4−γ_n）
```

| 成員 | 已註冊依據 |
|:--|:--|
| `k_x` | 探針指派（M14；`docs/01 §一` 之 P 側） |
