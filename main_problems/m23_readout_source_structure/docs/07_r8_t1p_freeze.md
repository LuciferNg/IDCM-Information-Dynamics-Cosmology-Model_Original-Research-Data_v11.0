## §〇 為何「源」可以係剖面

已註冊恆等（M12 `docs/28` R15）：`δ_x = Σ_n w_n φ_n(k_x) Δ_n`，其中 `Δ_n` 係**源剖面之模態投影**：

```text
δ_x = Σ_j s_j · G(j, k_x)          （station-space 剖面 s ∈ ℝ^44）
⟺  Δ_n = Σ_j s_j φ_n(j)            （mode-space 剖面）
```

⟹ 「源對」只係 `s = e_b − e_a`（兩點差）之特例。S 側之**完整**自由度 = 「揀邊個 `s`」。
`docs/01` 三型 ＋ `docs/06` T1x 只覆「`s` 為（一或兩）點差」⟹ 本輪補「`s` 為已註冊剖面」。

## §一 語法（T1p）

```text
δ_x ≡ Σ_j s_j G(j, k_x)      ｜  ρ_x ≡ δ_x / δ_s
准入：s 須係**已註冊結構**（下表 P1–P8）或**自由剖面**（P9，只作參數代價披露）
```
