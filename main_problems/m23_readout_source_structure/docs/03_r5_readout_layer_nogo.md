## §三 失敗機制：形狀層，唔係來源層（`scripts/04` C2b）

```text
相鄰站同段（k_d=3 與 k_s=4 落同一段）⟹ ρ_d = 該段之 k 依賴比值：
   OUT 段（k>b）： ρ_d = (45−3)/(45−4) = 42/41 = 1.02439  ⟹ **必然 ≈ 1**
   IA  段（k≤a）： ρ_d = 3/4      = 0.75
量測：ρ_d = 0.40350365
   42/41 ÷ 0.40350 = 2.5387  ⟹ 結構值係量測之 2.54 倍
   量測 ÷ 42/41   = 0.39390  ⟹ 量測只係結構值之 39.4%
```

★ **關鍵**：`d` 與 `s` 係**相鄰站**（3, 4）；任一「一階源差」讀法若兩站落同一段，比值就被
`(45−k)` 律鎖死於 1.02 或 0.75，**唔可能係 0.4035**。要跨段，則弦須短（`b=3` 或 `a=3/4`），
而該類成員之 `(ρ_d,ρ_u)` 已在 F-A 中窮盡（`−3/41`、`3/4`、`39/82` …）⟹ 仍無 1σ 命中。

★ 因此 M20 `docs/02 §十` 之診斷（「缺者 = 讀數之來源結構（單核 → 雙源／關係型）」）
**被本輪否證**：來源側三型窮盡、被迫型死、旋鈕型非預言。
真缺口係 **W 側（核之結構來歷，M12 R15 之 `T0` `f`-provenance）** 或 **δ 之形狀（超本 M 章程）**。
