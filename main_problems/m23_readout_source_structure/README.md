## 一句話

M20 證明了載體側已封（最小物件唯一且被否證），並診斷失敗在**單核 ansatz** ——
本 M 處理該診斷：**三個 `δ` 是否必須共用同一個 `G`**。

**結論（2026-11-20）**：**必須同源，而且來源結構唔係缺口。**
源對側三型窮盡：被迫型 `(2,3)`（零參數）給 `ρ_d = 42/41`（z **+17.69**）；關係型（零參數、形式唯一）給 `(−1/2,+1/4)`（**27.07σ**）；唯一近命中（0.231σ）屬雙源型、代價 **7.35 bit** ⟹ 旋鈕。
真缺口 = **W 側（核之結構來歷，M12 `T0`）** ＋ **`δ` 形狀層（超本 M 章程）**。
關鍵新結果：`SL1` 形狀引理（`δ` 之三段閉式，7 段位類）＋ `DA1` 區分軸唯一性 ＋ `NG1` 讀數層 no-go。
