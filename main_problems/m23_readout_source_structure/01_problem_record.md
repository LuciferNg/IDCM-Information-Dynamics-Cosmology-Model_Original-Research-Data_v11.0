## §一 問題陳述

M20 之三條實測事實：

```
① 單鍵 ±1 類 3606 成員：ρ_u 易中（592 個 |z_u|<1）而 ρ_d 一個都唔中（0 個 |z_d|<1）
② 「中 ρ_d」之罕見下尾成員 ⟹ ρ_u 必大錯（F4：ρ_d 14/41 z=−1.77 vs ρ_u −28/41 z=−19.96）
③ 加弦普遍抬高 ρ_d（90–96%）；目標要求壓低至 0.4035 ⟹ 方向相反
```

⟹ 同一 `G` 同時供三個 `δ` 之**單核假設**係綁定約束：兩讀數對核之要求方向相反。

**Q（問題）**：

| # | 問題 |
|:-:|:--|
| Q1 | `δ_x = G(3,k_x) − G(2,k_x)` 之**正確定義域**係咩？三個 `δ` 是否必須同源（同一 `G`）？抑或「源站」本身就是物件（`δ` 係**源-站配對**之函數，唔係單一場量之差）？ |
| Q2 | 若讀出式須改，改動之**最小結構形式**係咩？能否由已註冊結構（M12 R24 之 Gram 幾何、M13 近正交、M14 站指派）**逼出**，而非由 `ρ` 目標值反解？ |
| Q3 | 新讀出式能否**零參數**同時閉合 `ρ_d = 0.40350365` 與 `ρ_u = −0.02588837`（並使 `δ_u < 0` 自動）？ |
| Q4 | 若不能，如何證明「單源不可 ∧ 雙源亦不可」而**唔係**「未找到」？ |
