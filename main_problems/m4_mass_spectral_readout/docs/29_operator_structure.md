## 四、M1 之結構讀法（**標記：後驗，非推導**）

```
⟨O⟩ = 1 + (B − 2)·n_s / N_q ,   B = 4（樹分支）、N_q = 3（價夸克數）
```

即「每個奇異夸克令 isovector 矩陣元增加 `(B−2)/N_q = 2/3`」。
**動機**：`B−2` 係樹上「非主幹分支」數、`N_q` 係價夸克數 —— 兩者皆已註冊之結構常數，無新參數。
**但**：此形式係睇完 3 錨才寫出，按本 M 紀律屬**後驗**，**不得稱為 derived**，只能當**盲測候選**。

## 五、如何令它變成結構（下一步之驗收規格）

在 IDCM 譜架構上計 `⟨O⟩_ch = ∂M_h/∂(m_d − m_u)`（Feynman–Hellmann），要求**零參數**產出：

| 驗收 | 內容 |
|:--|:--|
| V1 | 質量讀出 `M_h = F(γ_n, 樹重疊)` 對味質量參數作**有限差分**，須得 `a = 0.89 ± 0.11`、`b = 0.68 ± 0.16`（不得事後調 `B`、`N_q`）|
| V2 | 對 `n_s = 0,1,2` 三點**同時**符合（不許只中一點）|
| V3 | 對 `K`（介子）給 `⟨O⟩ = 1.6–1.7`，即 `em(K⁰−K⁺) ≈ +0.3 MeV` |
| V4 | 對 `D`（charm 旁觀）給 `⟨O⟩ = 1.0 ± 0.2`，即 `em(D⁺−D⁰) ≈ +2.3 MeV` |
| V5 | 不得引入未註冊常數；`B = 4`、`N_d = 88`、`N_gen = 3` 之外唔准加 |

## 六、界限與誠實標記

- 三錨全部來自**同一篇** lattice 工作（BMW 2013），系統誤差相關；`σ` 未含其 QED 淬火誤差（`O(10%)`）⟹ 本文 χ² 偏樂觀。
- `⟨O⟩_Σ` 對 `Σ` 之**兩個**通道（`Σ⁻−Σ⁰`、`Σ⁰−Σ⁺`）共用一個值，屬**假設**（BMW 只給 Σ 總值）。
- `D` 之 `n_s` 計法（charm 旁觀不計 s）屬**選擇**；若 charm 亦計入則 `⟨O⟩_D → 1.667`、`em_D → +0.55`，兩種預言差 1.7 MeV ⟹ 須先釘死計法。
- 斜率判別力不足（見 §二末），故 M1 vs M3 vs M4 **目前不可分**；本文不宣稱 M1 優於 M3/M4。
- 全部預言只依 `⟨O⟩`；**未**觸及 `docs/26` 之窗（已於 `docs/28` 撤銷）。
