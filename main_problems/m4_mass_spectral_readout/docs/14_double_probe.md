## 五、結論報告

1. **G5 核心被量化為單一數字**：三條 Δm 全部係 `|ΔQ| = 1` 通道，但 π 通道 em 讀數係 K/N 通道嘅 **3.479 倍且符號相反**（`R_em = 3.479111`）。所以「em 讀數」唔係單一算子 —— 呢個就係 gap G5 嘅精確定義（唔再係模糊嘅「反相」）。
2. **`R_em` 譜身份 🔴**：γ 比池 0.0698% 看似靚，但 density P1 = **34.73%** ⟹ 隨機級；結構整數比池 27.90% 亦隨機級。**呢個係 density 殺嘅又一實例**（docs/09 protocol）。
3. **反相 ≠ 新物理**：P3 顯示 `ΔN = (m_d−m_u) + E`、`ΔK = −(m_d−m_u) + E` 係 **E 嘅定義式** ⟹ 「反相」只係 `E < 0` 加夸克內容符號翻轉嘅**恆等還原**，唔構成證據（同 O246 P1 ms/mu 校準恆等同一類陷阱）。要真正解釋反相，仍然要推導 `E` 本身（即 em 讀數算子）。
4. **`E` 無 IDCM 譜形式 🔴**：13104 族 0 命中 <0.1%，最近 1.75%，density 4.39% ⟹ 唔可辨識。
5. **🟡 反解值（未升格）**：`m_d−m_u = 2.613666 MeV` vs lattice 2.56±0.094 ⟹ **+0.57σ** 統計一致，**但 dev 2.0963% 未過事前 <1% 門檻** ⟹ 依事前判準維持 🟡（唔可因為 σ 細就放寬門檻；亦唔可因為 dev 大就當否證）。
6. **H1 前提（`E_K = E_N`）本身未推導**：反解值依賴「K 與 N 屬同一 |ΔQ|=1 通道且 em 讀數相同」；此前提由數據結構支撐（同夸克對、同 |ΔQ|），但**唔係 K_chain 推導** ⟹ 屬 premise，非結構強逼。
