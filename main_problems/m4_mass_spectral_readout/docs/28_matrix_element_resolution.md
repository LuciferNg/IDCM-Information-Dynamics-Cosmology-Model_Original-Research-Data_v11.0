## 一、前設問題

`docs/27` 以 `E = Δm − coeff·X`（單一 `X = 2.56`）作殘餘，得出「三通道聯合要求 `X > 3.934`，與 `2.56 ± 0.094` 差 14.6σ」。
三條逃生口中 **E2（`X` 非普遍）** 最可疑：夸克質量差 `m_d − m_u` 係普遍，但**強子矩陣元** `⟨h|d̄d − ūu|h⟩` 不必係 1。
本輪用 lattice QCD+QED 之權威分割直接檢定。

## 二、外部錨（BMW TABLE I，MeV；取向 `ΔM_X = M(高電荷) − M(低電荷)`）

| X | `ΔM_X`（total） | `ΔQED M_X` | `ΔQCD M_X` | 實驗 `ΔM_X` |
|:--|--:|--:|--:|--:|
| N | −0.68(39)(36) | **+1.59(30)(35)** | **−2.28(25)(7)** | −1.2933 |

| Ξ | −7.16(76)(47) | **−1.29(15)(8)** | **−5.87(76)(43)** | −6.8500 |

其分解式 `ΔM_X = A_X α + B_X ΔM²`（`ΔM² ≡ M²_ūu − M²_dd`）之 `B_X ΔM²` 即夸克質量部分 ⟹
**`⟨O⟩_ch ≡ |ΔQCD| / (coeff · X)`** 即「該強子之 isovector scalar 密度矩陣元」（Feynman–Hellmann：`∂M_h/∂(m_d−m_u)`）。

## 六、新增零參數目標（M4 新主線）

IDCM 必須**預言** isovector scalar 矩陣元 `⟨O⟩_ch = ∂M_h/∂(m_d − m_u)`：

| 錨（lattice，獨立於 M4）| 值 |
|:--|--:|
| `⟨O⟩_N` | 0.891 ± 0.107 |
| `⟨O⟩_Σ` | 1.498 ± 0.262 |
| `⟨O⟩_Ξ` | 2.293 ± 0.351 |
| `⟨O⟩_K` | **> 1.537**（必要條件，非量度）|
| `⟨O⟩_D` | 未得（需 charm lattice QED）|

**結構判讀（僅記錄，未採信）**：`⟨O⟩` 隨奇異數 `n_s` 單調升（0.891／1.498／2.293）。
兩參數線性 `⟨O⟩ = 0.891 + 0.701 n_s` 給 `⟨O⟩_K(n_s = 1) = 1.592`（僅 1 自由度，**不足為證**；且 K 係介子非重子）。
若該趨勢成立，`em(K⁰−K⁺) = −3.934 + 2.56×1.592 = +0.14 MeV`（近零）—— 此為**可證偽預言**，須待獨立 lattice QED 之 kaon 值。

## 七、界限與誠實標記

- `⟨O⟩` 由 BMW 之 `ΔQCD` 反推；該文 QED 用 quenched（sea 無電磁），自評 QED 淬火誤差 `O(10%)`，未計入誤差棒 ⟹ 本文 `σ` 偏樂觀。
- BMW 總值與實驗本有 0.24–0.61 MeV 張力 ⟹ `em(M4)` 與 `−ΔQED` 之差即此張力，**本文不把它算入 M4 誤差**。
- K 通道 `⟨O⟩_K` 係該文輸入 ⟹ 不可用於檢定；本文只給必要條件。
- `Σ⁻−Σ⁰` 與 `Σ⁰−Σ⁺` 之分拆無外部對照（BMW 只給 Σ 總值）⟹ 該兩通道之 `⟨O⟩` 借用同一 `Σ` 值，屬**假設**，已標明。
- D 通道（charm）缺 lattice QED 錨 ⟹ 本文不覆蓋；`docs/26` 舊窗以 D 之 `A = 2.26` 計算者隨之失效。
- **可證偽點**：若將 `⟨O⟩_ch` 全設 1，本文所有結論退回 `docs/27` 之 14.6σ（即本文與 `docs/27` 之判別完全在 `⟨O⟩` 一項）。
