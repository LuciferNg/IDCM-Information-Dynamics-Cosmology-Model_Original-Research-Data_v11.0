## 五、結論報告

1. **hop 階梯唔係質量算子**：10 個費米子比，除 `s/d`（假命中）外全部 >1%（多數 >500%）⟹ 🔴。
2. **`s/d = 20.000` 係算術必然**：PDG 引用值 `m_s = 93.4`、`m_d = 4.67` ⟹ `93.4/4.67 = 20.0000` 恰好；兩者皆為 running mass 引用值（誤差 2.7%/10.3%）⟹ 唔可當命中（→ `docs/07` 追擊、`docs/11` lattice 判 19.8866±0.2452）。
3. **hop log 間距 vs 費米子 log 間距**：ν `m1→m2`（0.0347）近 hop 11→12（0.0378）dev 8.3% ⟹ 觀察級 🟡（→ `docs/07`）。
4. **雙 probe 比**：`|K/(n−p)| = 3.044` vs hop 比 3.0 dev 1.472% ⟹ 唔過門檻但係全部最好 ⟹ gap G5 線索。
5. **判定**：🔴（hop 作質量算子）；🟡（ν 近簡併 ↔ hop 微間距、雙 probe 比 ≈3）。
