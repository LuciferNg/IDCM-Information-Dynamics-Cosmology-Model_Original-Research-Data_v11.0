## 四、結論報告

1. **四個 sector 嘅最小 PN 分別係 48.07% / (n/a) / 48.16% / 30.98%** ⟹ 全部 > 5% ⟹ **01–08 所有「命中」皆隨機級** 🔴。
2. **舊數字作廢記錄**：05 記錄 8.7%（不可復現）→ 實跑 43.3%（原 protocol）；統一 protocol 下 `(n−p)/m_e` **PN = 30.98%**。三者關係已在 `docs/r01` §三、`docs/r02` §二 append-only 附註說明。
3. **密度殺 vs 誤差帶殺（方法核心）**：密度殺同實驗精度無關 ⟹ **不可逆**；誤差帶 kill 會隨精度提升失效（見 `11` T3）。故每個閉合必須同時報 `dev/σ` 與 `PN`。
4. **本腳本係方法資產** 🟢：往後任何 sector 命中判定，一律用呢個 protocol（thr = 命中自身 dev、域 = 受測比值域、雙軸報告）。
5. **注意**：池 = `γ_a/γ_b`（1936 值）**唔覆蓋** `γ_n²·常數`、`hop`、`exp`、`φ` 族 ⟹ 其他族需自建池（`12`、`13` 各自建族）。
