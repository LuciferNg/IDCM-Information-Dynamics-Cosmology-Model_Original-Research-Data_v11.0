## 二、事前判準（統一 protocol，先行寫死）

1. **池 P** = `{γ_a/γ_b | a,b ∈ 1..44}`，`γ_n = 4sin²(nπ/88)`，`|P| = 1936`，range [0.001274, 784.965]
2. **命中判準**：`dev(t) = min_{p∈P} |p/t − 1| × 100%`
3. **thr = 該命中自身 dev**（唔可以放寬）⟹ 每個命中都回答同一問題：「池密度本身就足以產生咁細嘅 dev 嗎？」
4. **null 域** = 該 sector 受測比值嘅 `[min,max]`（log-均勻抽樣）
5. **兩個判準都報**：單比級 `P1` = 一個隨機目標落入 thr 嘅機率；家族級 `PN` = N 個獨立隨機目標至少一個命中（N = 該 sector 受測比數）
6. **NMC = 10⁶**；向量化 ＋ log 空間最近鄰 ＋ 4 鄰居精確 dev 校正
7. **實作核對**：抽 200 target 對全池暴力驗證，**200/200 一致 ✅**

## 六、結論報告：判讀規則與跨 sector 判決

1. **全部 sector 命中 PN ≥ 31%** ⟹ γ 譜比池（1936 值）密度 = 隨機級；任何 0.01–0.7% 單點命中都唔可升格。
2. 差異只在池覆蓋：夸克域（比值細）密度最高（PN 48–99%）；輕子域（比值大）池稀疏（3/1936 落域內）。
3. **兩層唔可以互相借證據**：「差值閉合（Δm²+R）」嘅 🟢 係**力學層**（少參數解譜），唔係「比 = γ比」層（O257 §二 已劃）。
4. 要出現可升格命中：需 PN < 1% ⟹ 需要**更細嘅譜池**（結構強逼出唯一 mode，而非 1936 值任揀）。
5. `γ20 = γ_{B·F₅}`、`γ5 = γ_{F₅}`、`γ29 = L₇`、`γ16 = B²` 嘅「mode 身份靚」**唔改變 density 事實**。
