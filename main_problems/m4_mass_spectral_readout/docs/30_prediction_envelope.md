## 一、前設問題

`docs/29` 之 `b = 0.675 ± 0.161` 令 `2/3`、`1/2`、`3/4` 三者不可分。與其爭形式，本輪改問：

> 在**所有通過 χ² 門檻**之結構形式下，各通道 `em` 之取值範圍（包絡）幾寬？
> 若包絡狹窄 ⟹ 預言**型式無關**、可即時證偽；若寬 ⟹ 老實承認不可判。

## 四、結論報告：三條型式無關之可證偽預言

1. ✅ **`em(K⁰−K⁺) ∈ [−0.52, +0.55] MeV`** —— **全部**通過模型皆給 `|em(K)| ≲ 0.55 MeV`。
   標準 Dashen 式估計 ~ +2.3 MeV 落在包絡外 **4.2×** ⟹ 一條獨立 lattice QED kaon 值即可判生判死。
   **此為本 M 目前最鋒利、且不依賴形式選擇之預言。**
2. ✅ **`em(Σ⁰−Σ⁺) < 0`（恆成立，`[−1.21, −0.14]`）** —— 恰合 `docs/27` 符號定理之必要條件。
   ⟹ `docs/27` 之 FAIL 判詞在**任何**通過之 `⟨O⟩` 形式下都復原為 PASS，此結論已**型式無關**。
3. ✅ **`em(D⁺−D⁰) ∈ [+2.26, +2.90] MeV`** —— 穩健；與 `docs/18` 之 `E = 2.26` 相容 ⟹ D 通道之「殘餘」基本上即 em。

## 五、IDCM 側應建之對象（下一步規格，非本輪結果）

若味插入係樹上之**局部**算符，Feynman–Hellmann 給

```
⟨O⟩_ch = N_q · P_flip ,   P_flip = |ψ(d_flip)|² 在翻轉位點之歸一密度
⟹ ⟨O⟩ ≤ N_q = 3   （自動滿足：數據最大 2.293）
```

A2 之佔用率讀法 `P = (n_s+1)/B` 即此形式之具體化（每多一個 s 夸克佔一條分支）。
**待建**：`K_chain ⊗ K_tree` 上之「味插入算符」與其密度 `P_flip`（M5 之 41×41 骨架可直接擴充），

或 `em(D)` 之獨立 lattice QED 值（A1 給 2.26、A2 給 2.90，差 0.64 MeV）。
