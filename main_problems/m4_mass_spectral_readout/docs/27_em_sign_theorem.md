## 一、前設問題

`docs/26` 之承載窗定理用「正核 ＋ 重疊 ≤ 1」給出 `a ≤ 0.3357 fm`，但它仍**依賴**兩條前設：

- **H1**：`E_ch = Δm_ch − coeff·X` 之殘餘即 em 部分（`X` = `m_d − m_u` 標度，單一值）。
- **H2**：em 核為**正**（Coulomb `B^{−d}`、on-site 接觸皆正）。

本輪唔碰任何標度、唔碰任何波函數，只問一個更弱嘅問題：
**只靠符號，H1 ＋ H2 能否同時成立？** 若符號都對唔上，則 `docs/26` 之幅度結論會被完全繞過（更強），
而 `docs/18` 之 8 個 `E` 值亦唔可以再叫「em 殘餘」。

## 二、定理陳述

對任意正核 `V(d) > 0`、任意歸一化態：

```
em(A) − em(B) = Δ(Σ_i q_i²)·S + Δ(Σ_{i<j} q_iq_j)·P ,   S, P ≥ 0
```

（`S`、`P` 為 self 與 pair 重疊之歸一期望；核正 ⟹ 期望正。）故：

> **若 `Δ(Σq²)` 與 `Δ(Σpair)` 同號，則 `sign(em(A) − em(B))` 被固定**，
> 與耦合強度、節點間距 `a`、波函數形狀、動態 `P₀` **全部無關**。

`E_ch ≡ em(A) − em(B)`（`A` = 通道名第一態；由 `n−p` 核對：`Δm = +1.2933`、`coeff = +1`、`E = +1.2933 − 2.56 = −1.2667 = em(n) − em(p)` ✓）。
方向鐵律：`em(A) − em(B) = −[Δs2·S + Δpair·P]`（`Δ` 取 `B − A`）。

## 四、X 不等式化（本院最強結論）

`E(X) = Δm − coeff·X`，要求 `sign(E(X)) = 預言` ⟹ 每條通道給 `X` 一條單邊界：

| 通道 | 要求 |
|:--|:--|
| n−p | `X > 1.2933` |
| K⁺−K⁰ | `X > 3.9340` |
| Σ⁰−Σ⁺ | `X > 3.2720` |

```
三通道聯合 ⟹ 3.9340 < X < ∞
框架／FLAG 值 X = 2.56 ± 0.094
⟹ 距下界 3.9340 有 (3.9340 − 2.56)/0.094 = 14.6σ  ⟹ 🔴 不一致
```

## 五、結論報告

1. 🔴 **H1 被否證（符號層）**：`K⁺−K⁰`（14.3σ）與 `Σ⁰−Σ⁺`（6.0σ）之殘餘符號與**任何正 em 核**之預言相反；
   要救符號，`X` 必須 `> 3.934 MeV`，而 `X = 2.56 ± 0.094` 低 14.6σ。
   ⟹ `docs/18` 之 7 個 `E` 值**唔可以再稱為「em 殘餘」**；它們係「em ＋ 某第三源（強 IB 非線性項）之混合」。
2. ✅ **n−p 通過**：13.5σ 同號 ⟹ 該通道之殘餘符號與 em 相容（唯一一條）。此與核物理直覺一致（質子 Coulomb 自能較高）。
3. 🔴 **對 `docs/26` 之影響（加強而非削弱）**：承載窗定理之前設 `H1` 既已被符號層否定，
   則「8 通道 em 承載」不再只是「幅度不足」，而係**殘餘本身唔係 em**。
   故 `docs/26` 之 `a ≤ 0.3357 fm` 應讀作：**即使**把混合殘餘全數當 em，亦已需要 `a` 如此之小；
   真實 em 份額只會更小 ⟹ 窗更緊。判詞（em 兩體核不足）由「幅度」升至「符號」層。
4. 🟡 **三條逃生口（各自代價，逐條列明；未選定）**
   - **E1 符號奇異 em 項**：若 em 核含 sign-odd 部分（如 magnetic contact 之 `−3c/+c` 結構），符號可反。
     代價：必須同時預言 `c`（自旋通道）之值 —— M4 `c` 組現為 `0.107 ± 0.094` 與 `3.578`（跨 33×），
     任何 sign-odd 機制須解釋此跨度，否則只係把矛盾搬去 `c` 組。

## 六、界限與誠實標記

- 定理只要求「核正」；**不適用**於含 sign-odd 項之核（E1 逃生口即此事，非定理漏洞）。
- `S, P ≥ 0` 用「核正 ＋ 態歸一」；若態未歸一或核含約束項（π-exchange 之交換項），需重述。
- 4 條無判別通道（含全部 `Σ`／`Ξ`／`D` 大殘餘者）**不**支持亦**不**反對本定理。
- `X` 之下界 3.934 恰等於 `m(K⁰) − m(K⁺) = 3.934 MeV`（巧合於形式：K 通道下 `E > 0 ⟺ X > Δm`）；
  故此界**不是**新物理數字，而係「要救 K 就必須吞掉整個 K 質量差」之重述 —— 這一點必須講明，唔可以當成預言。
