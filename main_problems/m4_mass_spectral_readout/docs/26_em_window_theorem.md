## 二、定理陳述（em 承載窗）

**前提（三條，全部已在本框架內）**
- H1 兩體 em 核之形狀：`V_ij = (α ħc/a)·q_iq_j·O(d_ij)`，其中 `O(d) = B^{−d}` 於 `d = 0` 取最大值 1、單調衰減。
- H2 能量差可寫成 `ΔE = (α ħc/a)·[Δ(Σ_i q_i²)·S + Δ(Σ_{i<j} q_iq_j)·P]`，`S, P` 為歸一化重疊期望（`∈ (0, 1]`）。
  此為 `⟨Σ_{i<j} q_iq_j V_ij⟩` 之代數展開（self 與 pair 兩類項）。
- H3 `S, P ≤ 1`（由 `docs/25` V5：逐元素 `B^{−d} ≤ 1` ＋ 權重歸一 ⟹ 任何歸一化態之期望 ≤ 1）。

**定理**：對任一通道，
```
|ΔE_em| ≤ (α ħc / a) · Q^max ,   Q^max ≡ |Δ(Σ_i q_i²)| + |Δ(Σ_{i<j} q_i q_j)|
```
故若該通道之實測幅度 `A_i` 真由 em 承載，**必要條件**為
```
a ≤ a_i^max ≡ α ħc · Q_i^max / A_i
```
全部通道一致 ⟹ `a ≤ min_i a_i^max` ≡ **em 承載窗**。

## 四、結論報告（Q2／Q3／Q8 定理化終判）

1. 🔴 **主判**：以 IDCM 兩體 em 核（H1–H3）承載 M4 8 通道，必要條件為 `a ≤ 0.3357 fm`；
   M5 由 D 通道自洽解出之 `a₀ = 0.377422 fm` **已在此窗外**，且窗外時 `Ξ⁻−Ξ⁰` 需飽和度 `1.124 > 1`（結構不可達）。
   ⟹ **在 M5 校準點上，8 通道之 em 承載不只是「數據不合」，而是「代數上不可能」**。
2. 🟡 **窗內亦不足**：取 `a` 入窗（`0.10–0.20 fm`），7 個通道所需飽和度跨 **4.02×**；
   同一 `(a, t)` 兩體解必須同時給出此跨度 —— M5 A3 已測 5 標度律 × 3 作用模式 **0 命中**（`docs/12`＋`docs/13` §四.4）。
   ⟹ 窗口存在 ≠ 可實現：窗只係**必要條件**，充分條件另需波函數動力學，而該層已被否證。
3. 🔴 **家族分辨力定理（`docs/25` 已驗證）加碼**：於 `s_ud` 族，數據 `A` = `1.3335／1.2668／−1.0895`（符號亦反），
   而 em 兩體模型對同 `(m_h, m_l)` 只給**單一** `A` ⟹ 結構不可能。此條與 `a` 無關、與窗口無關，係獨立第二刀。
4. ⟹ **Q2／Q3／Q8 終判（升級）**：由「群論 no-go ＋ 密度排除」升為
   「**群論 no-go ＋ em 承載窗（代數上界）＋ 家族分辨力定理**」三刀並立，且三刀互不依賴。
   `docs/18` 之四類形式排除現可視為此定理之特例（皆屬 `O(d)` 形狀族內之擬合檢定）。
5. 🟡 **π⁺−π⁰ 獨立註記**：屬湮滅型通道（初末態非單一置換），代數上界形式不同，本輪**不納入**窗口計算；
   不得以此通道反對本定理，亦不得用它放寬窗口。

## 六、界限與誠實標記

- 本定理用到 `A_i`，而 `A_i` 繼承 M4 之 `X = 2.56 ± 0.094`（FLAG24）扣除 ⟹ 若 `X` 變動 1σ，`a_i^max` 移約 2–7%（已於表中報 σ 帶 `[0.3177, 0.3537]`）。
- 上界用 `|ΔΣq²| + |ΔΣpair|`（最鬆版本）。當兩項**同號**時界較緊；反號時較鬆。收緊需知 `S`、`P` 之關聯（本輪未做，屬可續項）。
- 定理只封「em 兩體核」；**不封**「em 多體／集體效應」或「非 em 來源」。
- 若日後 `a₀` 被其他 O 獨立釘到 `≤ 0.30 fm`，則本窗失效（需重算），此為可證偽點。
