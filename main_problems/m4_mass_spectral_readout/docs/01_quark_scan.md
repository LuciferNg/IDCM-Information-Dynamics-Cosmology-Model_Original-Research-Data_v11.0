## 六、腳本 bug 取證：[C] 段 TypeError

- **症狀**：`TypeError: unsupported format string passed to numpy.ndarray.__format__`，`scripts/01_quark_scan.py:118`
- **根因①**：`Aq = m/g2` 係 44 值向量 ⟹ `abs(b1[0]/Aq−1)*100` 亦係向量 ⟹ `:.2f` crash
- **根因②（更根本）**：`argmin(|A_q(n) − 1/γ_n|)` 係**同 index 硬配**，冇物理意義
- **修法（well-posed 化，非降標準）**：自由 index 掃描 `∃(n,k): γ_n²·c_k = m_q`（4356/夸克）＋ MC density
