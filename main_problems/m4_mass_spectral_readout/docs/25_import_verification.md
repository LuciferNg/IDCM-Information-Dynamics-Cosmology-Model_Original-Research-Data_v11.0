## 四、引用限制（**M4 以後引用 M5 必須連同以下四項一齊寫**）

1. **①「r 只依 `m_h·m_l`」之範圍**：只成立於**固定 `(a, t, q)`**。
   解析式 `r = (6/π)(m_h m_l a²/(ħc)²)(rA/P₀)` 中 `α`、`q` 在乘子層精確相消（故「與電荷無關」正確），
   但形狀 `rA/P₀` 仍依 `g = αqħc/(at)` ⟹ 固定 (a,t) 而改 q（2/3 → 1/3）時 `r` 由 **1.170 → 1.544**。
   ⟹ 引用時寫「**乘子層**與電荷無關；同乘積、同 (a,t,q) ⟹ 同 r」。唔可以簡化成「r 只依質量」。
2. **②「無束縛態」之陳述須修正為「未收斂」**：於天花板點，`s_ud`／`c_s` 之 `E₀` **確實低於能帶底**
   （−3.988、−3.961 < −3.464），故**不是**「無束縛態」；真問題是 `⟨B⟩`、`P₀` 隨 L **未收斂**
   （0.0154 → 0.0056；0.0072 → 0.0011）⟹ 波函數未局部化 ⟹ 幅度未定義。
   M5 `docs/23` 之判決（該兩類無預言）**結論不變**，但**理由須由「無束縛態」改為「未收斂」**，
   且門檻應以 L 收斂判據取代啟發式 `d_peak ≤ 20`。
3. **③ 接觸半徑之約定**：`r = 0.314 fm` 用 `r = (π|ψ(0)|²)^{−1/3}`；若改用 top-hat `(3/4π)^{1/3}` 得 **0.2852 fm**。
   引用時必寫約定，否則差 10%。
4. **④ 單位陷阱**：M5 腳本以 `ħc = 0.1973 GeV·fm` 入式 ⟹ `t` 以 **GeV** 代入；文檔寫 `0.7884 MeV`。
   混用差 1000×（本輪首次重算即撞上）。

## 五、結論報告

1. ✅ **M5 之乘子層數字全部可獨立重現**（15/15）：重校點 `(a₀, t, ⟨B⟩, P₀)`、D 通道逐位回代、
   乘積不變性、封頂 `A_max = 1.2718`、幾何比 `B⁷ = 16384`、接觸半徑 0.314 fm（約定已註明）。
2. ✅ **兩項可安全支撐 M4**：
   - **封頂不等式** `<B^{−d}> ≤ 1`（逐元素證明）⟹ `A ≤ α q ħc/a`，零模型假設。
   - **家族分辨力定理**（乘積層）⟹ 任何「只依夸克質量」之 em 算子在**同夸克內容**族間必給同 `r`；
     而 `s_ud` 三族數據 `r` = 98.78／3.88／−1.81（跨 54×）⟹ **結構不可能**。此為 M4 `docs/18` 四類形式排除之**升級版**（由擬合排除升為定理）。
3. ⚠️ **一項須降格引用**：M5 之「4/6 族無束縛態 ⟹ 無預言」只能寫成「4/6 族之 `⟨B⟩` 未 L 收斂 ⟹ 無定義幅度」。
4. 🔴 **一項不可引用**：M5 `docs/16` 之「硬上界 4.86% 超越」只在 `a = a₀(D 校準)` 有意義；
   換用天花板點 `a = 0.2433` 則 `A_max(q=1/3) = 1.973 MeV`，K 系 1.3335 **不再超越** ⟹ 該「硬」界係**條件界**，唔可以當模型無關 no-go。
5. ⟹ 對 M4 之影響：Q2／Q3／Q8 之 em 歸因可由「群論＋擬合雙 no-go」升級為「群論 ＋ 家族分辨力定理」；
   **能量學封頂只作條件性論據**（連 `a` 一齊寫）。§11.5 真缺口之描述改為「em 兩體核不足以承載 8 通道；缺族分辨算子」。
