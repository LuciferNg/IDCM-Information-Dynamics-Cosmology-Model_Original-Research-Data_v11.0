## 一、Protocol（事前固定，唔准見結果改）

```
池 P = { γ_a/γ_b | a,b ∈ 1..44 }，γ_n = 4sin²(nπ/88)，|P| = 1936，range [0.001274, 784.965]
命中判準：dev(t) = min_{p∈P} |p/t − 1| × 100%
MC null：域 = 該 sector 受測比值嘅 [min,max]（log-均勻抽樣）
  單比級 P1 = P(一個隨機目標 dev < 該命中自身 dev)
  家族級 PN = P(N 個獨立隨機目標，N = 受測比數，至少一個命中)
NMC = 10⁶（固定 thr baseline）／2×10⁵（家族級逐命中）
判讀：PN > 5% ⟹ 隨機級（後驗，唔升格）；PN < 1% ⟹ 池密度不足以解釋（可進入盲測）
```

**為何 thr 用「命中自身 dev」**：舊 protocol 用固定 thr（0.1%／0.05%），會令「dev 0.02% 嘅命中」同
「dev 0.09% 嘅命中」得到唔可比嘅 density。用自身 dev ⟹ 每個命中都回答同一個問題：
**「池嘅密度，本身就足以產生咁細嘅 dev 嗎？」**

實作核對：log 空間最近鄰 + 4 鄰居精確 dev 校正，抽 200 target 對全池暴力 **200/200 一致 ✅**。

## 五、跨 sector 結論

1. **全部 sector 命中 PN ≥ 31%** ⟹ γ 譜比池（1936 值）密度 = 隨機級；任何 0.01–0.7% 單點命中都唔可升格。
2. 差異只在池覆蓋：夸克域（比值細）密度最高（PN 48–99%）、輕子域（比值大）池稀疏（3/1936 落域內）。
3. 「差值閉合（Δm²+R）」嘅🟢係**力學層**（少參數解譜），唔係「比=γ比」層 —— 兩層唔可以互相借證據（O257 §二 已劃）。
4. 若要出現可升格命中：需要 PN < 1%，即需要**更細嘅譜池**（結構強逼出唯一 mode，而非 1936 值任揀）。
