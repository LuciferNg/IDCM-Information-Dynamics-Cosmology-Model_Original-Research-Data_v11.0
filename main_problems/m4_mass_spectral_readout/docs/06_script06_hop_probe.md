## 四、結論報告

1. **hop 階梯唔係質量算子**：直接比對 10 個費米子比，除 `s/d`（假命中）外全部 >1%（多數 >500%）⟹ 🔴。
2. **`s/d = 20.000` 係算術必然**：PDG 引用值 `m_s = 93.4`、`m_d = 4.67` ⟹ `93.4/4.67 = 20.0000` 恰好；而呢兩個係 **running mass 引用值**（誤差 2.7%/10.3%）⟹ 唔可以當命中（→ `07` 追擊、`11` lattice 判 19.8866±0.2452）。
3. **hop log 間距 vs 費米子 log 間距**：只有 `m3/m2`（ν 第二間距 0.3741）與 hop 0.1383/0.301 無對應；ν `m1→m2`（0.0347）近 hop 11→12（0.0378）dev 8.3% ⟹ 觀察級 🟡（→ `07`）。
4. **雙 probe 比**：`|K/(n−p)| = 3.044` 最優 hop 比 3.0（dev 1.472%）⟹ 唔過 1% 門檻但係全部中最好 ⟹ 屬 gap G5 線索。
5. **判定 🔴**（hop 作質量算子）；**🟡**（ν 近簡併 ↔ hop 微間距、雙 probe 比 ≈3）。
