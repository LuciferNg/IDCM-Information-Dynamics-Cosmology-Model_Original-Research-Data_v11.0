## 三、譜代數（精確，sympy 驗證）

```
c ≡ cos(π/44)，  γ_n ≡ 4sin²(nπ/88) = 2 − 2T_n(c)          [T_n = 第一類 Chebyshev]
γ₀ = 0,  γ₁ = 2(1−c)
γ₆ = −64c⁶ + 96c⁴ − 36c² + 4
γ₆/γ₁ = 32c⁵ + 32c⁴ − 16c³ − 16c² + 2c + 2 = (U₅(cos π/88))²
遞推：γ_{n+1} = 2c·γ_n − γ_{n−1} + 2γ₁
```

| 項 | 驗證結果 |
|:--|:--|
| 遞推恆等 | sympy `simplify` = **0**（n = 1..44 全對） |
| 50 dps 數值核 | 最大誤差 **1.8e−35** |
| 生成元 | `c = 1 − γ₁/2` ⟹ `ℤ[c] = ℤ[γ₁/2]` ⟹ 全譜係**單一生成元 γ₁** 嘅多項式 |

**裁定 🟢**：「橋未解」正式解除 —— 橋 = Chebyshev 恆等 ＋ 遞推嘅 `+2γ₁` 平移項（「邊界之間嘅邊界」在代數上係每階加同一 `2γ₁` 位移）。加任何新常數都同 `ℤ[γ₁]` 定義衝突 ⟹ 結構強逼。
