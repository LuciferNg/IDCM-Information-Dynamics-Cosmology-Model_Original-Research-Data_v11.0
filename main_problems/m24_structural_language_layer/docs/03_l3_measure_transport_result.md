## §2 `M2` 範疇內零參數傳輸窮舉（三路）

### (a) 等變傳輸 —— 死

```
群側 orbit（44 非對合）：A₅ 共軛 → {20,12,12}｜g ↦ g⁻¹ → 22×{2}
模式側 orbit：trivial → 44×{1}｜n ↦ 44−n → 21×{2},1,1｜Galois → {20,10,5,5,2,1,1}
等變雙射必要條件（orbit 多重集相等）：命中 **0 / 6**
```

### (b) 序統計（sort matching）—— 型別上不存在

```
群側排序塊（階類）= {24,20,15,1}（4 塊）
模式側排序塊（gcd）= {20,10,5,5,2,1,1}（7 塊）
⟹ 連 rank matching 亦無（塊數不同，冇典範對應）
```

### (c) 仿射 × 置換（分割層）—— 只有一個粗標籤

```
兩側典範分割各 7／6 族，逐對多重集比對：命中 1 / 42
  P2「gcd=1 vs >1」≡ G1「階3 vs 階5」⟹ {24,20}
  {20,24} 在 cut 空間密度 = 2/43 = 4.65%
```

該命中係**二分標籤**：無元素對應、無方向、無振幅內容（與 M21 `docs/06 §2.2` 一致）。

### (d) 形式理由：任何「由排序多重集決定」之傳輸 = 過 forgetful functor 分解

排序傳輸只依賴兩側多重集，因而對任何重標籤不變 ⟹ 必然忘卻 `Aut(O)` 作用
⟹ 與 L0 之 **S4（等變）** 不相容 ⟹ 即使存在亦不構成結構身份（`docs/04`）。
