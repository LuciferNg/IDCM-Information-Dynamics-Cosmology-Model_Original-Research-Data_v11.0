## §3 R-c：算術域障礙（凍結）

```
C1  5 ∤ 88 ⟹ ℚ(√5) 之唯一 ramified prime（5）在 ℚ(ζ₈₈) 非 ramified
    ⟹ ℚ(√5) ⊄ ℚ(ζ₈₈)（定理：K ⊂ L ⟹ K 之 ramified primes ⊆ L 之 ramified primes；
       ℚ(ζ_n) 之 ramified primes = primes | n）
C2  機核：枚舉 mod 88 之全部二次特徵標（2-torsion of (Z/88)^×），逐個求 conductor
    與關聯二次域；確認無一為 ℚ(√5)
C3  後果（結構推論）：任何「算術自然」之跨側字典，其像必落於 ℚ(√5) ∩ ℚ(ζ₈₈) = ℚ
    ⟹ 可携帶者僅為度集之 ℚ-對稱函數（Σd, Σd², Σd(d−1), …）
    ⟹ 等價類標籤（V₃ vs V₃' 需 √5）**不可**跨側；逐 isotypic 精細結構不可跨側
```

判：C1／C2 必須機核；C3 為結構推論（標「推論」，不得作定理引用）。
