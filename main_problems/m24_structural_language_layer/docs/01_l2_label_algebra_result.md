## §3 ★ 交集定理（本輪硬結果）

```
L2-A ∩ L2-B = {16}
```

- `16` 係**唯一**兩側同時可命中之值（群側 `#{g²=e}`＝模側 `Σd`／`Λ¹`；Frobenius–Schur 定理同一量）。
- `36` 對 L2-A 可命中（`#{ord ≤ 3}`）但對 L2-B **分級層零命中**；
  `98` 對 L2-B 可命中（cross `Λ²`）但對 L2-A **型別上不可能**（> 60）、對 L2-C 亦無計數型讀法。
- ⟹ **三數不可同源**；唯一可作橋者係 `16` 本身，但橋值 = 其中一數 ⟹ 循環，不可作 producer。

## §4 後驗診斷（非凍結判據；MC null）

```
null 域：隨機度集 k=5、d ∈ 1..8，N = 20,000
P(16) = 4.39% ｜ P(98) = 0.69% ｜ P(36) = 2.27%
P(16 ∧ 98) = 0.18%（lift over independent = 5.8×）
```

兩點判讀（誠實）：

1. **正面**：`16` 與 `98` 同源於 L2-B **非**密度巧合（P = 0.18% ≤ 5%）⟹ 該 pair 携帶真實結構信息
   （FS 對合計數 ↔ cross-isotypic `Λ²`）。
2. **反面**：`36` 於 aggregate 層並非結構性缺席（P = 2.27% ≠ 0）⟹ 「36 缺於 L2-B」係
   **A₅ 度集 `{1,3,3,4,5}` 之事實**，不可寫成一般定理。判詞只可寫「此 D 下缺席」。
