## §1 `C1`（定理級）：ℚ(√5) ⊄ ℚ(ζ₈₈)

```
88 = 2³·11 ⟹ ram(ℚ(ζ₈₈)) = {2, 11}
ℚ(√5) 之 discriminant = 5 ⟹ ram(ℚ(√5)) = {5}
定理：K ⊂ L ⟹ ram(K) ⊆ ram(L)
⟹ 5 ∉ {2,11} ⟹ ℚ(√5) ⊄ ℚ(ζ₈₈)          ∎
```

機核：`factor(88)`、`factor(5)`、`5 ∉ ram(ζ₈₈)`、`disc(ℚ(√5)) = 5`（5 ≡ 1 mod 4 squarefree ⟹ fundamental）。

## §3 `C3`（結構推論，非定理）：可携帶之內容

```
χ₃(5A) = (1+√5)/2 ｜ χ₃(5B) = (1−√5)/2  ⟹ 分辨 V₃ 與 V₃' 需 √5
但 √5 ∉ ℚ(ζ₈₈) ⟹ 鏈側（ℚ(ζ₈₈) 域內）不可分辨此二 isotypic 標籤
⟹ 任何「算術自然」之跨側字典，像 ⊆ ℚ(√5) ∩ ℚ(ζ₈₈) = ℚ
⟹ 可携帶者 = 度集之 ℚ-對稱函數（Σd、Σd²、Σd(d−1)、Σ_(i<j) d_i d_j …）
```

**具體核**：三目標之已註冊表達式全部為度多重集之無序函數：

```
16     = Σd = #{g²=e}                 （對稱）
98     = Σ_(i<j) d_i d_j              （對稱）
36     = C(d₁+d₂,2)（d≥B 者）／N_d − 2B（對稱形式存在）
```

⟹ **算術障礙不個別殺任何一數**；它殺的是「精細 isotypic 結構跨側」——
即：L1／L2 之函子不可能是表示論式（representation-theoretic）的，
只可能是度集對稱函數的算術式。這正好**解釋**第一輪之 inventory 為何長成那樣
（L2-A／L2-B 兩庫存皆係度集／階類之對稱函數集合）。

## §5 誠實缺口

1. `C3` 之前提「算術自然」未形式化（何謂 natural w.r.t. 兩側 Galois 作用？）——
   若字典允許非算術之對應，`C3` 失效（但該對應即需額外假設 = dof）。
2. 本檔**未**證明「不存在精細跨側對應」；只證明「算術自然者不能携帶精細標籤」。
3. `88 = 2³·11` 之 `ram(ℚ(ζ₈₈)) = {2,11}` 係標準事實（導體－判別式），本檔只機核 `5 ∤ 88`，
   **未**獨立重證 `disc(ℚ(ζ_n))` 之支撐定理。
