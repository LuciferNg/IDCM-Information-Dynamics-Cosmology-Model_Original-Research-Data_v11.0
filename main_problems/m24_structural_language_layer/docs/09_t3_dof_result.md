## §1 `D1` 定義級命題

> **零參數（由結構唯一決定）⟹ Aut-不變。**
> 反之，任何非 Aut-不變之對應，必須在 `Aut(O)` 之 orbit 之間作**選擇**；
> 該選擇即自由度（參數），使 `dof = 0` 失效。

此命題把第一輪 `docs/03 §4(3)` 之「兩路證據」升為**定義級**：
不再需要逐個 scheme 窮舉，只需承認「零參數」之語義。

## §2 量化（本輪新）

| 傳輸類 | 選擇數 | bits |
|:--|:--:|:--:|
| 非等變雙射（44 非對合 ↔ 44 模式） | `44!` = 2,658,271,574,788,448,768,043,625,811,014,615,890,319,638,528,000,000,000 | **log₂ = 180.79** |
| 同上 mod `\|Aut(A₅)\| = 60` | `44!/60` | 175 |
| 共軛不變（`⟨共軛,逆⟩`；orbit `{20,12,12}`） | `2³ = 8` | **3** |
| 僅逆不變（22 個 2-element orbit） | `2²² = 4,194,304` | 22 |
| **等變雙射** | **0**（6 對 orbit 多重集全不中） | — |

```
⟹ 非等變路線之自由度 ≥ 175 bits ⟹ 絕對違反 dof = 0
⟹ 等變路線：雙射 0 個；即使放寬至「不變子集」，共軛不變族只有 8 個（3 bits）
```

## §3 ★ 內容上界：等變族之全部可觀測內容 ≤ 3 bits，且唯一命中 = `{20,24}`

```
共軛不變子集之大小集（8 個選項）= {0, 12, 20, 24, 32, 44}（子集和 of {20,12,12}）
與模式側典範分割逐對比對：命中 1 對
   群側「階3 vs 階5」= {24,20}  ≡  鏈側「gcd=1 vs >1」= {24,20}
⟹ 等變族能携帶之信息 = 該 3-bit 選擇；其中唯一與模式側可比者 = {20,24} 粗標籤
```

而振幅指派需 **44 個實數**（≥ 44 bits，實際為連續值）≫ 3 bits
⟹ **等變族在維度上不可能承載振幅** —— 此即 M21 `AB4`（BR1 只餘 count-level 約定）之**定量版**。

## §6 誠實缺口

1. `D1` 係語義命題（「零參數」之定義），非數學定理；本檔把它寫成可反駁形式
   （逃生路徑已列明），但未證明「IDCM 之零參數紀律必然採用此語義」。
2. `44!` 之選擇數係**上界**（實際非等變映射可能更多類）；用於說明量級，非精確 dof。
3. 3 bits 之上界只針對「子集／分割型」內容；未排除「以 3 bits 選擇後再做非線性內插」
   之混合方案 —— 該類方案之非線性部分即自由參數（同 `O210 §4(d)` 論證）。
