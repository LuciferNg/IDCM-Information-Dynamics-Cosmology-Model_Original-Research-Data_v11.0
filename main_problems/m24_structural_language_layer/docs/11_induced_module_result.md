```

```

**枚舉事實（不加一般化）**：`98` 在此族 **0/81** 命中。逐表 `D3`（`m`-加權交叉和）：

```

98 被跳過（介於 54 與 146 之間）
```

即「置換模之 graded 塊」在 9 個子群類上取不到 `98`；而 `98 = Σ_(i<j) d_i d_j`
係**五個 isotypic 因子各恰一次**之全交叉和（模 `V = ⊕V_i`，dim 16 本身），
置換模之多重度 `m` 一旦有重數，加權和即跳階。此處只記錄**枚舉事實**，
**不宣稱**「任何置換模皆不可能給 98」之一般定理。
