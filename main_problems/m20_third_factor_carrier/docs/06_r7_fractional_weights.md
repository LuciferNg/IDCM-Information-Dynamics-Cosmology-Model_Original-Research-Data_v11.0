## §三 判（三條）

**① RD7 具名分數：全滅。** 無任何具名分數令 `χ < 3`；最小 `χ = 24.99`（K₃、`c=1/3`）。
**② 新結構觀察（非預言）**：`ρ_u` 對「同一支撐之縮放」不敏感（[A]/[B] 之 `ρ_u` 恆 `−2/41`）。
⟹ 縮放只動 `ρ_d`；要動 `ρ_u` 必須**改變支撐**（不同站對／不同站集），而改變支撐即改變 `ρ_d` ⟹ 鎖鏈之源。
**③ 載體側之極限**：把本 M 全部已窮盡之類列在一起 ——

| 類 | 成員 | 聯合 3σ 命中 |
|:--|--:|:-:|
| 單鍵 `{L,M} × ±1`（`scripts/02`） | 3,606 | 0 |
| 單位強度支撐 ≤2 完整（`scripts/06b`） | 20,700 | 0 |
| 反射完備 2 弦（`scripts/06` 期外測） | 2 | 0 |
| 具名分數 × 3 形式（`scripts/07`） | 15 | 0 |
| 鏈上簽名／kink（`scripts/03` L1，4 gauge 類） | 4 | 0（且 `\|ρ_d\|≡42/41`） |
| 讀數側（M23 `NG1′`／`SC1`） | 251 三元組 | 0 |

⟹ **對 `K` 之局部結構性擾動（任何支撐 ≤2、任何 ±1 或具名分數）皆不可能**。

## §四 剩下兩個維度（皆超出「局部擾動」框架）

| # | 維度 | 障礙 |
|:-:|:--|:--|
| **MC01** | 支撐 ≥3 站且**權重獨立**（秩 ≥3） | 缺結構理由；且秩 3 自由度 = 3 ⟹ 2 約束必有解 ⟹ 除非 3 個權重皆結構固定，否則即擬合 |
| **RD8** | 高階／非線性（self-energy） | 偶階 `∝ λ²` ⟹ **sign-blind**，不能生 signed `ρ`；奇階 = 一階 = 已窮盡 |

**⟹ 本 M 之載體側結論（最終措辭）**：

> 目標 `(ρ_d, ρ_u) = (0.4035, −0.0259)` 落於「局部結構性擾動」之可達集**之外**，
> 且非「位置揀錯」、非 look-elsewhere、非精度不足（禁帶寬 0.016 ⟹ 遠大於 `σ`）。
> 要跨越，必須引入**秩 ≥3 且各權重獨立固定**之結構，或**非微擾式**之核重定義（後者違 A6）。
