## §八 MC04 之精確化（2026-11-20 追加；`scripts/05_tradeoff_frontier.py`，EXIT=0）

**原 MC04**：「『壓低 `ρ_d`』之結構操作」—— 太模糊。本輪把它算成一條**權衡前沿**：

```
類 A（difference-type，3606）：聯合最佳 χ = 3.097（M λ=+1 (1,4)：ρ_d = 21/41, ρ_u = −1/41）
類 B（sum-type ＝ 加弦＋鏈上簽名之 frame 變體，放寬 A6 之測試，3376）：聯合最佳 χ = 4.711
兩類 **同時** |z_d|<1 ∧ |z_u|<1 之成員 = 0 / 3606 與 0 / 3376
```

**分支表（精確）**：

| 支線 | 物件 | `ρ_d` | z_d | `ρ_u` | z_u |
|:--|:--|--:|--:|--:|--:|
| A：`ρ_u` 命中 | M λ=+1 (1,4) | 21/41 | +3.10 | **−1/41** | **+0.05** |
| B：`ρ_d` → 16/41 | M λ=−1 (1,4) sum | **16/41** | **−0.38** | −11/41 | −7.36 |
| B：`ρ_d` → 2/41 | M λ=−1 (1,5) | 2/41 | −10.11 | −2/41 | −0.70 |
| A：`ρ_d` → 85/41 | L λ=+1 (2,4)（= F1） | 85/41 | +47.57 | −2/41 | −0.70 |

**權衡密度（致命一格）**：`ρ_d ∈ [0.36, 0.46] ∧ ρ_u < 0` 之成員 = **1 個**（`16/41`），其 `|ρ_u| = 0.268`
= 目標 `0.025888` 之 **10.4×**。目標比值 `|ρ_u|/ρ_d = 0.064159`；該點為 `0.6875`。

**⟹ MC04 之精確形狀（一句）**：

> 缺者 = **「`ρ_u` 平坦之壓低機制」** —— 令 `ρ_d` 由 `42/41` 降至 `0.4035` 而 `|ρ_u|` 保持 `~0.026`（比值 1/15.6）者。
> 現存一切機制（加弦、簽名、兩者複合）**都係耦合**：`ρ_d` 一壓低，`|ρ_u|` 急升。

**⟹ 為何「再加一個算子」不可能解決**：`dof = 42 ≫ 2` ⟹ 存在性恆真（`§〇 MA06`）⟹ 只有**零參數機制**可判；
缺者係**機制**，唔係參數。此即 M12 `R24 §五`「真正缺者 = 使 `⟨w,v_u⟩` 近零之結構理由」之定量版。
