## §〇 為何要定義先行

M12 十四輪全滅之共同死法 = **先有候選、後判生死**，於是每一輪都可被指「揀過」。
本輪次序強制反轉：**先寫死物件係咩（公理），再寫死准入條件，最後才計**。
若物件按公理被唯一逼出 ⟹ 唯一候選 ⟹ 無 look-elsewhere。

## §一 公理（A1–A7）

```
A1 離散      Φ 之全部係數 ∈ ℤ；無連續參數、無標度常數
A2 非遞移    Φ ∉ Comm(K)   （= 不與鏈 Laplacian 對易；見 §五 T1）
A3 非二部    supp(K+Φ) 含奇環（⟺ Ising AF 阻挫 > 0；二部 ⟺ 阻挫 ≡ 0）
A4 ±1 阻挫   全部鍵耦合絕對值 = 1（= 鏈自身鍵標度，非新常數）；阻挫指數 = 1（最小非零）
A5 帶味      Φ 之支撐錨定於味站集 S ≡ {k_u,k_d,k_s} = {2,3,4}；
             即 Φ 之每個非零矩陣元所涉站 ∈ S（否則味盲 ⟹ δ 不可見）
A6 附加性    Φ 不得改動鏈既有鍵之權重（重定義第一因子 ≠ 第三因子）；
             Φ 只可加入鏈上不存在之鍵
A7 可傳播    K+Φ 於 Dirichlet 子空間正定（否則無 Green 核 ⟹ 該 Φ 非載體）
```

**A1 之實義**：`Φ` 冇「耦合強度」自由度 —— 強度 1 係鏈之自身鍵標度（K 之非對角元 = −1），
故「±1」唔係參數，係**沿用既有標度**。

## §二 語法（物件規格，可機械檢查）

```
Φ = Σ_{e ∈ E_new} λ_e · L_e ,        E_new ⊆ {非鄰站對 (i,j) , |i−j| ≥ 2}
                                        λ_e ∈ {±1}
L_{(i,j)} = (e_i − e_j)(e_i − e_j)ᵀ      （邊 Laplacian：對角 +1、非對角 −1）
M_{(i,j)} = e_i e_jᵀ + e_j e_iᵀ          （純 hopping：只改非對角，見 §七 F3/F4）
```

> `L` 與 `M` 之差 = 「加邊時 on-site 能量是否跟隨 degree 上升」。
> 兩者皆零參數；**兩者皆列入凍結族**，唔准事後挑（見 §七）。

## §四 可執行小模型（精確有理，零浮點）

`G₀ = K⁻¹` 有閉式（本 M `scripts/00` 已以 `Fraction` 精確核 `K G₀ = I`，1936 元零差）：

```
G₀(i,j) = min(i,j)·(45 − max(i,j)) / 45
```

`Φ` 為有限支撐擾動 ⟹ Woodbury 恆等（秩 k ≤ 3，全部 `Fraction` 精確）：

```
GΦ = G₀ − G₀U (C⁻¹ + UᵀG₀U)⁻¹ UᵀG₀        (Φ = U C Uᵀ , U ∈ ℝ^{44×k})
```

驗收：`GΦ·(K+Φ) = I` 逐元精確（`Fraction`），偏差必須 = 0。

## §五 T1 成員定理：`Φ ∉ 已枚舉類 ⟺ [Φ,K] ≠ 0`

**已枚舉類之精確刻畫**（M12 R15／R28 之「支撐 × 權重」）：

```
𝒞 ≡ { Σ_{n=1}^{44} w_n φ_n φ_nᵀ : w ∈ ℝ^44 }  =  { f(K) : f 實函數 }  =  Comm(K)
```

- 第二等號：`φ_n` 為 `K` 之完備特徵基 ⟹ 對角化子空間 = `{f(K)}`。
- 第三等號：`K` 譜**單簡**（`γ_n = 4sin²(πn/90)`，n=1..44：`sin²(πn/90)=sin²(πm/90) ⟺ n=m`（因 `90−m ≥ 46 > 44`））⟹ 對易 ⟹ 同時對角化 ⟹ `∈ 𝒞`。

**⟹ T1 判據由「枚舉對照」升級為單一對易子**：

```
Φ ∉ 𝒞  ⟺  [Φ, K] ≠ 0        （精確可算，零枚舉、零容差）
```

此即 A2 之可執行版。**注意**：M12 全部十四輪候選皆 `∈ 𝒞`（皆為 `w_n` 權重） ⟹ 全部落在同一代數內，
故其全滅係**類內全滅**，與本 M 之「類外物件」假設一致。

## §六 強逼鏈：為何唯一對象係 **(2,4) 鍵**

**S1（阻挫 ⟹ 需環）** 圖上 ±1 簽名「平衡」⟺ 每個環之符號積 = +1（Harary 平衡定理）。
路徑／樹無環 ⟹ 任何簽名皆平衡 ⟹ **阻挫 ≡ 0**。
⟹ A3/A4 要求 ⟹ 必須存在環。

**S2（鏈上無環 ⟹ 環需「鏈外鍵」）** `P₄₄` 之邊 = `(i,i+1)`，i=1..43，無環。
由 A6（只准加鏈上不存在之鍵）⟹ 環只能由 `E_new` 造成。

**S3（最小環 = 三角形 ⟹ 最短新鍵 = NNN）** 用一條新鍵 + 若干鏈鍵閉環：
最短者 = `(i,i+2)` 與 `(i,i+1),(i+1,i+2)` 成三角形。任何更長者含三角形為子結構 ⟹ 非最小。

**S4（錨定 ⟹ 位置唯一）** A5 要求支撐 ∈ `S = {2,3,4}`。
`{2,3,4}` 內之鏈上既有鍵 = `(2,3),(3,4)`；**唯一非既有鍵 = (2,4)**。
⟹ `E_new = {(2,4)}`，三角形 = `(2,3,4)`。

**S5（符號唯一）** A4：耦合絕對值 = 1 = 鏈標度；符號 = 鏈之 AF 型（非對角 −1）。
FM 型（+1）留待 A7 判別（見 §七 F2/F4）。

**⟹ 逼出**：`Φ = λ·L_{(2,4)}`，`λ=+1`（A4＋A7），`E_new={(2,4)}` —— **零自由度**。

**位置唯一性之理由再述**：δ 之讀出軸係站 2 vs 站 3（isovector 差分）。
一物件若錨在不涉味之位置（如 `(20,22)`），其效應對 `δ_x` 只能經對稱組合進場 ⟹ 味盲（A5 違）。
故「帶味」＋「最小環」＋「位置固定」三條同時成立 ⟹ 只有 `(2,4)`。
