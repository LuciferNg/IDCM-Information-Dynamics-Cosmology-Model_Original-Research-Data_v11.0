## §十 診斷：失敗係在**單核 ansatz**，唔係在載體類

三條實測事實合起來指向同一結論：

```
① 單鍵類 3606 成員，ρ_u 易中（592 個 |z_u|<1）而 ρ_d 一個都唔中（0 個 |z_d|<1）
② 「中 ρ_d」之罕見下尾成員（如 F4 14/41）⟹ ρ_u 必大錯（−28/41，−20σ）
③ 加弦普遍**抬高** ρ_d（90–96%），而目標要求**壓低**至 0.4035
```

⟹ `δ_x = G(3,k_x) − G(2,k_x)` 之**單核**假設（同一 `G` 同時供三個 `δ`）係**綁定約束**：
兩個讀數對核之要求方向相反。此與 M12 R24 §五（「− 非物件之性質，係**配對**之區分」）
及 M13 之近正交性（`cos(v_u,v_d) = −4/5`）指向同一處 —— 但 M20 唔重推 M13。

**故 M20 之真結論**：缺者唔係「再一個算子」，而係**讀數之來源結構**（單核 → 雙源／關係型）。
此超出 M20 章程（§三 明文禁改讀出式）⟹ 只可**記錄並發還**，不得在本 M 內改讀出式以容納。
