## §1 判準（凍結）

### DA1（22 三重身份）

| 碼 | 判準 | PASS 定義 | 失敗後果 |
|:--|:--|:--|:--|
| `E1a` | 代數檢查：`N_d = 2·Σ_χ dim Λ²V_χ` 對**任意**度多重集是否恆等 | 恆等 = True | 若恆等 ⟹ 「22 = N_d/2」**零內容**（除 2 之算術） |
| `E1b` | 鏈側 22 是否獨立於 44／88 | 存在一個鏈側 canonical 22 **唔係** 44／88 之函數 | 全部皆為函數 ⟹ 非獨立 |
| `E1c` | 群側 22 是否獨立於 44 | 同上 | `#逆對 = 44/2` 恆為 44 之函數 ⟹ 非獨立 |
| `E1d` | 模側 22 之密度：canonical module dims 池內命中數 | = 1 | ≥2 ⟹ 候選非唯一 |

**DA1 升格條件（全中）**：`E1a` 非恆等 ∧ `E1b` 有獨立鏈側 22 ∧ `E1d` = 1。
**否則**：`DA1 = 🔴 vacuous（算術除 2）`，並列「候選三重身份」為純數值巧合。

### DA2（`h11 = 36`）

| 碼 | 判準 | PASS 定義 | 失敗後果 |
|:--|:--|:--|:--|
| `E2a` | 預登錄池 `𝔇` 內命中 36 之元素數 `n₃₆` | `n₃₆ ≤ 1` 且該元素有算子讀法 | `n₃₆ ≥ 2` ⟹ 零判別力 |

**DA2 升格條件**：`n₃₆ = 1` ∧ 非恆等 ∧ `q ≤ 5%` ∧ 該元素可用算子語言陳述。
**否則**：`h11 = 36` 維持 🔴（真缺口），但附「候選讀法清單 ＋ 密度」。
