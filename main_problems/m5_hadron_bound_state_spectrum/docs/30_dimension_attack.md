## 二、Z1：由樹導出維度（結構，非擬合）

層站數 `N_d = 4, 12, 36, 108, 324`（`d = 1..5`）；層距 `r_d = B^{−d}`。

$$\frac{\ln\left(N_{d+1}/N_d\right)}{\ln B}=\frac{\ln 3}{\ln 4}=0.792481250361\quad(\text{全 39 層波動}=0.0\text{e}{+}0)$$

⟹ `d_H = ln3/ln4 = 0.792481250361`。
★ 即：現行模型用 `(ħc/a)³`（3D 空間維度），但 contact 項住喺 `d_H = 0.79` 嘅結構上 —— **維度不自洽**，
呢點本身係一個真結構缺陷（無論今次攻唔攻得穿）。

## 五、缺口方向定理（本輪確立）

由 `docs/25` §二 之分解 `r = [6 m_h m_l/(π(ħc/a)²)]·(⟨B⟩+ε)/P₀`（`q` 全消）：

$$\frac{r_K}{r_D}=\underbrace{\frac{m_s}{m_c}}_{0.3898}\cdot\Lambda,\qquad \Lambda\equiv\frac{(\langle B\rangle+\varepsilon)_K}{(\langle B\rangle+\varepsilon)_D}\cdot\frac{P_{0,D}}{P_{0,K}}$$

- 質量因子 `0.3898 < 1` ⟹ **方向相反**（數據要 `r_K/r_D = 28.96`）
- 全部可調槓桿住喺 `Λ`；本輪已證 `Λ` 對 `p`、支撐不敏感，對 `κ` 亦只到 `R_max = 1.647` ⟹ `Λ_max ≈ 4.23`
- 要到 28.96 需 `Λ = 74.3` ⟹ **差 17.6×**，且**方向**要靠 `Λ` 補回 2.6× 以上

⟹ 缺口**必然**來自 `⟨B⟩`／`P₀` 以外之自由度：**mode 佔用／J^PC／徑向激發**（即 `docs/23` D5 所指，
兩端被封：供給側 flavour→mode 已被 O140 否證）。
