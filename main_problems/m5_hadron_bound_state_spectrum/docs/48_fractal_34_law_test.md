## 一、問題拆兩層

「3/4」在 M5 出現嘅身份係「**4 族中 3 族通過**」—— 一個**計數**。
而表面/體積分形律（Kleiber `M^{3/4}`、WBE `D/(D+1)`）係**連續量之比值**。
兩者要等同，必須證明：①族數 4 係結構量；②比率之值 = 3/4；③抑制因子由同一幾何給出。本檔逐項判。

## 二、層一：3/4 之三個精確結構身份（`F1`–`F3`）

| 身份 | 內容 | 值 |
|:--|:--|--:|
| **F1** | `b = 4` 之 b-ary 樹：`L_n/T_n = b^n / [(b^{n+1}−1)/(b−1)]`，`n→∞` | **3/4 精確**（n=7 已 0.750011）|
| **F2** | 3-of-4 Cantor 子集之 Hausdorff 維度 `d_H = ln3/ln4` | 0.792481 |
| **F3** | `45/60 = (N_d+1)/|I|`（`|I| = 60` 二十面體旋轉群階）| **0.750000** |

★ **F1 正是 Kleiber／WBE 之來源**：`(b−1)/b = D/(D+1)`，此處 `b = 4 = N_gen + 1 = 3 + 1 = D + 1`。
即 3/4 唔係巧合數字，**有結構根源**：分支數 = 空間維數 + 1。

## 三、層二：作為 M5 之操作律 —— 三路否證

### `G1` 樸素表面/體積比：**值域不足**
樹之 `T_n/L_n ∈ [1, b/(b−1)] = [1, 1.3333]`（`n→∞` 才達 4/3）。
觀測 `s = A_B/A* = 0.06968 = 1/14.35` ⟹ **`s` 遠細於下界 1** ⟹
**樸素表面/體積律（任何方向）都不可能**：最強只到 1.333，差 19×。

### `G2` 整數冪 `(4/3)^k`：**假命中**
`1/s = 14.352`：`k = 9` 給 13.3183（偏 **−7.2%**），在 10% 容差內「命中」。
**但**：候選 12 個、容差 10%（對數空間寬 0.19）⟹ 隨機期望命中 `12 × 0.19 ≈ 2.3` 個 ⟹
**一個命中係隨機水平**，且 `k = 9` 無任何結構理由（9 = `N_gen²` 只在事後可指）。⟹ **不採**。

### `G3` 分形維度擬合（最強版本）：**否證**
設 `A_f ∝ (r_h/a₀)^d`（`r_h = ħc/m_h`）。由 B/D 定 `d`：
`(r_h/a₀)` 比 = 0.30383，`A` 比 = 0.06432 ⟹ **`d = 2.3033`**。
盲測 K：預言 `A_K = 42.2251` vs 觀測 **3.9340** ⟹ **偏 10.7×** ⟹ **同一分形維度不可能**。

## 四、生還者：二值 UV/IR 判準（`G4`）＋ 其 fitting 警告

⟹ 若用 `r_h/a₀ < 1/8` 作界，**恰只有 B 落入 UV**，與「3 族通過、B 失敗」一致。
★ **但必須標明**：`0.1229` 距 `0.125` 只 **1.7%** ⟹ **此閾值實質係擬合**，非預言。
（可注意 `1/8 = b^{-3/2}`（`b = 4`）與 `8 = 2³` 之結構候選存在，但**在閾值本身係擬合之前，不得宣稱**。）

## 五、結論（可直接引用）

1. **係**：`3/4` 有精確結構身份 `(b−1)/b`，`b = 4 = D + 1 = N_gen + 1`，與 Kleiber／WBE 之 `D/(D+1)` 同源。
2. **唔係**：`3/4` **唔係** M5 之操作律 —— 表面/體積比之值域 `[1, 4/3]` 差 19×；分形維度版對 K 偏 10.7× ⟹ 否證。
3. **紀律**：「4 族中 3 族」係**計數**，唔係**測度**；把計數映射到幾何比值屬範疇錯誤，除非先由結構導出「族數 = 4」與「UV 族恰 = 1」。
4. **可續攻**：唯一未被否證之幾何成分係**二值 UV/IR 分界**（`r_h` vs `a₀`），但其 `1/8` 閾值目前係擬合（margin 1.7%）⟹ 下一關必須**事前**給出閾值之結構值，再以 B 檢定。
