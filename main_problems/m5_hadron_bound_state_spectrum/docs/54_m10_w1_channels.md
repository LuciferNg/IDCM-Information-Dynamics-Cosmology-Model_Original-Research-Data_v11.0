## 一、前設問題（docstring 原文）

```text
M5 docs/54 配套 — M10 W1 接口：`em(n−p)` 之兩條通道能否補 1.38% 缺口？
================================================================================
M10（`docs/14` W1）要求：`em(n) − em(p) ≥ 1.2667 MeV`（FLAG 中性）或 `1.3963`（`γ` 比值），
而 M5 譜側兩體上限 `A_max(v2) = 1.2494 MeV` ⟹ 差 **1.38%**，M10 Tier II 判詞因此永久阻塞。

本輪問：**有無第二條通道可以補？** 唯一候選 = 自能（`∝ q²`，格點上以 `g(0)` 加權、有限）。
判準（事前寫死）：
  W1 兩體上限 `A_max = α(ħc/a₀)·|Δ(q_h q_l)|·⟨B⟩`，`⟨B⟩ ≤ 1` ⟹ 精確值 `α(ħc/a₀)/3`。
  W2 自能通道之號：`Δ(Σq²) ≡ Σq²(p) − Σq²(n)`（`p = uud`、`n = udd`），
     自能恆抬升 ⟹ `em(p) − em(n) ∝ Δ(Σq²)` ⟹ 若 `Δ(Σq²) > 0` 則 **p 較重** ⟹ `em(n) − em(p) < 0`。
  W3 若自能通道之號與所需相反 ⟹ 該通道**不可能**補缺口（不論係數大小、不論 `g(0)` 多大）。
  W4 若兩體上限 < 需求 ⟹ 兩體亦不足 ⟹ **兩通道皆無力 ⟹ W1 永久阻塞**（唔係「邊緣」）。
  W5 不引入新參數、不改 M10 任何結論；本檔只交「能否」之判定。
輸出：`data/56_m10_w1_channels.json`
```

## 二、自能通道：號相反（決定性）

| 量 | 值 |
|:--|:--|
| `Σq²(p) = 2(4/9) + 1/9` | **1.000000** |
| `Σq²(n) = 4/9 + 2(1/9)` | **0.666667** |
| `Δ(Σq²) ≡ p − n` | **+0.333333** |

自能恆為正抬升 ⟹ `em(p) − em(n) ∝ Δ(Σq²) > 0` ⟹ **`em(n) − em(p) < 0`**。
需求係 `+1.2667` ⟹ **號相反** ⟹ 此通道**不可能**補缺口（與係數大小、與 `g(0)` 多大無關）。

> 附量級（只作對照、不可用）：若硬套自能式 `(α/2)(ħc/a₀)|Δ(Σq²)|g(0) = 4.5804 MeV`，
> 量級遠超需求 3.6×，但**號錯** ⟹ 越強越錯，不可以「調細係數」救（調細後兩體亦已不足）。

## 三、兩體通道：上限不足

`A_max = α ħc/a₀ × |Δ(q_h q_l)| = 3.7481 × 1/3 = ` **1.2494 MeV**（`⟨B⟩ ≤ 1` 係恆等式級）

| 需求口徑 | 值 | 缺口 |
|:--|--:|--:|
| FLAG 中性 | 1.2667 | **+1.39%**（0.0173 MeV）|
| `γ` 比值 | 1.3963 | +11.76%（0.1469 MeV）|

## 四、判

1. 兩體：`1.2494 < 1.2667` ⟹ 不足 1.39%，且 `⟨B⟩ ≤ 1` 係恆等式 ⟹ **無參數可加**。
2. 自能：號相反 ⟹ 排除（`W3` 之無條件性）。
3. ⟹ **兩通道皆無力 ⟹ `W1` 永久阻塞**；M10 Tier II 之解鎖**唔可能出自譜側 EM 通道**，
   只能靠：(i) `em` 之觀測口徑本身（FLAG 中性 vs `γ` 比值之差 0.13 MeV 係 QED/`γ` 輸入慣例，非物理），
   或 (ii) M10 側引入非 EM 之新成分。**兩者皆不在 M5 範圍**。

## 五、與 `docs/49` 之同源性

同一結論在介子側已現：`Δ(Σq²)_π ≡ 5/9 − 5/9 = 0` ⟹ 自能通道對 π 恰零（`docs/49`）。
現於重子側：`Δ(Σq²)_{p−n} = +1/3 ≠ 0` 但**號相反**。
⟹ **自能（`∝q²`）通道在介子與重子皆被排除**（介子：零或號錯；重子：號錯）⟹ 可升為一條跨系統之排除律：

> **排除律（`q²` 自能）**：任何 `∝ q²` 之 EM 自能項，其對「同電荷多重態」之質量分裂之貢獻，
> 在介子係（K/D/B：`Δ(Σq²) = −1/3` 而觀測要求中性較重）與重子係（p−n：`Δ(Σq²) = +1/3` 而觀測要求 n 較重）
> **一律與觀測反號** ⟹ 該通道唔可能係任何一族之主要來源。

## 六、結論

1. 🔴 **`W1` 永久阻塞**（兩體不足 1.39% ＋ 自能號相反）⟹ M10 Tier II 之譜側解鎖路徑**已封**。
2. ✅ **跨系統排除律成立**：`q²` 自能在介子與重子之號皆與觀測相反 ⟹ 唔再作任何 O 之候選。
