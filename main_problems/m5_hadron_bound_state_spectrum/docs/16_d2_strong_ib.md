```text
M5 docs/16 配套 — D2：K 系殘餘是否「M4 X 線性扣除不足」所致？（四判準）
================================================================================================
背景：`docs/13` §六 判準草案；D1 已判死（自旋標度解耦）。D2 命題：K 系之
`E(K⁰−K⁺) = 1.374`、`E(K*⁰−K*⁺) = 1.320`（近相等、自旋盲）並非本核之 em，而係
M4 `X = m_d − m_u` **線性扣除不足**所留之強 IB 殘餘。

判準（掃描前寫死；任一破 ⟹ D2 破）：
  Q1 **量級**：同一核內，把 `m_d ≠ m_u` 分開（`m_l ± X/2`）後之非線性殘餘
     `Δ_nl = [E(m_l+δ) + 3|c|(m_l+δ)] − [E(m_l−δ) + 3|c|(m_l−δ)] − 2δ`（δ = X/2 = 1.28 MeV）。
     要 D2 成立，`Δ_nl` 須解釋 K 系觀測殘餘 1.374 之 **≥ 50%**（即 ≥ 0.687 MeV）。
  Q2 **自旋盲**：K 與 K* 之殘餘須近相等（強 IB 自旋盲）：觀測 1.374 vs 1.320，差 0.054 ± 0.3545。
  Q3 **族模式**：Σ/Ξ 系（含 s、無 c）同見「大電荷分裂、零自旋分裂」。
  Q4 **零參數比**：核預言 `ΔE_K/ΔE_D = |c|_K/|c|_D` 對比觀測 0.054/1.41 = 0.0383。
  Q5 **硬上界審計**（新）：`A = α q(ħc/a_C)⟨B⟩`，`⟨B⟩ ≤ 1` ⟹ `A_max = α q(ħc/a_C)`；
     檢 `A_req = 1.3335 ± 0.2570` 與 `A_max` 之關係（超界 ⟹ 該算子族結構上不可能）。

界限：只論本核（同一 ψ、兩體、contact on-site）；不引入格點 QED／手徵外推（本 O 無此能力）。

輸出：`data/17_d2_strong_ib.json`
```

⟹ |Δ_nl| ≈ 0.0201 MeV = 所需 1.374 之 **1.46%** ⟹ **Q1 破（差 34×）**。

物理解讀：`X = m_d − m_u` 之線性扣除已吃掉全部 constituent 質量差；剩下嘅「非線性」只係 contact 深度 `h ∝ 1/(m_h m_l)` 對 `m_l` 之 0.43% 響應 ⟹ 必然 ~10⁻² MeV 級，無法產生 1.374。

核預言 `|c|_K/|c|_D = 0.1880/0.3525 = 0.5334`；觀測 `0.0540/1.4100 = 0.0383` ⟹ 高估 **13.9×**（ΔE_K 統計上 +1.97σ，故屬解釋力不足，非否證）。

### 四.5 Q5 硬上界審計（本輪新增，最強結果）

`A = α q(ħc/a_C)⟨B⟩`，而 `⟨B⟩ ≡ Σ_d B^{−d}|ψ_d|² ≤ 1` ⟹ **`A_max = α q(ħc/a_C) = 1.2718 MeV`**（⟨B⟩ = 1，完全定域，物理上不可達）。

觀測要求 `A_K = 1.3335 ± 0.2570` ⟹ `A_req/A_max = 1.0486` ⟹ **中心值超界 4.86%**（需 `⟨B⟩ = 1.0486 > 1`）；統計上僅 **+0.24σ**。

⟹ 本核 em 對 K 系電荷分裂之貢獻**結構上封頂**於 1.2718 MeV（且實際 ⟨B⟩ < 1，故更低）。要解釋 1.374 必須有本核以外之來源。

## 五、結論報告

1. 🔴 **D2 判死**：非線性強 IB 殘餘 0.0201 MeV = 1.46% ⟹ 差 **34×**。Q2／Q3 只支持「殘餘唔似 em」，**唔**支持「係 X 線性扣除不足」。
2. ★ **Q5 硬上界**：`A_max = 1.2718 MeV`，而 `A_req` 中心值超界 4.86% ⟹ K 系 1.374 之 em 解釋在本算子族內**結構上不可能**（與 contact、層釘、自旋標度全部無關）。
3. ⚠️ **統計保留**：Q5 之超界只 0.24σ（σ_A = 0.2570 偏大）；故嚴格講係「需要 ⟨B⟩ = 1.0486，超界 4.9%」，即**要求完全定域且再多 4.9%** ⟹ 結構上仍不可能，但統計上唔算硬殺。此點必須明示，不得當作「5σ 級否證」。
4. ⟹ **路線終述**：M5 之 em 通道（A1–A3、D1、D2）**全部試盡且全數判死**。`⟨1/r⟩` 重疊算子已建立並驗證（`docs/01`–`docs/09`），但**用於強子質量差之 em 閉合唔成立**。
5. ⟹ **建議 D3 收檔**：M5 記 `negative`（em 閉合不可行），並 register 新問題：
   「K 系 `E(K⁰−K⁺) = 1.374`／`E(K\*⁰−K\*⁺) = 1.320`（自旋盲、超本核 em 上限 4.9%）之來源」，候選路徑：
   (i) 格點 QED 混合－強 IB 非微擾（M5 無此能力）；
   (ii) 態依賴算子（非同一 ψ，即 D1 之更強版本）；
   (iii) `X` 非普適（M4 之 `m_d − m_u` 隨 `m_h` 有係數）——但 Q1 已證此路量級不足。

## 附註更正（append-only；2026-10-24 立，原文一律不動）

**Q5「硬上界」之適用範圍更正**：`A_max = α q(ħc/a_C)·1` 只對 **指數核** `B^{−d}` 成立
（因 `⟨B^{−d}⟩ = Σ w_d B^{−d} ≤ 1`，`Σ w_d = 1`）。M5 自己嘅 H1（`docs/01`）給出嘅**精確**
⟨1/r⟩ 鏈上和係 `g(d) = [(N²−1) − 6d(N−d)]/(12N)`，其 d = 0 值為 `g(0) = 2581/352 = 7.332386`
⟹ 以 g 為核時上限為 `7.3324 ×`，**唔封頂**。故 §五 第 2／3 點之「結構封頂」須降級為
**「指數核 ansatz 內封頂」**，不得作為算子族之普遍結論。

**連帶**：`D3 收檔` 建議**撤回**（理由：em 路線未窮盡——H1 之 g(d) 從未入過兩體振幅；
且 `g(7)/B^{−7} = 6.735e4`，即舊計算把跨層 Coulomb 壓死 4–5 個數量級）。

**g 核第一驗（`docs/17`、`scripts/18`）結果**：D 通道校準落入 `bound = False`（`a₀ = 0.042180 fm`、
`t = 376.5 MeV`、`P₀ = 0.000515`）⟹ 依 R3/R4 記 **N/A**（無可接受之束縛解），K 系預言
`E(K⁰−K⁺) = 24.29`（z = +238.51）⟹ 亦不中。原因為**類別錯誤**：`g(d)` 係「層間重疊和」
（矩陣元），唔係「相對坐標勢」；把佢當勢會產生負尾（`g(20) = −0.394886`、`g(44) = −3.667614`）而令態離域。
正確用法應為 Toeplitz 型層間耦合 `g(|d−d'|)`，此路**尚未推**。

**結論修正**：D2 之 Q1（強 IB 非線性差 34×）不受影響（與核選擇無關）；但「em 路線終述」不成立。
