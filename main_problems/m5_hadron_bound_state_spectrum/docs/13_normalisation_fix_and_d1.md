## 五、結論報告

1. 🔴 **D1 判死**：7 條結構自旋標度 **0 命中**；且 §六 之 1-D 曲線論證**不依賴候選清單** ⟹ 自旋項「與 Coulomb 標度解耦」本身不足夠，因為耦合死結在 **A_K 與 K_K 對同一個 h 嘅相反需求**。
2. ★ **A2 正規化缺陷（本輪最重要發現）**：`docs/10` 之 K 目標多除一個 q_h（0.5287 = 1.5|c|），致其自身通道公式對自身校準通道給出 2.7886 vs 2.2600（**+4.49σ**）⟹
   - `docs/10` 之 `z(ΔE_K) = +3.20` **作廢**；
   - 正確重校：`a₀ = 0.377422 fm`、`t = 0.7884 MeV`；此時 **ΔE_K 反而過（+1.97σ）**，失敗移到 **E(K⁰−K⁺) = −5.41σ**（電荷分裂水平）。
3. 🟡 **A3 結論不變**：層釘族仍 0/5，束縛窗 [0.2000, 1.2306]，χ²_min 13.50 @ s = 0.9392 ⟹ 「層標度族救唔到」結論穩健（且與正規化修正無關，因為失敗在 A 而非僅在 K）。
4. ★ **結構判讀（新）**：數據要求 K 系之「Δ(q_iq_j)-歸一化」Coulomb 幅度 ≥ 1.27 MeV × 1.05 ⟹ 其重疊 ⟨B⟩ 必須 ≥ 1.05（**超界**）；換言之 **K 系之電荷分裂 1.374 MeV 大於本核任何組態之上限**。而在夸克模型裏 K 比 D **更大**（更輕）⟹ 重叠應**更小** ⟹ 數據與「em Coulomb」方向相反 ⟹ **K 系殘餘（E(K⁰−K⁺) = 1.374、E(K*⁰−K*⁺) = 1.320，且兩者近相等）主要唔係此核之 em**，而係 M4 `X = m_d − m_u` **線性扣除不足**所留嘅強 IB 殘餘。
5. ⚠️ **界限**：只論介子；b 味未釘層；π 系不在定義域；本結論不排除「非同一 ψ」之算子（即 D1 之更強版本：自旋項與 Coulomb 項用**不同波函數**）。
