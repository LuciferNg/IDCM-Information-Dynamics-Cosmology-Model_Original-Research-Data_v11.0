## 五、結論報告

1. **C_N Coulomb 核有精確閉式**：`g(d) = [(N²−1) − 6d(N−d)]/(12N)`，N=8/12/88 殘差精確為 0。此為 M5 嘅**基礎物件**（以後所有束縛態計算都用它，零浮點）。
2. **★結構結論（本輪最重要）**：緊緻 1D 環上嘅核係**反屏蔽**（近正遠負、比值 −2），**完全冇 1/r 行為** ⟹ **K_chain 單獨不可能承載 QED 自能差**。`⟨1/r_ij⟩` 必須由 **K_tree 嘅徑向（非緊緻）自由度**提供 —— 呢點把 M5 嘅主戰場由 chain 移到 tree／tensor 結構。
3. **非加性係核嘅內稟性質**：固定取代對、移動 spectator 已可產生 20.989 嘅跨度（相對觀測 5.664 MeV 係 3.7 倍）⟹ 唔需要任何新機制就滿足 O216 R2 嘅要求（加性被否證）。
4. **量級匹配**：κ ≈ 0.270 MeV 即可令 pairwise 跨度對上觀測 5.664 MeV ⟹ 量級上可行（非預言，只係可行性）。
5. **本輪明確唔做**（避免越界）：flavour→site 指派（O140 已證不存在）、QED 自能重整、波函數 ansatz；三者屬 M5 後續 H2–H4。

## 附註 A1（append-only 更正，2026-10-27；由 register handoff M6→M5 觸發，M5 自行重算核實）

上列 §一.B 之方向敍述**錯誤**（原文保留不動，此處更正）：

- `g(d) = [(N²−1) − 6d(N−d)]/(12N)` 對 `d` 係**凹向下拋物線**，頂點在 `d = N/2`：
  `0 ≤ d ≤ N/2` **嚴格遞減**（`g(0) = +2581/352 ≈ +7.332` → `g(N/2) = −1291/352 ≈ −3.668`，後者為**最小值**），
  `d > N/2` 回升。
- 故「遞增至 `d = N/2`」「二次增長」皆錯；正確為「**遞減至 `d = N/2` 之極小**」。
- 零交叉在 `d ≲ N/5`（`g` 於其後全負）—— 由 `6d(N−d) = N²−1` 解得。

**不受影響之結論**：`g` 無 `1/r` pole、`g(0)/g(N/2) = −2`（緊緻 1D 反屏蔽）、非加性（`g(1)+g(1) ≠ g(2)`）
—— 三項皆與單調方向無關，故 `docs/02`–`docs/26` 之依賴不變。
