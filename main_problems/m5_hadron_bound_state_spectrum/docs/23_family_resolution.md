## 二、定理

由 `docs/14` §四.1 恒等式：`r ≡ A/|c|` **與電荷無關**，只由 `(a, t, m_h, m_l)` 決定；而 `(a, t)` 係全域標度 ⟹

> **同一夸克內容（同 `m_h`、同 `m_l`）之所有族，模型必給同一個 `|r|`。**

故「同族多族」構成**零自由度**之檢定（只需 D 兩數校準一次）。

## 六、結論報告

1. ★★ **決定性否證（本 session 最強結果）**：`r = A/|c|` 之質量依賴性 ⟹ **同族必同 `|r|`**；
   數據中 **Σ[0/+]（1.814 ± 0.806）** 與 **Ξc（2.695 ± 0.974）** 分別以 **14.7σ／73.2σ** 排除模型。
   此結論**與 K 無關**、**與 `docs/22` 之層指派無關**、與 `κ` 之取值無關（兩 κ 皆排除）。
2. 🟡 **唯一未排除者 = `c_ud` 類**（D 與 Σc，χ² = 0.13）—— 因為此類正是校準類，且 Σc 之 σ 極大（119.9）。
   即：模型只在「自己校準嘅類」內自洽，**跨類即崩**。
3. ⟹ **原因係結構性的**：兩體 `(A, |c|)` 參數化只帶 `(m_h, m_l)` 兩個標籤，冇「族」自由度；
   而數據之 `|r|` 在同族內跨 **54×**（點估計）⟹ 需要一個**與夸克內容無關、與族／激發態有關**之算子。
   M5 無此機器（只有 `⟨1/r⟩` 與 contact）。
4. ⟹ **M5 em 路線正式判死（negative）**，理由比 `docs/21`／`docs/22` 更根本：
   唔係「某個因子凑唔到」，而係**參數化本身冇族分辨力**。
5. ★ **對 A3 之回饋**：`docs/22` 之層指派 fork 雖然存在，但即使改指派亦救不了 —— 因本輪否證只依賴
   `(m_h, m_l) → |r|` 之單值性，與 `ℓ` 無關。故 M5 之失敗**唔可以**歸咎於 A3 層指派。
