## 二、定理 P（精確、與幾何無關）

觀測反解：`A_K = (E1 + 3E2)/4 = (1.3740 + 3×1.3200)/4 = 1.33350`、`c_K = (E1 − E2)/4 = 0.01350`。

$$A_K \le \frac{q_K}{q_D}\cdot\frac{A_D}{\langle B\rangle_D}=\frac{1}{2}\cdot\frac{1.2025}{0.48120}=\mathbf{1.24948\ \text{MeV}}<1.33350$$

差 **6.72%**。上界之推導只用：①`A` 之定義 ②`⟨B⟩ ≤ 1` ③`q_K/q_D = 1/2` ④`A_D` 由校準固定
⟹ **與 `a_C`、`a_X`、`t`、ρ、`p`、支撐、`κ`、權重約定全部無關**。

★ 注意：此定理解釋 `docs/28`–`docs/33` 所有掃描為何都停在 `A_K ≲ 0.33` —— 佢哋全部係同一上界嘅數值投影。

## 三、逃生門量測（252 點設計、36 點實現）

- 臨界值：`⟨B⟩_D < (q_K/q_D)A_D/A_K = 0.45088`
- 實測 `min⟨B⟩_D = 0.07110` @ `(r = 0.30, κ = 0)` ⟹ **名義上逃生門存在**（上界可升至 8.46 MeV）
- 但全掃描：
  - `A_K ≥ A_K_REQ` 之點數 = **0 / 36**
  - `R ≥ 9.65` 之點數 = **0 / 36**
  - `R ∈ [0.427, 0.434]`（需 28.96）

**⟹ 定理 P 係真但唔緊**：放寬 `⟨B⟩_D` 嘅同時 `⟨B⟩_K` 亦同步縮小（兩者同受 `(a_C, t)` 校準約束），
所以上界雖然升高，實際 `A_K` 反而更細。逃生門係**假門**。

## 四、附帶發現：`κ` 兩種約定之分別（非矛盾，但須統一）

- `docs/28`（`scripts/29`）之 `κ` **只加在回報之 `r` 分子**（`(A + κ g(0) q)/c`），**唔入 Hamiltonian、唔影響 D 校準**
  ⟹ 該輪之 `κ = 0.26986` 合法，`A_D` 仍為 tree 值 1.2025。
- 本輪（`scripts/36`）把 `κ g(0) q/t` **放入 Hamiltonian** 並重新校準 ⟹ 由 `A_D = α q_D(ħc/a)⟨B⟩_D + κ g(0) q_D`（`⟨B⟩_D ≤ 1`）得硬界

$$\kappa<\frac{A_D}{g(0)q_D}=\frac{1.2025}{7.3324\times(2/3)}=0.2459$$

  故 `κ ∈ {0.26986, 0.35}` 在此約定下**無法校準**（掃描中 216 點失效即此因）。

⟹ **兩者唔矛盾**（約定不同）；但兩約定必須統一，否則「chain 旁觀者」之強度無從比較。登記為獨立審計項（下一輪處理）。
