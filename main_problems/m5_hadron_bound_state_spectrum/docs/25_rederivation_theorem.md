## 二、分解恆等式（T1：✅ 4.39e−16，21 個束縛點）

$$r \equiv \frac{A+ch}{c} = \frac{6\,m_h m_l}{\pi\,(\hbar c/a)^2}\cdot\frac{\langle B\rangle+\varepsilon}{P_0},
\qquad \varepsilon \equiv \frac{\kappa\, g\cdot 10^{-3}}{\alpha\,\hbar c/a}$$

- **`q` 完全消去**（`C_q ∝ q` 與 `A ∝ q` 相消）⟹ `r` 與電荷無關（`docs/14` 恒等式之精確化）
- **`r ∝ m_h m_l`**（乘積，非個別質量）—— 與 C27 數值一致（`r(0.495,0.30) = r(0.594,0.25)`）
- 非平凡部分集中於**局部化因子** `Λ ≡ [(⟨B⟩+ε)_K/(⟨B⟩+ε)_D]·(P₀_D/P₀_K)`

## 三、質量因子（T2）

`m_s/m_c = 0.389764`（< 1）；數據需 `R = 98.7778/3.4113 = 28.956` ⟹ **局部化因子需 `Λ = 74.29×`**。

## 四、局部化因子之結構（T3）—— 一個被數值推翻嘅直覺

| 量 | 值 | 來源 |
|:--|--:|:--|
| `h_K/h_D`（接觸井深比）| **1.282828** | `(q_s/q_c)(m_c/m_s)`，**與 `κ, a, t` 無關** |
| `g_K/g_D`（Coulomb 強度比）| 0.500 | `q_s/q_c` |
| 實測 `P₀_K/P₀_D`（21 點）| **0.093 – 0.737（全部 < 1）** | `scripts/27` |

★ **直覺被推翻**：接觸井雖然對 K 較深（1.283×），但 Coulomb 對 K 只有一半（0.5×），兩者競爭後
**淨井對 D 較深** ⟹ K 反而**較唔局部化**（`P₀_K < P₀_D`）。
⟹ 因此**唔存在「方向不可能」**（方向其實對），問題純粹係**幅度**：需 `Λ = 74.3`，束縛族最大 `Λ = 9.384`。
