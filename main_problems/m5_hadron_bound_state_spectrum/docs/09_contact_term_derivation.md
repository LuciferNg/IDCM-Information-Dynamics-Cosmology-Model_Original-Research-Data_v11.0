**問題定位**

`docs/03`–`08` 之核一律用 **電荷-電荷** 部分：`V_ij = q_i q_j B^{−d_ij}`。此算子**對自旋完全盲** ⟹ 必然預言 D 與 D* 之 em 讀數相同，而 PDG 實測差 **1.4100 ± 0.1663 MeV（8.48σ）**。故缺失成分唔在樹結構，而在**算子類型**。

## 三、定量：由數據反解接觸幅度

介子（兩自旋 1/2）：`⟨σ_i·σ_j⟩ = −3`（J=0 單態）／`+1`（J=1 三重態）。
ΔI=1 磁項 `= −K·q_h·Δq_l·⟨σ·σ⟩`，`Δq_l = q_d − q_u = +1` ⟹ `c ≡ (E(J=1) − E(J=0))/4`，`K = |c|/|q_h|`。
再由 Fermi 公式 `K = (8π/3)·α·|q_h|/(16 m_h m_l)·|ψ(0)|²` 反解 `|ψ(0)|²`，取 `r = (π|ψ(0)|²)^{−1/3}`。

## 四、結論報告

1. 🟡 **缺失成分已識別**：Fermi 磁接觸項，**超度量樹上只存活於 `d = 0`**（同節點）⟹ on-site 算子。
2. 🟢 **強度非自由**：`(8π/3)α q_iq_j/(16 m_i m_j)·|ψ(0)|²`，其中唯一未知 = `|ψ(0)|²`（波函數）。
3. 🟢 **數值落在物理預期**：由 D/D* 反解 `|ψ(0)|² = 0.0791 GeV³` ⟹ **r = 0.314 fm**，
   與 heavy-light 介子核心尺度（D 介子電荷半徑 ~0.4 fm、`1/(2m_c) ≈ 0.078 fm`… `~0.3 fm` 核心）**同量級**。
   此為**零調參**檢定（除組分質量 m_l 為標準值）。
4. 🟢 **符號律成立**：`sign(c) = −sign(q_h)`，K（q_h=+1/3）與 D（q_h=+2/3）**皆命中**（2/2）—— 非事後配符號。
5. 🟡 **K 通道無約束**：ΔE = 0.054 ± 0.355（與 0 一致）⟹ 反解 r = 0.80 fm，只可講「同量級」，不可作命中。
6. ⟹ **A1 交付**：em 算子之正確類型 = `q_iq_j B^{−d_ij} − (8π/3)μ_i·μ_j δ_{d_ij,0}`（Coulomb ＋ on-site 磁接觸）。
   呢個就係 docs/03–08 一直缺嘅「分母」之來源；下一步只需 **一套 ψ** 同時供 `|ψ(0)|²` 與層型。

## 附註更正（append-only；2026-10-24 立，原文一律不動）

**缺陷位置**：§三 之定義 `K = |c|/|q_h|`（第 40 行）**多除一個 `q_h`**，正確應為 `K = |c|`。

**推導（物理定義，一次講清）**：`H = −(8π/3)(q_1q_2)/(16 m_1 m_2)(σ_1·σ_2)δ³`；
通道差（重夸克不變、輕夸克 d→u）：
`ΔH = −(8π/3)·q_h·(q_d − q_u)/(16 m_h m_l)(σ·σ)δ³ = −(8π/3)·q_h·|Δq_l|/(16 m_h m_l)(σ·σ)δ³`
⟹ 係數 `K_phys = (8π/3)α q_h|Δq_l|/(16 m_h m_l)|ψ(0)|²` 只有 **一個** `q_h` 因子，
而 `E(J=0) − E(J=1) = −K_phys(⟨σσ⟩₀ − ⟨σσ⟩₁) = 4K_phys` ⟹ **`|c| = K_phys`，即 `K = |c|`**。
若寫成 `K = |c|/|q_h|` 再於通道公式乘一次 `q_h`，能量將 ∝ `q_h²`（物理上錯）。

**傳播後果**：`docs/10` 之校準目標 `K_D = 0.5287 = 1.500 × |c|`（`|c| = 0.3525`）即由此來，
致其參數集以其自身通道公式核其自身校準通道差 **+4.49σ** ⟹ `docs/10` §五 `z(ΔE_K) = +3.20` 作廢。
重校結果見 `docs/13` §四.1–四.3（`a₀ = 0.377422 fm`、`t = 0.7884 MeV`）。

**本檔 §一–§四 其餘內容不受影響**：磁接觸項之識別（超度量 ⟹ `δ³` 只 `d=0`、on-site）、
強度之 Dirac 流來源、`|ψ(0)|² = 0.07909 GeV³ ⟹ r = 0.314 fm`、符號律 2/2 均與此因子無關
（`r` 之反解用 `K = (8π/3)α q_h/(16m_hm_l)|ψ(0)|²` 之**數值** `0.5287`，而該數值本質係 `|c|/q_h`；
若改用 `|c| = 0.3525` 反解，得 `|ψ(0)|² = 0.05272 GeV³ ⟹ r = 0.3593 fm`，同量級）。
