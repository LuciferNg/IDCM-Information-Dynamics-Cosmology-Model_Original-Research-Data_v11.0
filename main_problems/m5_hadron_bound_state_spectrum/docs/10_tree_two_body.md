## 六、結論（誠實）

1. 🟢 **模型可解、可校準、尺度合理**：`(a, t)` 由 D 通道唯一確定，`a = 0.299 fm` 落在強子尺度，`P₀ = 0.276` 為 O(1) 合理值；mpmath 覆核至 1e−16。
2. 🔴 **但普適 (a, t) 之兩體模型被 K 通道否證**：`|ΔE_K|` 預言 1.19 MeV vs 實測 0.054 ± 0.355（**z = +3.20**），`E(K*⁰−K*⁺)` 差 3.73σ。
   ⟹ 「一個節點間距 + 一個跳躍」**不足以**同時描述 c 系與 s 系。
3. 🟡 **失敗位置有結構意義**：P10 明確講粒子**釘在唔同層**（Up@ℓ=0、Down@ℓ=7、Lepton@ℓ=14），
   而 `a` 與耦合隨層縮放（層間 `B^{−ℓ}`、`λ_sync ∝ 4^ℓ`）。本輪把 `a` 當**全味普適**，等於抹平層釘。
   ⟹ 若 s 夸克之有效節點間距較大，其接觸項被壓低，`ΔE_K → 0`，正合實測（0.054 ± 0.355）。
   此為 **A3** 之具體假設（可證偽：須同時命中 Ξc/Ξc′、Σ 系）。
4. ⚠️ **界限**：本輪只用兩體（介子）；三夸克（重子）之自旋因子 `Σ_{i<j}⟨σ_i·σ_j⟩ = 2S(S+1) − 9/2`（S=1/2 → −3，S=3/2 → +3）未入 ψ。

## 附註更正（append-only；2026-10-24 立，原文一律不動）

**發現**：`§四 A2a` 之校準目標 `K_D = 0.5287` 與本檔 `§五` 自己所用嘅通道公式 `E = A ± {3,1}K` 不相容 ——
`0.5287 = 1.500 × |c|`（`|c| ≡ (E₀−E₁)/4 = 0.3525`），即多除了一個 `q_h = 2/3`。

**定量證據**：以本檔自己嘅參數（`a = 0.299337 fm`、`A = 1.2025`、`K = 0.5287`）代入本檔自己嘅公式：
`E(D⁺−D⁰) = A + 3K = 2.7886` vs 實測 **2.2600** ⟹ 差 `+0.5286 MeV = +4.49σ`
⟹ 該參數集**不重現自己用嚟校準嘅通道**。

**正確重校（物理定義 `K = |c| = 0.3525`）**：`a₀ = 0.377422 fm`、`t = 0.7884 MeV`、
`⟨B^{−d}⟩ = 0.4728`、`P₀ = 0.3689`；`A_D = 1.202500`、`K_D = 0.352500` 零殘差，
且 `E(D⁺−D⁰) = 2.2600`、`E(D*⁺−D*⁰) = 0.8500` 逐位重現。

**重校後 K 通道（`docs/13` §四.3）**：`A_K = 0.2903`、`K_K = 0.1880` ⟹
`E(K⁰−K⁺) = 0.8544` vs `1.3740 ± 0.0961`（**z = −5.41**）、
`E(K*⁰−K*⁺) = 0.1023` vs `1.3200 ± 0.3412`（**z = −3.57**）、
`ΔE_K = 0.7521` vs `0.0540 ± 0.3545`（**z = +1.97 ✅**）。

**結論修正**：`§五` 之 `z(ΔE_K) = +3.20` 🔴 **作廢**（源於不一致校準）。重校後 ΔE_K 反而通過，
失敗移到**電荷分裂水平**（`E(K⁰−K⁺)` 偏低 5.41σ）。`§四 A2a` 之 `(a, t, ⟨B⟩, P₀)` 亦一併作廢，
以 `(0.377422 fm, 0.7884 MeV, 0.4728, 0.3689)` 取代。詳見 `docs/13`。
