## 二、維度論（硬證，唔依賴掃描）

`P` 係投影、`K_chain` 與 `K_tree` 係**純數**矩陣（`b = 4`、`N = 88`、`γ_n` 全無量綱）。
任何由佢們造出之量 `F(P†(K_chain⊗K_tree)P)` 必**無量綱**；而 `a₀`（長度）、`t`（能量）各帶量綱。
⟹ **單靠算子構造不可能產生 `a₀` 或 `t`**；最多產生其組合比 `w = t/(ħc/a₀)` 或 `t·a₀/ħc`。
故「算子消除」之可測內容只有一條：`w` 係否為結構數。
