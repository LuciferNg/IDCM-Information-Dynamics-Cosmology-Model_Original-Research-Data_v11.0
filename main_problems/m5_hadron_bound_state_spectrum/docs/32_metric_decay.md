## 三、定理：單尺度模型不可能產生 `A_K`（本輪主收穫）

模型只有**一個長度** `a`，同時決定 Coulomb 射程與 contact 尺度：

$$A=\alpha q\,\frac{\hbar c}{a}\langle B\rangle,\qquad \langle B\rangle=\sum_d w_d\rho^{d}\le 1\ (\rho\le1)$$

故 `A` 之絕對上界 `A_max(a) = α q (ħc/a)`。**可達條件**：

$$A_K \le A_{\max}(a)\iff a\le\frac{\hbar c}{A_K/(\alpha q)}=\frac{0.197327\ \text{GeV·fm}}{1.3335\ \text{MeV}/((2/3)(1/137.036))}=0.35997\ \text{fm}$$

但 D 兩數校準要求 `a = 0.384184 fm`（`p = 3`、ρ = 1/4）⟹

$$\boxed{a_D = 0.384184\ \text{fm} > 0.35997\ \text{fm}}$$

**兩條件無交集** ⟹ 單尺度模型**不可能**同時重現 D 與 `A_K`；等價地需 `⟨B⟩_K = A_K/A_max = 1.3335/1.2494 = 1.067 > 1`（機率上界）。

### 推論（重要性）

1. 此定理**與 ρ、`p`、支撐、`κ` 全部無關**（因 `a` 由 D 釘死），亦與權重約定無關（`⟨B⟩ ≤ 1` 係恆等式）。
   ⟹ 之前所有掃描式天花板（17.58×）只係此定理之數值投影。
2. `R ∈ [0.43, 0.47]` 之剛性由此得解：`R = (m_s/m_c)·Λ`，而 `Λ = (⟨B⟩_K/⟨B⟩_D)(P₀_D/P₀_K)` 受 `⟨B⟩ ≤ 1` 及 D 校準夾死。
3. **唯一必要延伸＝兩個長度**：Coulomb 射程 `a_C` 與 contact 尺度 `a_X` 必須分離，且由定理得**硬約束**

$$\frac{a_C}{a_X}<\frac{0.35997}{0.384184}=0.9370\quad(\text{若 } a_X = a_D)$$

   即 **Coulomb 射程必須短於 contact 尺度**（約 ≤ 0.94×）。呢個係下一輪推導之**結構目標**，唔係擬合參數。

## 四、結論報告

1. 🔴 **衰減律（計數 4 vs 度量 3 vs 帶中 3^−½）皆非缺口**；`R` 對勢形 ±4.6% 內不敏感。
2. ✅ **單尺度不可達定理**已立：`a_D = 0.3842 fm` 與 `A_K` 所需 `a ≤ 0.3600 fm` 無交集 —— 與 ρ／`p`／支撐／`κ` 無關。
3. ★ **缺口定位升級**：唔係「勢形唔夠好」，而係「**一個長度做兩件事**」。
   必要延伸 = `a_C ≠ a_X`，硬約束 `a_C/a_X < 0.9370`。
