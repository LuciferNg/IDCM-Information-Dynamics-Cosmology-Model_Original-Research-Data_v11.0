## 一、前設問題（docstring 原文）

```text
M5 docs/31 配套 — `a₀`、`t` 結構化之可行性（可識別性 no-go ＋ 預註冊掃描）
================================================================================
`docs/30` 已封死 contact 幾何；剩餘唯一全開之門 = 兩體尺度 `(a₀, t)` 有無結構式（M6 交接項）。
`docs/28` 校準：`ħc/a₀ = 0.513626232 GeV`、`t = 1.7711 MeV`；以 `M₀ = 0.027900914 GeV`（M6）除之得兩個無量綱數：

  u ≡ ħc/(a₀ M₀) = 18.408939…,    v ≡ t/M₀ = 0.063478206…

本輪唔係「搵條式出嚟湊」，而係先問：**喺可達精度下，封閉式能否唯一識別 (u, v)？**
做法 = 預註冊文法（只准 IDCM 已認證原子 ＋ 有限運算）＋ 全枚舉 ＋ **隨機目標零假設**（Monte Carlo 對照）。
若命中數 ≈ 隨機期望，則任何「命中」皆不可作為結構證據 ⟹ 封閉式路線 no-go，必須走算子推導。

判準（事前寫死）：
  W1 原子集只准已認證結構量（N_d、層計數、φ、π、√2/√3/√5、γ_n 譜、d_H、Σγ、F₁₀、L₇ 等），不得臨時加入。
  W2 表達式複雜度上限：≤ 3 個原子（含 1 個二元運算 ＋ 可選 √ 或整數次方 2,3,−1）。
  W3 命中定義：|expr/u − 1| ≤ 1e-3（0.1%）；另報 1e-4 嚴格命中。
  W4 顯著性：以 20,000 個隨機對數均勻目標（範圍 u ∈ [1,100]、v ∈ [1e-3,1e-1]）求每次期望命中數 E；
     須 obs/E ≥ 10 才算「非偶然」，否則記 no-go。
  W5 不得以命中為由改 atom 集重跑（p-hacking）；本腳本 atom 集寫死於碼內、單次枚舉。
輸出：`data/33_scale_identifiability.json`
```

## 二、設定

- 目標：`u = 18.408939299`、`v = 0.063478207`（`M₀ = 27.900914 MeV`，M6）
- 原子集 **25 個**（全部已認證）：`N_d, N_d/2, L₇, F₁₀, N_gen, B, b−1, Σγ, d_H, π, φ, √2, √3, √5, e, γ₄₄, γ₂₂, γ₁₁, γ₇, γ₁, μ², sec(π/88), F₇, L₆, L₈`
- 枚舉 **30 125 條**（≤ 3 原子、1 個二元運算 ＋ √／整數次方）
- 零假設：20,000 個對數均勻隨機目標，同樣文法、同樣容差，求期望命中數 `E`

## 四、判決

🔴 **封閉式不可識別**：兩個數之命中數皆與隨機期望同量級（obs/E = 1.91、0.68、3.78，全部 ≪ 10）。

- `u` 之最佳近命中 `90×18/88` 達 0.00082%（5 位有效），但 1e-4 期望 0.53 條 ⟹ **唔顯著**（且兩個「命中」其實係同一條式之運算次序重複）
- `v` 更差：0.1% 只有 2 條、1e-4 零命中 ⟹ 連湊都湊唔到
- ⟹ 任何「`a₀`／`t` = 某封閉式」之主張，在此精度下**皆屬後驗湊數**，不得採納（此即 φ-power trap 之推廣形式）

## 五、結構含義（本輪真正收穫）

1. `(u, v)` 係兩體問題之**全部**輸入（等價於 `(g, h) = (1.410841, 0.511501)` 兩個無量綱耦合）。校準後 `g = 1.410841` 距 `√2 = 1.414214` 0.24%、`h/g = 0.362550` 距 `8/22` 0.3% —— 全部落在隨機水平，同樣不得採納。
2. 因此 M5 之正確定位：**兩參數模型（對 D 校準）、對 K／Ξc 盲測**，而「零參數」只成立於 *給定* `(a₀, t)` 之後。
3. 唯一合法完成路線：**唔係解釋 `(a₀, t)`，而係消除它們** —— 由 `K_chain ⊗ K_tree` 直接寫兩體算子，
   即 `H_pair = P†(K_chain ⊗ K_tree)P`，令 `ħc/a` 與 `t` 成為鏈譜 `{γ_n}` 之本徵組合（`M₀` 單位）。
   此即 `docs/26` 所記「dof = 1 之外第二缺口」，亦係 M6 交接項之正確形式。

## 六、結論報告

1. 🔴 封閉式路線 **no-go**（`u`：obs/E 1.91／3.78；`v`：0.68／0.00）。
2. ✅ 方法層：本輪把「可識別性」變成可計算判準（預註冊文法 ＋ 30 125 條枚舉 ＋ 隨機目標 MC），
   以後任何「常數 = 封閉式」主張都可以用同一 harness 判生死，唔需再靠直覺。
3. → 下一前線：`H_pair = P†(K_chain⊗K_tree)P` 之算子推導（消除 `(a₀,t)`），或 mode 佔用算子（blocked-by-O140）。
