## 一bis、方法（零新參數、只重算不重推）

`data/21_R_ceiling.json` 之 57 個校準點（`(a₀, t)` 由 D 兩數定）逐點重算 K（`s_ud`）與 D（`c_ud`）態，
加回 `scripts/15/19/21` R1 之束縛守門 `⟨B⟩ > 1e−3 ∧ d_peak ≤ 20`：

- **K 與 D 同時束縛**：21／57 點 ⟹ 只有這些點可入上限
- 其餘 36 點（含 v1 所用之 κ = 0.2150）至少一類非束縛 ⟹ 不得入上限

## 二、`docs/19` 天花板：13.4034 → **1.4754**（短缺 66.95×）

| 項 | v1（非守門）| v2（守門）| 差 |
|:--|--:|--:|--:|
| 最佳點 | κ = 0.2150（K 態 `d_peak = 36`，非束縛）| κ = 0.18（`d_peak = 2`，束縛）| — |
| `R = r_K/r_D` | 3.9291 | **0.4325** | 9.084× |
| `r_K` 天花板 | 13.4034 | **1.4754** | 9.084× |
| 短缺倍數（數據 98.7778）| 7.37× | **66.95×** | 9.084× |

★ **方向翻轉**：守門後模型之 `R = r_K/r_D` **最大只有 0.4325 < 1**，即「形狀上 K 之 `A/|c|` 必然細過 D」，
而數據要 28.96（大 67×）⟹ 唔止「差幾多」，而係**連方向都相反**。此與 `docs/21` 符號定理一致（同一結論之另一表述）。

## 五、⚠️ 一個未解釋之數值巧合（只記錄，不宣稱）

守門後短缺 = **66.948×**；`docs/20` 之目標 `F_7/F_0 = 1/66.9921` ⟹ 兩者相差 **0.066%**。

- 前者 = `R_data / R_bound_max`（動力學形狀比之短缺）
