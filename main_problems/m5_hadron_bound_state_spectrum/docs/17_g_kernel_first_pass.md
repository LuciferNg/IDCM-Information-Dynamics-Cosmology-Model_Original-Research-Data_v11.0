## 五、結論報告

1. ★ **`docs/16` Q5 之上界係 kernel-dependent**：`A_max = α q(ħc/a_C)` 只對指數核 `B^{−d}` 成立；g 核下上限 ×7.3324 ⟹「結構封頂」**唔可以**作為算子族之普遍結論。**`D3 收檔` 建議撤回。**
2. 🟡 **但 g 核亦冇救到本輪模型**：D 通道校準落入 `P₀ = 5e−4`（非束縛）⟹ N/A；K 系更離譜（z = +238.51）。原因唔係「g 核錯」，而係**用法錯**：`g(d)` 係「層間重疊和」（矩陣元），唔係「相對坐標勢」。
3. ★ **正確用法（未推）**：Coulomb 部分應寫成 Toeplitz 型層間耦合 `g(|d − d′|)`（即 H 喺 d、d′ 兩層之間有非對角耦合），而唔係對角勢 `−α q g(d)/a`。此路尚未推，係 M5 真正未試之出口。
4. ⚠️ **對「關係本體論」之意義**：呢輪死嘅係「**把一組關係壓成單一形狀變量**」（單 ψ × 單調核 × 兩參數），唔係本體論本身。`⟨B⟩ ≤ 1` 係「區分權重歸一」之計數恒等（ontology-native），而 `g(d) > 1` 正係「關係不只係形狀」之直接後果。
