## 八、本輪由 L1 抓出之執行層缺陷（已修）

`scripts/28` 首版用 `ROOT = Path(__file__).resolve().parents[1]`；但 `scripts/12` 之沙盒以 `cwd = work` 執行
`[PY, sc.name]`（`__file__` 為相對名）⟹ `parents[1]` 指向沙盒上層 ⟹ `docs` 為空 ⟹ `IndexError`（exit 1）。

- 修正：改用本 O 既有慣例 `ROOT = Path.cwd() if (Path.cwd()/"README.md").exists() else Path(__file__).resolve().parent.parent`（與 `scripts/16` 一致）
- 驗：沙盒與實跑皆 exit 0；`scripts/12` 重跑 byte-identical（86 行）
- 意義：L1（打包）能抓出 L2／L3 本身嘅執行層錯誤 —— 三層互相覆蓋，唔係單向。
