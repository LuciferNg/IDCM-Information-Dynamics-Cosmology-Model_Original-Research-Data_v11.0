## 五、否證（兩條，互為印證）

**① 解析**：K 通道所有 x 係數 `{2/9, 1/9}` **皆正**，且 x ∈ (0,1] ⟹
`E_model(K⁺)−E(K⁰) ≥ 0`（A）／`≥ κ/3 = 1.2667`（B），**恆為正**。
實測 **−1.3740** ⟹ 矛盾幅度 **2.6407 MeV ≈ 2× 效應本身**。
任何 κ、任何 b、任何層指派都無法翻轉符號（符號由 q² 排序決定，層只改變**大小**）。

**② 全枚舉**：34³ = 39 304 組層指派，κ 由 n−p 釘死，檢其餘 7 通道 ⟹
最小 max-dev = **4.2257 MeV**（ℓ_u = ℓ_d = ℓ_s 退化族）≫ σ ≈ 0.1 MeV ⟹ 無救。
