> 比 < 1 **若且僅若** `d_K > d_D`，即「**s 較 d 更深層**」。

A3 現行指派 `ℓ(u) = ℓ(c) = 0`、`ℓ(d) = ℓ(s) = 7` 給 `d_K = 0`、`d_D = 7` ⟹ 比 = `B^7 = 16384`。
