## 五、推導（點解係 1/b ⟹ α = ln b/ln w）

徑向化：源喺 root、樹 b 分支、葉端 Dirichlet，level-symmetric 方程

`A g = e₀`，`A = tridiag[−1, (b, b+1, …, b+1, 2), −b]`

⟹ 相鄰兩層 Green 比值在全樹 **bulk 恆等 1/b**（與 w 無關；b=2 精確 `2^(−ℓ)`）。
質量 resolvent 閉式 `u(ε) → 1/b` 於 ε→0 證同一件事。

半徑若隨層幾何增長 `r_ℓ = w^ℓ`：

`G_ℓ = b^(−ℓ) = (w^ℓ)^(−ln b/ln w) = r^(−α)`，**α = ln b / ln w**

⟹ 1/r ⟺ `ln b = ln w` ⟺ **w = b**（分支數 = 徑向增長因子）。

**IDCM**：MERA isometry 係 **4 子 → 1 父**（b = B = 4，P10 docs/00 §5），而層時間 `t_ℓ = 4^ℓ·t_site`，
光錐半徑 `r_ℓ = c·t_ℓ` ⟹ w_t = 4 = b ⟹ **α = ln4/ln4 = 1，零參數、精確**。
