## 五、結論報告

1. 🟡 **族**（態依賴層 + Z₂ 號 + 超度量核）**未被否證**：恰好 **1/8** 號組合有解 ——
   `s_u = +1, s_d = −1, s_s = +1`（`s_c` 不受限），且 κ 被壓到窄窗 **[68.5696, 70.5744] MeV**（另有 ≈ 137–141 之諧波窗）。
2. 🟢 **結構性副產品（可證偽）**：**s_d = −1** 係唯一可行號 —— 即 d 味帶 Z₂ 號而 u、s 不帶。
   此為 H5 之明確檢定目標：須由 A₅ 阻挫／樹二色**導出**（唔准擬合）。
3. 🔴 **8 通道唔足以定 ψ**：20+ 個態層參數 vs 8 條方程 ⟹ 有解係自由度使然，唔係證據。
   ⟹ `docs/05` 之「0 命中」與本輪「有解」合起來講嘅係同一件事：**8 通道對此族無鑑別力**。
4. ⟹ **方法結論**：ψ 必須由 lattice Hamiltonian（P10 §5 之 H_ℓ）**導出**，8 通道只作事後檢定；
   檢定力必須靠**樣本外通道**（M4 未用過：Λ、Ξ_c、Δ 系）＋ δ★ 閘（M4 `docs/20`）。
5. **尺度**：κ ≈ 69 MeV 屬量綱定義（同 M₀ 一樣，絕對值 = 單位制 artifact）；與 `Λ_IDCM = 45.2849 MeV`（O142）之比 ≈ 1.515，**僅記錄，不作匹配宣稱**。
