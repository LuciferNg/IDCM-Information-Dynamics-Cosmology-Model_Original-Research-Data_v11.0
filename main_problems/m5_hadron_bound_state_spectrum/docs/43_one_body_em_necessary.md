## 二、上界（`E1`／`E2`）

`|Δ0| ≤ |Δ(q_h q_l)|·α·(ħc/a₀)·⟨B⟩`，其中 `⟨B⟩ ≤ 1`（恆等式）、`a₀ = 0.384184 fm`（v3 校準）：

| 量 | 值 |
|:--|:--|
| `α(ħc/a₀)` | `3.7481 MeV` |
| `α(2/3)(ħc/a₀)`（最大電荷差組合）| **`2.4987 MeV`** |
| `α(1/3)(ħc/a₀)`（π/K/B 之 `|Δ(q_hq_l)| = 1/3`）| `1.2494 MeV` |

## 三、逐族判（`E3`）：**π/K/D 全部超上界**

| 族 | `|Δ0^data|` | `|Δ(q_h q_l)|` | 兩體上界 | 超出 | 一體項至少 |

**⟹ 兩體 Coulomb（含正確 `q_h q_l` 符號）在**任何**允許之 `⟨B⟩ ≤ 1` 下都達不到 π/K/D 之電荷分裂。**
上界係「恆等式級」（`⟨B⟩ ≤ 1`），非擬合 ⟹ 結論不依賴 `(a,t)` 之細節，只依賴 `a₀` 之校準值。
