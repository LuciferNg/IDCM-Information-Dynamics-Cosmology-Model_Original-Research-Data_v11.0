## 四、結論報告

1. 🔴 **「改指數」路線終結**：單一冪律兩族要求差 2.06σ；任何統一 `p` 都必然令一族偏 ≥ 該族 σ。
2. 🟢 **v3 為現時最佳**（唯一在 10% 內者），保留；殘餘 4.4σ／2.4σ 記錄為 open。
3. ★ **剩餘可能性（未驗，勿宣稱）**：①自旋-自旋之非接觸部分（非 Fermi contact）；②輕夸克動能之相對論修正；
   ③`D_s`／`B_s` 之 `m_h` 或 `m_l` 取值（現用組分質量 1.27／4.18／0.495 GeV，若換 PDG 跑動質量會移動 `p_f`）。
   ⚠️ 第③項屬**輸入敏感度**，須先做敏感度掃描才可排除 —— 列下一步（低成本）。
4. ⚠️ 本檔**不**主張「ΔI=0 已解釋」；只主張「v3 之後，剩餘偏差唔可以由 `m_l` 冪律吸收」。

## 六、可能性③ 已收（同日，代數論證，非掃描）

v3 下 `c = C_q(m_h)·(ħc/a₀)³·P₀`，其中 `C_q ∝ 1/(m_h·m_ref)`、`m_ref = 0.30` **固定**、`P₀` 由 `(a₀,t)` 決定。
同一 `m_h` 之兩族（`D`／`D_s`、`B`／`B_s`）除 `m_l` 外全部相同，而 v3 **完全不含 `m_l`**
⟹ `c(D_s)/c(D) ≡ 1`、`c(B_s)/c(B) ≡ 1`，**與 `m_l` 之取值無關**（`m_l` 只影響 v2 之 `C_q`，v3 已移除）。
⟹ 換 PDG 跑動質量、改組分質量、改 `m_s` 均**不可能**移動此比值 ⟹ 可能性③ **代數上不可能**，撤銷該列項。
殘餘 4.4σ／2.4σ 因此係對「`c` 與 `m_l` 無關」之**真否證**，只能由 ①非接觸自旋項 或 ②相對論修正解釋。
