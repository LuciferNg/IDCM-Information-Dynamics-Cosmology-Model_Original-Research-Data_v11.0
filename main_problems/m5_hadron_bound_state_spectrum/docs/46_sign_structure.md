## 四、`q_l²` 形式被符號排除（重要）

`docs/45` 曾以 `V_self ∝ q_l²` 估量級。今見：`q_l²` **恆正** ⟹ 其對 `Δ0` 之貢獻
`∝ (q_l²)_N − (q_l²)_C`，對 `ū ↔ d̄` 之配對恆為 `4/9 − 1/9 = +1/3`（**四族同號**）⟹
**不可能產生 −, +, −, + 之交替**。⟹ `V_self` 必須 ∝ `q_h`（重夸克），非 `q_l²`。
**⟹ `docs/45` §三 之 `r* = 0.0697 fm` 須改**：按 `α q_h (ħc/r*) = r_f`：
`ħc/r* = r_f/(α q_h) = 7.06/(0.0072974×2/3) = 1452 MeV` ⟹ **`r* = 0.1359 fm = 0.354 a₀`**（`ħc/r* = 1.45 GeV`）。
