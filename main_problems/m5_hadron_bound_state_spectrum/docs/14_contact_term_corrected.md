## 四、原始輸出（引自 log）

### 四.1 P1 算子計數

`H_mag = −(8π/3)(q₁q₂)/(16 m₁m₂)(σ₁·σ₂)δ³(r)`；通道差（重夸克同、輕夸克 d ↔ u）：

`ΔH = −(8π/3)/(16 m_h m_l)·[q_h(q_d − q_u)]·(σ·σ)δ³ = −(8π/3)/(16 m_h m_l)·[q_h·(+1)]·(σ·σ)δ³`

⟹ 係數只有**一個** `q_h`；`K = |c|/|q_h|` 再於通道式乘 `q_h` ⟹ 能量 ∝ `q_h²`（雙重計數）。

可測恒等式：A 與 `|c|` 共用同一 `q_h|Δq_l|` ⟹ `A/|c|` 與電荷無關，只由形狀 `(a, t, m_h, m_l)` 決定。

| 系統 | 數據 `A/|c|` |
|:--|--:|
| D | 3.4113 |
| K | 98.78 |
| 比 | **29.0×** |

⟹ 兩個系統 `q_h` 相差 2×，但 `A/|c|` 差 29.0× ⟹ 差異**只能**來自形狀；任何把 `q_h` 計兩次之寫法會直接把此比污染 2× 或 0.5×。
