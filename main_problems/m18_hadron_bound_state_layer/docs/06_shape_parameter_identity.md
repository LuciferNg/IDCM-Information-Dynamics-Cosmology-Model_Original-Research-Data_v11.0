# M18 docs/06 — 強子形狀參數之算子身份掃描（M6 帳本「強子形狀 2」）
> 腳本：`scripts/06_shape_parameter_identity.py`｜log：`data/run_06_shape_parameter_identity.log`｜JSON：`data/06_shape_parameter_identity.json`
> 狀態：🔴 **兩個形狀參數皆無算子身份**（命中數 **低於／等於隨機期望**）⟹ M6 帳本「強子形狀 2」維持
> ｜實作閘 5/5 PASS（+2 實質 negative）

## 一、前設問題

```text
M6 final 帳本：dof_scale = 1 ＋ 速率軸 ≤6 ＋ 強子形狀 2（a₀, t）⟹ ≤9。
該 2 參數係 M5 兩體模型標度（a₀ = 0.37742216816391858835 fm、t = 0.788398083633567408 MeV，
M7 R0 30 dps 重現）。問：有冇算子身份（= M₀ 之結構倍數），抑或係真自由度？
無量綱化：T_A = (ħc/a₀)/M₀（M6 記 18.73876）；T_t = t/M₀（M6 記 0.0282571）
```

## 二、事前判準（寫死；族必須先列印，後掃）

| # | 判準 |
|:-:|:--|
| X1 | 原子集只准用已註冊整數／有理結構數（28 個），禁自創、禁 `44±k` 類算術碎片 |
| X2 | 族形式 = 三個原子之積，指數 ∈ {−2,−1,+1,+2}；族大小先報 |
| X3 | 命中門檻：dev ≤ 0.1%（初篩）／≤ 0.01%（嚴格）|
| X4 | 密度控制：同族對**隨機目標**之命中率為 p；命中數 ≤ 隨機期望 ⟹ 判隨機 |
| X5 | 須同時報 (dev, 族大小, coverage, 表達式)，缺一作廢 |
| X6 | MC 對照：5000 個 log-uniform 隨機目標，核密度估算無偏 |

## 三、執行

1.0 s。`PASS 5 / FAIL 2（共 7）｜實作閘 FAIL 0`，exit 0。

## 四、結果

**目標重算（唔照抄）**

| 目標 | 值 | M6 記載 | \|Δ\|rel |
|:--|--:|--:|--:|
| `T_A = (ħc/a₀)/M₀` | 18.7387500758 | 18.73876 | 5.30e−7 |
| `T_t = t/M₀` | 0.0282570691188 | 0.0282571 | 1.09e−6 |

**族（先列印）**：28 個已註冊原子 ⟹ 112 展開項 ⟹ 三項積 = **1,404,928** 個值。

**掃描**

| 目標 | dev ≤0.1% 命中 | dev ≤0.01%（去重後）| 最近 dev | 隨機期望（tol 0.01%）|
|:--|--:|--:|--:|--:|
| `T_A` | 174 | **0** | 0.027% | 10.50 |
| `T_t` | 129 | **2** | 0.00137% | 10.50 |

`T_t` 之兩條命中（皆去重後唯一值）：

```
0.02825745683  (dev 0.00137%)  =  F7^-1 · h11^1 · h21^-1
0.02825836217  (dev 0.00458%)  =  N_gen^-1 · K34^-2 · h21^1
```

**MC 對照**：5000 個 log-uniform 隨機目標之 coverage(0.1%) mean = 0.008%（與 `T_A` 之 0.012% 同量級）；
tol=0.01% 之命中數**期望 = 10.50**。

⟹ `T_A` 觀測 0 < **期望 10.50**；`T_t` 觀測 2 < **期望 10.50** ⟹ **兩者皆低於隨機期望**。

## 五、判決

1. **🔴 `a₀` 無算子身份**：嚴格閘（0.01%）**零命中**，最近值亦差 0.027%。
2. **🔴 `t` 無算子身份**：兩條「命中」數量**少於**隨機期望（2 ≪ 10.5）⟹ 隨機級，唔可辨識。
3. ⟹ **M6 帳本維持**：`dof_scale = 1` ＋ 速率 ≤6 ＋ **強子形狀 2** = **≤9**；本輪**冇**降低帳本。
4. ★ 方法論記錄：**「族夠大 ⟹ 必有命中」係陷阱**。必須用「隨機期望命中數」對照，
   而唔係「coverage < 1%」。本輪首次把該對照寫入事前判準（X4/X6），救咗一次假命中
   （若只用 coverage，`T_t` 會被誤判「有候選」）。
