## 一、前設問題

`MD16` 只報耦合空間維數（`11/100/300`）。本輪兩件**可算即判**：

```text
Q-a 每 J 多重態之 d=0 根權重上限 = ？（由模塊內容直接定，零參數）
Q-b 11 維之中，有幾多維由幾何典範構造（子節點關聯之 A₄-平均）填滿？
```

判準：`cap(J) = Σ_{R∈J↓, R∈F₀} dim R / (2J+1)`；典範性必須由**平均構造**（唯一）提供，唔准「揀一個似嘅」。
