**W2 ★ 最小忠實度 = 5**

| `k` | `|S_k|` | `60 | k!` |
|--:|--:|:-:|
| 1–4 | 1,2,6,**24** | ✗ |

⟹ `A₅ → S_k`（`k ≤ 4`）只能平凡 ⟹ **`A₅` 作用於 4 點必平凡**。

推論（W2c，殘項成立）：若 `A₅` 保結構作用於 `B = 4` 之樹，則 level 1（4 點）之作用 = `hom A₅ → S₄`，

**W3 鏈（環）**
`|Aut(C₄₄)| = |D₄₄| = 88 = 2³·11`、`|Aut(C₈₈)| = |D₈₈| = 176 = 2⁴·11`；`60 ∤ 88`、`60 ∤ 176`

## 五、判決

1. **新 no-go `MC10`**：`A₅` **保結構**忠實作用於樹（`B=4`）或鏈（`C₄₄/C₈₈`）**結構上不可能**。
   ⟹ 幾何層唔可以透過「作用於徑向樹／鏈環」供 irrep 標籤。
2. **三向張力成立**：`MD3`（`J` 載體 = `A₅`）× `M16`（`B = 4` 閉合）× 本輪（忠實 ⟹ `B ≥ 5`）
   —— 三者**唔可以同時為真**。本輪唔裁決，只標價：`E2` 係唯一中價路線。
3. **`MA1` 收窄為可交付規格**（唔再係空口「要新層」）：
   ```
   新載體須為 A₅-齊性空間：|orbit| ∈ {5,6,10,12,15,20,30,60}
   且與徑向樹之連接須 ≥ 5 分支等變（最小規格 = degree 5 = F₅）
   ```
4. **呢個張力要 register 為正式結構張力**（同 M4 `⟨O⟩` 3.36σ 張力同類），唔可以靜靜當「未做」。
5. **唔准嘅解法**：改 `B`（E3，斷 6 條恆等式）；改 `A₅` 身份（`MD3` 已被 `J=2` 逼死）；靜靜揀一個 orbit 分解（`MC9`）。
