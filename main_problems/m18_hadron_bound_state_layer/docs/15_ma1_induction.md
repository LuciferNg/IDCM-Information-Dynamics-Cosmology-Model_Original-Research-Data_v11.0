## 一、前設問題

```text
docs/14 收窄至 {20, 60}（1 bit）。問：
  Q-a 20 能否由已定結構誘導（5-orbit 接駁層 ＋ B = 4）⟹ 零自由參數？
  Q-b 60 係咩誘導？（F₅·B·N_gen 三重關聯）
  Q-c 可分辨差異（非美學）：多重態 ⟹ 精確退化預言
依據：Frobenius 誘導 Ind_H^G χ(g) = (1/|H|) Σ_{x: x⁻¹gx∈H} χ_H(x⁻¹gx)
```

## 三、結果

**A1 ★ `MD11` 誘導恆等（逐類精確）**

```
Ind_{A₄}^{A₅}(A₄ 對 4 = B 點之置換特徵)（按類）= [20, 0, 2, 0, 0]
χ_20（逐 coset 實數，按類）              = [20, 0, 2, 0, 0]   ✓ 逐元素相等
```

⟹ **`20`-載體 = 由接駁層誘導**：
`A₅` 之 `5`-orbit（= 接駁層）→ 穩定子 `A₄` 對 `4 = B` 個子節點之作用 → `Ind_{A₄}^{A₅}` ⟹ `20` 點。
即 **`20 = F₅·B` ＝ {(四面體, 子節點)} 關聯集**；`60 = F₅·B·N_gen` ＝ 三重關聯（regular）。
兩者**皆**可誘導（`60` = `Ind_{1}^{A₅}` trivial），故誘導本身唔判別 —— 見 A3/A4。

**A2 重數（態數）**

| irrep | `20` 重數 | `60` 重數 |
|:--|:-:|:-:|
| `A` | 1 | 1 |
| `T1` | 1 | **3** |
| `T2` | 1 | **3** |
| `G` | **2** | **4** |
| `H` | 1 | **5** |
| 合計 | 20 | 60 |

**A3/A4 ★ `MD12` 精確退化（可證偽差異）**
機制審計：`M5`／`M18` 之算子 `= H_tree`（徑向模式）`＋ V₀`（接觸項）；`MD7` 晶體場分裂只作用於**同一份**多重態內部。
⟹ 若載體重數 `m_R > 1`，`m_R` 份**完全同譜**，樹之分裂對每份**相同** ⟹ **退化唔會被抬升**。

| 載體 | 預言之精確退化 |
|:--|:--|
| `60` | `J=1`（`T1`）3 份、`J=2`（`H`）5 份、`J=3`（`T2`）3 份、`G` 4 份 —— **同 `J^PC` 同質量** |
| `20` | 只 `G` 2 份（`J=3` 或 `J=4` 兩態退化）；其餘 `1` 份 |

觀測（PDG 介子）**冇**此類精確退化（同 `J^PC` 態普遍劈裂數十至數百 MeV）⟹ `60` 排除。

## 四、判決

1. **`MD11`**：載體 `20` 由（接駁層 `5`，分支 `4`）**誘導** ⟹ **唔再係自由揀**（`1 bit` 消失於構造）。
2. **`MD12`（條件性）**：`60` 之精確退化預言與觀測唔相容 ⟹ 排出；條件 = **算子對載體盲**（`H_tree`／`V₀` 只作用徑向）。
3. **若日後 `MA1` 連接律令算子非載體盲** ⟹ 多重態可被劈開 ⟹ `60` 復活。此條件已明寫，唔怕日後翻案。
4. **`MA1` 殘餘收窄至單一項**：**接駁層 ↔ `d = 0` 之連接律形式**（載體、度數、位置、頻譜全部已定）。
5. **禁**：以觀測質量反解載體（`A6`）；以「細啲靚啲」代替重數論證。

## 七、★ append 更正（2026-11-19，`docs/16` 核後）

**`MD12` 撤回**：其推論鏈需要前提「`H` 係 `A₅`-等變」。該前提**被接駁結構否證**：
`d = 0` 係 `N_0 = 1` 之單一節點 ⟹ 揀定 `5`-orbit 之一點 ⟹ 只餘 `A₄`；若 `H` 真係 `A₅`-等變，
則 `d = 0` 唔會係特別點（與 M5 已閉合之 `V₀` 單點接觸項矛盾）。
機器核（`docs/16`）：`A₅`-交換子維數 `= 8`、`A₄`-交換子維數 `= 36`，且有非純量見證 ⟹ 重數**可被劈開**
⟹ **退化論證對 `{20,60}` 無判別力** ⟹ `60` 唔被排除（`MD12` → `withdrawn`）。

**`MD11` 不受影響**（Frobenius 誘導逐類相等，屬模塊層事實）。

**本檔 §四 判決 2／3 之措辭作廢**（原文保留不刪）：`60` 之排除**不成立**；`{20,60}` 之 `1 bit` **未解**。
