## 五、判決

1. **T2 🟡**：兩體選擇律 **✅ 由對極結構精確導出**（`a+b=44` ⟺ σ-閉合），零觀測輸入、零可調參數；
   但佢**強制全部簡併**（E = 4）⟹ 冇質量結構，與 T2 想解決嘅 Q2/Q3/Q8 無直接接駁。
2. **新 no-go（本輪最重要）**：**鏈譜對三體加法唔封閉（0/15180）**。⟹ 「譜閉合」唔可以係
   一般供給律；baryon 層必須由**其他算子**（非鏈譜加法）承載。
3. 呢個 no-go 同時解釋咗 M4 Q2/Q3/Q8 為何一直卡：佢哋要求「3 個 constituent → 谱上一個態」，
   而該映射**根本唔存在**。
4. 44 之「乾淨」性有結構理由（`γ₂₂ = μ²` 之唯一巧合落喺對極律內），但定律**形式**係 generic。
