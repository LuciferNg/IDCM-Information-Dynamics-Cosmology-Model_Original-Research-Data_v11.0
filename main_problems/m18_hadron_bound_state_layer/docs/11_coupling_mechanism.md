## 四、結果

**Y1 `A₅` 軌道大小（由子群階推）**
`{1, 5, 6, 10, 12, 15, 20, 30, 60}` ⟹ **44 / 34 / 68 / 88 / 176 全部 ∉ 此集**
⟹ **冇任何已註冊指標集可以『就係』一個 `A₅` orbit**（Y3 瞬殺）。

**Y2 ★ 晶體場分裂律（H1 結果）**

| `J` | 分解 | `n_lev` |
|--:|:--|--:|
| 0 | `A` | **1** |
| 1 | `T1` | **1** |
| 2 | `H` | **1** |
| 3 | `T2 ⊕ G` | 2 |
| 4 | `G ⊕ H` | 2 |
| 5 | `T1⊕T2⊕H` | 3 |
| 6 | `A⊕T1⊕G⊕H` | 4 |

| 8 | `T2⊕G⊕2H` | 4 |
| 9 | `T1⊕T2⊕2G⊕H` | 5 |

⟹ **`J ≤ 2` 完全唔分裂（單 irrep、`2J+1` 退化完整保留）；`J ≥ 3` 起一律 ≥ 2 層。**
`Σ n_R·dim R = 2J+1` 對 `J=0..9` **10/10 閉合**。

**Y4 耦合非典範（H2 結果）**

| `N` | ∉ 軌道大小集？ | 分解候選 `M(N)` | bit |
|--:|:-:|--:|--:|
| 34 | ✓（∉）| 99 | ≥ 6.6 |
| **44** | ✓（∉）| **249** | **≥ 7.96** |
| 68 | ✓ | 1483 | ≥ 10.5 |
| 88 | ✓ | 4824 | ≥ 12.2 |
| 176 | ✓ | 189502 | ≥ 17.5 |

**嚴格下界（唔靠 DP）**：`44 = 30+12+1+1` 與 `44 = 20+12+12` 兩個明確不同分解皆成立
⟹ 耦合選擇 **≥ 1 bit**；以候選數計 ≥ 7.96 bits。

⟹ **`A₅` 作用於鏈／樹指標集非典範**：揀邊個 orbit 分解 = 後驗自由選擇 ⟹ **每強子 irrep 指派
唔可能零參數**。

**Y5 弱對照（H1 側可證偽）**

| `J^PC` | 成員 | 跨度 |
|:--|:--|--:|
| `1−−` | ρ(770)、ω(782)、φ(1020) | 31.5%（ρ↔ω 僅 **0.95%**）|
| `2++` | f₂(1270)、a₂(1320) | 3.4% |
| `0++` | f₀(980)、a₀(980) | 1.0% |

⟹ 同類內**冇** ~O(10² MeV) 之系統性幾何分裂 ⟹ 與「`J ≤ 2` 單 irrep、唔分裂」一致（弱證據：
跨度主要由 flavour 造成，`0−+` 之 π/K/η 達 292% 即為 flavour 差，非幾何）。

## 五、判決

1. **H1 ✅ 分裂律升為結構結果**：`J≤2` 唔分裂、`J≥3` 起 ≥2 層（`n_lev` 序 `1,1,1,2,2,3,4,4,4,5`）。
   呢個係**可證偽**預言：若 `J=1` 有幾何分裂，應見同 `J^PC` 內 ~O(10² MeV) 雙層，實測無。
2. **H2 🔴 指派 no-go**：`A₅` 作用非典範（`M(44) = 249` 候選、嚴格 ≥1 bit）⟹ 每強子 irrep 指派
   **結構上有自由選擇** ⟹ 唔可以零參數。此 no-go 同時封 **MA1（指派部分）＋ MA2（映射）**。
3. **唔可以「加一個映射」救**：任何 `(n,k) → irrep` 之映射，若 `A₅` 未典範作用於 `I₄₄`，
   則映射要麼（i）由 `n,k` 算術決定（= 後驗湊），要麼（ii）需先揀一個 orbit 分解（≥1 bit）。
   兩者皆違零參數鐵律。
4. **正面殘留**：H1 之分裂律已可用（`MD7`）；H2 之 no-go 需一個**新嵌入層**
   （例如把樹節點映到 `A₅` 節點集之帶重數嵌入），屬「質性新載體」家族（與 M12 殘餘同類）。
5. **記賬更新**（`docs/10`）：
   - `MD7` 新定理：晶體場分裂層數序；
   - `MC9` 新禁區：`A₅` 作用於 `I₄₄/I₃₃` 作零參數耦合（非典範）；
   - `MA1` 收窄為「**新嵌入層**」；`MA2` 併入 `MA1`（同一阻塞）。
