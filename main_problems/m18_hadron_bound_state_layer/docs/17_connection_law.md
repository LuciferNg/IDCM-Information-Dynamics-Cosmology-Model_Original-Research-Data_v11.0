> 狀態：**`MD14`（已導）**：連接律 = 徑向樹上之**誘導束** `fiber_d = Ind_{H_d}^{A₅}(triv)`，

> ⟹ 新預言 `P1`：`J = 1, 2` 於 `d = 0` 振幅 = 0

## 一、前設問題

```text
docs/16 留兩項殘：(a) 載體 {20,60}（1 bit）；(b) 接駁層 ↔ d=0 連接律。
本輪主張：寫出 (b) 之後 (a) 自動解消 —— 因為「單一載體」本身係錯嘅問題設定。
```

## 二、事前判準（寫死）

| # | 判準 |
|:-:|:--|
| E1 | 穩定子逐層實核，並核層大小與 `|A₄|/|H_d|` 一致 |
| E2 | 誘導模塊以置換特徵實算，核 `Σ mult·dim = |fiber|` |
| E3 | 「完整承载 `J`」判準：`J` 之**全部** irrep 成分 ⊆ 該深度 irrep 集 |

| E5 | 可證偽：`J = 1, 2` 於 `d = 0` 之振幅 = 0 |

## 三、結果（全部機器核）

**E1 穩定子塔（沿徑向深度）**

| 深度 | 穩定子 `H_d` | 階 | `|A₄|/|H_d|` | 樹層大小 |
|:--|:--|--:|--:|--:|
| `d = 0` | `A₄` | 12 | 1 | 1 |
| `d = 1` | `C₃` | 3 | 4 | 4 |
| `d = 2` | `1` | 1 | 12 | 12 |
| `d ≥ 3` | `1` | 1 | — | 36, 108, … |

前三層 `1, 4, 12` 與 `|A₄|/|H_d|` **逐層一致**；`d = 3` 起 `×3` 續（`36 ≠ 60`）⟹ **塔結構停於 `d = 2`**，
之後穩定子恆為 `1`（無新群結構）⟹ 纖維恆為 regular。

**E2 ★ 誘導束纖維**

| 深度 | `|fiber|` | 分解 | irrep |
|:--|--:|:--|:--|
| `d = 0` | **5** | `A ⊕ G` | `{A, G}` |
| `d = 1` | **20** | `A ⊕ T1 ⊕ T2 ⊕ 2G ⊕ H` | 全部五 |
| `d = 2` | **60** | regular（`A ⊕ 3T1 ⊕ 3T2 ⊕ 4G ⊕ 5H`）| 全部五 |
| `d ≥ 3` | 60·多重 | regular 之倍 | 全部五 |

`Σ mult·dim = |fiber|` 全閉合（4/4）。

**E3 每深度可「完整」承载之 `J`**（`SO(3)↓I` 表維數自核 9/9：`Σ dim = 2J+1`）

| 深度 | 可完整承载 |
|:--|:--|
| `d = 0` | **只有 `J = 0`** |
| `d ≥ 1` | `J = 0 … 8` 全部 |

**E4 判詞：`1 bit` 解消**
```
舊設定：「載體 = 20 定 60」（假設單一纖維）
實際：state = 徑向樹上之截面，fiber_d = Ind_{H_d}^{A₅}(triv) ⟹ 束（5, 20, 60, …）
```
⟹ `20` **唔係「被選中嘅唯一載體」**，而係 **`J`-content 首現之纖維（`d = 1`）**；
`60` **唔係「被排除之候選」**，而係 `d ≥ 2` 之纖維。**兩者同時存在於束中** —— 故 `{20,60}` 之爭係 ill-posed。

**E5 可證偽預言（登記）**

```
P1  J = 1, 2 之徑向波函數於根節點振幅 = 0（d=0 纖維只有 A⊕G）
P2  J = 0 係唯一可完全局域於 d = 0 之態
P3  J ≥ 3 之 G 成分可見於 d = 0；T1／T2 成分必須 d ≥ 1
```

## 四、判決

1. **`MD14`**：連接律 = **誘導束**；纖維 `(5,20,60,…)` 由穩定子塔強制，**零自由參數**。
2. **`{20,60}` 之 `1 bit` 解消**（`E4`）：唔係靠新證據推翻，而係指出**原問題假設錯**（單一纖維）。
3. **`MA1` 形式層至此閉合**：分裂律（`MD7`）＋兩層分離（`MD10`）＋載體誘導（`MD11`）＋穩定子塔（`MD9`）＋誘導束（`MD14`）。
4. **剩項收窄為「動力學」**：`H` 喺束上如何作用（即 `fiber_d` 之間之耦合強度）—— 屬 M5 振子模型範圍，
   本 M 唔重推 M5，按紀律 **handoff M5**（同版本 `v11.0`，合法）。
5. **一個明確假設（必須掛牌）**：每個樹節點皆携帶同一接駁結構（等變束定義）。若唔係，
   `A₅` 就唔會係樹上之等變作用 —— 故呢個假設同 `MD10` 之「接駁層存在」等價，唔係額外自由度。
6. **`P1` 係 Hilbert 空間層事實**（唔係動力學）：`A₅` 模塊喺 `d = 0` 缺 `T1`／`H` ⟹ `J = 1, 2` 無 `d = 0` 分量。
