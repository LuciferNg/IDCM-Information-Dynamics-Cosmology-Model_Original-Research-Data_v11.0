## 五、三項判定

**（1）`MD10` 兩角色分離（已導，PASS）**
`5`-orbit `= A ⊕ G` ⟹ **缺 `T1`（J=1）與 `H`（J=2）** ⟹ 樹接駁層**唔可能**承载 `J` 譜。
⟹ `docs/13` 之「根上層 degree 5」與本檔之「`J` 載體」係**兩件唔同物件**，唔可以合併。
呢個唔係措辭問題：`5` 之分解係算出來嘅，缺 `T1`／`H` 係硬事實。

**（2）`J` 譜完整性只能收窄到 3 個（誠實 negative，`Z3b/Z3c`）**
含全部五 irrep 者 = `{20, 30, 60}` ⟹ **唔唯一** ⟹ 唔可以宣稱「由 `J` 譜逼出」。8 → 3。

再與等變塔層 `{1,5,20,60}` 求交 ⟹ **`{20, 60}`**（`30` 唔係塔層 ⟹ 出局）。
剩 `20 = [A₅:C₃]`（二十面體面）vs `60 = |A₅| = B(B²−1)`（regular）。

> 若採「**塔終端（穩定子平凡）**」原則 ⟹ 取 `60`。此係**原則**（最大細化、無剩餘穩定子），
> **非推導** —— 本檔明標，唔升格為定理。

**（3）`12` vs `12` 得結構理由（`Z6`，加強 `docs/13` X6）**
`12`-orbit `= A ⊕ T1 ⊕ T2 ⊕ H` ⟹ **含 `G` ？否** ⟹ 只可承載 `J ≤ 2`。
故 `MD6` 之「容量 12」（`3` irrep × `P` × `C`）係**標籤數**，**唔係載體點數**；
且若載體 = `12`-orbit，則觀測 `J = 3, 4` 無處安放 ⟹ `12` 唔可能係唯一載體（`Z6c` 誠實 negative）。

**（4）副產品（可證偽）**
`12`-orbit 恰 = `{A, T1, T2, H}` = 「`J ≤ 2` 頻譜 ＋ 多餘一個 `T2`」⟹ 若低 `J` 扇區用單一 `12`-orbit，
則 **`J ≤ 2` 之低窪態全部落同一載體**，而 `J ≥ 3` 必須另置 —— 呢個係可測分裂圖樣。

## 六、判決

1. **`MD10` 成立**：接駁層（`5`-orbit）≠ `J` 載體 ⟹ `MA1` 結構**兩層**，唔係一層。
2. **`MA1` 收窄紀錄**：`docs/12` degree ≥ 5 → `docs/13` 根上層 degree 5 → **本檔 載體 ∈ {20, 60}（1 bit）**。
3. **唔可以宣稱「逼出」**（`Z3b`）：`J` 譜完整性只給 3 個，唔唯一。
4. **終端原則**可取 `60`，但必須寫明係原則；若日後有人用 `20`，須另立結構理由（`20 = [A₅:C₃]`）。
5. **禁區新增理解**：`12_JPC`（容量）**≠** `12`-orbit（載體）—— 因為後者缺 `G`。
