1. **動力學層自由度已量化**：`11／100／300`（`A₄`）；最好情況（`A₅`）`3／20／60`。
2. **零參數動力學結構上不可能** —— 唔係「未推」，而係**自由度本身多於 1**。
   ⟹ `MA1` 之殘項正式由「未定」升級為「**已量化**，且證明唔可以由束結構唯一決定」。

   **選擇原則**（而原則唔屬 M18 可推範圍）⟹ 已隨 handoff 附上維數表。
