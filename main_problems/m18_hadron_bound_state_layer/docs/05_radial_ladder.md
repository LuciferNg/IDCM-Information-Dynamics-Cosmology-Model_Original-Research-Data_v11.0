## 四、結果

| 項 | 結果 |

## 五、判決

1. **T4 🔴**：階梯**唔係** `γ_n` 子序列（唯一交集 = `μ²`）；且**需新標度**（缺口 12424×–57649×）。
2. **替代結構（可入帳，但唔閉合）**：
   - 徑向塔之**自然形式** = 樹譜 `λ_k`（16 對 + 自對點），零參數、容量 16；
   - 但**標度 `t*` 身份未定**（要求 `t*` ≈ 10²–10⁴ MeV），M5 之 `t = 0.79 MeV` 唔係塔標度。
3. **★ 對 M5 之診斷（新，重要）**：M5 用 `t` 校準 contact 通道；本輪證 `t` **唔可能**同時係徑向塔標度
   （差 ≥ 4 個數量級）⟹ M5 模型內 `t` 之雙重角色（hop ＋ 徑向塔）**唔成立**，
   即 M5 之徑向自由度**未正確接入**。
4. Cayley 算子只得 0–2 束縛態 ⟹ 亦唔係塔載體 ⟹ **兩個已註冊樹算子皆唔係徑向塔**。
5. 新禁區：唔准用 `λ_k` 直接配觀測徑向間距（形狀相反 + 標度缺 10⁴×）。
