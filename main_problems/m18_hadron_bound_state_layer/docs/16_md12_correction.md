## 一、本輪目的

`MD12` 之推論鏈：

## 三、結果（全部精確）

**C1/C2 交換子維數（置換模塊定理：不變矩陣 = `X×X` 軌道矩陣）**

| 作用群 | 同一 `20` 點集 | 交換子維數 | 交叉核 |
|:--|:--|--:|:--|
| `A₅` | `A₅/C₃` | **8** | `= Σ mult² = 1+1+1+4+1 = 8` ✓ |
| `A₄` | 同上 | **36** | `36 > 8` ⟹ 允許更多混合 ✓ |

**C3 顯式見證**
`G`-等型分量維數 `= rank(P_G) = 8 = 2 份 × dim G`（重數 2 ✓）；
喺該 `8` 維上，`A₄`-等變算子維數 `= 8`（`A₅`-等變只有 `4 = 2²`）⟹ 多出 `4` 維混合方向，
且實取到**非純量見證算子**（rank 8）⟹ 兩份 `G` 可被劈開 ✓。

**C4 ★ 自我更正**
```
d = 0 係 N_0 = 1 之單一節點 ⟹ 揀定 5-orbit 之一點 ⟹ 只餘穩定子 A₄
若 H 係 A₅-等變 ⟹ 5 點全等價 ⟹ d = 0 唔會被區分
但 M5 之 V₀ 係 d = 0 單點接觸項（已閉合）⟹ 矛盾
⟹ P 唔成立 ⟹ MD12 之退化論證失效 ⟹ 60 唔被排除
```
`MD11`（Frobenius 誘導）**不受影響** —— 佢係模塊層事實，與 `H` 之等變性無關 ✓。

**C5 替代判別（較弱）**

## 四、判決

1. **`MD12` 撤回**（前設被否）。原文保留於 `docs/15`，本檔為 `append-only` 更正。
2. **`MD13`（新，已導）**：`A₅`-交換子維數 `8` ≪ `A₄`-交換子維數 `36`，且有非純量見證 ⟹
   **接駁破 `A₅ → A₄` 後，載體重數可被劈開** ⟹ 任何「靠精確退化排除載體」之論證**結構上無效**。
3. **`{20, 60}` 之 `1 bit` 未解**（誠實報殘）。群論層兩者皆合法：
   `20 = Ind_{A₄}^{A₅}(4點) = F₅·B`（誘導，`MD11`）；`60 = Ind_{1}^{A₅} = F₅·B·N_gen`（regular）。
4. **可用嘅弱判別**：態數經濟性（`6` vs `16` 多重態／帶）⟹ 🟡 傾向 `20`，並列為可證偽計數預言。
5. **紀律**：唔可以因為「`20` 較靚」而升格為定理；必須維持 `1 bit` 記錄，交下一輪或治理層。
