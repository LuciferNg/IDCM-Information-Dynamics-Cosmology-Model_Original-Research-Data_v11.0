## 二、問題陳述

M12 之全部算術收斂到一個**單一觀測事實**（`docs/37`）：

```
v_u, v_d 為同一核於 u／d 兩站之讀出向量；cos(v_u,v_d) = −0.8000000
目標：  ρ_d = ⟨w,v_d⟩/⟨w,v_s⟩ = +0.40350365 ± 0.03510
        ρ_u = ⟨w,v_u⟩/⟨w,v_s⟩ = −0.02588837 ± 0.03292   （|ρ_u|/ρ_d = 0.064158949）
        ∠(w*, v_u) = 90.848631°   ⟹ w 幾乎與 v_u **正交**，卻與 v_d 高度相關
```

**Q1（主問題）**：是否存在一個**零參數**算子 `Ŵ`（或帶味耦合 `C(f,g)`），使得上兩式同時成立、且：

- (a) **非 Kronecker-可分解**（否則因子於比值相消 —— M12 `docs/31` 已證相消 ≤ 2e−31）；
- (b) **非二部**且帶離散 `±1` 阻挫（否則 `δ ≡ 0` 或退為相位）；
- (c) **本質非 ℤ₂-odd**（`docs/38` 定理：任何 ℤ₂-odd ⟹ `ρ_u = −ρ_d` 精確 ⟹ 與觀測差 15.5863 倍）；
- (d) **dof = 0**（無連續參數）；
- (e) 全部標度可追溯至已註冊常數（`K_chain γ_n`、`K_tree`、`N_d = 88`、`Σγ = 90`、`M₀`、A₅、`h11 = 36`／`h21 = 98`）。

**Q2（可裁決性）**：在現行量測精度下，**任何**結構候選是否可被裁決？M12 `docs/38 §E` 給出否定性計算：`σ_ρd ÷ 格距 = 0.03510 ÷ 0.0243902439 = 1.4391 > 1`，半格 `0.012195122 < σ` ⟹ 任何有理目標必落某格點 1σ 內 ⟹ 零資訊。**本 M 必須先答「要多少精度才可裁決」，否則一切命中皆不可判。**

**Q3（物件存在性）**：v11 存貨內**無**此物件（M12 `docs/24 §G2`：S5 無可算載體；`docs/28` 判死可分離族）。則本 M 之第一步不是掃描，而是**證明或否證該物件可由既有結構生成**（若不可 ⟹ 本 M 即判 scoped no-go，不得造物件）。

## 六、禁區（八條，硬性）

1. **不得重推 M12 五類 no-go**（§4.1 表，逐類附依據）。
2. **不得用 ℤ₂-odd 結構**（`docs/38` 定理 ⟹ `ρ_u = −ρ_d`）。
3. **禁三類恆真**：φ-power 擬合｜連分數收斂子｜0.5% 精度下之簡單有理數（唯一例外 = 事前指定之代數式或範疇性預言）。
4. **禁看到目標凑算子**：`ρ_d = +0.40350365` 只可在算子**寫死之後**作比較；反解指數／扇區／權重 = 擬合。
5. **禁連續參數**（dof 必須 0；若必含則 T2 判死）。
6. **禁無界掃描**：任何掃描須先證候選集**有限且完備**，並在腳本 docstring 寫死 `N_trials` 並全報（不得只報命中者）。
7. **禁跨版本推送**：`handoff --target-pid` 只可指向 v11 pid；`--force-cross-version` 一律不用。
8. **禁在本 M 宣稱 M12 閉合**（判定權在 M12；本 M 只可 `handoff --target-pid M12`）。
