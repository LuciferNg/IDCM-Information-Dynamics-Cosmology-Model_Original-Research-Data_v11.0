### 3.2 對 ① 幾何級數：恆等成立，但 **B-blind** ⟹ 0 bit

```
部分和 k=0..11 = 5592405/4194304 ✓（M15 值正確）
餘項           = 1/12582912 ✓
閉式           = 4/3
```

**問題**：`Σ_{k≥0} B^{−k} = B/(B−1)` 對**任何** `B` 皆成立
（`B=2→2`、`3→3/2`、`4→4/3`、`5→5/4`、`6→6/5`）。即：
它係「幾何級數之閉式」之恆等式，**唔會**告訴你為何係 `B=4`。

**關鍵 1**：`α_s/(α_u+α_d)` 與迹係**同一條量**（恆等，差 = 0.0）：

```
由 ρ_u = x − y/2、ρ_d = y − x/2（x=α_u/α_s, y=α_d/α_s）精確反解
x = 0.234484609246、y = 0.520745954258（回代差 ≤ 6e−42）
α_s/(α_u+α_d) = 1/(x+y) = 1.32409895511
1/(2·trace)             = 1.32409895511      差 = 0.0
σ = 0.040959349（由 σ(trace) 傳播）
```

⟹ **唔存在「α 通道 vs 迹通道」兩個獨立通道**；兩者係同一觀測量之兩種寫法。

**關鍵 2**：同一數據、不同族，鑑別力差很遠：

```
family A：α_s/(α_u+α_d) vs B/(B−1)（≡ trace vs (B−1)/(2B)）
  B=3 → 1.5       z = −4.295
  B=4 → 1.333333  z = −0.225   ← 最接近
  B=5 → 1.25      z = +1.809   ← 未達 3σ
  B=6 → 1.2       z = +3.030
```

⟹ ①（幾何級數）作為**恆等式**對 `B` 無資訊（∀B 皆成立）；而 `B/(B−1)` 呢個**弱族**只偏好 `B=4`（−0.23σ），
**不能排除 `B=5`**（+1.81σ）。故 ① 最多係「若權重律為 `B^{−k}`，則係數 = 4/3」之條件句，非 `B=4` 之證據。

### 3.3 對 ② `N_d/K_tree = 44/33`：與 ① **代數恆等**

```
44/33 = 4/3 ✓
但 33 = N_d·(B−1)/B = 44·3/4
(44/33) ÷ (B/(B−1)) = 1  ⟹ 同一條 1/(1−1/B)
```

⟹ ② **唔係**第二條獨立來源，除非 `K_tree = 33` 有**獨立於 `N_d(1−1/B)`** 之登錄（樹層模數直數）。

**另**：`B^{−ℓ}` 樹層權重核已被本 M `docs/06` 判死（`α=(1,1/4,1/16)` ⟹ `ρ_u=+14`、`ρ_d=−4`，z=417.6／−98.3）。
若 ① 之 `B^{−k}` 與該核同源，則 ① 亦不可用；若屬不同對象（全樹層權重和 vs 味權重），須明文界定。
