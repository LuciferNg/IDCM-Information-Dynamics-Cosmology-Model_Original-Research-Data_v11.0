## 一、標籤語義（出處：M4 `docs/32 §一`）

| 標籤 | 語義 | 取值 |
|:--|:--|:--|
| `k` | **扇區**（v9 `03_extended_derivation.md §D.1`：k=1→Up、k=4→Down、k=5→Lepton） | `{1,4,5}` |
| `d` | **Z₂ grading = 世代**（`paper/17` L217–231：三代） | `{3,2,0}` |

⟹ 三個讀出落喺 3×3 標籤網格：

```
u = (k=1, d=3)     上型・第一代
d = (k=4, d=3)     下型・第一代   ← 與 u **同代**（d 相同）
s = (k=4, d=2)     下型・第二代   ← 與 d **同扇區**（k 相同）
```

**呢兩個「同」就係定理之全部燃料。**

## 二、定理（三個 case，精確；`docs/09` 之 216 枚舉降為系論）

### A. α 只依 `k`
`u` 獨佔 `k=1`，`d`、`s` 同 `k=4` ⟹ **`α_d ≡ α_s`**（任何 `g: {1,4,5}→ℝ` 皆然）。

```
ρ_u = 0 ⟹ g₁ = g₄/2        （唯一解，與標度無關）
⟹ ρ_d = 1 − g₁/(2g₄) = 3/4  **強制**
⟹ 對比觀測：z = +7.74σ      🔴 排除
```

### B. α 只依 `d`
`u`、`d` 同 `d=3` ⟹ **`α_u ≡ α_d`**。

```
ρ_u = f₃/(2f₂)  ⟹ ρ_u = 0 ⟺ f₃ = 0 ⟹ α_u = α_d = 0
⟹ ρ_d = 0        **強制**
⟹ 對比觀測：z = −9.01σ      🔴 排除
（若 f₃ ≠ 0 ⟹ ρ_u > 0 > 觀測，直接違反 ρ_u = 0 —— 兩難，無解）
```

### C. α = `h(k,d)` 一般函數
`h` 於 9 格任取；三讀出佔 `(1,3)`、`(4,3)`、`(4,2)` **三格，彼此無函數關係**
⟹ 三格之值自由 ⟹ α 之 projective 維度 `= 3 − 1 = 2` ⟹ **`dof = 2`** ⟹ 違反 T2。

### ⟹ 定理（T1-α）
> **標籤網格 `(k,d)` 之**任何**函數（`g`、`f`、`h` 皆任意）都不可能產生 `(ρ_u, ρ_d) = (0, 3/8)`。**
> 單標籤 ⟹ 值被強制至 `3/4` 或 `0`（7.74σ／9.01σ 排除）；雙標籤 ⟹ `dof = 2`（違 T2）。

**範圍標籤（依 M12 `docs/28` 閘 3）**：`{k,d}` 標籤網格之**全函數族**（非「6 條規則」）。
`docs/07` 之 `0/216` 現為本定理之**系論**（該 6 條規則皆屬 case A／B）。

## 三、候選 `α = (1,2,4)` 之定位

`(1,2,4) = 2^r`，`r = 讀出**次序**（0,1,2）` ⟹ 係**序數規則**，唔係標籤函數。
而 `docs/05` 站無關性定理：換站／換次序**不影響 `ρ`** ⟹ 序數係 **gauge**。
⟹ 候選之 `α` **無標籤層出處**；T1① 之 FAIL 係**結構性**，不是「未搜夠」。

## 四、★ 但同時收緊了：`ρ_d = 3/8` 係**預言**，唔係擬合

族 `α = (1, x, x²)`（幾何性：`α_ℓ ∝ x^ℓ`）：

```
ρ_u(x) = (2 − x)/(2x²)   ⟹  ρ_u = 0 ⟺ **x = 2 精確**（族內唯一根）
⟹ α = (1,2,4) 唯一 ⟹ ρ_d = (2·2−1)/(2·4) = 3/8
```

⟹ **幾何性 + `ρ_u = 0` ⟹ 零自由度 ⟹ `ρ_d = 3/8` 係推出來，唔係揀出來。**
⟹ look-elsewhere 只關於「**族之選取**」（幾何族 vs 其他族），**唔**關於 `x`（`x` 已被 `ρ_u = 0` 釘死）。
（此點修正 `docs/04 §四` 之表述：`α_s` 之整數格掃描並非唯一讀法；族內 `ρ_u = 0` 已封死 `x`。）

## 五、密度：為何「換個表達式再搜」無資訊

- 若不假設幾何性：`ρ_d ∈ 1σ` 窗 `[0.358718, 0.448289]` 對應 `x ∈ [0.653, 0.757] ∪ [1.474, 2.135]`；
- 分母 ≤ 20 之簡單有理中，**162 個** `x` 令 `ρ_d` 落 1σ 窗。
⟹ `ρ_d` 條件**單獨幾乎零約束力**；全部判別力來自 `ρ_u = 0`（族內唯一）。
⟹ 任何「掃描命中」若不附 `ρ_u = 0`，皆屬零資訊。

## 六、T1 之真缺口收斂為**一個**問題

```
幾何性成立 ⟹ 一切已定（x=2, ρ_d=3/8）
∴ T1 之全部內容 = 「α_ℓ 為何是幾何級數？」
```

幾何級數之**自然出處** = 分枝計數：`α_ℓ = B^ℓ`（`ℓ` = 世代層）。
但已註冊 `B = 4` ⟹ `α = (1,4,16)` ⟹ `ρ_d = 7/32` ⟹ **4.15σ 死**（`docs/09 §四`）。
而要得 `(1,2,4)` 須底數 `2 = √B`（因 `B = 4 = 2²`）。

> **★ 殘餘問題（單一、可裁）**：世代權重之比 = `2`，而已註冊分枝 = `4`。為何權重取 `√B` 而非 `B`？
> 三種同值讀法（`√B`／`log₂B`／`|ℤ₂|`）在 `B = 2²` 下會塌縮為**同一條恆等式** `B = |ℤ₂|²` —— 但該恆等式**v11 未註冊**（`B` 之現有出處只有「分枝數」與 `γ_max = B`）。
