## 三、R1 —「4」之結構歸約（唯一有內容之殘餘）

### 3.1 兩步精確推導（無新輸入）

```
ρ_u = (2α_u − α_d)/(2α_s) = 0   ⟺   α_d = 2α_u        （A₂ Cartan 零方向，精確）
ρ_d = 3/(2·(α_s/α_u))           ⟹   ρ_d = 3/8 ⟺ α_s/α_u = 4
```

**且**：`(ρ_u, ρ_d)` 係 2 個約束、`α` 之投影自由度亦為 2 ⟹ **α 被數據完全決定**，無殘餘自由度：

```
α ∝ (1, 2, 4) = (2⁰, 2¹, 2²)
```

### 3.2 缺口由「4」縮為「每代 ×2」

```
4 = 2² = B            且   √B = 2 = 每代因子
2 = MERA 分支度（每個節點之子節點數；B = 2²）
```

⟹ 結構陳述可寫成：**每降一代，譜權重乘 `2 = √B`（分支度），兩代合計乘 `B`。**

### 3.3 單項式族窮舉（在已註冊不變量內）

對 `{B=4, 2(=√B), N_gen=3, N_d=44, γ44=4, rank(A₂)=2, log2B=2, B−1=3, N_d+1=45}` 掃
