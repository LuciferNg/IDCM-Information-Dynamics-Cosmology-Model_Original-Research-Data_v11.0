## 三、★★ 判定（本 M 第一條方法論結論）

```
E[hits] = N_class × P̂ ≫ 1   ⟹   該類之任何一個命中皆零資訊
```

- `K = 5`：雙 `1σ` 命中之**預期數 = 10,773**（不是「奇蹟」，而是**必然**）。
- 即使收窄至 `ε = 0.25σ`，`K = 5` 仍預期 **695** 個命中。
- `frac(|z_d| < 1σ) ≈ 1.6–2.2%` **對所有 `K` 近乎不變** ⟹ 密度不隨 `K` 增大而降。

**⟹ 任何 `N_class ≳ 60` 之離散類，於現行 `σ` 下皆不可正面裁決。**
M12 `R28 P4` 之 `1182 個 z<1` 並非異常，而係此定律之 `K=4` 實例（本輪獨立重現其量級）。

**⟹ 因此 `dof = 0` 之正確含義不是「無連續參數」，而是 `N_class = 1`** ——
即：**該核必須被結構唯一決定**，不容任何離散選擇（模式集、符號、扇區、指數）。否則 look-elsewhere 自動吞掉全部資訊。

**⟹ 候選類 A（`K ≥ 5` 枚舉）不應作為正面證據路線**（可作排除／null 用途，但成本 34.75M × 全枚舉換一個必然零資訊之結果，不划算）。

## 四、★ 由此重定 M13 之主問題（任務書改寫）

原 Q1 問「是否存在零參數算子使 `ρ_d`、`ρ_u` 同時成立」。由 §三，此問法**結構上不可裁決**（任何離散類皆可凑）。
正確問法必須是**唯一性**問題：

> **Q1′**：是否存在一個**結構原理**（變分／極值／對稱），其**唯一**產物 `w` 滿足 `ρ_d = 0.4035`？
> 若原理存在，`N_class = 1`，則問題可裁決；若不存在，本 M 寫 scoped no-go。

而 `ρ_u` 之地位須重新審視（M12 `docs/37 §〇` 已指出）：

```
ρ_u = −0.02588837，σ_ρu = 0.0335839（正典 R27）
⟹ 距 0 = 0.77σ   ⟹ 「負號」現象本身未達 3σ
```

⟹ **可裁決之最強形式 = 精確零預言**：若結構強制 `⟨w, v_u⟩ = 0`，則 `ρ_u ≡ 0` 精確（非 0.77σ 之拟合），
　　此乃**單點預言**（`N_class = 1`，無 look-elsewhere），且與現數據相容（0.77σ）。

**幾何等價式（本輪新增，結構形式）**：

```
δ_u = G(2,3) − G(2,2)，  δ_d = G(3,3) − G(2,3)，  δ_s = G(4,3) − G(4,2)
（G(i,j) = Σ_n w_n φ_n(i)φ_n(j)；k_u=2, k_d=3, k_s=4）

ρ_u ≈ 0  ⟺  G(2,2) ≈ G(2,3)  ⟺  **站 2 係 G(2,·) 之駐點（局部極大者給 δ_u < 0）**
```

⟹ 需要之結構性質 = 「**站 2 落於 Green 函數之極值／對稱點**」，且 `2→3` 之落差
為 `3→4` 落差之 `|ρ_u|/ρ_d = 0.0642` 倍、`ρ_d = 0.4035` 由同一落差給出。
此即 M12 `S2` 存活條件「非平移不變 ＋ 短程差分比 `2.4783`（需有『崖』）」之幾何重寫。

**對照（已判死之平移不變情形）**：若 `G(i,j) = g(|i−j|)`，則 `δ_u = g(1)−g(0)`、`δ_d = g(0)−g(1) = −δ_u`
⟹ `|ρ_u| = ρ_d`，偏 **15.5863 倍**（M12 `R24 A2`／`docs/38` 定理之同一障礙）。
