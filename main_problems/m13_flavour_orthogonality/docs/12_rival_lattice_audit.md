## 〇、為何要審

`docs/04 §四` 之 look-elsewhere 只掃 `α_s/α_u ∈ {1,…,8}`（**整數**）⟹ 得 `1/8 = 12.5%`。
但 `ρ_u = 0` 只固定 `α_d = 2α_u`；**`α_s/α_u` 之分母從未論證**。
⟹ 若分母唔係 1，`1/8` 無效。本文件按**格粒度**重審。

## 一、`ρ_u = 0` 之地位（不受本次審計影響）

`α_d = 2α_u` 係 `A₂ Cartan` 首行之零方向，`2` 係 **Cartan 元素**，非參數 ⟹ `ρ_u = 0` 精確、零自由度。
⟹ `ρ_d = 3/(2r)`，`r ≡ α_s/α_u` 為**唯一**未知。**此結構結果不變**（本 M 最硬之一項）。

## 六、判

3. **「唯一雙通」之正確範圍 = 整數格 `{1,…,8}`**（`docs/09 §四` 之表述須限於此）。
4. 配合 `docs/11`（T1 標籤層已推死：`k`-only 7.74σ、`d`-only 9.01σ、`h(k,d)` `dof=2`）：
   候選**既無數據擇優、亦無 provenance** ⟹ 依 corpus 標準「講不出算子即標籤」⟹
