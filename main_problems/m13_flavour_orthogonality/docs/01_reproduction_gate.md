## 三、三項發現（皆為 append-only 記錄，不改上游）

### 3.1 ★ `docs/38 §E` 之 `σ_ρd = 0.03510` 已 SUPERSEDED

- `docs/38`（R25）報 `σ_ρd = 0.03510` ⟹ `σ/格距 = 1.4391`、`半格 < σ ⟹ 不可裁決`。
- `docs/42`（R27）報「未計 `δ_d`–`δ_s` 協方差 ⟹ 更正為 `0.04478518`」⟹ `1.8362`。
- 本 M **獨立**以 PDG 2024 誤差（`σ(Δ_Σ) = √(2.9²+2.4²)e−5 = 0.037643`、`σ(Δ_Ξ) = 0.211896`）傳播得
  `σ_ρd = 0.044785178`、`σ_ρu = 0.033583899` ⟹ **與 R27 逐位吻合（8 位）**。
- ⟹ **正典 = R27 之 `0.044785178`**；`SESSION_START` 之重現閘表沿用 `docs/38` 之舊值，屬**繼承之陳舊數**。
  依「數唔對即停」之精神，本 M **不**因此停工（重點值全部 PASS），而係以**更嚴**之 R27 值為準，並以 register note 回報 M12（不寫其檔案）。

### 3.2 ★ `w*` 之符號圖樣**依賴兩個 δ-盲模式**，非結構不變量

- `Δ_n = φ_n(3) − φ_n(2) = 0` ⟺ `n ∈ {9, 27}`（`n ≡ 9 mod 18`）—— 即 `docs/28` 之 δ-盲模式。
- 於此二座標，三個測試向量 `v_u, v_d, v_s` **全部為零** ⟹ `w_n` 完全不受約束；最小範數解置 `w_9 = w_27 = 0`（實測 `5.5e−41`／`9.4e−42`）。
- ⟹ `docs/37` 之「`w*` 符號：正 28、負 15」係**計數慣例**（把 0 歸入正或負）之產物；本 M 實得 **正 27 / 負 16 / 零 2**。
- ⟹ **不可引用「正 28/負 15」作結構陳述**；符號圖樣在 kernel 維度上本就非唯一（差 `n=9,27` 任兩值）。

### 3.3 微差來源（不影響任何判詞）

- `R3` 之 `|Δ| = 5.4e−9`：M12 於 docs/14 以 7 位有效數字記 `δ_u = −0.0887`；本 M 用 PDG 原值 `−0.088667660`。所報 `ρ_u`（8 位）本 M 吻合至 `2.1e−9`。
