## 〇、觀測端之精確式（新，可作正典）

```
ρ_d = 2Δ_Σ/Δ_Ξ − 1 ，   Δ_Σ = m(Σ⁻) − m(Σ⁰) ，   Δ_Ξ = m(Ξ⁻) − m(Ξ⁰)
```

PDG 2024（vendored 檔獨立解析）：

| 粒子 | `m` (MeV) | `σ` (MeV) |
|:--|--:|--:|
| `Σ⁻` | 1197.449 | 0.029 |
| `Σ⁰` | 1192.642 | 0.024 |
| `Ξ⁻` | 1321.71 | 0.07 |
| `Ξ⁰` | 1314.86 | **0.20** |

`Δ_Σ = 4.807 MeV`、`Δ_Ξ = 6.85 MeV` ⟹ `ρ_d = 2(4.807)/6.85 − 1 = 0.403503649635`
（與 M12 之 `0.40350365` 差 **3.65e−10** ⟹ 逆向工程正確）。

## 一、誤差預算（變異數分解）

```
敏感度：∂ρ/∂Δ_Σ = +0.2919708     ∂ρ/∂Δ_Ξ = −0.2048910
σ_ρd = 0.04478517819            （與 M12 R27 之 0.044785178 逐位吻合）

逐質量：   Ξ⁰ 83.72%   Ξ⁻ 10.26%   Σ⁻ 3.57%   Σ⁰ 2.45%
```

⟹ **單一限制項 = `m(Ξ⁰)`（佔 84%）**。`σ_ρd` 之改善等於「改善一個 25 年前之系統誤差」。

## 二、`m(Ξ⁰)` 之來歷（PDG 2024 原檔）

PDG 2024 之 `Ξ⁰` 質量**擬合值 `1314.86 ± 0.20`，只由一組輸入構成**：

```
FANTI 00（NA48, p Be 450 GeV, 3120 事件）：1314.82 ± 0.06(stat) ± 0.20(syst)
```

⟹ `σ = 0.20` **係系統誤差**（統計僅 0.06）。`m(Ξ⁻) − m(Ξ⁰) = 6.85 ± 0.21`（PDG OUR FIT）。
⟹ 任何現代高統計測量（BESIII `Ξ⁰Ξ̄⁰`：`Ξ⁰ → π⁰Λ`、`10⁷` 級事件；或 J-PARC）**極可能**把 `σ` 壓到 0.05–0.10。

**文獻核查（2026-10-30，外部渠道）**：PDG 2024 listing 仍以此單一輸入為唯一來源（`FANTI 00` = NA48, `Eur.Phys.J. C12 (2000) 69`）。
BESIII 2024–2025 之 Ξ⁰ 工作集中於衰變／分支比（`Ξ⁰→Λγ`、`Ξ⁰→γΣ⁰`、`Ξ⁰Ξ̄⁰` 截面），**未見新嘅 Ξ⁰ 質量測量**。
⟹ 3σ 檢定（`σ(Ξ⁰) ≤ 0.183`）**目前無現成數據可用**，須待專用測量（BESIII `10¹⁰ J/ψ` 級數據 + 雙標記，或 J-PARC）。

**硬底（新結果）**：即使 `σ(Δ_Ξ) → 0`，仍有 `σ_ρd ≥ 0.01099`（純由 `σ(Δ_Σ) = 0.0376` 而來）。

```
⟹ 任何 < 0.9% 級之 ρ_d 分辨（4 vs 2/5、4 vs 134/36、4 vs √2−1）
   在「只改善 Ξ」之情況下**結構上不可能** —— 必須連 Σ 質量一併改善。
```

## 四、判：乙 之結論 = **該測的是整數問題，不是細分辨問題**

```
現況：α=4 (ρ_d=3/8) vs α=3 (ρ_d=1/2) 分離 = 2.79σ   ← 已近 3σ
      且窗內唯一整數 = 4 (docs/06)
⟹ 可裁決命題：「若 α_s/α_u ∈ ℤ，則必為 4」。現 2.79σ；σ(Ξ⁰) ≤ 0.183 即 3σ；≤ 0.084 即 5σ。
```

- **不應**追求 `4` vs `2/5` 級之細分辨（Σ 質量硬底，5.4× 且與 Ξ 無關）。
- **應**追求 `m(Ξ⁰)` 之單一改進：現值受一組 2000 年系統誤差支配，改善空間大且代價低。

## 五、為何「細分辨」整條路線應放棄（並記錄為禁區候選）

```

⟹ 唯一有意義之判準仍是：α 之**代數來歷**（docs/07：已雙重封閉）或整數性（本檔：可測）。
```

### 7.2 BESIII：**冇 Ξ⁰ 質量論文**，但**數據已經喺手**

近三年 BESIII 之 Ξ 工作全部集中於 CP／極化／衰變參數／截面（`arXiv:2312.17486`、`arXiv:2509.06304`）：

| 分析 | 數據量 | 產出 |
|:--|:--|:--|

| `J/ψ → Ξ⁻Ξ̄⁺` | `1.3×10⁹ J/ψ` | `α_Ξ⁻`、CP 觀測量 |
| `Ξ⁰ n → Ξ⁻ p` | 同上 Ξ⁰ 束 | 首次強作用散射截面 |

⟹ 佢哋**已經重建 `Ξ⁰ → Λπ⁰`**（`Λ→pπ⁻`、`π⁰→γγ`），即測質量所需之最終態完全就緒；
   只係**冇做質量擬合**（物理目標唔在此）。

**量級估算（非預言，假設明列）**：`BR(J/ψ→Ξ⁰Ξ̄⁰) ≈ 1×10⁻³`（±2 倍不影響結論）
`× BR(Ξ⁰→Λπ⁰)² × BR(Λ→pπ⁻)² × BR(π⁰→γγ)²` ⟹ 未計效率 **3.9×10⁶**；效率 15–45% ⟹ **N ≈ 0.6–1.8×10⁶**。

```
σ_stat = σ_res/√N ：N=10⁶, σ_res=1.5 MeV ⟹ 0.0015 MeV
```

⟹ **統計完全不成問題**（比現 σ 小 100 倍以上）；該測量**純系統誤差主導**（絕對標度，`J/ψ` 質量錨）。
   BESIII 相對標度控制 ~10⁻⁵ ⟹ 0.013 MeV @1.3 GeV ⟹ **低於 5σ 門檻 0.084**。
⟹ 判：**3σ 與 5σ 兩級門檻，BESIII 現有數據皆足以跨越**；缺嘅只係一篇質量分析。
