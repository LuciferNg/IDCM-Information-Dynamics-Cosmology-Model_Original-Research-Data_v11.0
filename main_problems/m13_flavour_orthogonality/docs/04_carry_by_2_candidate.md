## 一、定義（零可調參數）

```
α = (2^0, 2^1, 2^2) = (1, 2, 4)            ← carry-by-2（gen 序：0→u, 1→d, 2→s）
u = 1·v_u + 2·v_d + 4·v_s
w = K⁻¹ u
```

由 `docs/03` 之精確 Gram `M = (1/90)(A₂ Cartan ⊕ 1)`、`δ = Mα`：

```
δ_u = (2·1 − 2)/90 = 0                  ⟹ ρ_u = 0        （精確，Cartan 首行零方向）
δ_d = (2·2 − 1)/90 = 3/90
δ_s = 2·4/90 = 8/90                     ⟹ ρ_d = 3/8      （精確）
```

實算（60 dps）：`ρ_u = −5.6e−62`（= 0）、`ρ_d = 0.375` **精確 `3/8`**、`δ_s = 0.0888…`（非退化）、`‖w‖ = 1.94594`。

**等價表述（出處稍佳）**：因 `δ_s = α_s/45`，故 `α_s = B` ⟺ **`δ_s = B/(N_d+1) = 4/45`**。
即「s-讀出之歸一化 = 分支數 ÷ 樹站數」，全為已註冊量（`B=4`、`N_d+1=45`），無自由參數。
（此表述與 `α_s = 4` 數值等價，不改變任何結論。）

## 六、判決

- **結構部分（非擬合）**：`ρ_u = 0` 精確 —— A₂ Cartan 首行之零方向（`α ∝ ω₂ ⊕ α_s`）。此係 `docs/03` 之定理推論，與 `α_s` 取值無關。
- **數值部分（後驗）**：`ρ_d = 3/8` 依賴 `α_s = 4`；look-elsewhere 12.5% ⟹ **不作證據**。
- **狀態**：🟡 **待精度**（非 🔴 死 —— 未被否證；非 ✅ 閉 —— 判別力不足）。
- **禁區 4 遵守**：本輪**拒**以「`α_s` 取使 `ρ_d` 近 0.4035 之值」定案；`α_s = 4` 係 carry-by-2 給定，非反解。
- **G1 閘之設計缺陷（append-only 記錄，不回溯改寫）**：凍結版 `G1` 要求 `ρ_u < 0`，
  但現象本身 `ρ_u = −0.0259 ± 0.0336`（0.77σ）**從未達 3σ**，故「嚴格負」從不是可裁決要求；
  `ρ_u ≡ 0` 之預言反過來比 `ρ_u < 0` 更強。建議閘改為「`ρ_u ≤ 0` 且與數據相容」—— 待 M13 下次凍結時另立 `G1'`，本輪不動。
