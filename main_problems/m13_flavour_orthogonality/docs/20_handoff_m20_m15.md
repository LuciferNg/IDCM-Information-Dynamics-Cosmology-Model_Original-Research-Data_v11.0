
### 1.3 ★ 獨立性警告（M20 最需要聽的一條）

`α` 係由**同一批強子質量**反解：

```
δ_s = Δ_Ξ/2 → δ_d = Δ_Σ − δ_s → δ_u = Δ_N − δ_d → (ρ_u, ρ_d) → α
```

⟹ 任何以**強子質量**為輸入之檢定，用 `α` 作「獨立第二權重」＝ **同一數據兩次入帳（循環）**。
`α` 只可在**不同扇區**（CKM／PMNS／宇宙學）作固定比 `(1,2,4)` 使用；
且其固定性受 M14 `Q2` 限制 ⟹ 現階段屬**條件性固定**。

- 若其缺口之檢定輸入**不含強子質量** ⟹ `α` 側可用，但須標「條件性（序未閉）」。
