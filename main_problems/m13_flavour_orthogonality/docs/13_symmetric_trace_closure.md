## 一、對稱演繹：A₂ Cartan 譜分解

`Cartan K = [[2,−1],[−1,2]]`，特徵值 **1**（對稱方向）與 **3**（反對稱方向），`tr = 2`、`det = 3`。

令 `s ≡ α_u + α_d`、`a ≡ α_d − α_u`：

```
ρ_u = (s − 3a)/(4α_s)
ρ_d = (s + 3a)/(4α_s)
```

**同一條公式、同一個 `3`、只差 `±` 號** —— 呢個就係「同一套規則下的對稱性演繹」。
（相加 ⟹ `s/(2α_s)`；相減 ⟹ `3a/(2α_s)`。）

## 二、★ 恆等式：迹 = 與 u,d 完全無關之單一比

三錨（零自由度）：`δ_s = Δ_Ξ/2`、`δ_d = Δ_Σ − Δ_Ξ/2`、`δ_u = Δ_N − δ_d`
其中 `Δ_N ≡ m_n − m_p`、`Δ_Σ ≡ m(Σ⁻) − m(Σ⁰)`、`Δ_Ξ ≡ m(Ξ⁻) − m(Ξ⁰)`。

```
ρ_u + ρ_d = (δ_u + δ_d)/δ_s = Δ_N/(Δ_Ξ/2) = **2Δ_N/Δ_Ξ**
```

實算逐位吻合（差 `0.0`）：`ρ_u + ρ_d = 0.377615281752 = 2Δ_N/Δ_Ξ`。

⟹ **迹完全不涉及 `u`、`d` 之任何標籤或權重**，亦**完全不含 `Δ_Σ`**。純錨系統代數。
同理 `ρ_d − ρ_u = (4Δ_Σ − 2Δ_N)/Δ_Ξ − 2`。
