## 一、R1 續推 — 把「每代因子 2」接上已註冊之翻倍結構

### 1.1 候選之來源

鏈譜 `γ_n = 4sin²(nπ/88)` 有一個**已註冊**之翻倍恆等（分形張量讀數 `γ_n(88) = γ̃_2n(176)`）：

```
γ_{2n}/γ_n = 4cos²(nπ/88)      （恆等，n=1 時 = 3.994904229）
```

即「指標翻倍」把譜權重乘 `4cos²(nπ/88)`，`n` 細時 ≈ 4。而本 M 之缺口正是 `α_s/α_u = 4`：

| 候選 | 值 | `z`（vs `3.717438495 ± 0.412601`） | 機制 |
|:--|--:|--:|:--|
| **`B = 4`（整數，bare）** | 4 | +0.685 | **無**（純標籤） |
| **`γ₂/γ₁ = 4cos²(π/88)`** | **3.994904229** | **+0.672** | **有**：指標翻倍 `n → 2n`（已註冊） |
| `4/cos²(π/88)` | 4.005102271 | +0.697 | 無 |

⟹ 兩個零參數候選並列；只有後者有已註冊機制。

### 1.2 但「落窗」本身唔係證據（密度審計）

鏈譜比 `γ_a/γ_b`（`a,b = 1..44`，共 1,892 個有序對）落 1σ 窗者 **53 個 = 2.80%**：

```
−log₂(0.0280) = 5.16 bit      ⟹ 落窗約值 5 bit，非零但亦非「唯一」
最簡命中：γ₂/γ₁ 3.99490、γ₄/γ₂ 3.97964、γ₆/γ₃ 3.95429、γ₈/γ₄ 3.91899 …
（全部係「翻倍對」之聚集 —— 見 §1.3）
```

### 1.3 為何聚集：任何 `γ_{2n}/γ_n` 都近 4

`4cos²(nπ/88)` 在 `n` 細時近 4（`n=1: 3.9949`、`n=5: 3.8739`、`n=11: 3.4142`、`n=22: 2.0`）。
⟹ 落窗者**多數**只係同一翻倍結構之不同 `n`，**唔**代表「`a=2,b=1` 被選中」。

### 1.4 關鍵：兩候選觀測上**永久不可分**

```
ρ_d(B=4)           = 0.375
ρ_d(γ₂/γ₁)         = 0.375478337886
差 = 0.00047833789 = 現 σ_ρd 之 0.0107σ
要 3σ 分辨需 σ_ρd ≤ 0.00015945  ⟹  現值之 280.9×
```

⟹ **即使 Ξ 精度提升到極限亦不可分**（`σ_ρd` 之硬底 0.0110 已 > 所需 69×）。
**分流只能靠結構，不能靠數據。**

### 1.5 判：R1 之殘餘與 M14 `Q2` **係同一問題**

`γ₂/γ₁` 要成立，需「`u` ↔ 指標 1、`s` ↔ 指標 2」之指派 —— 即**世代序**。
而 `B = 4` 要成立，需「每代乘 `√B`」之一條算術，唔需要序。
兩者之差恰好就係「序有無觀測後果」：

- 若序係 gauge（本 M 站無關性定理）⟹ 兩候選等價 ⟹ 取簡單者 `B=4`。
- 若序有結構（M14 `Q2` 解出）⟹ `γ₂/γ₁` 勝，並**預言** `α_s/α_u = 3.994904229`（非整數 4）。

⟹ **R1 併入 M14 `Q2`**，本 M 不再單獨持有。
