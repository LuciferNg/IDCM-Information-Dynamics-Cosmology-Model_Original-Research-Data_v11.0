## 一、S1：A₂ 塊係**普遍結構**，不能作站指派之選擇原理

掃描 `(p_u, p_d, p_s)`，`p_u ≤ 7`、`p_d ≤ 8`、`p_s ≤ 10`（共 **112** 組），各算 `K⁻¹`-Gram：

| 類 | 定義 | 數 | 佔比 |
|:--|:--|--:|--:|
| **A2⊕1** | `M_uu=M_dd=M_ss`、`M_ud=−M_uu/2`、`M_us=M_ds=0` | **44** | 39.3% |
| A2塊 | 僅 2×2 塊成立（單態不正交或不等範） | 43 | 38.4% |
| 非A2 | — | 25 | 22.3% |
| 退化 | `M_uu=0` | 0 | — |

⟹ **A₂ 型 2×2 塊 = 87/112 = 77.7%**，故 `A₂ Cartan` 係**普遍結構**，**不是** `(2,3,4)` 之專有性質。
⟹ 因此 `A₂` **不可**用作站指派之選擇原理（此點推翻我上一輪之暗示）。
⟹ **但**：`ω₂` 方向（`α_d = 2α_u`）⟹ `ρ_u = 0` 之**機制**反而因此更穩健 —— 它對幾乎任一指派皆成立，
   即「近正交」不需精調、不需特選站，係該構造之通性。此為 `ρ_u ≈ 0` 現象之**結構解釋**（`z = +0.77`）。

## 二、★★ S2：站無關性定理（本 M 最強結構結果）

在 44 個 `A2⊕1` 三元組上，對 `α ∈ {(1,2,1), (1,2,3), (1,2,4), (1,1,1)}` 逐一比對：

```
ρ_u = (2α_u − α_d) / (2α_s)          ρ_d = (2α_d − α_u) / (2α_s)
```

| `α` | 閉式 `ρ_u` | 閉式 `ρ_d` | 全 44 三元組最大偏差 |
|:--|--:|--:|--:|
| (1,2,1) | 0 | 1.5 | 1.34e−50 |
| (1,2,3) | 0 | 0.5 | 1.07e−50 |
| (1,2,4) | 0 | 3/8 | 9.35e−51 |
| (1,1,1) | 0.5 | 0.5 | 1.07e−50 |

**定理（站無關）**：於 `A2⊕1` 類內，`(ρ_u, ρ_d)` **只依賴權重 `α`**，與站指派、鏈長、載體**完全無關**（偏差 ≤ 1e−50）。

三個推論：
1. **「站指派」問題在此族內不存在** —— M12 花了多輪處理之 `u→2/d→3/s→4` 之爭議，對比值預言**無影響**。
2. **M12 `docs/21 §S2` 之「載體無關（三者極差 1.718%）」獲得結構解釋** —— 那不是巧合，係 `α`-收斂之必然。
3. **自由度收斂**：全族只剩 `α` 之比值；配合 `ω₂` 條件（`ρ_u = 0`）⟹ 只剩 **一個數**。

## 三、S3：缺口收斂為單一數字 `α_s/α_u`

```
ω₂ 條件 ⟹ α_d = 2α_u ； ρ_d = 3α_u / (2α_s)

由數據反演：α_s/α_u = 3/(2ρ_d) = 3.7174385 ± 0.4126   （1σ）
1σ 窗 = [3.3048, 4.1300]
```

⟹ 故 `docs/04` 之 `α_s = B ⟹ ρ_d = 3/8` 不可升格 —— 它與 `N_gen`、`√5+1` 等**共存於不可分辨帶**。

```
K⁻¹-夾心族之完整狀態：
  ✅ 結構預言（強）：ρ_u = 0（ω₂ 方向；普遍、零調參、與數據 0.77σ 相容）
```
