## 三、★★ 推論 1：近正交（`ρ_u = 0`）之**結構理由**已找到

對 `u = α_u v_u + α_d v_d + α_s v_s`、核 `w = K⁻¹u`，由 `δ = Mα`：

```
δ_u = (2α_u − α_d)/90       δ_d = (2α_d − α_u)/90       δ_s = 2α_s/90
ρ_u = (2α_u − α_d)/(2α_s)   ρ_d = (2α_d − α_u)/(2α_s)

ρ_u = 0  ⟺  α_d = 2α_u          ← A₂ Cartan 首行之零方向
⟹ α ∝ (1, 2, α_s) = ω₂ ⊕ α_s   （ω₂ = A₂ 第二基本權重）
```

⟹ **「`⟨w,v_u⟩` 近零」不再需要凑**：只要 `α` 取基本權重 `ω₂` 方向，`ρ_u = 0` **精確**成立，**零調參**。
