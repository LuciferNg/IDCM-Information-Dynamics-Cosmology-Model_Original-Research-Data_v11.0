## 六、★ 跨記錄發現：M12 `t*` 與 M13 迹值數值等同（10 位）

```
M12 docs/28 之 LP maximin  t* = 0.37761528
M13 迹（Δ_N/δ_s）              = 0.377615281752
```

兩者係**唔同定義**之量（`t*` = `min_ij G(i,j)` 在 `w ≥ 0, Σw = 1` 下之最大化值；迹 = 質量比）。
10 位數字相同不可能係巧合 ⟹ 兩種可能：
1. `t*` 之 `w` 係由觀測 `(ρ_u, ρ_d)` **反解**（M12 `run_37` log 同段確實印住 `δ_u/δ_s`、`δ_d/δ_s` 作覆核）
   ⟹ `t*` 變咗**數據函數**，唔係純結構量 ⟹ 不能作「entry-positive 類可行」之獨立證據；
2. 兩者存在未識別之恆等式。
**本 M 不裁**（屬 M12 守備範圍）⟹ 已 `register note` 請 M12 核 `t*` 之 `w` 來源。
★ 此事對 M13 之影響：**零**（M13 之迹值由 PDG 質量獨立算出，與 M12 之 `t*` 無依賴）。
