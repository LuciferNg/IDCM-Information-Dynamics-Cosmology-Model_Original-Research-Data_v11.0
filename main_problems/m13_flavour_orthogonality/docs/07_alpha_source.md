規則（跑前凍結）：
`R1 α=k`、`R2 α=1/k`、`R3 α=2^d`、`R4 α=2^{−d}`、`R5 α=B^d`、`R6 α=B^{−d}`（`B=4`）

## 二、★ 為何必然失敗（結構理由，非統計）

`ω₂` 條件要求 `α_d = 2α_u`（即 `ρ_u = 0`）。逐規則核查：

| 規則 | 能否給 `α_d/α_u = 2` | 說明 |
|:--|:--|:--|
| `k ∈ {1,4,5}` | **不可能** | 比值只可能 `{4, 5, 5/4, 1/4, 1/5, 4/5}` |
| `1/k` | **不可能** | 同上取倒 |
| `B^d = 4^d`，`d ∈ {3,2,0}` | **不可能** | `4^{Δd} ∈ {4^{±1}, 4^{±2}, 4^{±3}, 1}`，無 2 |
| `2^d` | **可能**（`d_u = 2, d_d = 3`） | **但**此時 `d_s = 0` ⟹ `α_s/α_u = 2^{−2} = 1/4` ⟹ `ρ_d = 3/(2·1/4) = 6`（窗外 126σ） |

⟹ 達到 `ρ_u = 0` 的唯一途徑（`2^d`，`d=(2,3,0)`）**同時鎖死** `ρ_d = 6`；
  任何使 `α_s/α_u ≈ 3.7` 之指派則破壞 `α_d = 2α_u`（`ρ_u` 偏 `4.5σ`–`417σ`）。
⟹ **標籤層之離散域 `{1,4,5}`／`{3,2,0}` 太窄**，無法同時承擔 `ω₂` 條件與 `ρ_d` 之量值。
