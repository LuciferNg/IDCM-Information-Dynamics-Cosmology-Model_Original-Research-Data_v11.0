## §一 本 session 之問題重述

`N_gen = 3` 之**結構身份**能否由本載體以外之結構給出？
四條候選載體（`SESSION_START` §依賴）：**C1** A₅ 幾何／**C2** CY₃／**C3** M45 帶（`K_chain` 質量譜）／**C4** `T_pipe` 截斷。

★ 本檔先把問題**重新定型**，因為 §二 之算術事實使「3 從何來」唔可以照原樣問：

```
N_gen 在 SM 之準確定義 = 費米子表示空間中 (SM rep) 之**重數**（multiplicity）
                      ⟹ 一個 3 之量詞，其定義域必須係費米子內容之**分割**（partition）
                      ⟹ 「3 之身份」之正確形式 = 「是否存在 dof=0 之典範滿射 τ : F → S，|S| = 3」
                                  （F = 費米子模式集；S = 3 元素結構集）
```

⟹ 本 M 之判死語言**不限於**「3 可否被計出」（幾乎任何載體都可計出 3），而係
「**3 係一個帶分割映射之重數，抑或只係一個數字**」。此為 M14 `docs/09`「量詞偷換」之直接教訓。

## §三 ★ 判準（跑前凍結；每項含判死門檻與範圍語言）

### P1 — 歸約定理（`O137 §一`）之形式地位

**C1（恆真審計）**：檢 `O137 §一` 清單 ①–⑤ 是否**含 `n` 本身**或含任一對 `n` 單射之量。
判準：若清單含之 ⟹ 定理「任何幾何供給之量皆 `f(n)`」**恆真** ⟹ **零鑑別力**（形式地位 = tautology，非 no-go）。
**C2（清單窮盡性之可測版本）**：取一個**不在清單**之 A₅ 幾何量 `m_ρ(n)`（諧波之 A₅-irrep 重數，本 M 新算），問 `m_ρ(n)` 是否可由清單 ①–⑤（**剔除「`n` 本身」一項**）決定。判準：若可 ⟹ 清單（剔除 ① 後）仍完備；若不可 ⟹ 清單**非**窮盡（但定理仍恆真，因 ① 已含 `n`）。
**C3（模式同一性之 dof）**：`O137 §五` 之受保護集 `P = {1,2,3,4,5,7,9,11,13}`（9 模式）與 `K_chain` 之模指標 `n` 之同一性，若無已註冊原則固定 ⟹ 配對自由 = `9! = 362880`。
判準：`dof > 0` ⟹ **違 A3** ⟹ 任何依此配對之預言不可裁決。門檻：`dof > 0` 即判死（非數值門檻）。

### P2 — 非 `𝒜` 載體之第二標籤

**C4（完美群定理）**：任一群 `G` 以表示作用於 44-模空間且與 `H` 交換 ⟹ 像 ∈ `𝒞(H)` = 對角 ⟹ 阿貝爾。判準：若 `G` 非阿貝爾且完美（`[G,G]=G`），則作用**必然平凡** ⟹ `G` 不可能供給任何標籤。**A₅ 完美性須精確核**（`[A₅,A₅]` 之階 = 60）。
**C5（簡併逃逸）**：唯一可容非平凡標籤之情形 = 特徵值簡併（`γ_n = γ_n′`，`n≠n′`）。判準：`γ` 嚴格遞增之**精確證明**（`γ_{n+1}−γ_n = 4 sin((2n+1)π/90) sin(π/90) > 0`）⟹ 簡併 0/946。
**C6（`ℤ_m` 分級之 dof）**：對角相位分級 `n ↦ ω^{g(n)}` 之自由度 = 44 個相位（`ℤ_m^44`）⟹ 若不論 `m` 皆可任意選 ⟹ `dof = 44` ⟹ 判死。唯一生路：由結構**強制**之 `ℤ_3`（見 C10）。

### P3／P5 — 計數普查與互斥性

**C7（分割測試 ★ 核心）**：一計數身份可作 `N_gen` 身份 ⟺ 同時滿足
(i) 供給 3 元素集 `S`；(ii) 供給**典範滿射** `τ: F → S`（`F` = 9 元素受保護模式集）；(iii) `τ` 由結構唯一決定（`dof = 0`）。
判準：三項缺一即 **不成立**（標 `NO-PARTITION`／`NON-CANONICAL`）。**本判準唔准事後放寬。**
**C8（供給曲線／選擇性）**：對每載體建結構整數目錄，計 `k = 2..12` 之獨立來源數 `s(k)`（目錄定義見腳本 docstring，跑前寫死）。
判準：若**每個**載體皆有 `s(3) ≥ 1` ⟹ 「3 來自某載體」**不可由計數身份裁決** ⟹ 標 `NON-DIAGNOSTIC`。
**C9（互斥性）**：兩身份「同一個 3」⟺ 底層集合同 signature（基數＋作用型＋典範雙射存在）。判準：非同構者標 `INDEPENDENT`；若同載體內兩個獨立 3 並存 ⟹ 該載體不供唯一 3。

### P4 — `/88 ↔ /90` 顯式映射

**C10（adic 自相似唯一性）**：`n ↦ mk` 保族（`4sin²(mkπ/x) ≡ 4sin²(kπ/x′)`）⟺ `m | x`（須證，`x′ = x/m`）。
判準：若 `x=90` 之 `m=3` **非唯一**（同型子鏈 ≥ 2 個且皆 ≥ 4 站）⟹ `ℤ_3` 由結構**不**唯一選出 ⟹ 標 `NON-UNIQUE` ⟹ C6 之生路關閉。
**C11（映射存在性）**：γ-級 `γ^{(88)}_n = γ^{(90)}_σ(n)`；仿射指標級 `σ(n) = an+b (mod 44)` 窮舉；摺疊分層級（`v₂` 對稱）。
判準：0 命中 ⟹ `no-go`，範圍 = `{γ-級, 仿射指標級, 摺疊分層級}`。門檻：精確（容差 `1e−50`）。

### C2 — CY₃

**C12（標準世代計數）**：`CY₃` 之唯一已註冊世代計數機制 = `N_gen = |χ|/2`（`χ = 2(h11−h21)`）。
判準：若 `|χ|/2 ≠ 3` 且 `| |χ|/2 − 3 | / 3 > 0.1` ⟹ **該機制判死**（數量級錯，非擬合問題）。
**C13（單整數凑數之密度閘）**：任何由 `{h11, h21, χ}` 經 `{+,−,×,÷}` 得 3 之表達式，須報該目錄對 `[1,100]` 之覆蓋率。
判準：若覆蓋率 > 50% ⟹ 命中無訊號（照 `O137 §四` 之密度基準）。

### C3／C4

**C14（出處閘）**：`C3` 之味標籤 `k ∈ {1,4,5}`、`d ∈ {3,2,0}` 全部字面值（M14 `docs/03` AST 追溯 6 處零 `Name` 依賴）⟹ 違 **A1**。
判準：字面值**不可**作計數來源；`C3` 之任何「3」只可標 `LITERAL（inadmissible）`。
**C15（自由度閘）**：`C4` `T_pipe` 截斷 `n* = N_d − L₆ + 1 = 27` 只過濾、不生成（M14 `docs/17`）。判準：無獨立自由度 ⟹ 不可單獨供 3，標 `NO-DOF`。
