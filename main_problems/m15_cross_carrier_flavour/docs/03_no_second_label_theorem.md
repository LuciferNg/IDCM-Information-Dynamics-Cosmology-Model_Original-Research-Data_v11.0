## 前設問題

M14 `docs/19` 單標籤定理只覆蓋「與 `H` 交換之量」在**本鏈**上。P2 問：
**是否存在不經 `𝒜` 之載體，其守恆量非 `f(n)`？**（即第二個獨立標籤可否由他載體供給。）

## 事前判準

```
C4 完美群定理：G 以表示作用於模空間且 [ρ(G), H] = 0 ⟹ ρ(G) ⊆ 𝒞(H)（對角、阿貝爾）
               ⟹ G 非阿貝爾且完美 ⟹ ρ 平凡。
C5 簡併逃逸：唯一可容非平凡標籤之情形 = γ_n = γ_n′（n ≠ n′）。須精確否證。
C6 ℤ_m 分級：由結構強制者須 dof = 0；任意相位分級之自由度 = 22 個三元選擇（反射等變下）。
```

## 結論報告

### 一、定理（完美群 ⟹ 標籤不可能）

```
設 V = 44-模空間，H = K_chain 哈密頓（γ 互異）。
ρ : G → Aut(V) 以 [ρ(G), H] = 0 作用 ⟹ ρ(G) ⊆ 𝒞(H)。
𝒞(H) 對角（M14 docs/19）⟹ 𝒞(H) 阿貝爾 ⟹ ρ(G) 阿貝爾。
G = A₅：精確核 [A₅,A₅] = A₅（⟨60 個交換子⟩ 之閉包階 = 60），且非阿貝爾（存在 ab ≠ ba）
⟹ 任何同態 A₅ → 阿貝爾群必平凡 ⟹ **ρ 平凡**。
```

⟹ **A₅ 幾何不可能在模式空間上供給任何非平凡標籤**（不論經 `𝒜` 與否）。
補充核：A₅ 確有 44 維表示（`5a+4b+3c+3d+e = 44` 共 1672 個分解）——**存在 ≠ 可用**：
任何此類表示皆不可與 `H` 交換，故不構成分類。

### 二、簡併逃逸之否證（精確）

```
γ_{n+1} − γ_n = 4·sin((2n+1)π/x)·sin(π/x) > 0     （n = 1..43，x ∈ {88, 90}）
/90：閉式 max|dev| = 5.64×10⁻⁶¹；最小相鄰差 0.0145919630；946 對簡併 = 0
/88：閉式 max|dev| = 6.13×10⁻⁶¹；最小相鄰差 0.0050957708；946 對簡併 = 0
```

⟹ 無退化子空間 ⟹ 非阿貝爾標籤之最後逃生口關閉。

### 三、`ℤ_m` 分級之 dof（量化）

```
(a) 反射等變分級 g: {1..44} → ℤ_m（g(45−n) = −g(n)）：
    反射配對 22 對（45−n = n 無整數解 ⟹ 無固定點）⟹ 自由位 22
    m = 2：2²² = 4,194,304    m = 3：3²² = 31,381,059,609    m = 4：4²² …
    ⟹ **dof = 22 個三元選擇 ⟹ 違 A3**（除非另有結構強制）

(b) 算術分級 g(n) = n mod m（canonical，dof = 0）之窮舉：
    m  類大小            類 0 為同族子鏈？  反射反等變？
    2  [22,22]          否（x′=45 奇）      否
    3  [14,15,15]       是                 是
    4  [11,11,11,11]    —                    否
    5  [8,9,9,9,9]      是                 是
    9  [4,5,5,5,5,5,5,5,5] 是               是
    其餘 m ≤ 11         多為否
```

### 四、判詞：兩條「3」之路皆不通

```
(i) 任意 ℤ₃ 分級：3²² 個 ⟹ dof > 0 ⟹ 違 A3。
(ii) 算術分級 n mod m：canonical（dof = 0）但 **m 自由** ——
     「要求恰 3 類」即等於**假設** m = 3 ⟹ **循環論證（把答案當前題）**。
(iii) 非循環之路：由「同族子鏈」唯一選出 m。核得 m ∈ {3, 5, 9}（x′ = 30, 18, 10；14/8/4 站）
      ⟹ **非唯一** ⟹ 路線死（詳 docs/05）。
```

## 判詞

| 項 | 判 | 範圍 |
|:--|:--:|:--|
| 非阿貝爾載體（含 A₅）在模式空間供標籤 | 🔴 **定理級不可能** | 任何 `[ρ(G),H]=0` 之表示 |
| 簡併逃逸 | 🔴 否證（946 對 0 簡併，精確） | /88 與 /90 |
| 任意 `ℤ_3` 分級 | 🔴 dof = 22 ⟹ 違 A3 | 反射等變族（3²²） |
| 算術分級 `n mod 3` | 🔴 **循環**（m = 3 係前提） | — |
| 同族子鏈選 m | 🔴 **非唯一**（{3,5,9}） | 詳 docs/05 |

⟹ **P2 之答案：不存在**（範圍：以模式集為底、要求與 `H` 交換之載體）。
「3」之來源只能係**計數**或**模式集以外之張量因子**——後者屬本 M 邊界，見 docs/07。
