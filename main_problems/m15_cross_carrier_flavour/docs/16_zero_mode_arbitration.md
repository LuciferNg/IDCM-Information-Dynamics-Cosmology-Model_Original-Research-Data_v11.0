## §0 兩個「3」互相打架

```
路線 A（模計數）  κ 閘門 e^{−n} > 1/16 之可見模數
                  v10 O163 docs/05：「e⁻ⁿ = κ → n = 0,1,2」⟹ 3

兩者都給 3，但**對象不同**；且路線 A 含 `γ₀ = 0`。本輪裁決。

## §1 模式集之端點：45 個相異半譜值 vs `N_d = 44`

```
88-site 環 Laplacian 譜：γ_k = 4sin²(πk/88)，k = 0..87，對稱 k ↔ 88−k
相異半譜值 = k = 0,1,…,44 ⟹ **45 個**（含 γ₀ = 0 與 γ₄₄ = 4 兩端點）
而 N_d = 44（註冊值）⟹ **恰排除一個端點**
```

排除哪一個，由結構定：

| 端點 | 值 | 身份 | 可否屬物質扇區 |
|:-:|:--|:--|:--|
| `γ₀` | `0` | 常向量（零動量）⟹ 全局真空模；`m = M₀√γ₀ = 0` | ❌ **無質量**，唔可能係三代費米子之一；且真空側已計入 41，再計即**雙重計數** |
| `γ₄₄` | `4 = B` | Nyquist | ✅（T7 以之為 `γ_max`） |

⟹ **模式集 = `k = 1..44`**（恰 44 模、全 > 0、嚴格遞增）；`γ₀` 屬真空／常向量，唔屬任何扇區。

★ 反證：若含 `γ₀`，模式數 = **45 ≠ N_d = 44**，與註冊值直接矛盾。

```

## §5 「五個身份」逐條審

| 條目 | 判 | 理由 |
|:--|:--:|:--|
| `3 = B − 1` | ✅ | `4 − 1 = 3`（端點減一） |
| `3 = 色數` | ✅（同值） | SM 觀測值 3 |
| `3 = λ_max − 1` | ✅（**同一陳述重寫**） | `λ_max = γ_max = 4` |
| `3 = N_gen` | ✅（輸入） | SM 觀測值，非本理論產出 |
| `3 = rank(P_κ)` | 🔴 **假** | 物理索引下 `rank = 2` |

⟹ 舊「五個獨立身份指向同一個數」**不成立**：三條係同一陳述重寫、一條係觀測輸入、一條為假。
真正獨立者只有 **`B − 1`** 一條。

## §6 裁決

```
① 模式集 = k = 1..44；γ₀ = 0 屬真空側（且與 N_d = 44 互斥）
② rank(P_κ) = 2 ⟹「可見模式 = 3」**永久作廢**（本 O 與任何引用者）
③ 預算分子 3 = γ_max − 1 = B − 1 —— **分支計數**，非模計數
   結構讀法：B 條分支排除「身份／真空」分支 ⟹ B − 1 條物質分支（🟡 未完全導出，見下）
④ 兩個 3 係唔同對象；舊記錄混為一談 ⟹ 兩結論各自「真」而互相打架
⑤ 歸一化唯一 = ÷60
```
