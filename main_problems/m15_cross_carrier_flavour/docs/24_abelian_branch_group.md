## §1 階 4 群之分類（實枚舉）

| 群 | 階 | abelian | 交換子群 |
|:--|:-:|:--:|:--|
| `ℤ₄` | 4 | ✅ | `{0}` |
| `V₄ = ℤ₂×ℤ₂` | 4 | ✅ | `{(0,0)}` |

⟹ **階 4 之群恰 2 個，兩者皆 abelian**（分類定理，dof 0）。

`V₄` 之特徵標：4 個，**維數全部 1** ⟹ 非平凡者 3 個、每個 1 維 ⟹ 容量 = 3 單位。

## §2 對照：`S₃`（階 6，非 abelian）—— 公式失效

```
S₃ 不可約表示維數 = [1, 1, 2]
Σ維數² = 1+1+4 = 6 = |G|        （Burnside）
Σ維數  = 4 < 6                   （因 d² > d 對 d ≥ 2）
非平凡：維數 [1,2] ⟹ 個數 2、Σ維數 3 ≠ |G| − 1 = 5
```

⟹ 非 abelian 時「容量 = `|G| − 1`」**失效**（會少算）。

## §3 判準定理

```
命題： Σ_{ρ ≠ 1} dim ρ = |G| − 1   ⟺   G abelian

(⇐) G abelian ⟹ 不可約表示全 1 維、共 |G| 個 ⟹ Σ = |G| − 1
(⇒) 若某 dim d ≥ 2，則 Σ_ρ dim ρ < Σ_ρ dim²ρ = |G|
    ⟹ Σ_{非平凡} dim = Σ_全部 dim − 1 < |G| − 1    ⟹ 命題不成立
```

## §4 裁決

```
① 階 4 群恰 2 個，皆 abelian（§1）
② ⟹ 分支群（階 B = 4）必 abelian ⟹ 特徵標全 1 維 ⟹ 容量 = B − 1 = 3
③ B = γ_max = 4（Nyquist：4sin²(π/2) = 4，精確）⟹ 零自由參數
④ ⟹ 容量 = 3/60 = 1/20 **完全結構**（dof = 0）
⑤ 第二條獨立理由（互為冗餘）：通道 = 費米子種類位，Pauli ⟹ 每通道 1 單位，與 abelian 無關
```

⟹ `docs/23 §6` 之殘留**收束**。

## §5 容量鏈之最終形式（全部 dof = 0）

```
B = γ_max = 4                 Nyquist（譜端點）
3 = B − 1                     階 4 群之非平凡不可約表示（皆 1 維）
60 = N_d + B²                 譜和 = N_d + γ_max²
Ω_b = 3/60 = 1/20             +0.82σ
溢出不可能                     階 4 群只有 3 個非平凡表示，無第 4 通道
```

## §6 方法註記

原殘留表述為「需證分支群必 abelian」——追下去發現**唔需要「證明」一個假設**：
階 4 之群**全部** abelian 係分類定理，故「分支群 abelian」唔係額外假設而係**必然**。
真正的內容係判準定理（§3）：`Σ dim = |G| − 1 ⟺ abelian`，而 `B = 4` 落入該定理之適用範圍。
