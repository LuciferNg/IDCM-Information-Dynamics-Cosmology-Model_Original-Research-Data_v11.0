## §1 ★ A₅ 之表示論恆等式（同一個 irrep 清單）

```
A₅ 之不可約表示維數 d = [1, 3, 3, 4, 5]
共軛類大小            = [1, 15, 20, 12, 12]（Σ = 60）

Σd²    = 1 + 9 + 9 + 16 + 25 = 60
Σd     = 1 + 3 + 3 + 4 + 5   = 16
Σd(d−1)= 0 + 6 + 6 + 12 + 20 = 44
⟹ **Σd² = Σd + Σd(d−1)**  ⟺  60 = 16 + 44      （恆等式，非拆數）
```

★ 此結果**修正** `docs/15 §10` 之「`60 = 44 + 16` 係跨空間相加」：
在 A₅ 之 irrep 清單下，三者係**同一個和**之兩部分 ⟹ 同質（homogeneous）。

## §3 唯一性檢定（A₅ 不變量池）

池（`d`、`d²`、`d(d−1)`、類大小、`Σd`、`Σd²`、`Σd(d−1)`）：
`{1, 3, 4, 5, 6, 9, 12, 15, 16, 20, 25, 30, 44, 60}`

和為 60 之三分拆（皆在池內）：**6 組**

```
(1, 15, 44)   (4, 12, 44)   (5, 25, 30)
(15, 15, 30)  (15, 20, 25)  (20, 20, 20)
```

⟹ **`(3, 16, 41)` 唔在清單**，因為 `41 ∉ ` 池。
⟹ 「`(3,16,41)` 在 A₅ 池下唯一」**不成立**。

## §4 但兩步分解：第一步唯一，第二步唔係

```
① 60 = 16 + 44     ← 由 irrep 恆等式唯一確定（Σd² = Σd + Σd(d−1)）
② 44 = 3 + 41      ← 3 有身份（d_fund = 3，最小非平凡 irrep）；41 只係補集
```

`41` 之 A₅ 讀法（全部可行，故**非唯一**）：

```
44 − 3 = 41 ｜ 25 + 16 = 41 ｜ 60 − 19 = 41 ｜ 20 + 15 + 6 = 41 ｜ 30 + 9 + 1 + 1 = 41
```

## §5 裁決

| 問題 | 答 |
|:--|:--|
| `60 = 16 + 44` 是否結構必然？ | ✅ **是**（A₅ irrep 恆等式，同一清單） |
| `16` 有 A₅ 身份？ | ✅ `Σd = 16` |
| `3` 有 A₅ 身份？ | ✅ `d_fund = 3` |

⟹ **唯一性只到「`60 = 16 + 44`」為止**；`44 → 3 + 41` 之切法由 `3` 一端決定，`41` 係餘數。
