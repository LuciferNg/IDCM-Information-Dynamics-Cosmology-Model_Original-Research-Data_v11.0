### 三、★ 第十二候選：閘門能見層數（`N_gen = ⌈2 ln B⌉`）

v11 M3 §3（已註冊）：`gate : κ = B⁻² = 1/16 ; 可見模態數 = #{n ≥ 0 : e^{−n} > κ} = rank(P_κ) = 3`。

```

  n=0: 1.0        > 1/16 ✅      n=3: 0.0498 ≤ 1/16 ❌
  n=1: 0.3679     > 1/16 ✅      n=4: 0.0183 ≤ 1/16 ❌
  n=2: 0.1353     > 1/16 ✅      n≥5: ❌
⟹ **N_gen = ⌈2 ln B⌉ = ⌈2.7726⌉ = 3**
```
