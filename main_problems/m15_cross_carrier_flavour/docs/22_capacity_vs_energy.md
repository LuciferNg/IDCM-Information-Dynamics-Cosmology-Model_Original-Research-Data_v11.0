## §2 可見模之零點能

| 慣例 | `½Σ√γ` | 佔 `T⁰₀` |
|:--|--:|--:|
| 含零模 `n = 0,1,2` | 0.107034 | **0.1189%** |
| 不含零模 `n = 1,2` | 0.107034 − 0 = 0.107034（`√γ₀ = 0`） | 同值 |

⚠ 注意：`γ₀ = 0` ⟹ `√γ₀ = 0` ⟹ **兩種慣例之零點能完全相同**（零模對能量無貢獻）。
即：零模污染只影響**計數**，唔影響**能量**。此為 `docs/16` 判死「模計數」之另一面。

## §3 ★ 兩個競爭預言（數據可判別）

```
Ω_b(obs) = 0.049302 ± 0.000857
P1 零點能讀法 = 0.001189   z = **−56.15σ**   ⟹ 否證
P2 容量讀法   = 0.050000   z = **+0.82σ**    ⟹ 支持
兩者分離 = 57.0σ
```

⟹ **能量讀法（可見模零點能 = 重子能量）以 56σ 排除；容量讀法入 1σ。**
⟹ 呢個問題**可判別**，唔係不可證偽 —— 呢點係本輪最重要嘅方法論結果。

## §4 「容量／零點能 = 42」= 誘餌，只記錄不採信

```
容量/零點能 = 42.0476
結構整數池（±×÷ 一次運算，1..400，**已排除目標值 42**）= 156 個值
落入 ±1% 者 = 1 個：{42}
```

`42 = N_d − 2`（隱藏模數）同值。**但**：比值係**事後**由 `P2/P1` 算出 ⟹ 只可記錄為
**未解釋巧合**，不可作證據；亦不可宣稱「每模佔據數 = 42」（無機制）。

## §5 容量之結構定義（零觀測輸入）

```
物質容量 = (B − 1) / (N_d + B²) = 3/60 = 1/20 = 0.05     （精確）
         = 非平凡特徵標數 ÷ 總 dof
```

⟹ `P2` 之 5% **唔係擬合**：佢係結構數之比，與觀測無關。觀測只作事後核對（+0.82σ）。

## §8 方法註記

只有 `42 = N_d − 2` 一個 —— 但**事後計算**，故只列為待查巧合。呢個區分（事前預言 vs 事後巧合）
