## §1 問題

`docs/16` 已鎖死 `3 = γ_max − 1 = B − 1`（分支計數），但**「減一」本身未導出**：
為何物質分子係 `B − 1` 而唔係 `B`？

## §2 導出：分支群之特徵標

```
B = γ_max = 4（Nyquist：4sin²(π/2) = 4，精確）
階 4 之群只有兩種：ℤ₄ 與 V₄ = ℤ₂×ℤ₂ —— **兩者皆 abelian**
abelian 群階 n ⟹ 特徵標 n 個、其中平凡（χ ≡ 1）恰 1 個
⟹ 非平凡特徵標 = n − 1 = B − 1 = 3
```

實枚舉（`V₄`，四元素 `(0,0),(0,1),(1,0),(1,1)`）：

```
χ_(0,0): +1 +1 +1 +1   ← 平凡
χ_(0,1): +1 −1 +1 −1
χ_(1,0): +1 +1 −1 −1
χ_(1,1): +1 −1 −1 +1
⟹ 平凡 1 個、非平凡 3 個
```

`ℤ₄` 同樣給非平凡 3 個 ⟹ **結果與群之選擇無關**（階 4 全 abelian）。

## §3 觀測判別：階 n 由 Nyquist 鎖死

`Ω_b = (n−1)/60`：

| `n` | `(n−1)/60` | z | 判 |
|:-:|--:|--:|:--:|
| 2 | 0.016667 | −38.09σ | 🔴 |
| 3 | 0.033333 | −18.64σ | 🔴 |
| **4** | **0.050000** | **+0.82σ** | ✅ |
| 5 | 0.066667 | +20.27σ | 🔴 |
| 6 | 0.083333 | +39.72σ | 🔴 |

⟹ **只有 `n = 4`**，而 `n = B = γ_max = 4` 由 Nyquist 精確給出 ⟹ 無自由參數。

## §4 與零模排除係同一條原則

| 對象 | 「唔作區分」者 | 後果 |
|:--|:--|:--|
| 分支空間 | 平凡特徵標 `χ₀ ≡ 1`（任何分支皆不被區分） | 減去 ⟹ 物質 = `B − 1 = 3` |
| 模式空間 | `γ₀ = 0`（常向量、零動量、無質量） | 不屬任何扇區 ⟹ 模式集 `k = 1..44`（`docs/16 §1`） |

⟹ 「減一」與「排除零模」**係同一條判準**（trivial channel 不作區分）作用於兩個不同對象。
兩個結果（`3` 與 `2`）因此並不矛盾 —— 它們本來就係唔同對象。

## §5 證偽

```
若物質 = 全部 B = 4 個特徵標（唔減一）⟹ Ω_b = 4/60 = 0.066667 ⟹ z = +20.27σ
```

⟹ 「減一」被觀測**硬性要求**，非可選。

