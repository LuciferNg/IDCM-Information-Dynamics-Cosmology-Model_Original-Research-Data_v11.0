## §2 容量上限（結構，非擬合）

```
V₄ 之特徵標 = 4（abelian 對偶定理）；平凡 1、**非平凡 3**
特徵標皆 1 維 ⟹ 每通道容量 = 1 單位 ⟹ 總容量 = 3 單位
⟹ 容量份額 = 3 / (N_d + B²) = 3/60 = 1/20 = 0.05     （精確）
```

## §3 ★ 溢出在定義上不可能

```
非平凡特徵標恰 3 個 ⟹ **冇第 4 個通道**
⟹ 物質無處可溢
```

即：飽和問題之一半（「為何唔溢出」）**由群論封死**，唔需要動力學。

## §4 另一半：「為何填滿」

```
通道數 = 3（結構） ⟹ 容量 3 單位
觀測側：三代費米子全部存在 ⟹ 三通道全佔用 ⟹ 填滿
而「三」係**預言**（= B − 1 = 非平凡特徵標數），非擬合參數
```

⟹ 唯一經驗輸入係「三代皆存在」；而通道數 3 係本 O 導出（`docs/17`）。
⟹ 三代存在 = 三通道被佔用，係同一件事之兩種講法 —— 故「填滿」**冇額外自由度**。
