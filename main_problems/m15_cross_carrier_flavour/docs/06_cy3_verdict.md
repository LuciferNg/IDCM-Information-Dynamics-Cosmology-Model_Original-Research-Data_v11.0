## 結論報告

### 一、C12：標準機制給 **62**，非 3

```
χ = 2(36 − 98) = −124
|χ|/2 = **62**
相對偏差 |62 − 3|/3 = 19.667（**20.67 倍**）≫ 門檻 0.1 ⟹ 判死
```

⟹ **CY₃ 之標準世代計數機制在 IDCM 之 CY₃ 上數量級錯。** 此為機制層判死，非擬合失敗
（62 與 3 無參數可調：`h11`、`h21` 皆已註冊）。

⚠ 範圍：只針對 `χ/2` 此一機制；不宣稱「CY₃ 整體不可能」。後者見 §三。

### 二、C13 密度閘：目錄只得 1 條「3」，且係恆等

```
primitive：h11 = 36、h21 = 98、|χ| = 124、|h21 − h11| = 62（4 個）
目錄（±×÷、C(·,2)、v_p，層 2 去平凡化）：覆蓋 [1,100] 中 20 個整數（**20.0%**）
得 3 之表達式（1 條）：(χ + |h21−h11|) / |h21−h11|
```

★ **平凡性核**：`χ ≡ 2(h21 − h11)` 係定義恆等 ⟹ 該式 ≡ `2 + 1 = 3`，**與 CY₃ 之具體數據無關**
（任何 CY₃ 皆得 3）⟹ **VACUOUS-3**，不作證據。

### 三、跨載體輸入審計：C2 之「3」須借用 C1 之 12

```
流通說法：3 = h11/12 = 36/12
核：12 ∉ CY₃ 之 primitive（36／98／124／62），且 12 不可由 {36,98,124,62} 之 ±×÷ 合成
    （目錄核：12 ∈ catalogue？ **否**）
12 之出處：C1（A₅／icosahedron）之 |頂點| = 12
⟹ 3 = （CY₃ 量 h11）／（A₅ 量 |V|）⟹ 兩者無已註冊映射（docs/05 已證三層皆無）
⟹ 標 **CROSS-IMPORT**，違 A1 出處閘
```

### 四、非對稱核：3 只係單一 Hodge 數之因式

```
h11 = 36 = 4·9 ⟹ 3 | h11，v₃(h11) = 2
h21 = 98 = 2·7² ⟹ 3 ∤ h21，v₃ = 0
χ = −124        ⟹ 3 ∤ |χ|，v₃ = 0
```

⟹ 「3」若取 `h11` 之因式，係**單一 Hodge 數之算術因式**（唔係任何集合之基數）；
且 `3 ∤ h21`、`3 ∤ χ` ⟹ **冇任何 CY₃ 整體量攜帶 3**。
