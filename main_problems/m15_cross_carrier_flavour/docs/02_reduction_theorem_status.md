## 前設問題

`O137 §一` 宣稱「A₅ 幾何對每模式供給之數據完全由 `n` 決定」⟹ `m = f(n)` ⟹ 幾何不能供質量標度。
`SESSION_START` 之 P1 問：**此歸約定理之適用範圍**為何？是否只及 `𝒜` 內算子？
（若只及 `𝒜`，則幾何路線未封死；若普遍成立，則 C1 由質量側徹底出局。）

## 事前判準（`docs/01` C1／C2）

- `C1`：清單若含 `n` 本身（或含任一對 `n` 單射之量）⟹ 定理對「由 `n` 計算之量」恆真 ⟹ **零鑑別力**。
- `C2`：取一**不在清單**之幾何量 `m_ρ(n)`（諧波之 A₅-irrep 重數），核其是否可由清單（剔除 ①）決定。

## 結論報告

### 一、清單之形式結構：**恆真**

`O137 §一` 之五項：① `n` 本身；② `parity(n)`；③ `block(n)`；④ `γ_n`；⑤ 活躍不變調和次數。

```
① 含 n 本身 ⟹ 任何由 n 定義之量 D 皆有 D = f_D(n) ⟹ ∀D : D = f(n) 恆真。
④ γ_n 對 n 單射（最小相鄰間隙 5.09577077949×10⁻³，n = 1..44）⟹ 僅 ④ 一項已經決定 n
   ⟹ ②／③／⑤ 對「決定 n」而言冗餘；清單整體冗餘。
```

⟹ **歸約定理之邏輯地位 = tautology**（與 M14 `docs/22` E3「恆真判 ⟹ 零檢定力」同型）。
其真正內容唔係「幾何冇第二自由度」，而係兩件**未證之前提**：

```
(i) 幾何之模式指標 ≡ 鏈之模指標（同一性）；
(ii) m = f(n) 之 f 低複雜度不存在（O137 §二 之屏障曲線：k ≤ 7 參數 ⟹ RMS ≥ 0.1657 dex；
     達標需 9 參數 = 點數 ⟹ 飽和）。
```

(ii) 係**維數論證**（9 點／9 參數必然飽和），唔係幾何必然 ⟹ 定理之名不副實。
(i) 係本輪新量出之 dof 缺口（下節）。

### 二、★ (i) 之 dof：模式同一性 `9! = 362880`

`O137 §五` 之受保護集 `P = {1,2,3,4,5,7,9,11,13}`（9 模式）由**諧波條件**定義，而質量式用**鏈** `γ_n`。
兩者共用符號 `n`，但無已註冊原則固定其配對 ⟹ 自由配對 `9! = 362,880` ⟹ **`dof > 0` ⟹ 違 A3**。
（`O137 §六` 自己在 Φ 矩陣上做過同一個 `9!` 全枚舉並報「最佳命中 1/9」——即同一 `9!` 歧義早已存在。）

⟹ **範圍**：任何以同一整數 `n` 索引兩套結構、而無典範雙射者，其預言皆不可裁決（`dof > 0`）。
此為本輪對 P1 之正面答案：**歸約定理唔止「唔封死」，而係「從未測過」——它冇內容可測。**

### 三、★ 新精確表：A₅ 諧波重數 `m_ρ(n)`（`n = 0..44`）

### 四、誘餌：正則表示之「3」
