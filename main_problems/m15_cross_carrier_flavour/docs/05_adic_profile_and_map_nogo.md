## 前設問題

P4：`O218`（`γ′_{2n} = γ_n`）能否給 `/88 ↔ /90` 之顯式映射？
（`SESSION_START` 之「跨載體接口之唯一已量化事實」。）

## 事前判準（`docs/01` C10／C11）

```
C10 保族判準：n ↦ mk 保族（γ_{mk}^{(x)} ≡ γ_k^{(x′)}) ⟺ m | x（x′ = x/m）。兩方向皆須精確核。
C10 唯一性：x = 90 之合格 m（x′ 偶、站數 ≥ 4）須唯一，否則 ℤ₃ 路線關閉。
C11 映射存在性：γ-級（精確有理）／仿射指標級（44×44 窮舉）／摺疊分層級，三層皆須 0 命中。
```

## 結論報告

### 一、C10 保族判準：`m | x`（精確）

```
m | x  ：4729 個 (x, m, k) 樣本（x = 6..200，m = 2..12）⟹ max|dev| < 10⁻⁴⁵（dps = 60 之機器零）
m ∤ x  ：同掃描 ⟹ 最小不可約偏差達 4.0（例 x=6, m=4, k=3，最近同族 x′=2）
⟹ 判準精確成立：**保族 ⟺ m | x**（推導：sin(mkπ/x) = sin(kπ/(x/m)) 要求 x/m ∈ ℤ）
```

### 二、★ adic 深度剖面（摺疊判準：環 `x ≡ 0 (mod 4)`；Dirichlet `x ≡ 2 (mod 4)`）

```
/88 環   2-adic：88 → 44 → 22                （3 層，2 步）
         3-adic：88                            （1 層；3 ∤ 88）
/90 Dir  2-adic：90 → 45                      （2 層，1 步）
         3-adic：90 → 30 → 10                 （3 層，2 步；30、10 皆偶，同型 Dirichlet）
/176 雙鏈 2-adic：176 → 88 → 44 → 22          （4 層，3 步）

深度剖面（2-adic 層數, 3-adic 層數）：
     /88 (3, 1)      /90 (2, 3)      /176 (4, 1)
```

★★ **觀察（本輪新）**：`/88` 與 `/90` 之剖面**互換** —— 「3」在 `/88` 出現於 **2-adic** 方向（88 = 2³·11），
在 `/90` 出現於 **3-adic** 方向（90 = 2·3²·5）。兩者皆 3，但**方向不同**。

⟹ 「3 = 下降層數」在兩載體皆成立（不同質數方向）⟹ **非判別量**（無法分辨「3 來自哪一載體」）。
⟹ `/176` 剖面為 (4,1) ⟹ 該值亦**非載體不變量**（若果係，雙鏈亦應給 3）。

### 三、C10 唯一性：`m = 3` 不唯一（盲測 B2 成立）

```
x = 90 之合格 m（m | 90、x′ = 90/m 偶、站數 x′/2 − 1 ≥ 4）：
     m = 3 ：x′ = 30，14 站，3-adic 層數 2
     m = 5 ：x′ = 18， 8 站，3-adic 層數 3
     m = 9 ：x′ = 10， 4 站，3-adic 層數 1
⟹ 合格集 = {3, 5, 9}（3 個）⟹ m = 3 由結構**不**唯一選出
```

⟹ `ℤ₃` 分級之非循環生路關閉（與 `docs/03 §四` 同結論，兩路獨立）。

### 四、C11 三層映射 no-go

```
(a) γ-級（精確）：
    γ^{(88)}_n = γ^{(90)}_{n′} ⟺ cos(nπ/44) = cos(n′π/45) ⟺ 45n = ±44n′ + 3960j
    配合 n, n′ ≤ 44 窮舉（j ∈ {−1,0,1}）⟹ **0 解**
    （手證：+ 支 |45n − 44n′| ≤ 3916 < 3960 ⟹ j = 0 ⟹ n = 44t, n′ = 45t ⟹ t = 0；
      − 支 45n + 44n′ = 3960 ⟹ n ≡ 0 (mod 44) ⟹ n = 44 ⟹ n′ = 45 出界）
    數值雙核（dps = 60，容差 1e−50）：命中對 = **0**
(b) 仿射指標級：σ(n) = (an + b) mod 44，a, b ∈ 0..43（1936 個）：
    對值 γ^{(88)}_n = γ^{(90)}_σ(n)          ⟹ 命中 **0**
    對補值 γ^{(88)}_n = 4 − γ^{(90)}_σ(n)    ⟹ 命中 **0**
(c) 摺疊分層級：2-adic 層數 /88 = 3 vs /90 = 2 ⟹ 分層雙射**不存在**
```

⟹ **範圍 = {γ-級, 仿射指標級, 摺疊分層級} 內，不存在 `/88 ↔ /90` 之顯式映射。**
（此 no-go 獨立於 M14 `docs/20 §六` 之「兩譜零交叉」——本輪加 (b)(c) 兩層並補 (a) 之手證。）

### 五、唯一跨載體關係 = **深度剖面互換**（對偶陳述，非映射）

```
(2-adic, 3-adic) = /88 (3,1)  ⟷  /90 (2,3)
各分量之和皆為 4 = B（數值相等，未證因果）
```

⟹ `O218`（`γ′_{2n} = γ_n`）只連 `/176 ↔ /88`（同 2-adic 族），**不**連 `/88 ↔ /90`。
（`/90` 屬 3-adic 族，與 2-adic 族無交集——此即 `docs/20` 之「兩譜不相交」之 adic 表述。）
