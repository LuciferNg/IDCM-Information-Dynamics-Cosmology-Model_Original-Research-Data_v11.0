# docs/09 — R9：𝒞 完備化第二輪（cluster／2β／三分裂／最優裂變）

> **腳本**：`scripts/10_channel_completion.py`（9 check：6 PASS ／ 3 FAIL）
> **數據**：`data/10_channel_completion.json`
> **前設**：`docs/07` §十 明示「合法集 134 係**上界**，尚有 cluster／雙 β／三分裂未含」。
> 本輪把該三類補齊，並把裂變由「對稱分割」升級為「**最優（含不對稱）分割**」。

## 一、真正要問的問題

R7 之 6 通道 𝒞 給出合法集 134 條、`A_max = 163`。但 R7 之裂變通道只算 `Z/2 + A/2`（對稱分割），
而真實裂變幾乎全為**不對稱**（如 ²³⁶U → ¹⁴¹Ba + ⁹²Kr）。若對稱分割 Q<0 而不對稱分割 Q>0，
則 R7 之判詞為**偽陽性**（把會衰變者判成永久）。故本輪之核心問題：

> **`A_max = 163` 係 𝒞 之極限，抑或「對稱分割」這個偷懶選擇之極限？**

答案（下節）：**後者**。`A_max` 由 163 直落 92。

## 五、兩項結構發現

### 5.1 通道之間有**蘊涵關係** ⟹ 不可假設「加一類 = 收縮 30%」

`ternary-α` 對基線**零殺傷**：凡有 α 通道者（Q_α>0），α-伴隨三分裂之 Q 必亦 >0
（多一個 α 之束縛能之差恆負）。故 `ternary-α ⊂ α` 之殺集 ⟹ **𝒞 之完備化有冗餘結構**。

同理 `cluster`：其累積邊際為 0（獵物已被 SF_opt 吃掉），但**獨立**殺傷力 28 條（20.6%）。
⟹ **「邊際收縮」係次序依賴量，不可用單一次序之數字去論證「每類 30%」**。
`docs/07` §五 之「每漏一類 ~30%」須改寫為：**獨立殺傷力 6%–23%，視通道而定；且通道集合非自由（有蘊涵）**。

### 5.2 裂變通道之正確形式係「最優分割」而非「對稱分割」

對稱分割對基線殺 0 條（§四 基線即含 SF_sym）；最優分割殺 **31** 條，並使 `A_max` 由 163 直落 **92**。
⟹ R7 之 `A_max = 163` **唔係 𝒞 之極限，係對稱分割之 artifact**。

物理上顯然：中重核之對稱裂變 Q 常 < 0（兩片皆遠離 β 穩定線），而不對稱分割可兩片皆近穩定線。

## 七、𝒞_v2 合法集之**結構**：每 A 恰一條

90 條分佈於 90 個相異 A 值，**每個 A 恰好一條**：

```
P = { 各 A 之 β 穩定同量異位素 }        A ∈ {1,…,92} \ {5, 8}
```

- A = 1…92 中**只缺 5 與 8**：A=5（⁵H／⁵He，n 通道開）、A=8（⁸Be，α 通道開）。
- `A_max = 92` 之成員 = **⁹²Zr（Z=40）**；A ≥ 93 起，該 A 之 β 穩定同量異位素**皆有通道開啟**（主要係 SF_opt）。
- 代表成員：`¹H ²H ³He ⁴He ⁶Li ⁷Li ⁹Be ¹⁰B … ⁵⁶Fe(Z=26) ⁶²Ni(Z=28) ⁶⁸Zn(Z=30) ⁹²Zr(Z=40)`。

⟹ 合法集之結構極簡：**「每個質量數留一條最穩定者」**。此係 𝒞_v2 之真正內容，
亦解釋為何 `A_max` 係 92 而非任意數：A ≥ 93 之 β 穩定者，其最優裂變 Q 已轉正。

## 八、結論

1. **𝒞 不完備之代價由「每類 30%」修正為「獨立殺傷力 6%–23%，且有蘊涵冗餘」**。
2. **合法集 136 → 90（−33.8%）**；`A_max` **163 → 92**，主因係 SF_opt（不對稱裂變）。
