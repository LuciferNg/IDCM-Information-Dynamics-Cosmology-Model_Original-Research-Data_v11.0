## §十 界限與誠實標記

- 只用 **6 類**能量通道；cluster 發射（²²³Ra→¹⁴C+²⁰⁹Pb 等）、雙 β、三分裂、同質異能（isomer）皆未含 ⟹ 合法集之 134 係**上界**。
- 對稱裂變只取 `Z/2 + A/2` 之單一分割；真自發裂變之最有利分割多為不對稱 ⟹ `Q_SF(sym)` 係**下界**，可能低估非法性。
- AME 表含 1230 條外推值（`#`）；本輪分兩段報（全表／實測），不以任一單段下最終判詞。
- 無 NUBASE2020 之半衰期標籤（IAEA 鏡像被 Cloudflare 阻），故「觀測穩定」未作獨立標籤 ⟹ 全部判詞只用 AME 質量，**不用任何 T½ 數據**。
- 原子質量 vs 核質量：β 通道用原子質量（電子消去）；α/p/n 通道已驗電子抵消（`q_alpha` 之 docstring）。
