## §二 H1 譜功能性 no-go（EXACT）

**論證結構**

1. `γ_n = 4sin²(πn/88)` 於 `n=1..44` 嚴格遞增 ⟹ 譜非簡併 ⟹ 任何守恆量若係「譜之函數」，必為 mode 佔用數之函數。
2. 量子數須組合性（張量積加法）⟹ `B = Σ c(n_i)`。
3. 問：`c(n)` 可以依 `γ_n` 嗎？

**已註冊指派**（O209 `docs/08` §三）：`Gen1 {9,11,13} = [dn, up, lp]` ⟹ **d = mode 9，u = mode 11**，e = mode 13。

```
p = {11,11,9}，n = {11,9,9}，要求 B(p) = B(n) = 1
2c(11) + c(9) = c(11) + 2c(9)  ⟹  c(11) = c(9) = 1/3（精確解）
```

若 `c(γ) = a + bγ`（仿射），則上式成 `b(γ₁₁ − γ₉) = 0`，而

```
γ₉ = 0.3989175182，γ₁₁ = 0.5857864376，γ₁₁ − γ₉ = 0.1868689195 ≠ 0  ⟹ b = 0
```

⟹ **譜內容對 B 之系數精確為 0**。再推廣：夸克六槽 `{1,2,4,7,9,11}` 之 `γ` 值**全相異**（6 個），要求 `g(γ_i)` 全等 ⟹ `g ≡ const` ⟹

```
B = (1/3)·N_q   （純計數，與 γ_n 完全無關）
```

同一結論對 O209 `docs/15` 之 u/d 指針對 (2,3) 亦成立（`γ₃ − γ₂ = 0.025349 ≠ 0`）。

**判詞**：`B` **唔可能**由 `K_chain` 本徵值導出 —— 呢個係 **no-go**（非「未找到」）。可導出者只有「佔用數分級」= Fock 空間結構。
