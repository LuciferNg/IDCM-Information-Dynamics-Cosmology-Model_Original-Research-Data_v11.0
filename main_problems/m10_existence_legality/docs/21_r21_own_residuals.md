## 一、P9（T2c）— **封閉：對本 M 判準之影響 = 0**

### 1.1 命題

`T2c` = 「面型（`B`）守恆之精確性」依賴「已註冊結構無規範動能項」。
過去記為「無承載／待上游」。本輪改以**可算命題**處理：若 𝒞 之全部通道 `ΔB = 0`，
則 `T2c` 之真假不改任何 `x(c)`，亦不改任何判詞。

### 1.2 逐通道重子數帳（`A = 100` 樣本）

| 通道 | 內容 | `ΔB` |
|:--|:--|:--:|
| β⁻ | `n → p e ν̄` | 0 |
| β⁺/EC | `p → n e⁺ ν` | 0 |
| α | `A → (A−4) + ⁴He` | 0 |
| p | `A → (A−1) + p` | 0 |
| n | `A → (A−1) + n` | 0 |
| cluster | `A → (A−A_c) + A_c` | 0 |
| SF_opt | `A → A₁ + A₂`（`A₁+A₂ = A`） | 0 |
| 2β⁻ | `A → A + 2e⁻ + 2ν̄` | 0 |
| 2β⁺/ECEC | `A → A + 2e⁺ + 2ν` | 0 |
| ternary-α | `A → (A−12) + 3α` | 0 |
| SF_sym | `A → 2(A/2)` | 0 |

**𝒞 之 11 通道 `ΔB` 集 = {0}** ⟹ 判準完全在 `B` 守恆子空間內運作。

### 1.3 `T2c` 之唯一足跡

| 項 | 狀態 |
|:--|:--|
| `P1`（`ΔB≠0` 速率 = 0） | **兩支皆不變**：零溫抑制 `1.19e-173`（`S_inst = 199.0856`）⟹ 速率實質為零 |
| `P2`（`B` 淨生成） | **唯一受影響**：若補規範動能項，需 `B−L = 1.7526e−09` |
| 判詞集 | `P = 90`、`S\P = 182`、`max_rel = 2.836e−4`、`Nat\P = 198` —— **與 `T2c` 無關** |

### 1.4 判

```
P9 = closed（對本 M 零影響）
T2c 只決定「ΔB≠0 通道之速率有無」（禁區①），而 𝒞 無此類通道 ⟹ 不入判準、不入 verdict。
殘留（不屬本 M）：P2 之 B−L 生成機制（外部接口）。
```

## 二、P7（W1）— 自能通道之**抑制因子結構檢定**（陰性）

### 2.1 問題

`W1` 之三條出路現況：`A` 算子缺失（結構封）；`B` 兩體上限約定閘（可逆）；
`C` 自能通道（∝q²）**號正確**但量級 `4.5804` vs 需求 `1.2667`（**3.62×** 超）。
若 `C` 要有出路，必須有 **`0.276548`** 之**結構性**抑制（零自由參數）。

### 2.2 事前登記（寫死於腳本 docstring，先於計算）

| 項 | 內容 |
|:--|:--|
| 目標 | `t = 1.2667 / 4.5804 = 0.276548` |
| 式族 `F`（單一比，不含乘積） | `γ_m/γ_n`（≤44）／`sin(πa/88)/sin(πb/88)`（≤43）／`k/88`／`1/k`（k≤880）／`φ^{±k}`／`Lucas、Fibonacci` 比 |
| 規模 | `|F| = 4538` |
| 判準 | 命中數 ≤ 零假設（500 隨機目標，seed 20261031）中位數 ⟹ **無結構信號** |

### 2.3 結果

| 窗 | 目標命中 | 零假設 median | 目標所處百分位 | 判 |
|:--|--:|--:|--:|:--|
| ±1% | **5** | 18（mean 19.22／p95 41） | **13%** | 低於隨機 ⟹ **無結構信號** |
| ±0.1% | **1** | 2 | **49%** | 與隨機無異 |

命中清單（±1%，僅列最近 5 條）：

| 式 | 值 | 偏 |
|:--|--:|--:|
| `sin7/sin31` | 0.276560 | +0.004% |
| `γ₁₅/γ₃₇` | 0.277338 | +0.286% |
| `γ₁₄/γ₃₂` | 0.277582 | +0.374% |
| `γ₉/γ₁₈` | 0.277694 | +0.415% |
| `sin4/sin15` | 0.278901 | +0.851% |

> `sin7/sin31` 落 ±0.1% 內，但**密度檢定陰性**：±0.1% 窗下隨機目標中位數 2 條，
> 即「有 1 條命中」係**預期之內**。依 φ-power 陷阱紀律，**不得**採納為結構式
> （除非另有獨立結構理由，且不得事後挑式）。

### 2.4 判

```
P7 = 結構面全封：
  A 無 em 算子（結構）
  B 兩體上限係約定閘（v1 不封／v2 封 0.184σ；可逆，槓桿在 M5）
  C 自能通道：號正確，但所需 0.276548 之抑制在事前登記式族內**無結構式**（密度檢定陰性）
  D γ 比值路線：兩支皆不足（9.79%／11.76%）
⟹ 除「新機制」（非本 M 式族所及）外，W1 無第四條出路。
```
