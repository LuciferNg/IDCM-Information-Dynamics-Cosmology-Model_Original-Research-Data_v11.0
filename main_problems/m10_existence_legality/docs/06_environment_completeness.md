## §二 三個機制（事前寫死，窮舉）

## §三 M1：²H 光致解離之臨界溫度（可對 BBN）

**判據（事前寫死）**：能量 > `Q_2H = 2.22456611 MeV` 之光子數密度 = 重子數密度

```
n_γ(>Q)/n_γ = f(y)，y = Q/kT，f(y) = ∫_y^∞ x²/(e^x−1)dx / (2ζ(3))
條件：f(y) = η_B
```

| 輸入 | y | T_D | 判 |
|:--|--:|--:|:--|
| η_B(IDCM) = 6.2116e−10 | 26.987 | **82.43 keV**（9.566e8 K） | — |
| η_B(Planck) = 6.10e−10 | 27.007 | 82.37 keV | 對 η 不敏感 |
| 標準 BBN 氘瓶頸 | — | ~70 keV | 比值 **1.178** |

**判詞**：判準（只用 `Q_2H` ＋ η_B）給出 82.43 keV，與標準 BBN 氘瓶頸同量級（差 +17.8%）。**量級命中，非精確預言** —— 判準只給能量帳，唔含反應率與核截面。

**真空／CMB 浴之不翻轉（定量）**：T = 2.7255 K ⟹ `y = 9.47e9` ⟹ `f ~ e^{−9.47e9}` ⟹ CMB 浴內 ²H 判詞與真空**完全相同**（`docs/01` §二 之「差 9.47e9×」於此得嚴格版本）。

## §四 M2：n 之合法化閾值（暴露 W3 之大小）

**判據**：`p + e⁻ → n + ν_e` 需 `μ_e ≥ Q_EC = m_n − m_p = 1.29333236 MeV`

```
極相對論簡併電子：n_e = μ_e³/(3π²(ħc)³)
μ_e = Q_EC ⟹ n_e = 9.5093e−9 fm⁻³ = 9.509e30 cm⁻³
⟹ ρ_th = 3.158e+07 g/cm³（Y_e = 0.5）
```

**對照觀測**（中子滴出）：

```
ρ_drip ≈ 4.0e11 g/cm³ ⟹ n_e = 1.204e−4 fm⁻³ ⟹ μ_e = 30.15 MeV
⟹ 缺口 = 30.15 − 1.293 = 28.85 MeV
```

**判詞**：

- 能量判準給出之 ρ_th 比實際中子化密度**低 4.10 dex**；
- 缺口 **28.85 MeV** = 核對稱能之量級，即 **W3（無核束縛／對稱能槽）之定量大小**；
- 與 W1 之 em 尺度（1.2494 MeV）差 **23×** ⟹ **核環境下判準不可用，且其失效尺度比 em 牆大一個數量級**。

⟹ 環境參數 μ_i **必然**把判準帶出 W1 之外、落入 W3：核物質環境唔係「微調」，係判準之空白區。

## §五 M3：磁場之結構不可見性

```
ħω_c = ħ·eB/m_e（SI，無 c）
B = 1e12 G ⟹ ħω_c = 11.577 keV
B = 1e15 G ⟹ ħω_c = 11.58 MeV
ħω_c = 0.78 MeV 需 B = 6.74e+13 G
ħω_c = Q(³H) = 18.6 keV 需 B = 1.61e+12 G
```

**判詞（結構性）**：β 通道之 `Q` 由**原子質量差**固定，磁場只量子化電子橫向模 ⟹ 對 sign 判準**零作用**。故依 D4（只用質量），**B ∉ ℰ**；B 只入速率（禁區①）。

磁星（1e15 G）之 `ħω_c = 11.58 MeV` 已達 MeV 級，會改變相空間與速率 —— 但唔會改變任何通道之質量差 ⟹ 判詞不變。此為**判準之優勢**（比速率模型穩健）亦是**其界限**（唔能講「幾快」）。

## §七 結論報告

1. ✅ **ℰ_min = (T, {μ_i})**：
   - `T` —— M1，只對 `x>0` 之通道**打開**閘，閾值 `f(Q/kT) = η_b/γ`；
   - `μ_i` —— M2，只對 `x>0` 之通道**封閉**閘，閾值 `μ ≥ Q`；
   - **B 不入 ℰ**（M3：不改質量差）。
2. ✅ **三機制互不蘊涵**（各有另一機制不可替代之通道）：M1 打開 ²H→pn（μ 無法）；M2 封閉 n→peν（T 無法）；M3 兩者皆不能。
3. ✅ **「永久」= ℰ 之邊界值**（T→0, μ_i→0）⟹ `docs/01` 之 D2 定義得證為邊界語句，非絕對屬性。
4. ✅ **M1 定量命中**：T_D = 82.43 keV vs BBN 氘瓶頸 ~70 keV（比值 1.178）。
5. 🔴 **M2 定量失效**：能量判準之 ρ_th 與實測差 4.10 dex，缺口 28.85 MeV = W3 之尺度。
6. 🆕 **³H = Tier III 實例**，且同一態之兩個通道分屬 Tier II／III ⟹ Tier 係通道屬性。
