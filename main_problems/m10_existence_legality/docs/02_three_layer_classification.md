## §三 層②「成面」：只有 t 失敗

判別量 `cτ / 1 fm`（強子化時間 ~ 1 fm/c = 3.336e−24 s）：

| 夸克 | cτ (fm) | 層②判 | 依據 |
|:--|--:|:--:|:--|
| t | **0.139** | ❌ 未及成面 | Γ_t = 1.42 GeV ⟹ τ = ħ/Γ = 4.64e−25 s |
| b | 4.55e+11 | ✅ 成面 | τ(B⁰) = 1.519e−12 s |
| c | 3.10e+11 | ✅ 成面 | τ(D⁺) = 1.033e−12 s |
| s | 2.68e+13 | ✅ 成面 | τ(K_S) = 0.8954e−10 s |
| d | 2.63e+26 | ✅ 成面 | τ_n = 878.4 s |

**判詞**：`t` 係**唯一**過唔到層②嘅夸克（衰變寬度 ≫ Λ_QCD，`cτ = 0.139 fm < 1 fm`）。`c`/`b`/`s` 全部成功成面（D、B、K 系皆為實測強子）⟹ 調律者原句「t c b s 並不能構成面型」**為偽**，須改為：

```
t      ：層②失敗（未及成面）+ 層③失敗
c b s  ：層②成功（有強子）  + 層③失敗（不永久）
```

此係**層之混淆**，非物理錯誤 —— 命題之結論（t c b s 不永久）不受影響，但機制描述須更正。

## §四 層③「永久」＝ 極值原理（最輕態定理）

**定理（本輪）**：`合法(C) ⟺ m_C 係 C 之通道閉包內之嚴格極小元`。

```
x(c) = m_C − Σm_f < 0  ∀c  ⟺  m_C < min{ Σm_f : c ∈ 𝒞(C) }
⟹ 「存在 vs 合法」之數學區分 = 「有槽」vs 「閉包內之嚴格極小元」
```

以數據質量表枚舉各超選擇類之最輕元：

| 類 (B,Q,L) | 最輕元 | 質量 (MeV) | 判 |
|:--|:--|--:|:--|
| (1,1,0) | **p** | 938.272088 | 合法（B=1,Q=1 最輕） |
| (1,0,0) | n | 939.565421 | 類內最輕，但可跨類衰變（n→p+e+ν）⟹ 不合法 |
| (0,±1,0) | **e** | 0.510999 | 合法 |
| (0,0,±1) | **ν** | 0 | 合法（ν 必須列入；原命題「唯二」漏 ν） |
| (0,0,0) | **γ** | 0 | 合法（真空係同類最輕，故一切有質量之 (0,0,0) 態皆不合法） |
| (2,1,0) | **²H** | 1875.612943 | 真空合法 |
| (2,2,0) | **⁴He** | 3727.379000 | 真空合法 |

⟹ 「唯二合法」之正確寫法：**基本（非複合）態 = {p, e, ν, γ}（四個，非兩個）**；複合態另有穩定族（核素圖上之穩定點），而 n 屬**條件合法**（環境層，`docs/01` §二）。

## §五 殺手：質子永久係「單一二進位輸入」

判準本身唔含結構。用 `x(n) = (m_d − m_u) − m_e`：

```
真實（m_u = 2.16 < m_d = 4.67）：X = +2.5100 MeV ⟹ n→peν x = +1.9990 > 0 ⟹ n 衰變、p 永久
互換（u/d 角色對調）           ：X' = −2.5100 MeV ⟹ p→neν x = +1.9990 > 0 ⟹ p 衰變、n 永久
```

**同一判準、同一譜結構、同一 γ 階梯，只換 O209 分配層 L5（塊內角色標籤，🔴 觀測輸入）**，永久者就由 p 變 n ⟹ 氫原子不存在 ⟹ 化學不存在。

即：

```
「為何只有 p 永久」 ⟺ 「為何 m_u < m_d」 ⟺ O209 L5 角色分配（觀測輸入，非結構）
```

## §七 結論報告

1. ✅ **重現閘 8/8**：`x` 表可獨立重建。
2. 🔴 **層之更正**：只有 `t` 過唔到層②；`c b s` 成面成功但仍不永久 ⟹ 原句須拆層。
3. ✅ **最輕態定理**：合法 ⟺ 通道閉包內之嚴格極小元（判準之唯一數學內容）。
4. ✅ **合法集之正確表述**：基本態 `{p, e, ν, γ}`（非「唯二」）；複合態另有穩定族；n 條件合法。
5. 🔴 **p 之永久性 = 單一二進位輸入**（`m_u < m_d`）：u/d 互換即令質子衰變、氫不存在；MC 顯示此判詞對誤差穩健（0.999958）但對結構零敏感，隨機質量空間中「p 永久」只佔 44.1%。
6. 🟡 **IDCM 側只餘比值層**：`γ₃/γ₂ = 2.24522`（z=+0.85，三對指針不唯一）；絕對層 dof=0（O120）。
