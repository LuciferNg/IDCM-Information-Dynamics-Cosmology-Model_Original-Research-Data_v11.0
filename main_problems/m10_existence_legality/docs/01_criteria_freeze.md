## §一 前設問題

調律者原句：

```
「p − n − e = uud − udd − e = x（合法存在），其中 x 必須是一個 range 以內，
  超過閥值就會衰變」
```

呢句同時承載兩件**互不相同**嘅事，而兩者混在同一個等號上：

| 成份 | 內容 | 數學歸屬 |
|:--|:--|:--|
| (α) 標籤帳 | `p − n − e = uud − udd − e` | 超選擇規則（荷守恆） |
| (β) 閾值泛函 | `x`，且 `x` 必須落 range | 能量／質量差 |

R1 之工作：**在任何推導之前**把兩者分離、寫死語義，並證明佢哋互不蘊涵。順序理由 —— 未凍結就掃描 = moving goalpost（§六 禁區③）。

四類皆存在 ⟹ 「閘」與「能量」互不蘊涵 ⟹ 合法 = **兩者之合取**。任何單閘都不可作判準。

## §四 原始輸出要點

**C1 帳目核（語法更正）**

```
字面式：Q(p) − Q(n) − Q(e) = (+1) − (0) − (−1) = +2  ≠ 0   ⟹ 🔴 不成立
正確帳：n → p + e⁻ + ν̄_e ：Δ(B,Q,L) = (0,0,0)            ⟹ ✅ 平衡
```

字面式差 **2 個電荷單位**。物理通道係 `n = p + e + ν̄`（唔係 `p − n − e`）。此為**語法錯，非語義錯** —— `x` 之定義（`m_i − Σm_f`）不變，只需改寫等式。

**C3 環境定量**：E_CMB,peak = k_B·2.7255 K = 2.349e−10 MeV；²H 光致解離門檻 2.2246 MeV ⟹ 需 T ≳ 2.582e10 K ⟹ 氘核在 CMB 浴內判詞不變，但「永久」一詞必須寫成「相對 ℰ」。

**C4 定理內容（唯一）**

```
設 (i) 能量守恆 exact、(ii) 譜離散、(iii) 𝒞(ℰ) 完備
則  永久(C) ⟺ ∀c∈𝒞: x(c) < 0
證明：x>0 ⟹ 相空間非零 ⟹ 躍遷可發生（除非被閘禁，已入 𝒞 之定義）；
      x<0 ⟹ 終態能量高於初態 ⟹ 能量守恆封死；x=0 ⟹ 零相空間 ⟹ 臨界。
```

**判準嘅全部非平凡內容落在 (𝒞, 譜) 兩件外部對象上**；判準本身只係「能量守恆之排序推論」。此結論直接決定 T1 之判詞（見 `docs/03` §五）。

- D1 之「𝒞 完備」係**假設**，不可證。本 M 只能列出已註冊之守恆荷（B, Q, L, 色單態）並註明「若有第五種守恆荷，判詞可能翻」。
