## §三 兩種精度需求必須分開（原診斷混用）

| 需求 | 定義 | 數值（中子通道） |
|:--|:--|:--|
| **判號精度**（sign） | 誤差 < 裕度（絕對級） | 4.17e−04（M 表示） |
| **辨識精度**（identity, δ★） | 密度池 coverage ≤ 1e−3 之反解 | F1 `4.0e−6`／F2 `2.0e−6`／F3 `6.0e−7`／F4 `8.1e−5`（M4 `docs/20` §四，四族） |

兩者語義完全不同：判號問「裕度內外」，辨識問「池中偶然率」。數值上只差 **5×** —— 呢個數量級巧合，正係原記錄混用兩欄而未被察覺嘅原因。

**★ 更關鍵：判號精度需求係「表示依賴」**

```
M 表示（先算 m_n、m_p 再相減）  ：需 ≤ 4.17e−04
X 表示（差值為本：X = m_u(γ₃/γ₂−1)）：需 ≤ 3.06e−01
⟹ M 表示嚴 734×
```

IDCM 之已註冊結構係**比值為本**（`m = M₀γ_n C_f`，質量差由 γ 比值一次乘法得出），即 X 表示 ⟹ **判號精度需求由 4.17e−04 降至 3.06e−01**。原診斷用 M 表示之數字，而 IDCM 從不用 M 表示。

> 「精度牆」唔係通道之不變量，係**表示選擇之產物**。

## §七 結論報告

1. 🔴 **原診斷被否證**：「中子為何穩定／不穩定係精度問題」在代數上唔成立 —— `x` 之 sign 由 **em 項主宰**（`em/|x| = 162%`），而 em 在 IDCM **無算子**；精度在 n 通道有 8.3× 裕度。
2. ✅ **「精度牆」係表示依賴**：M 表示需 4.17e−04，X 表示只需 3.06e−01（差 734×）。IDCM 用 X 表示 ⟹ 精度從未綁定。
3. 🔴 **真瓶頸 = W1**：`em(n)−em(p)` 所需 1.2667–1.3963 MeV 皆超 M5 v2 硬上限 1.2494 MeV（1.38%／11.76%）⟹ 中子臨界與 K 系同一道牆。
4. ✅ **六堵牆矩陣**：W1/W2/W3（概念）、W4（精度）、W5（dof=0）、W6（池密度）。無一通道只受 W4 限制。
5. ✅ **Tier 界定**：Tier I 恆真（無證據力）；Tier II 可判但需概念牆先開；Tier III（⁸Be 1.23e−5）永久不可判。

## §八 界限與誠實標記

- `A_max` 係 M5 **模型級**硬上限（含 `a_C`、`α`、`q`），非定理；M5 自身標記兩約定（weight）之數值待裁。本 doc 取 v2（`docs/27` 結構理由裁決）並同時報 v1（1.2718）之情形。
- `em` 之「無算子」係指 IDCM 已註冊結構內無；唔等於物理上不存在（QED 有）。
- 誤差預算用 `X = 2.56 ± 0.094`；若用 γ 比值路線則 `X = 2.6897`（無誤差帶，因 `m_u` 本身係輸入）。
- `δ★` 係 M4 以 log-uniform 目標池反解，其絕對值依賴池定義；本 doc 只用其量級。
- W6（池密度）只在「用 γ 池找公式」時綁定；判號問題不用池。
