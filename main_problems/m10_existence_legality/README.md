## 狀態: 🟡 部分閉合（判據 ✅、ℰ ✅、𝒞 ✅ 完備化、**兩獨立標籤檢定（⟸ 零反例）**、**失效機制已完全分類（D6）**；判詞 🔴 卡 W1/W2/W3/W5）

**問題**：**存在**（譜上有槽）≠ **合法**（永久存在）。合法 ⟺ 對所有可達通道 `x(C) = m_C − Σ m_f < 0` **∧** 面型守恆。

**本輪結論一句話**：判準成立，但**零判別力** —— 判準係「定義 ＋ 一條件理」，非平凡內容 100% 落喺（譜之質量值、超選擇閘）兩件 IDCM 皆未閉合之外部對象。

## 三條最重要結果（R1–R5）

1. **最輕態定理**：`合法(C) ⟺ m_C 係其通道閉包內之嚴格極小元`。⟹ 「存在 vs 合法」之數學區分 = 「有槽」vs 「極小元」。
2. **p 之永久性 = 單一二進位輸入**：`p 永久 ⟺ m_u < m_d`，而 u/d 之角色分配係 O209 L5（🔴 觀測輸入）。互換即令質子衰變、氫不存在。
3. **原診斷被否證**：「中子係精度問題」唔成立 —— `x(n)` 之 sign 由 **em 項**主宰（`em/|x| = 162%`），而 em 在 IDCM **無算子**；精度裕度 8.3× 充足。

## 為何「面型」關鍵

`p → π⁰ + e⁺`：`x = +802.78 MeV`（能量**足夠**）但永禁 —— 因為「3 夸克嘅面」唔可以變成「2 夸克面 ＋ 一個點」。⟹ 調律者之「面型」＝ **B 數守恆嘅幾何表述**，且比純能量判準**強**。
