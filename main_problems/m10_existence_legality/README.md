# M10 — 存在性 vs 合法性：threshold functional

## 狀態: 🔴 已註冊（只開不推）

**問題**：**存在**（譜上有槽）≠ **合法**（永久存在）。合法 ⟺ 對所有可達通道 `x(C) = m_C − Σ m_f < 0` **∧** 面型守恆（夸克數守恆）。

`t c b s` 及其他玻色子：**存在但不合法**（`x > 0` 於多條通道 ⟹ `Γ` ~ MeV–GeV ⟹ 存活 ~`1e−24 s`）。

## 為何「面型」關鍵（本 M 起手式）

`p → π⁰ + e⁺`：`x = +802.78 MeV`（能量**足夠**）但永禁 —— 因為「3 夸克嘅面」唔可以變成「2 夸克面 ＋ 一個點」。
⟹ 調律者之「面型」＝ **B 數守恆嘅幾何表述**，且比純能量判準**強**：它自動解釋質子穩定（唯一看似開放嘅通道被拓撲封死）。
