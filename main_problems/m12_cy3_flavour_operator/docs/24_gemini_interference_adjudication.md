## 二、G2 之可計算讀法（逐個核）

`a(k,x)` = 對荷；`δ_x = a(k_d,x) − a(k_u,x)`；`k_u=2, k_d=3, k_s=4`。
`T` = 鏈 adjacency（`T(i,j)=1 ⟺ |i−j|=1`，實測 `T(3,2)=1.0`、`T(x,x)=0.0`）。

| 讀法 | 定義 | 結果 | 判 |
|:--|:--|:--|:--|
| **R0** | `a(k,x) = ⟨k,x|T_c⊗I|k,x⟩ = T_c(k,k)` | **`δ ≡ 0`**（adjacency 無自環） | 🔴 恆等零 |
| **R1** | `a(k,x) = T_c(k,x)`（以 hopping 矩陣元作對荷） | `ρ_d = −1.0`（**z = −39.99**）、`ρ_u = +1.0`（**z = +31.16**） | 🔴 符號全反 |
| **R2** | `δ_x = ⟨3,x|T_c⊗I|2,x⟩ = T_c(3,2)` | `δ_u = δ_d = δ_s = 1.0` ⟹ **與 x 無關** | 🔴 與實測 2.5× 變動矛盾 |
| **R3** | `δ_x = ⟨3,x|T_c⊗D_t|2,x⟩ = T_c(3,2)·d(x)` | `δ_x ∝ d(x)` ⟹ 退化為任意譜函數；取 `d=γ` 得 `ρ_d = 0.56417703`（z +4.58）、`ρ_u = 0.25127883`（z +8.42） | 🔴 = R10 形狀族（已判零證據） |
| **R4** | `δ_x = ⟨3,x|T_c⊗T_t|2,x⟩ = T_c(3,2)·T_t(x,x)` | `T_t(x,x) = 0 ∀x`（任何圖 adjacency 皆無自環）⟹ **`δ ≡ 0`** | 🔴 恆等零 |

**R4 係「交叉干涉」之字面讀法**（兩個因子同時非對角）—— 而它恆等零：
同一個 `x` 上之雙 hopping 無自環 ⟹ **兩點交叉干涉在同 `x` 恆為零**。

⟹ **G2 之五個可算讀法全部判死。**

## 三、「拓撲代數空間」讀法 —— 已由 R3-P1 定理級排除

若把「拓撲代數空間」理解為 **CY₃ 幾何層**：R3-P1 已證（scoped 定理）

```
rank_ℚ(K^(1)) = 2 ,   char(K^(1)) = x³⁴(x² − 5) ,   非零譜 = ±√5
L2 獨立確認 C1：rank(K1)=2 ⟹ 非零特徵值僅 ±√5，|λ| = 2.2360679775
```

⟹ 幾何層**只供一個標度（√5），冇味結構** ⟹ 若「非對角干涉」發生在該層，則它**不能**產生味依賴之 `δ`。
（此即 R3-P1 之定理：CY₃ 幾何層對味係盲嘅。）

## 五、裁決

| 主張 | 裁決 | 理由 |
