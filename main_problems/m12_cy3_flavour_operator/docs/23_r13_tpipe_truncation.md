## 一、為何測截斷核（R12b 之直接後果）

R12b 把存活條件收窄為**兩條同時**成立：

1. **非平移不變** —— 否則 `ρ_u = −ρ_d` 恆等（實測偏 **15.5806×**）；
2. **短程差分比達 `2.4783`** —— Green 族只得 0.967–0.984（差 **2.5×**），需 `n=1→2` 有「崖」。

載體中**唯一已註冊**之「崖」= `T_pipe` 模式截斷：

```
n* = N_d − L_6 + 1 = 44 − 18 + 1 = 27        （L_6 = φ⁶+φ⁻⁶ = 18）
ker(T_pipe) = {n ≥ 28} = 17 模式              （F_proj = N_d − n* = 17）
f_proj = (57/2 − Σ_{1..26}γ)/γ_27             （使 E_proj 恰為 57/2）
```

本輪**不掃 `n*`**（掃即擬合）；`n* = 27` 由結構固定。
