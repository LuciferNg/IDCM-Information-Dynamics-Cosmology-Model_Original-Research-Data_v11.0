## 三、二體荷（S2）— δ 唯一解，無自由度

定義 `δ_x ≡ a(d,x) − a(u,x)`。光夸克八重態給

```
n−p    = δ_u + δ_d
Σ⁻−Σ⁰  = δ_d + δ_s
Ξ⁻−Ξ⁰  = 2 δ_s
```

三未知三方程 ⟹ **唯一解**：

| 量 | 值 (MeV) |
|:--|--:|
| `δ_u` | **−0.0887** |
| `δ_d` | **+1.3820** |
| `δ_s` | **+3.4250** |
| `δ_c`（由 `Σc⁰−Σc⁺` 解） | −0.2820 ± 0.283（與 0 相容 1.0σ） |

兩點結構事實：`δ_u < 0` 而 `δ_d, δ_s > 0` ⟹ **味對荷對夸克味非單調**；`δ_s/δ_d = 2.48` ⟹ s 旁觀者之效應大於 d 旁觀者 2.5 倍。

## 五、關鍵：δ 係「通道相依」而非味對常數（S2b）

把每個通道反解成 ansatz 下之 `δ`，若 ansatz 真則全部相等：

| 通道（J^P, 旁觀者） | `δ_s^eff` | 與基準差 |
|:--|--:|--:|
| `Ξ⁻−Ξ⁰`（1/2⁺, ss）錨 | +3.4250 | 0 |
| `Σ⁰−Σ⁺`（1/2⁺, s） | +3.3607 | **−0.0643**（0.29σ） |
| `Σ*⁻−Σ*⁰`（3/2⁺, s） | +2.1180 | −1.3070 |
| `Σ*⁰−Σ*⁺`（3/2⁺, s） | +0.9587 | −2.4663 |
| `Ξ*⁻−Ξ*⁰`（3/2⁺, ss） | +1.6000 | −1.8250 |
| `Σ⁻−Σ⁰`（1/2⁺, s）錨 `δ_d` | +1.3820 | — |
| `Σ*⁻−Σ*⁰`（3/2⁺, s）`δ_d` | +0.0750 | −1.3070 |

**這是最有訊息的一張表**：偏差**不是隨機**，而係結構性地集中於
1. **十重態 3/2⁺**（`δ_s^eff` 由 3.36 落到 0.96–2.12）；
2. **帶粲 Ξ 通道**（`Ξc⁰−Ξc⁺` 連符號都反：預言 −3.14，實測 **+2.73**）。

而 **1/2⁺ 八重態內部完全自洽**（`Σ⁰−Σ⁺` 與 `Ξ` 兩通道之 `δ_s` 差 0.29σ）。
⟹ 味對荷 ansatz 對 **1/2⁺ 基態**係一個良好描述；不足之處係 **「多一個標籤」**，唔係「全盤錯」。

同時注意：**自旋唔係唯一判別式** —— A2/A3（3/2⁺，單 s 旁觀者）通過（1.17σ／2.34σ），只有 A4（3/2⁺，**雙 s** 旁觀者）死。故失效與「兩個同性質旁觀者」相關，非單純 J。

## 六、介子扇區（S6）— 零約束，但一個交叉驗證

介子每型只有一個價對 ⟹ 對配對 ansatz **零約束**（5 個值 = 5 個獨立 δ，無方程可測）。只報值：

`K⁺−K⁰ = −3.9340`／`K*⁺−K*⁰ = −3.8800`／`D⁺−D⁰ = +4.8200`／`D*⁺−D*⁰ = +3.4100`／`B⁰−B⁺ = +0.3100`（皆 MeV）。

**交叉驗證**：`ρ_s ≡ |δ^{q q̄}_s| / |δ^{qq}_s| = 3.9340/3.4250 = 1.148613` —— 與 R4-P2 純由 `r` 比值推得之 `ρ = 1.148613` **逐位相同**（兩條完全獨立之路徑），確認 R4-P2 之 14.86% 破缺量無算術錯誤。

**但 `ρ_c` 不可判**：`δ_c = −0.282 ± 0.283` 與 0 相容 ⟹ 分母過零，`ρ_c = 17.09` 無統計意義。**不得引用為「charm 定向更強」之證據**。

## 七、本輪結論（範圍內事實，非裁決）

1. 一體荷：**3/4 通道判死，最高 93σ**（量級錯 3.7 倍）。
2. 二體荷：**7 條獨立樣本外檢定，5 通 2 死**；`δ` 三參數由三錨唯一解，無擬合自由度。
3. 失效**結構性集中**：3/2⁺ 十重態（A4）＋ 帶粲 Ξ（B2/C2）；1/2⁺ 八重態自洽（0.29σ）。
4. 介子扇區對本 ansatz **零約束力**（資訊論事實，非擬合問題）。
5. `ρ_s = 1.148613` 兩路徑逐位吻合；`ρ_c` 因 `δ_c ≈ 0` 而不可判。

**未裁決**：本記錄仍維持 `partial`。唔判「二體荷成立」亦唔判「二體荷死」—— 因為 5 通 2 死既非全滅亦非閉合，且失效模式有結構（可補標籤）。
