## 一、被檢對象

R7 收窄後唯一殘路：

```
Δm = （2 體對荷，單重旁觀者精確）⊕ C(f₁,f₂)
```

其中 `C` 係**兩個重旁觀者之成對相關能**，且必須滿足 R6/R7 實測之符號結構：

| 味對 | 所需符號 | 實測偏移 |
|:--|:--|--:|
| `(s,s)` | **負** | −3.65 MeV |
| `(s,c)` | **正** | +3.6 … +5.9 MeV |
| `(s,b)` | ≈ 0 | −0.22 MeV |

最自然之候選核 = IDCM 鏈之兩點函數 `C(f₁,f₂) = G(x_{f₁}, x_{f₂})`，`G = K_chain⁻¹`。

## 二、G1：44-site 鏈 Dirichlet Green 函數之符號普查

`G(x,y) = Σ_n φ_n(x)φ_n(y)/γ_n`，`φ_n(j) = √(2/45)·sin(πnj/45)`，`γ_n = 4sin²(πn/88)`。

| 量 | 值 |
|:--|--:|
| 元素總數 | 1936（44×44） |
| 正元素 | **1936** |
| 負元素 | **0** |
| 零元素 | 0 |
| 最小值 | +0.021245525（於 `(1,44)`，即最遠對） |
| 最大值 | +10.7558（近中點） |
| `G(22,23)` | +10.281548 |

⟹ **全正** ⟹ `G` 為 sign-definite ⟹ 任何 `C(f₁,f₂) = G(x₁,x₂)` 對**所有**味對同號 ⟹ **不可能**同時給出 `(s,s) < 0` 與 `(s,c) > 0` ⟹ **範疇判死 🔴**。

## 三、G2：為何必然全正（結構理由，非數值偶然）

- `γ_n > 0`（全 n），故 `1/γ_n` 加權全正；
- 對 Dirichlet 鏈，`G` 係離散 Laplacian 之逆 ⟹ **Stieltjes 型**、對稱正定，且以極值原理（maximum principle）逐點為正：`−ΔG = δ` 且邊界為零 ⟹ `G > 0` 於全部內點；
- 跨中點之 `G(1,44) = 0.0212 > 0` 亦正 ⟹ 連「長距離反相關」都唔存在。

⟹ 呢個正性係**定理級**，唔係此 44-site 之特別選擇；任何以 Dirichlet 鏈 Green 函數作相關能之方案同樣死。
