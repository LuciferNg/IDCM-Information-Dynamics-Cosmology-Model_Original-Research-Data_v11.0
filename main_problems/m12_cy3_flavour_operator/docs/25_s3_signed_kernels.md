### S3b 之結構變化（值得記）

staggered 核給的不是差型而是**和型**：

```
δ_x = (−1)^{3+x}G(3,x) − (−1)^{2+x}G(2,x) = (−1)^x·[ −G(3,x) − G(2,x) ]
```

⟹ `ρ_d` **變號**（`−1.0255633`）且幅度近 1 ⟹ 加號把 u／d 之差抹成對稱和。與目標（`+0.4035`）不但量差、**號亦反**。

### S3c 之真結果：唔係「數值不中」，係**核唔存在**

`γ_n = 4sin²(πn/88)`，`γ_44 = 4`（Nyquist）⟹ `4 − γ_44 = 0` ⟹ `1/(4−γ)` **於 n = 44 有極點** ⟹ `(4−K)` 奇異 ⟹ 該核非良定義。

並且更根本：**`4 − γ_n = γ_{44−n}` 為恆等** ⟹ 對偶核 = 同一個**正核之反向重標** ⟹ 它**本來就唔係帶號核**，只係 R11 之核換索引。故 S3c 既非新形式、又奇異 —— 不引入任何正則化（正則化即臨場造參數）。

**S3（帶號核）全數判死。** 三變體：一個量差 + 號反、一個結構奇異、一個符號全反。
