## 〇、先講張量載體為何**不**構成獨立測試（代數，非假設）

`K = K_chain ⊗ K_tree` 可分解 ⟹

```
G_tensor(i,j) = Σ_{n,ℓ} φ_n(i)φ_n(j)/(γ_n μ_ℓ)
              = (Σ_ℓ 1/μ_ℓ) · Σ_n φ_n(i)φ_n(j)/γ_n
              = const × G_chain(i,j)
```

樹因子係**共同常數**，在 `δ` 之比中精確相消 ⟹ 與 R11 之 P1 **逐位相同** ⟹ 退化，`N_trials` 不增。
（機制：`u`、`d` 只差**鏈指標**，唔差樹標籤；故任何只依賴鏈指標之差分，必對樹因子不敏感。）

故 R12 只剩兩條**真正獨立**協議。

## 一、載體（已註冊定義）

even-mode carry 檢查：`max|γ'_{2n} − γ_n^{(44)}| = 0.0` ⟹ **O218 遷移精確**（非近似）。

## 三、R12b — 四條精確陳述

### S1：平移不變（TI）核 ⟹ `ρ_u = −ρ_d` **恆等**

| 核 | `δ_u` | `δ_d` | `δ_u+δ_d` |
|:--|--:|--:|--:|
| `e^{−0.3n}` | −0.25918178 | 0.25918178 | **0.0** |
| `1/(1+n)²` | −0.75 | 0.75 | **0.0** |
| `cos(nπ/3)` | −0.5 | 0.5 | **0.0** |

實測 `|δ_u|/δ_d = 0.064182344`（`δ_u = −0.0887`、`δ_d = 1.3820`）。
TI 預言此比值 = 1 ⟹ **偏 15.5806 倍** ⟹ **任何 TI 核（不論形狀、載體大小、是否 PSD）判死。**

### S2：三個載體之 `ρ_d` 集中度（本腳本由譜重算）

| 載體 | `ρ_d` | z | 對目標偏離 |
|:--|--:|--:|--:|
| 44-site Dirichlet（R11） | 1.0340457 | +17.96 | 2.5627× |
| 88-site carry-by-2（R12 A1） | 1.0260233 | +17.74 | 2.5428× |
| 88-site direct（R12 A2） | 1.0162822 | +17.46 | 2.5186× |

三者極差 **1.718%** ⟹ **載體無關**。⟹ 失效係**族性質**，唔係「揀錯載體」。

### S3：單模 PSD 核之閉式（精確）

`f(n) = cos(nθ)` ⟹ `ρ_d = 1/(1+2cosθ)`，**最大偏差 7.2e−39**（`dps=40` 之捨入底噪）⟹ 精確。
範圍 `ρ_d ∈ (1/3, ∞)`。反解目標：`cosθ = 0.73914616` ⟹ `θ = 42.341267°`。

★ **陷阱警告**：`θ = π/4`（即 176-鏈之 Nyquist，`k = 44`）給

```
ρ_d = √2 − 1 = 0.4142135624     （目標 0.40350365 ⟹ 差 2.65%，z = +0.30）
```

**呢個係「命中」嘅假象**：同一個核同時強制 `ρ_u = −0.4142135624`，與實測 `−0.02588837` 相差 **15.6×**（`z ≈ −11.8`）⟹ **被 S1 範疇判死**。
教訓：只核 `ρ_d` 就會誤報命中；`ρ_u` 之存在正係用嚟殺呢類「漂亮但錯」嘅候選。

### S4：曲率診斷（**不是** no-go）

需 `1/ρ_d = 2.4782923`：

| 核 | `1/ρ_d` | 距目標 |
|:--|--:|--:|
| 44-site Dirichlet | 0.967075 | 2.5627× |
| 88-site carry-by-2 | 0.974637 | 2.5428× |
| 88-site direct | 0.983979 | 2.5186× |
| `e^{−0.3n}` | 0.740818 | `ρ_d = 1.34986` |
| `e^{−n²/4}` | 1.8577 | `ρ_d = 0.538301` |

⟹ Green 族之**短程結構不足 2.5 倍**；達標需 `n = 1→2` 有「崖」（單模 PSD 有，但 TI 已死）。
⟹ **不可**由此推出「必須帶號」——帶號性係 `S1` 之推論（TI 死），非 `S4` 之推論。
