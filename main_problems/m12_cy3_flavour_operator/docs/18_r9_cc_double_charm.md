## 一、為何 Ξcc 係關鍵

PDG 2024 `mass_width` 檔**不含 Ξcc**（MC-ID 未定），故 R5–R8 從未測過 (c,c) 扇區。LHCb 2026 首次完成 Ξcc 同位旋雙重態，提供 `Δm(Ξcc⁺⁺ − Ξcc⁺)`。

**計數慣例（明文）**：`Δm = Σ_(無序價對，計重數) a(f_i,f_j)`。
`Ξcc⁺⁺ = {u,c,c}` ⟹ 對 = `(u,c)×2 + (c,c)`；`Ξcc⁺ = {d,c,c}` ⟹ `(d,c)×2 + (c,c)`。
⟹ `Δm = 2[a(u,c) − a(d,c)] = −2δ_c`，**(c,c) 對精確相消**。

⟹ 此通道**不**探測重-重相關項；它係 `δ_c` 之**扇區普適性**檢定（δ_c 由 `Σc⁰−Σc⁺` 定，屬 (d,c)/(u,c) 單重扇區）。

## 四、三個結構後果

1. **(c,c) 扇區延續二體對荷**：`z = +1.18`（含 lifetime syst 更小）。二體對荷現時在
   `(u,d) / (d,s) / (u,s) / (d,c) / (u,c) / (s,b) / (c,c)` **七個重味組合**上成立，累計 **10 通道通**（R6 之 8 條 Σ-型 ＋ `Ξb` ＋ 本輪 `Ξcc`）。
2. **「雙重旁觀者必偏移」假設被判死**：`z = −3.37`。加上 R7-B2 之 `Ξb`（−5.78σ）⟹ 兩條獨立路線否定「旁觀者數目」解釋。
3. **失效集合收窄至 `{(s,s), (s,c)}`**：
   通 = `(u,d)`、`(d,s)`、`(u,s)`、`(d,c)`、`(u,c)`、`(s,b)`、`(c,c)`；
   死 = `(s,s)`（`Ξ*` −5.12σ）、`(s,c)`（`Ξc` +11.85σ、`Ξc′` +4.65σ、`Ξc(2645)` +8.14σ）。
   ⟹ 失效**只**出現於「`s` 與 `s` 或 `c` 共存之 Ξ-型」；`s` 與 `b` 共存（Ξb）**通**，`c` 與 `c` 共存（Ξcc）**通**。

## 五、對「仍存活」清單的影響

R7-B1 之「Ξc 家族常數 `+4.826`」曾係唯一可參數化之殘路；T2 以 **−3.37σ** 判死其扇區普適性 ⟹ 該常數若存在，亦只限於 `(s,c)` 扇區，**不能**作為統一修正項。

⟹ 現時**冇任何**參數化方案可以同時容納
`(s,s)` 負偏移、`(s,c)` 正偏移、`(s,b)`≈0、`(c,c)`≈0。

## 六、範圍聲明

- 本輪**只**測 (c,c) 一個通道（LHCb 僅此一個雙粲雙重態）；統計精度受 lifetime syst 主導（±1.3–1.9 MeV）。
- T1 之 `z = 1.18` 係「未否證」，**唔等於**證成；`(c,c)` 只測 `δ_c` 之普適性，**不**測重-重相關項。
- 依 O238 教訓，本輪不 close、不裁決。
