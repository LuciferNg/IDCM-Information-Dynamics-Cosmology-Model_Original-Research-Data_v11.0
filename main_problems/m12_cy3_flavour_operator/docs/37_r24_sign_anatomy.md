## 二、第五讀法：『−』係**配對之差**（區分）

恆等式（`docs/28`）：

```
δ_x = ⟨w, v_x⟩ ，  v_x(n) ≡ φ_n(k_x)·Δ_n ，  Δ_n ≡ φ_n(3) − φ_n(2)
ρ_u = ⟨w, v_u⟩ / ⟨w, v_s⟩
```

⟹ **數據之「−」= ⟨w,v_u⟩ < 0 而 ⟨w,v_s⟩ > 0** —— 同一個核，對兩個**不同**測試向量，配對異號。

### 精確幾何（測試向量之 Gram）

```
‖v_u‖ = ‖v_d‖ = 0.23570226 = √2/6    ；‖v_s‖ = 0.21081851 = (√2/6)·(2/√5)
cos(v_u, v_d) = −0.8       = −4/5        （143.13°）
cos(v_d, v_s) = −0.4472136 = −1/√5       （116.57°）
cos(v_u, v_s) = +0.2236068 = +1/(2√5)    （ 77.08°）
Gram 譜 = (0.00900666, 0.0378208, 0.108728)
```

⟹ 三個測試向量**既不平行亦不正交**，其互角係精確代數數（`−4/5`、`−1/√5`、`1/(2√5)`）。
**「−」即係 `w` 相對 `v_u` 之取向，而非 `w` 自身之任何性質。**
