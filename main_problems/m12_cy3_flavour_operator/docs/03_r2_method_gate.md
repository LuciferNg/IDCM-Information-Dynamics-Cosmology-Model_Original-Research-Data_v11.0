## 一、方法論釘死（使用者裁示，2026-10-28）

**不是找必要點，是找崩潰邊界。** 假設宇宙只有一個解 ⟹ 每條崩潰邊界 = 可行域的一條邊 ⟹ 解 = 全部「不崩潰」邊界之交疊點。

形式化（本文件採用）：

| 物件 | 數學身分 | 來源 |
|:--|:--|:--|
| 參數空間 | `ℝ^m`（`m` = 味型幅度數）| 味型分解（docs/02 §4.5、§十）|
| 錨通道 | **等式**（超平面）| 四錨觀測 |
| 崩潰邊界 | **半空間邊界**（不等式 `≥ 0`／排序）| 結構裁決 |
| 唯一解 | 交集為**點** | ⟺ 獨立等式 = `m−1` ∧ 另有一條結構邊界與該線交成點 |

**判準（本閘，R2 全程有效）**：

- **V1** 觀測（錨）只能把解收到**線**；收到**點**必須由結構邊界完成。若最終點位置依賴觀測 ⟹ 該點非預言。
- **V2** 每條邊界必須 **`t`-無關**（唔依賴自由參數之取值），否則只係重述擬合。
- **V3** 邊界判定須附 σ；`< 3σ` 之邊界**不得**用作裁決，只可作方向記錄。
- **V4** 位元預算：可共存標籤自由度數必須 ≥ 所需味位元數；不足即宣告「該載體不能承載味」，不許以參數補。
- **V5** 盲通道只用於**最終判**，不得用於釘點（用於釘點即耗盡預言力）。

## 二、錨系統之秩：解集係「線」

`scripts/04 H1`（精確 `Fraction` 高斯消元，變數序 `(a_uu, a_ud, a_us, a_ss, a_us̄)`）：

```
N(udd) : a_uu + a_ud              = ⟨O⟩_N − 1 = +0.1263
Σ(uds) :         a_ud + a_us      = ⟨O⟩_Σ − 1 = +0.9090
Ξ(uss) :                a_us+a_ss = ⟨O⟩_Ξ − 1 = +1.1719
K(u s̄) :                       a_us̄ = ⟨O⟩_K − 1 = +1.4213
```

**秩 = 4 / 5 ⟹ 零空間維度 = 1 ⟹ 1 維仿射解集（線）**，以 `t ≡ a_ss` 參數化：

```
a_us̄ = +1.421300      a_us = +1.171900 − t
a_ud = −0.262900 + t   a_uu = +0.389200 − t
```

⟹ **單靠觀測永遠得線。** 呢個就係「必要點法」失效之數學原因：必要條件只係把候選集合切細，唔會產生頂點。

## 四、真·`t`-無關之崩潰邊界：衰減核全族死（`scripts/04 H3`）

**代數**：`a_uu − a_us = a_N − a_S`（`a_ud` 相消）⟹ **與 `t` 完全無關**。

**結構**：已註冊模式指派 `u→2`、`s∈{4,5,7}`（O137→O209 d14→O233）。任何**衰減**徑向核 `k(d)`（`d(u,u) = 0 < d(u,s)`）：

```
k_uu ≥ k_us ⟹ a_uu ≥ a_us ⟹ ⟨O⟩_N ≥ ⟨O⟩_Σ
```

**實測**：`⟨O⟩_N − ⟨O⟩_Σ = −0.782700 ± 0.242811` ⟹ **z = −3.223**。

⟹ 🔴 **衰減核全族崩潰**（`k` 隨距離單調下降者一律死）：
`K_tree` 徑向族 `1/b^ℓ`、M5 `docs/02` 之 `B^(−d_tree)`、M5 `docs/03 §六.3` 之 `s_A s_B B^(−|ℓ_A−ℓ_B|)`（= docs/02 §九 之 T4）。

**唯一存活方向**：`k_us > k_uu` ⟹ 味耦合**隨味距遞增** ⟹ 味部分係「**荷**」型（label magnitude），唔係「距離衰減」型；度規只能定標度，唔能定味序。
⟹ M5 之 `Z₂` 標籤（`±1`）只給**號**、唔給**遞增幅度** ⟹ 標籤層亦不足。

遞增方向之可數邊界（`scripts/04 H3`）：

| 邊界 | 量 | 值 | σ |
|:--|:--|:--|:--|
| M1 | `Σ − N` | +0.7827 ± 0.2428 | **3.22σ** ✅ |
| M2 | `Ξ − Σ` | +0.2629 ± 0.1886 | 1.39σ 🔴 |
| M3 | `K − Ξ` | +0.2494 ± 0.1446 | 1.72σ 🔴 |

按 V3：**只有 M1 可作裁決**；M2／M3 僅作方向記錄。

## 五、局域容錯架構之硬算（`scripts/05`、`scripts/06`）

假設：宇宙係局域容錯架構 ⟹ (a) 局域穩定子必須**飽和**（每個缺陷面恰好 1 個缺陷）；(b) 標籤自由度不得增加缺陷密度；(c) 容錯**記憶**需非平凡同調。

**建構**（二十面體展開，零外部表；skill `polyhedral-graph-analysis §15(h)` 可靠構造）：
`V = 60`、`E = 120`、4-regular、邊角 `25.878637°` ✅

**F2 飽和族**：BFS from 60 roots，mod 全域翻轉去重 ⟹ **30 族員，全族缺陷數 32/32** ✅
⚠ 但**缺陷集唔唯一**：30 個族員給出 **30 個相異缺陷邊集**（全部大小 32）。此與 skill `polyhedral-graph-analysis §7b`「every trial returns the same 32 frustration edges」**不一致**，須回報更正（見 §七）。

**F3 對稱**：`|I| = 60`、60/60 保點集、可用 permutation 60 個；30 個族員在 `I` 下構成 **單一 orbit（大小 30）**。
⟹ 族員互為晶格對稱像 ⟹ 對任何 `I`-不變可觀測量，`30` 重簡併 ⟹ 標籤自由度係 **gauge**，非資訊。

**F4 拓撲**：RH 係球面上平面圖（`check_planarity = True`，62 面）⟹ 圈空間維度 `E−V+1 = 61 = F−1` ⟹ 面邊界生成整個圈空間 ⟹ `H₁(S²) = 0` ⟹ **Z₂ 標籤碼冇 logical qubit** ⟹ 球面上不可存邏輯資訊。`K_tree` 係樹 ⟹ `b₁ = 0`，同樣冇同調記憶。

**B2 位元預算（`scripts/06`）**：族內兩兩乘積 `c_i·c_j` 之缺陷數分佈

```
{64: 480, 72: 210, 88: 60, 96: 60, 104: 60, 120: 30}
飽和乘積 = 0 / 900
```

⟹ **冇任何第三個可共存之 Z₂ 頂點着色**：`c₁c₂` 飽和 ⟺ `c₂ = c₁` 或 `¬c₁`。
⟹ 局域容錯要求下，A₅ 頂點層只可供應 **1 個 bit**，且該 bit = 全域翻轉 = **gauge**。
⟹ 味**唔可以**係第二個 Z₂ 頂點着色（任何獨立着色令缺陷 ≥ 64 > 32 ⟹ 崩潰）。
