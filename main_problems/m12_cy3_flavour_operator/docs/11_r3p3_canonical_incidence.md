## 四、★ 殘餘範疇性要求（任何成功方案必須全中）

本輪把「要滿足什麼」壓成三條**不需數值即可檢**的要求：

1. **符號**：`r_K < 0`（−3.04），而重子三通道 `> 0`。
   ⚠ **即時自檢（本節寫後立核）**：`r_D = +3.7268`（D⁺−D⁰，介子）亦為**正**。
   ⟹ 故「重子 vs 介子」之 ℤ₂（奇／偶價組分數）**不足**：K（u s̄/d s̄）負而 D（c d̄/c ū）正，
   兩者皆介子 ⟹ 符號依賴**旁觀夸克之味**（s̄ vs d̄/ū），非價組分數之奇偶。
   ⟹ 任何以「2 vs 3 個組分」定符號之方案**已被數據排除**，毋須計算。
   ⟹ 須另尋有號結構（帶旁觀者味依賴之 ℤ₂ 或更強分級）。
2. **序**：`r_N(=1) < r_Σ(3.72) < r_Ξ(5.30)`，且增量**遞減**（`+2.72` 後 `+1.58`）。

3. **幅度**：三個數值須落 0.5%–3% 內（純分割比之 σ）。

**三條同時可檢、且皆不需擬合。** 任何候選若不滿足 (1)，即時出局，毋須計算。
