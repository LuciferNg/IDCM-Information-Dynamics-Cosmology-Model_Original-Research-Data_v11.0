## 六、更正（append 2026-10-28；§一–§五 原文不動，以本節為準）

🔴 **§一 之「普適數 2.5600 MeV = 普適預言」講錯，須撤回。**

回查 M11 得知：

```
X ≡ m_d − m_u = 2.56 ± 0.094 MeV   （FLAG 2024, Eq. (43)：4.70(5) − 2.14(8)）
E_ch ≡ Δm − coeff·X                （**定義式**，非獨立計算）
```

（`docs/01 §一`、`docs/09 §附帶溯源核對`、`scripts/01_r1_criteria.py:26`、`SESSION_START.md:9`）

故 `Δm − E_ch = ±2.5600` 之「普適性」係**定義使然**：`E_ch` 正是由 `Δm` 減去 `coeff·X` 得到。
⟹ 2.5600 **唔係** IDCM 預言，而係外部夸克質量差輸入；`⟨O⟩ = 強分割/X` 即「每單位夸克質量差之強矩陣元」。
⟹ §一 之「殘差」語言可保留（`⟨O⟩−1` 確係偏離自由組分基線 1 之 dressing），但**不得**稱 2.56 為結構常數。

**仍然成立而有用之兩點**：

- σ 來源分解（§二）不變：`n−p` 之 σ 97.5% 來自 em 錨 `0.4610`；但現已知 `E_ch` 之 σ 應 = `|coeff|·σ_X = 0.094`（各通道同值）⟹ 表中 `σ_E` 分別為 `0.0940/0.0962/0.1015/0.2318`，只有 n−p 與定義相符，**Σ 與 Ξ 之 `σ_E` 無來源**（Σ +8%、Ξ +147%）⟹ 發還 M11 之範圍擴大：不只 Ξ，Σ 亦須核。
- `⟨O⟩` 之**物理身份**確定：`⟨O⟩_ch = (∂M_h/∂X)·(1/coeff)`，即 isovector scalar charge。此引導 route (B) 之正確形式（見 `docs/07`）。
