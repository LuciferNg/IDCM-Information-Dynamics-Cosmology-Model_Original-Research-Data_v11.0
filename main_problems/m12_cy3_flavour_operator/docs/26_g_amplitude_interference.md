## 一、G 路線之定位（與 `docs/24` 之分界）

`docs/24` 已把「非對角干涉」之五個**矩陣元**讀法（R0–R4）判死。本輪測其**唯一未被覆蓋**之數學形式：

> **振幅之雙線性干涉叉項** —— 唔係矩陣元之差，亦唔係 `G` 之線性組合。

定義（先於計算）：

```
振幅   A(i,j) = Σ_n φ_n(i)φ_n(j) / √γ_n          （G = Σ φφ/γ ⟹ 對 G 係非線性）
G1     δ_x = C·2·A(k_d,x)·A(k_u,x)                （實振幅叉項）
G2     Ã(i,j) = Σ_n φ_n(i)φ_n(j)·e^{iθ_n}/√γ_n ，θ_n ≡ 2πn/88（環之自然相位，非自由參數）
       δ_x = C·2·Re[ Ã(k_d,x)·conj(Ã(k_u,x)) ]
```

**為何唔屬已殺族**：R10 係譜值之函數 `f(γ)`；R11–R13 係 `G` 之線性組合；G1／G2 係 `G^{1/2}` 之乘積 ⟹ **非線性**，未被覆蓋。

## 三、★ 兩個結構結論（比數值更重要）

### G1：符號障礙係**結構性**，唔係數值不巧

相鄰模式下振幅**全正**（`A(3,2) = 0.4866 > 0`）。故

```
δ_u = 2·A(3,2)·A(2,2) > 0    恆正
```

而實測 `δ_u = −0.0887 < 0`。**任何正振幅之實叉項必然給正 `δ_u`** ⟹ 與 R7-A1 同一個符號障礙：干涉型（平方量）天然正定，無法供給 `u` 之下移。範疇錯誤，非擬合不足。

### G2：相位只移動幅度，不動方向

加入環相位後 `ρ_d` 由 `2.864 → 1.688`（下降 41%），**但距目標仍 4.18×**。相位項做不到 `0.4035`，而 `ρ_u` 仍為正 `+1.3837`（目標負）。

⟹ 相位干涉可以「消一點」，但**方向（u 下移）根本由 `2|A|²` 之正定性鎖死**。

## 四、判定

**G 路線（振幅雙線性干涉，兩形式）全數判死。** 負控制仍判死 ⟹ pipeline 有效。

**Gemini 之想法至此已系統性窮盡**：矩陣元讀法（`docs/24` 五讀法）＋振幅干涉讀法（本輪兩形式）—— 共 7 個可算形式，全部判死。其餘（非張量分解之真交叉項）**無可算載體**，屬 S5。

## 五、對後續之意義

干涉型路線之死刑理由係**正定性**（同 R7-A1、同 R12b-S1 之 `ρ_u = −ρ_d`）：
凡「由正量組成之生成式」皆不能產出 `δ_u < 0`。

⟹ **任何新路線之第一道閘應改為「能否給出負 δ_u」**，成本遠低於跑完整比值。此為本輪之方法收穫（已寫入 `docs/27` 之閘）。
