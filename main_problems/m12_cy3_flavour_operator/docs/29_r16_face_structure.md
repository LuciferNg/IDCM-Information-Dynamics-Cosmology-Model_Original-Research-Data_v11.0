## 五、要救面型，需要什麼（精確缺口）

必須先註冊一個**非二部、帶 `±1` 阻挫耦合**之因子 `X`，使 `𝒯' = P₄₄ ⊗ X` 有非均勻曲率。
約束：`X ∉ {P₄₄, P₆₈}`（兩者皆二部）；且 `X` 須帶**味**（否則回到 `docs/10` 之 flavour-blind 困境）。

⟹ 此即 **S5（非加性關係型）之載體缺口**，現已被精確刻畫：**缺口 = 一個非二部、帶阻挫、帶味之第三因子**。
v11 中無此物件 ⟹ 不得臨場造（造即自由參數）。
