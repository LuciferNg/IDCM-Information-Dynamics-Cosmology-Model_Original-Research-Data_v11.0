## 一、測試設計

`docs/03` 已定：解集 = 1 維線（`t ≡ a_ss`）；衰減核已死；A₅ 頂點標籤只 1 bit 且係 gauge。剩下「荷型遞增」方向。

故把 `a(x,y)`（價對係數）之**所有零自由參數形式**逐個列出並硬算：

| 形式 | 定義 | 結構依據 |
|:--|:--|:--|
| F1 乘性荷 | `a(x,y) = w_x·w_y` | `γ_a γ_{44−a} = γ_{2a}` 之 rank-1 類比 |
| F2 加性荷 | `a(x,y) = c(γ_x + γ_y)` | 譜值線性相加 |
| F3 衰減距 | `a(x,y) = k(|Δn|)`，`k` 遞減 | `K_tree` 徑向族（對照組，已判死）|
| F4 環境計數 | `f(n_s) = α + β n_s` | 非二體；測「環境響應」能否釘點 |

literal 價對（D6）：重子 3 價 → 2 對、介子 2 價 → 1 對；`N(udd)` 取 `(u,d)(d,d)`；`Σ(uds)` 取 `(u,d)(u,s)`；`Ξ(uss)` 取 `(u,s)(s,s)`；`K(u s̄)` 取 `(u,s̄)`。

判定：解不出實數 / 違正性 / 與註冊質量序 `m_u < m_d < m_s` 相反 / 落於正性段 `[0.262900, 0.389200]` 之外 ⟹ 判死。

## 二、結果

**F1 乘性荷**：3 方程 3 未知，實解 2 個（互為全域負號）。正性解：

```
w_u = +1.282146   w_d = +0.091917   w_s = +0.617050      序：w_u > w_s > w_d
```

既不屬 `w_u < w_d < w_s`（`w ∝ m` 遞增），亦不屬 `w_u > w_d > w_s`（`w ∝ 1/m` 遞減）
⟹ 🔴 **與任何單調 `w(m)` 不相容**（方向約定無關）。rank-1 荷分解不可行。

**F2 加性荷**：精確分數解

```
X ≡ cγ_u = +0.357200    Y ≡ cγ_d = −0.076967    Z ≡ cγ_s = +0.271567
```

`γ_d < 0`（負質量）∧ `γ_s < γ_u`（與 `m_s > m_u` 相反）⟹ 🔴 **死**（兩條獨立死因）。

**F3 衰減距核**（對照）：`⟨O⟩_N − ⟨O⟩_Σ = −0.782700 ± 0.242811` ⟹ `z = −3.223` ⟹ 🔴 死（`t`-無關，見 `docs/03 §四`）。

**F4 環境線性**：由 `N(n_s=0)`、`Ξ(n_s=2)` 定 `α = +0.126300`、`β = +0.522800`；
預言 `Σ(n_s=1) = +0.649100` vs 實測 `+0.909000`（差 `+0.259900`）；
預言 `K = +0.649100` vs 實測 `+1.421300` ⟹ `z = +4.131` ⟹ 🔴 **介子與重子不可同碼**。
且 `β` 無結構來源 ⟹ 線性環境響應**不足以釘點**。

## 三、判詞

- 🔴 F1 乘性荷：實解序與任何單調 `w(m)` 不相容
- 🔴 F2 加性荷：`γ_d < 0` ∧ `γ_s < γ_u`
- 🔴 F3 衰減距核：3.22σ，`t`-無關
- 🔴 F4 環境線性：介子／重子 4.13σ 不可同碼，`β` 無來源

⟹ **二體（pair-sum）形式族空**；環境線性亦不足以釘點。
⟹ 與 `docs/03 §五` 之局域容錯圖像一致：`F̂` 必須係**多體（stabiliser 型，weight ≥ 3）**，作用於面／鄰域之積，而非價對之和。
