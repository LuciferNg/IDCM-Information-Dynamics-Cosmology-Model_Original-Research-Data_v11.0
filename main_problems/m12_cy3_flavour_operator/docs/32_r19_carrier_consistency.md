## 一、缺陷

R8–R14（`scripts/21`、`24`、`25`、`26`、`29`、`30`、`31`、`32`、`33`）用：

```
γ_n = 4 sin²(nπ/88)          ← 43 站 Dirichlet 之譜
φ_n(j) = √(2/45)·sin(nπj/45) ← 44 站 Dirichlet 之特徵向量
```

兩者**屬不同站數**：

```
φ_n(j) = √(2/(N+1))·sin(nπj/(N+1))  ⟹  K 之譜必為 4 sin²(nπ/(2(N+1)))
N = 44  ⟹  2(N+1) = 90  ⟹  譜 = 4 sin²(nπ/90) ≠ 4 sin²(nπ/88)
```

數值對照：

| | `γ₂` | `γ₃` | `γ₄` | `γ₄₄` |
|:--|--:|--:|--:|--:|
| `γ(/88)` | 0.020357116 | 0.045706268 | 0.081014053 | **4.0** |
| `γ(/90)` | 0.019463863 | 0.043704799 | 0.077476608 | **3.9951281** |

`K G = I` 對任何 `γ` 皆形式上成立（同一個 `γ` 分子分母相消，殘差 ~3e−30），
故**不能**用 `KG=I` 診斷 —— 唯一判據係「`φ` 之站數 ⟹ `γ` 之分母」。

**⟹ `scripts/34`–`40` 用 `/90`（一致，`N=44`）；`scripts/21`–`33` 用 `/88`（不一致）。**

## 四、為何十輪皆不受影響（結構理由）

`δ` 之比值對 `γ` 之**整體重標度**不敏感（同一個 `γ` 出現於分子分母）；`/88 → /90` 係一個近恆等之局部變形
（`sin(nπ/88)` vs `sin(nπ/90)`，於 `n ≪ 44` 時相對差 ~ (n/90)² 級）⟹ 只移動 `ρ` 之第三位。

而所有判死之 `|z|` 皆 ≳ 6（多數 > 10）⟹ 遠大於此擾動。

## 五、教訓（並入三閘）

```
閘 4（新）：載體自洽性須以「特徵向量之站數 ⟹ 譜之分母」核對，
           不得以 `K G = I` 或「數值合理」作判據（兩者皆對任何 γ 成立）。
           任何 `φ` 與 `γ` 來自不同站數者，一律視為未定義載體。
```

此缺陷係**靜默**（無例外、無 NaN、數值合理）—— 與 `scripts/34` 首版之漏報 `n=27` 同類：
**靜默數值漂移只能靠結構恆等式（此處：站數）抓，不能靠數值檢查抓。**
