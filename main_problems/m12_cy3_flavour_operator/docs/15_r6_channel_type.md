## 一、方法更正（S0，本輪最重要之技術修訂）

R5 之逐條 z 用「觀測 σ ⊕ 預言 σ」相加（假設獨立）。但本 ansatz 之**預言本身即質量之線性組合**，常與觀測**共用同一質量**——例如

- `δ_u` 內含 `Σ⁰`（因 `δ_d = (Σ⁻−Σ⁰) − δ_s`），而觀測 `Σ⁰−Σ⁺` 亦含 `Σ⁰`；
- `δ_c` 內含 `Σc⁺`，而觀測 `Σc⁺−Σc⁺⁺` 亦含 `Σc⁺`。

修正：一律以 `Form = {強子: Fraction 係數}` 表示預言與觀測，殘差 = `obs − pred`，`σ = √Σ(c_i σ_i)²`。
另：`scripts/19` 首版曾因此把 `Σc⁺−Σc⁺⁺` 誤判 `z = −3.64`（假死），改正後 **z = −1.78（通）**；舊版已備份為 `scripts/19_r6_channel_type.py.pre_patch_*`。

## 十一、附註更正（2026-10-29，R7 期間；原文不動）

**§七 T5 之「形式性判死（非統計性）」屬過度主張，撤回該強度。**

理由：`rank(M) < rank([M|b])` 係在**精確 Fraction** 算術下計算。觀測值本身係儀器測量（無理數級），任何線性關係都不會精確閉合，故 `rank([M|b]) = rank(M) + 1` **對任何非精確相依之數據必然成立** ⟹ 此陳述**無鑑別力**，不能作為「形式性判死」之依據。

真正的內容係**殘差大小**：`Ξ*⁻−Ξ*⁰` 殘差 `−3.65 ± 0.71`（z = −5.12），其餘關係在 1σ 內。故正確表述為：

> **「味對荷＋自旋盲」被 `Ξ*` 一通道以 5.12σ 統計性反例打擊**；非形式矛盾。

**判詞不變**（`Ξ*` 仍越界；R5/R6 之結論不受影響），僅依據由「rank 證書」改為「殘差」。同一更正適用於 `scripts/19` §T5 之輸出標籤，及 `docs/16 §六` 對 C1 rank 之處理（該處已改以「共線通道對之實測差分」為主證，rank 僅作定位）。
