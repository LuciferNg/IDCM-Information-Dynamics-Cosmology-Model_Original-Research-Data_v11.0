```
G_tensor(i,j; α,β) = G_chain(i,j) · G_factor(α,β)
δ_x = Σ_β G_factor(β,β) · [G_chain(3,x) − G_chain(2,x)]  ⟹  因子係公因數，於比值相消
```

## 五、結論與精確缺口

要令結構影響 `δ`，耦合必須**非 Kronecker-可分解**：

```
K(a,α; b,β) ≠ K_chain(a,b) · K_factor(α,β)
```

即 **S5 之真交叉項**。而 v11 之內：
- `docs/28` §五：條目缺口 = 缺一條已註冊 `f`；
- `docs/29` §五：幾何缺口 = 缺非二部帶阻挫因子；
- 本輪補上**第三條互相獨立之阻塞**：即使補到該因子，只要耦合仍可分離，仍然零貢獻。

⟹ 三輪（R15／R16／R18）從三個不同角度指向**同一個**缺口：**需要一個不可分離（non-factorizable）之耦合算子**。
此物件在 v11 **不存在**，且不得臨場造（造即自由參數）。
