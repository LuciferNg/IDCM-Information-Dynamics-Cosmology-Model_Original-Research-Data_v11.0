## 一、⟨O⟩ 之物理身份（由 docs/06 §六 定）

```
X ≡ m_d − m_u = 2.56 ± 0.094 MeV（FLAG24 Eq.43，外部輸入）
E_ch ≡ Δm − coeff·X（定義式）        ⟹ ⟨O⟩_ch = (Δm − em)/X = (∂M_h/∂X)/coeff
```

即 `⟨O⟩` = **isovector scalar charge**（每單位夸克質量差之強矩陣元）。自由組分基線 = 1，`⟨O⟩−1` = dressing。

## 二、type 計數（精確枚舉）

8 條通道（四錨 + π⁰ Dashen + 三盲）之價對展開：

- 夸克–夸克 type（6）：`dd, ds, du, ss, su, uu`
- 夸克–反夸克 type（7）：`Dc, Dd, Du, Sd, Su, Uc, Uu`
- **相異 type 總數 = 13**

| 量 | 值 |
|:--|--:|
| 方程數（全解盲）| 8 |
| 未知 type 數 | 13 |
| **欠定** | **5** |
| 只用四錨 | 欠定 **9** |

⟹ 🔴 **即使把三條盲通道全部解盲，仍欠 5 個方程。** 現有 8 通道下，二體框架**結構上不可辨識**。

## 三、可閉合性：兩類新通道之分野（本節係關鍵）

- (a) **新增重味**（`b d̄`/`b ū`）：方程 +1、type +2 ⟹ 欠定**增大**。此路不通。
- (b) **同味多重態**（Δ, Σ*, Ξ*, ρ, K*, D*）：只重用既有 type ⟹ 方程增、type 不增。

實算 9 條同味多態通道，**全部 0 個新 type**：

| 通道 | 用 type | 新 type |
|:--|--:|--:|
| Δ⁻−Δ⁰ ／ Δ⁰−Δ⁺ ／ Δ⁺−Δ⁺⁺ | 2 / 3 / 2 | **0 / 0 / 0** |
| Σ*⁻−Σ*⁰ ／ Σ*⁰−Σ*⁺ | 4 / 3 | **0 / 0** |
| Ξ*⁻−Ξ*⁰ | 3 | **0** |
| ρ⁻−ρ⁰ ／ K*⁺−K*⁰ ／ D*⁺−D*⁰ | 2 / 2 / 2 | **0 / 0 / 0** |

```
擴充後：type = 13，方程 = 8 + 9 = 17 ⟹ 超定 4
```

⟹ ✅ **框架可閉合且變為可檢定**（4 個獨立一致性條件）。缺口 5 由 6 條多態補足有餘。

## 四、唯一能減 type 之對稱：isospin

合併 `u↔d` 可把 13 降至 ~8 type，但 isospin 對稱 ⟹ 一切 isospin 分割 ≡ 0 ⟹ `⟨O⟩ ≡ 1`。
實測 `|⟨O⟩−1| = 0.1263 / 0.9090 / 1.1719 / 1.4213`（`z = 0.68 / 5.77 / 11.29 / 14.11`）⟹ 該極限被 3/4 錨以 ≥5.8σ 排除。
⟹ 🔴 **不可用 isospin 減 type**（兩難：不對稱 ⟹ 欠定 5；對稱 ⟹ 訊號歸零）。

要令二體框架至少**可檢定**（即使仍非零參數），需 6 條以上同味多態 isospin 分割，各自之 em 分解須達 `σ_em ≲ 0.03 MeV`：
