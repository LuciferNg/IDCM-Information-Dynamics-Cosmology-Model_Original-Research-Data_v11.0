# M12 docs/01 — 問題陳述：CY₃ 投影層之 flavour index（route A）

> 本檔係 M12 之**問題陳述與預註冊判準**，非結果。開推前不得改 §四（判準）。
> 來源：M11 `docs/10`（G0 判死）、`docs/11`（路線 C 判死）；M7 `docs/12`／`docs/15`／`docs/27`

## 一、問題

`⟨O⟩_ch`（強 IB 係數）是 M11／M4 之 em 通道分析中唯一未閉合之對象。M11 已證它在 v11 現有結構內**八處封閉**（`01_problem_record §四`）。剩下唯一未試之載體 = **CY₃／K_tree 投影層**。

問題：**定義於 CY₃ 投影層之 flavour index 算子 `F̂` 是否存在，並零參數給出 `⟨O⟩_ch`？**

## 三、為何 A 係唯一未封閉之載體

碳在 `{質量參數、電荷 sector pin、chain 指標、鏈模、常數族、算子槽位、2 向量總量}` 全部封閉（八處，見 `01_problem_record §四`）。而 IDCM 許諾 SM flavour 數據（質量譜、CKM／PMNS）住在 CY₃ 投影（O140 系列）⟹ 投影層係唯一未被證偽之所在。

**但**：M7 `docs/27` 已指出「缺『標籤層 → 譜量』之橋」；本記錄之工作**正是造此橋**，而唔係再掃式。

## 四、預註冊判準（寫死，開推前不可改）

- **G1 錨**：4 錨（`n−p`、`Σ⁻−Σ⁰`、`Ξ⁻−Ξ⁰`、`K⁺−K⁰`）+ `π = 0` 全部 `|z| ≤ 2`。
- **G2 盲測**：3 條 out-of-sample（`Σ⁰−Σ⁺`、`Σ⁻−Σ⁺`、`D⁺−D⁰`）`|z| ≤ 2`；**且**兩條符號反轉通道（`K⁺−K⁰` 需 em `+2.26 MeV`、`Σ⁰−Σ⁺` 需 `+0.71 MeV`）之符號須**自動**正確（不得事後調）。
- **G3 定性**：三特徵全中（§二）。
- **G4 剛性**：算子不得含可調參數；任何標度須追至已註冊常數（`K_chain γ_n`、`K_tree`、`N_d=88`、`Σγ=90`、`M₀`、`φ`-階梯、A₅）。
- **G5 加性岔路**：若 `F̂` 給出 `⟨O⟩ ≡ 1`，須明文宣告「強子層加性成立、與四錨衝突」並收負；**不得**以調參迴避。
- 判定：`G1∧G2∧G3∧G4` ⟹ 🟢；任一 `|z| ≥ 3` ⟹ 🔴 `F̂` 該形式死；`G5` 觸發 ⟹ 記錄 (i) 分支負結果並回報 M2／M7。

## 五、R1 計劃（第一步，不談數值吻合）

1. **定義域**（R1-Q1）：CY₃ 上 flavour 可為何種對象 —— 候選：(a) `d_tensor` 標號、(b) 週期／同調類 `H^{1,1}`（`h11=36`、`h21=98`，O211 已零輸入得出）、(c) `K_tree` 節點標籤之投影值。逐項寫出，檢「是否 well-defined 且可算」。
2. **加性岔路**（R1-Q2）：在量子力學層檢「質量泛函是否對構成子加性」—— 若模型含三體束縛或投影非線性，加性即失效；須給出可算之判據。
3. **`n_s` 之幾何候選**（R1-Q3）：由 `1.126 → 1.909 → 2.172` 反推所需斜率，檢查 `h11=36`／`h21=98`／`N_d=88`／`Σγ=90` 等已註冊量能否**事前**給出（禁止事後凑）。
4. 產物：`docs/02`（定義域 + 加性判斷 + 幾何候選表），**不出數值預言**。
