## C. ★★ 定理：奇宇稱 ⟹ `ρ_u = −ρ_d`（精確）

設 `w_{45−n} = −w_n`。則

```
G(i,j) = Σ_n w_n φ_n(i)φ_n(j)
       = ½ Σ_n [ w_n φ_n(i)φ_n(j) + w_{45−n} φ_{45−n}(i) φ_{45−n}(j) ]
       = ½ Σ_n w_n φ_n(i)φ_n(j) [ 1 − (−1)^{i+j} ]
```

⟹ **`G(i,j) = 0` 當 `i + j` 為偶**。於是

```
δ_s ∝ G(3,4) − G(2,4) = G(3,4) − 0            （3+4 奇、2+4 偶）
δ_d ∝ G(3,3) − G(2,3) = 0 − G(2,3)            （3+3 偶、2+3 奇）
δ_u ∝ G(3,2) − G(2,2) = G(3,2) − 0            （3+2 奇、2+2 偶）
且 G 對稱 ⟹ G(2,3) = G(3,2)
⟹ ρ_d = −G(2,3)/G(3,4) ，  ρ_u = +G(3,2)/G(3,4) = −ρ_d      **精確**
```

`P−` 之實測 `±28/41` 精確印證。

⟹ **「奇宇稱」與「鏡像」係同一件事** —— `docs/37` 之 A2 唔係獨立假設，而係任何 ℤ₂-odd 結構之**必然後果**。
⟹ 數據 `ρ_u = −0.0259 ≠ −ρ_d = −0.4035`（偏 **15.5863 倍**）⟹ **核必須有 `i+j` 為偶之成份 ⟹ 非奇宇稱**。
⟹ **「−」不可能係宇稱本徵值。**
