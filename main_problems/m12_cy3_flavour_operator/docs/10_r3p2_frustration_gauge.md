## 二、★ 主結果：`A_s ≡ S A S`（規範恆等）⟹ 譜與無符號 `A` 完全相同

由 BFS 2-色 `c` 定 `s_i = (−1)^{c_i}`、`S = diag(s)`、`J_ij = −1`（滿足）`/+1`（阻挫）：

```
A_s[i,j] = A[i,j]·J[i,j],   J[i,j] = s_i s_j  （恆等）
⟹ A_s = S A S        實測 max|SAS − A_s| = 0.0（精確 0）
⟹ spec(A_s) = spec(A)  實測兩譜逐位相同
```

| 項 | 值 |
|:--|:--|
| 阻挫邊 | 32 |
| 滿足邊 | 88 |
| Ising `H` | `−88 + 32 = −56` |
| `rank_ℚ(A_s) = rank_ℚ(A)` | 54 / 60 ⟹ **nullity = 6** |

**⟹ 定理（平凡但關鍵）：任何由 2-色所簽之「阻挫算子」皆係 `A` 之么正相似 ⟹ 零新資訊。**
**故「阻挫應力算子之譜」此路作廢** —— 同 R2 之 A₅ 頂點標籤（gauge）同類。

## 五、診斷：真正缺嘅唔係算子，係「入射規則」

| 載體 | 缺什麼 |
