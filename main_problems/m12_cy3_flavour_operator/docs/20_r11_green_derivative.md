## 一、結構動機（先於計算）

1. **可分離性排除**（代數，不依賴任何形式）：若對荷 `a(k,x)` 可分離（`f(k)+g(x)` 或 `f(k)g(x)`），則 `δ_x = a(3,x) − a(2,x)` 與 `x` 無關。實測 `δ_d : δ_s : δ_b = 1.382 : 3.425 : 1.893`（變動 2.5×）⟹ **可分離全死**。
2. 故 `a` 非可分離 ⟹ `δ_x` 係 `a` 對**模式指標之有限差分**，即 `δ = ⟨∂_k a⟩`。
3. 載體唯一提供之兩點關聯子 = `K_chain⁻¹`（44-site Dirichlet Green）⟹ 最簡先驗形式：

```
P1:  δ_x = C·[ G(3, k_x) − G(2, k_x) ] ,    G = K_chain⁻¹
```

`C` 在比值中相消 ⟹ `ρ_x` 係**零參數**預言。`N_trials = 2`（P1 主協議 ＋ P2 負控制）。
