## 二、A1：sign-definite 譜映射族 —— 範疇判死

任何 `δ_x/δ_s = f(k_x)/f(k_s)` 且 `f` 在全部 `k` 上定號（`γ`、`1/γ`、`√γ`、`γ²`、`4−γ`、任何正核）⟹ 三個 ρ 必**同號**。實測異號（`ρ_u < 0 < ρ_d, ρ_b`）⟹ **整個 sign-definite 族範疇性出局，不必掃描**。

⟹ 可行映射必須**帶符號**（例如 `f(k) = γ_k − γ_ref`、`±` 依 mode parity/chirality，或 inherently signed 之干涉項）。此為範疇限制，非數值失敗。

## 四、B1：Ξc 家族偏移是否為常數

（偏移 = 觀測 − 純配對荷預言）

| 態 | 偏移 (MeV) | z vs 0 |
|:--|--:|--:|
| `Ξc`（1/2⁺, `J_light=0`） | +5.873 ± 0.496 | +11.85 |
| `Ξc′`（2578, 1/2⁺, `J_light=1`） | +3.643 ± 0.784 | +4.65 |

⟹ 「家族常數」**僅邊緣可存 🟡**：三個偏移並非同一值，但亦未達 3σ 判死。若引入，即 1 個額外常數。

## 五、B2：`Ξb` 反駁「Ξ-型必偏」

若 Ξ-型（雙重旁觀者）之偏移確係上述家族常數 `+4.826`，則

`Ξb⁻−Ξb⁰` 預言 = `5.318 + 4.826 = 10.145`，實測 `+5.100`

⟹ 殘差 `−5.045 ± 0.872`，**z = −5.78 ⟹ 判死 🔴**。

⟹ 「雙重旁觀者必有正偏移」**被 `Ξb` 以 5.8σ 否定**。同時 `Ξb` 對純配對荷只有 `z = −0.27`（R6）。
⟹ 失效**唔係**「旁觀者數目」嘅普適效應，而係**隨重味組合而異**：`(s,s)` 負、`(s,c)` 正、`(s,b)` ≈ 0。

⟹ 下一步若要繼續，唯一有結構支撐嘅靶係：**`Ξ`-型通道之偏離是否等於兩個重夸克之成對相關能（可自 `88`-site 核之兩點函數算出）**。呢個係可盲測嘅：先由核算出 `C(s,s) : C(s,c) : C(s,b)`，再比 `−3.65 : +4.8 : ≈0`（符號本身即為判別 —— 若核給全正，即死）。
