## 三、值得記之兩個側面

### ① 部分 `f` 給出**精確代數值**（結構性，但與數據無關）

- `f4 = γ`（即核 = `K` 本身）：`ρ_d = −3`、`ρ_u = +3` **精確整數**。
  核實：`δ_d = K(3,3) − K(2,3) = 2 − (−1) = 3`、`δ_u = −1 − 2 = −3`、`δ_s = −1 − 0 = −1` ⟹ 比值 −3／+3。
- `f5 = γ(4−γ)`：`ρ_d = +2`、`ρ_u = −2` **精確整數**。
- `f1 = 1/(γ+μ²)`：`ρ_d = 3.7320508` 恰為 `2 + √3`（`√3` 之小數值不另列，見 log）。

⟹ 呢啲係**真結構值**（非巧合擬合），但全部落在數據之外（`|z| ≳ 45`）。可作反向定位：數據要求之 `ρ_d = 0.4035` 遠離所有「乾淨」結構值。

### ② `f2`（ρ 質量傳播子）最差

`ρ_d = 9.899`、`ρ_u = −9.898` —— 兩個比值幾乎等大反號，即 `δ_u ≈ −δ_d`（**TI 極限**）。
與 `R12b-S1`（`ρ_u ≡ −ρ_d`，偏 15.5806×）一致：大質量極限把核推向平移不變。

## 四、判定

**方向①在「已註冊 `f`」清單內無解（0/5）。**
配合 `docs/28` 之零約束結果，得：

```
類別層：無約束（任何 w 皆可行）⟹ 唔可以用「核族」閉合
函數層：已註冊 f 全部失敗（5/5 + 前七輪）⟹ 唔可以用「現有 f」閉合
⟹ 缺口精確化為：**需要一條新結構規則，且該規則須有 T0 來歷（非擬合）**
```

**不得**由「某個 `w` 能重現數據」（`docs/28` 之見證）反推該 `w` 有結構意義 —— 見證係數據反解，`maximin` 解不唯一。

## 五、下一步之必要條件（供後續 `f` 候選篩選）

任何新 `f` 必須先過三閘（`docs/26`／`27`／`28`）：
1. `δ_u < 0`（符號）
2. 不令 `|δ_x|` 趨同（分裂方向）
3. 判死範圍須標明（單一 `w`／有限集／族）

再加本輪之第四條件：**`f` 須在 charter／register 內有名，不得為本輪發明**。
