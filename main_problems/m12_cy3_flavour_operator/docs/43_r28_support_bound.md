## 〇 起點：R23 一個未解釋的事實

R23（`docs/36`）之 ℤ₄ 扇區核 `S5`／`S6` 之 `ρ_u` = `0.50016813`／`0.49475809`，即 ≈ **1/2**。

## 一 單模（局部）核：定理

模式 `n` 之站點分量 `φ_n(j) = √(2/45)·sin(πnj/45)`。單模核 `w = c·φ_n`（任何 `c ≠ 0` 皆同值 ⟹ 零參數）：

```
ρ_u(n) = φ_n(2)/φ_n(4) = sin(2x)/sin(4x) = 1/(2cos 2x),      x = πn/45
|ρ_u(n)| = 1/|2cos(2πn/45)|  ≥  1/(2cos(π/45)) = 0.501220949041
```

- 恆等逐 `n` 偏差：`> 1e−40` 之個數 = **0**（`dps = 50`）
- 實測 `min |ρ_u(n)| = 0.501220949041`（`n = 22`；`23` 對稱同值）
- 目標 `|ρ_u| = 0.02588837` ⟹ 單模最小者仍差 **19.36×**

**⟹ 判死（定理級）**：任何支撐於**單一模式**之核，`|ρ_u| ≥ 0.501221`，結構上不可能給出目標。

---

## 二 二模：判死（含**任意實數權重**）

設 `a_n = sin 2x`、`d_n = sin 3x`、`b_n = sin 4x`；`A_n = a_n − t_u b_n`、`D_n = d_n − t_d b_n`。
二模同命中 ⟺ 存在 `(c_1,c_2) ≠ 0` 使 `A·c = 0` 且 `D·c = 0` ⟹ **det = A_1D_2 − A_2D_1 = 0**。

- 窮盡 946 對：`min |det| = 3.924e−51` 於 `(n,m) = (15,30)`
- 但該對 `|b·c| = 0.000e+00` ⟹ **退化**（`a = −b`、`d = 0` ⟹ `ρ_u ≡ −1`、`ρ_d ≡ 0`，與目標無關）
- **非退化之 det = 0 配對數 = 0**

**⟹ 判死（定理級）**：二模 + 任意實數權重**皆不可**同時命中。注意此結論強於「權重係離散」之版本。

> ★ 此處正是 v1 之檢查器漏洞：v1 只查 `det ≈ 0`，會把退化配對當成解。v2 加 `|b·c| > 1e−8` 閘。

---

## 三 三模：可達，但代價 = 1 個連續自由度

2 方程（`ρ_u`、`ρ_d`）3 未知 ⟹ 恆有非零解（null space 維 = 1）。

- 窮盡 `C(44,3) = 13244` 三元組：「全 `c ≠ 0` 且非退化」= **13202（99.68%）**
- 抽 5 例以 `dps = 50` 回驗：最大殘差 `8.61e−47`（遠低於 `1e−30` 判準）

**⟹ 可達，但耗 1 個連續自由度 ⟹ 屬擬合，唔屬零參數。**
`⟹` 零參數路線之硬要求：**至少 3 個模式，且其權重比須由結構固定**（且固定比 ≠ ±1 之等權，見 §四）。

---

## 四 零參數真檢定：離散權重 `c ∈ {±1}`（K ≤ 4 窮盡，N_trials = 2,281,840）

判別量 `z ≡ √[((ρ_u − t_u)/σ_u)² + ((ρ_d − t_d)/σ_d)²]`；
**MC null**：隨機目標 `t' ~ N(t, σ)`，`R = 2000` ⟹ 得 `min z` 之 null 分佈 ⟹ `p = P(min z_null ≤ min z_obs)`。

| K | N_trials | 退化排除 | `min z` | 最佳支撐 | `z<1` 之候選數 | null `min z` 中位 | **p** |
|:-:|--:|--:|--:|:--|--:|--:|--:|
| 1 | 88 | 0 | 17.6397 | `(1,)` | 0 | 17.280 | 0.7240 |
| 2 | 3784 | 44 | **0.5717** | `(6,29)` `+,+` | 4 | 0.618 | **0.4300** |
| 3 | 105952 | 112 | **0.0637** | `(1,7,11)` `+,+,−` | 62 | 0.172 | **0.0980** |
| 4 | 2172016 | 924 | **0.0192** | `(1,2,4,12)` `+,+,+,−` | **1182** | 0.039 | **0.1520** |

★★ **全部 `p > 0.05` ⟹ 零命中**。此表係本輪最重要的一格：

- 若只報「`z < 1` 之候選數」，K=4 會報 **1182 個「命中」** —— 全部係 look-elsewhere 假象。
- MC null 顯示：呢個族嘅密度令 `min z` 本來就 ~`0.04`（中位），所以 `min z = 0.0192` **比隨機更差**（`p = 0.152`）。
- ⟹ **「近命中」在此族內零資訊**；`(6,29)`、`(1,7,11)`、`(1,2,4,12)` 等一律列**後驗候選，不作證據**。

> 判準 `p < 0.05` 係跑前寫死；此處**照實零命中**，不放寬。
