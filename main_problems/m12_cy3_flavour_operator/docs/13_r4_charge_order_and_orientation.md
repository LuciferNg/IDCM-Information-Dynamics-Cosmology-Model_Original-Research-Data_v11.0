## 二、結果

### 2.1 一體 vs 二體（D1／D2）

- **D1 一體**：預言 `13.70000` MeV，實測 `8.07900`，殘差 `−5.62100 ± 0.43058` ⟹ **`z = −13.05`，排除 🔴**
- **D2 二體**：預言 `8.14333` MeV，實測 `8.07900`，殘差 `−0.06433 ± 0.22517` ⟹ **`z = −0.29`，相容 🟢**
- **D3 樣本外**：一體 `z = −1.65`（σ 1.761）、二體 `z = −0.76`（σ 1.309）⟹ **兩者 σ 皆 > 0.5 MeV，解析度不足 🟡，不作判據**

⟹ 荷階 = **2（配對）**。一體在 13σ 排除，二體不但未死而且通過其自身必要恆等式。

⚠ 但 D2 係 **必要條件**，非充分：通過只證明「未被否證」，不證明「形式已識別」。

### 2.2 對稱 vs 有向（O1／O2）

- **O1**：對稱荷（`G_ij = G_ji` 實對稱 ⟹ `a(u s̄) = a(u s)`）給 `r(K⁺−K⁰) = −½·r(Ξ⁻−Ξ⁰) = −2.648199`；實測 `−3.041756`；殘差 `−0.393557 ± 0.083455` ⟹ **`z = −4.72`，對稱族判死 🔴**
- **O2**：所需正反破缺量 `ρ = 1.148613` ⟹ `a(q q̄)` 對 `a(q̄ q)` 之不對稱須達 **14.86%**

⟹ 「相關子（實對稱兩點函數）」路線整體出局；亦出局者：任何 `G(|i−j|)` 距離核。

### 2.3 光滑核（O4）

`G_ij = Σ_(n=1..44) φ_n(i)φ_n(j)/γ_n`，`φ_n(j)=√(2/45)sin(πnj/45)`，`γ_n = 4sin²(nπ/88)`；指派 `u→2, d→3, s→4`（敏感度 `s∈{5,7}`）。

| 比值 | 目標 | 預言 (s=4) | dev |
|:--|--:|--:|--:|
| `r(Σ⁻−Σ⁰)` | +3.716756 | +2.080657 | −44.0% |
| `r(Ξ⁻−Ξ⁰)` | +5.296397 | +2.045831 | −61.4% |
| `r(Σ⁻−Σ⁺)` | +6.246656 | +3.045831 | −51.2% |
| `r(K⁺−K⁰)` | −3.041756 | −1.022916 | +66.4% |

`max|dev|`：s=4 → **66.37%**；s=5 → 67.10%；s=7 → 68.76% ⟹ **光滑 Green 核判死 🔴**（三個指派全死，非指派選擇問題）。

形態上更致命：該核給 `Ξ ≈ Σ ≈ 2.0`（二者幾相等）、`K ≈ −1.0`；目標係 `3.72 / 5.30 / −3.04`，**並不同構**——鏈上衰減核之必然形態係「Ξ 與 Σ 同階」，數據係「Ξ 比 Σ 高 43%」。

### 2.4 可辨識性（O3）

自由味對荷：13 型（6 qq + 7 q q̄）；可用獨立比值 4 個（`n−p` 已作絕對標度）⟹ **欠定 9** ⟹ 自由荷不可唯一化，違零參數。
（R2-D 之「欠定 5」係以 8 方程計，含 π⁰ Dashen 與三盲通道；此處只計本 ansatz 內可用之比值約束，故為 9。兩者不矛盾。）

## 四、結構意涵

1. **這推翻 R1-Q2 之推廣版**：加性死亡者是「每夸克加性」，**不是「每價對加性」**。R2-A「二體族空集」只對四種具體核函數（乘性／加法 γ／衰減核／環境線性）成立，對一般配對荷 ansatz 不成立。
2. **定向係數據要求，非假設**：14.86% 之正反不對稱係由 `−3.0418` 與 `+5.2964` 兩個數反推之**必要條件**；任何味對正反不辨之結構不可能同時給出此二值。這是 M12 全部輪次中第一條**由數據導出之結構要求**（而非由推導假設）。
3. **但 realization 仍缺**：配對荷若自由，欠定 9；若為載體相關子，光滑核已死。故 M12 之缺口由「算子未知」精確化為：
   > 需要一個 **階 2、帶 14.86% 正反不對稱、非距離函數、非光滑衰減** 之味對荷，且其所有係數由載體唯一決定。
4. **態量子數之來源不能是譜配方**：本輪 `Ξ/Ξ*` 判別 `z = +5.12`（同味 multiset、不同自旋）與 v10 O144 `docs/30`「`R_h` 非 multiset 函數 ⟹ 必含態量子數」獨立同向；而 O144 `docs/31` 已排除 5 個自然譜配方。兩者合起來 ⟹ 態量子數與定向須由**扇區**而非**譜乘積**承擔 🟡（提案）。

## 五、唯一天然定向源（候選，未測）

88-site 雙鏈之 beat/sum 分解：

```
cos(ω_a t)·cos(ω_b t) = ½[cos((ω_a−ω_b)t) + cos((ω_a+ω_b)t)]
matter  = beat（差頻, T_pipe 投影, Q=+1）
antimatter = sum（和頻, 局部激發, Q=−1）
```

此為 corpus 內唯一「同一對、兩個扇區」之結構，天然提供 `a(q q̄) ≠ a(q̄ q)` 之標籤，且不需新常數。
