## 一、本體論前提（先立，後算）

本體論：**Reality = Relations + Distinctions；區分先於實體** ⟹ **區分係割（cut），唔係點**。

R10–R13 四輪全部把 `u`、`d` 實體化為**頂點標籤**（鏈上模式 2、3），再定義

```
δ_x = a(k_d,x) − a(k_u,x)        ← 兩個頂點權重之差
```

**割被寫成點。** 本輪把味之住所改為 **bond（割）**：

```
bond 態   |b_p⟩ = (|p⟩ + |p+1⟩)/√2 ，p = 1..43
bond 格林 G_b(p,q) = ⟨b_p|K⁻¹|b_q⟩ = Σ_n (φ_n(p)+φ_n(p+1))(φ_n(q)+φ_n(q+1))/(2γ_n)
位址      u → bond 2（邊 2–3）；d → bond 3（邊 3–4）；s → bond 4（邊 4–5）
```

**先例支持**：`docs/10`（R3-P2）已證 CMB／拓撲層之端點**不提供本徵值** —— 簽名鄰接 `A_s = S A S` 係么正相似 ⟹ 規範恆等 ⟹ 零新資訊；殘存之真不變量只有**面型三分 `{0:8, 1:40, 2:12}`**（RH 60v／120e／4-regular，阻挫邊 32）。本輪即把「本徵值住邊／面而非點」套到味層。

## 三、★ 兩個結構結論

### ① 「味之住所」係實質自由度（點 → 割 改變結果）

同一 Green 核、同一組數據，只換住所：

```
頂點版（R11，u→模式2、d→模式3）：ρ_d = 1.0340457（z +17.96）
邊版  （E1， u→bond2、d→bond3）：ρ_d = 0.74749853（z  +9.80）
```

`ρ_d` 由 1.034 降至 0.747（距目標 `0.4035` 由 2.56× 降至 1.85×）⟹ **住所唔係名稱問題**，係結構自由度。但 `ρ_u` 由 0.179 升至 0.214（更差）⟹ 換住所不足以救。

### ② E2「避免交叉」在結構上與味分裂**方向相反**

`t ≡ G_b(2,3) = 4.4101981` 係 **x-無關常數**，而

```
δ_x = sgn(Δ_x)·√(Δ_x² + 4t²) ≈ 4|t|·sgn(Δ_x)    當 t ≫ Δ
```

⟹ 分母 `4t²` 為常數 ⟹ `ρ_x → 1`（**味盲極限**）。實測 `ρ_d = 0.9919`、`ρ_u = 0.9823`，兩者**都被拉向 1**。

**level repulsion 抹平味差異** —— 故 E2 唔係「數值不中」，係**範疇錯誤**：避免交叉令各味趨同，而數據要求 `δ_s : δ_d : δ_u = 1 : 0.4035 : −0.0259`（強分裂 + 一項反號）。

## 四、判定

**E 路線（邊／割住所）本輪兩形式全數判死。** E3 結構控制通過。
