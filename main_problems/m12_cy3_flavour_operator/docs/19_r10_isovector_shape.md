**性質**: `final_result.md §殘餘 S2` 之首輪攻擊。判準 P1–P4 跑前凍結。**結果：P1 通過、P2／P3／P4 全不通過 ⟹ S2 未閉合。**

## 〇、誠實標記（先講清楚）

本輪形狀假設 H0 之「參考點 = `γ_{k_u}`」係**後驗**發現：原為解

```
ρ_d = (γ_{k_x} − c)/(γ_{k_s} − c)  ⟹  c = 0.021838
```

再注意到 `c ≈ γ_2 = 0.020357`（即 `γ_{k_u}`）。**故本輪全部結果屬後驗形式選擇**，`P2` 選擇性檢定即為此而設 —— 而它**不通過**。

## 一、形式族與判準

```
H0:  δ_x = C·[ f(γ_{k_x}) − f(γ_{k_u}) ]     ⟹  ρ_x ≡ δ_x/δ_s = [f(γ_{k_x}) − f(γ_{k_u})] / [f(γ_{k_s}) − f(γ_{k_u})]
```

`f ∈ {γ, √γ, γ², 1/γ, 4−γ, ln γ}`（6） × `k_s ∈ {4,5,7}`（3）= **18 組合**。
此形狀令 `δ_u ≡ 0`（`k_x = k_u`）⟹ `ρ_u` 之預言恆為 0（實測 `−0.02588837 ± 0.03292`，`z = −0.79`）。

判準（跑前凍結）：**P1** `|z(ρ_d)|<3` 且 `|z(ρ_u)|<3`；**P2** 命中 ≤ 2 且空檢定 `P(≥觀測) < 0.05`；**P3** 須存在對稱對荷 `a` 使該式成立（否則只係 `δ` 之 fit）；**P4** `C` 須有結構表達。

## 二、掃描結果（T1）

| `f` | `k_s`=4 | `k_s`=5 | `k_s`=7 |
|:--|:--|:--|:--|
| `γ` | **0.41791019（z +0.41）★** | 0.23972318（−4.67） | 0.1130221（−8.28） |
| `√γ` | **0.50095964（+2.78）★** | **0.33475751（−1.96）★** | 0.2020599（−5.74） |
| `γ²` | 0.27235122（−3.74） | 0.10813312（−8.42） | 0.028176026（−10.69） |
| `1/γ` | 0.740743（+9.61） | 0.66138028（+7.35） | 0.60494889（+5.74） |
| `4−γ` | **0.41791019（+0.41）★** | 0.23972318（−4.67） | 0.1130221（−8.28） |

目標 `ρ_d = 0.40350365 ± 0.03510`。

**命中 6／18**，去重後 **5 個相異比值**（`γ` 與 `4−γ` 恆給同值 ⟹ 非獨立形式）。

## 三、選擇性（T2）—— 不通過

空檢定（10⁴ 個亂數 target，`ρ_d ∈ [0.10,0.90]`、`ρ_u ∈ [−0.30,0.30]`，同一 18 組合、同一 3σ 門檻）：

| 量 | 值 |
|:--|--:|
| 每 target 命中數均值 | **1.35** |
| `P(≥6)` | **0.115** |
| `P(≥1)` | 0.305 |

⟹ 觀測 6 命中處於空分佈 **88 百分位**，**完全唔構成證據**。`P2` 判不通過。

## 四、可實現性（T3）—— 形式可實現但**非強制**

存在對稱 `a`（令 `a(3,x) := a(2,x) + C[f(γ_x)−f(γ_u)]`，對稱性一致），但 `a(2,x)` 對每個 `x` 皆自由（44 個自由度）⟹ **此形狀不決定 `a`，只約束其差**。

⟹ `H0` 係一句關於 **δ 之差** 的陳述，唔係關於**對荷**的陳述。要成為算子身份，必須額外證明該差被載體結構強制 —— 本輪做唔到。

## 五、標度（T4）—— 不通過

`C = δ_s/[f(γ_4)−f(γ_2)] = 56.4651 MeV`（`f=γ`）。`C` 之絕對值須由質量標度給出，而 v11 之質量標度 `M₀` 本身係 **O38 開放項**（`M₀ 絕對數值 = 單位制 artifact 偽命題`）。

⟹ **只得形狀，無算子標度**。`P4` 判不通過。

## 六、非擬合後果（T5，供記錄）

若採 `f=γ`、`k_s=4`：

| 項 | 結果 |
|:--|:--|
| 由 `δ_b` 反解 | `γ_k = 0.053887562` ⟹ **`k_b = 3.25857`（非整數）** |
| 由 `δ_c` 反解 | `γ_k = 0.015362881` ⟹ **`k_c = 1.73707`（非整數，且 < `k_u`）** |
| `k_s` 三讀 | 4 → `0.41791019`（+3.6%）／5 → `0.23972318`（−40.6%）／7 → `0.1130221`（−72.0%） |

⟹ 形狀**傾向 `k_s = 4`**（另兩讀偏 41%／72%），但既然 P2 不通過，此偏好**不可引用為證據**。
⟹ `k_b`、`k_c` 非整數，與「`c`、`b` 在 v11 未註冊模式指數」一致 —— 但同樣只作旁證。

## 七、判詞

| 判準 | 結果 |
|:--|:--|
| P1 命中 | 通過（`γ`/`k_s`=4 → `z=+0.41`；但共 6 命中） |
| P2 選擇性 | **不通過**（6/18，空檢定 `P=0.115`） |
| P3 可實現性 | **不通過**（形式不決定 `a`） |
| P4 標度 | **不通過**（`C` 無結構表達，繫於 O38） |

⟹ **R10 未達「算子身份」。** 只得一個**後驗形狀候選 🟡**，且已被自身之選擇性檢定否掉其證據地位。

⟹ **S2 仍然開放**；但本輪排除了「6 個自然 `f` 形狀 × 3 個 `k_s` 讀法」共 18 個組合之整體作為證據來源 —— 下一輪若再攻，必須：
1. **先驗**指定參考點之結構理由（為何係 `γ_{k_u}` 而非 `(γ_{k_u}+γ_{k_d})/2` 等）；
2. 或由載體**推出** `a`（令 `a(2,x)` 之 44 個自由度被固定），唔係只約束其差；
3. 並處理標度 `C`。
