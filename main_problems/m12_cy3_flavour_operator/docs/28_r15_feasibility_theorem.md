## 〇、為何本輪係方法論級而非數值級

前四輪（R11–R13、R14-S/G/E）嘅判詞形式都係「**某核族**判死」：
「sign-definite 族」、「平移不變族」、「Green 族」、「帶號核族」、「邊／割族」、「干涉族」。

但**核族有 44 維**（`w ∈ ℝ⁴⁴`），而每一輪實際只測咗 **1 至 3 個具體 `w`**。
故「族判死」係一個**未經檢定嘅推廣**。本輪直接判定：**族，到底有無約束力。**

## 一、關鍵恆等式（把核化為譜權）

```
G(i,j) = Σ_n w_n φ_n(i) φ_n(j)                      φ_n(j) = √(2/45)·sin(πnj/45)
δ_x = G(3,x) − G(2,x) = Σ_n w_n φ_n(x)·[φ_n(3) − φ_n(2)]  ≡  Σ_n u_n φ_n(x)
                                          其中 u_n ≡ w_n·Δ_n ，Δ_n ≡ φ_n(3) − φ_n(2)
```

**⟹ `δ` 只透過 `w` 進場；核之形狀與 `δ` 之間係一條線性譜展開。**
任何「核族」限制，都只係 `w` 之約束；而 `δ` 之三點讀數只係三條線性方程。

### ★ 新結構事實：δ-盲模式 `n ∈ {9, 27}`

`Δ_n = 0 ⟺ φ_n(2) = φ_n(3) ⟺ 5n ≡ 45 (mod 90) ⟺ n ≡ 9 (mod 18)`
⟹ 於 `1..44` 內只有 **`n = 9, 27`**，即 **`{N_gen², N_gen³}`**。

**味分裂對 `n = 9` 與 `27` 完全盲** —— 任何 `w_9`、`w_27` 皆不影響 `δ`。（結構事實，非證據。）

## 二、檢定一：PSD 類（`w_n ≥ 0`）有無約束？

`w ≥ 0` ⟹ `sign(u_n) = sign(Δ_n)` **固定**（非自由）。有效模式 42（25 個 `Δ>0`、17 個 `Δ<0`）。

檢定 = 3D 圓錐歸屬：`t ≡ (−0.02588837, 0.40350365, 1) ∈ cone{ v_n ≡ sign(Δ_n)(φ_n(2),φ_n(3),φ_n(4)) }`？
（Carathéodory ⟹ 三生成元窮盡；逐 triple 精確解。）

| 結果 | 值 |
|:--|:--|
| `t ∈ cone` | **是**（見證三支撐 1242 個） |
| 見證 | `n = [16, 36, 38]`，`λ = [5352.090787, 7100.113194, 2825.103401]`，`w = [−25491.137, 17705.99, 7348.6181]` |
| **cone = ℝ³？** | **500/500 隨機方向全部命中 ⟹ 是** |

**⟹ PSD 類對 `(ρ_d, ρ_u)` 零約束：任何目標值皆可由某個 `w ≥ 0` 精確重現。**

## 三、檢定二：entry-positive 子類（`G(i,j) > 0` 全部 1936 個）有無約束？
