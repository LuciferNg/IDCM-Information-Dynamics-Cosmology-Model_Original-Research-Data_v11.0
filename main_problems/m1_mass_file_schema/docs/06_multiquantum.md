## §0 問題

```
b：t = 149.815877839 ⟹ n_q ≥ 2      t：t = 6185.10192312 ⟹ n_q ≥ 69      （M6 §3，Σγ = 90 為每量子容量）
問：量子之間如何分配？有無零參數結構律？可否由質量反解？
```

兩條零參數候選律（本輪唯一容許之形式）：

```
E 等分        ：全部量子含量相同 ⟹ b: 2 × 74.90793892、t: 69 × 89.63915831
F 滿載＋餘額  ：前 n_q−1 個量子滿載（σ ≡ 1，含量 90），末量子內容 = 餘額
                b: 90 + 59.815877839、t: 68 × 90 + 65.10192312
```

## §1 可識別性：兩律皆精確重現 ⟹ 不可識別

| 律 | b | t | 自由度 |
|:--|:--|:--|:--|
| E | 2 × 74.90793892 = 149.815877839 ✓ | 69 × 89.63915831 = 6185.10192312 ✓ | σ 共用（44 維），零新常數 |
| F | 90 + 59.815877839 ✓ | 68 × 90 + 65.10192312 ✓ | σ 共用，僅末量子非滿 |

**定理（R6 主結果）**：因 `σ ∈ [0,1]^44` 連續，任何分配皆可精確表出，而 `n_q` 本身**不可觀測**
⟹ **跨量子組合律在質量值層不可識別**；E、F 及任意中間分配全部等價。

## §3 預註冊對帳

| # | 預言（`docs/05 §5` 原文） | 實測 | 判 |
|:-:|:--|:--|:--:|
| **R6-Q1** | 每量子 ≥ 86 = 90 − γ₄₄ | E 下 b 每量子 **74.9079** < 86；F 下末量子 **59.8159** < 86 | 🔴 **FAIL** |
| **R6-Q2** | 兩餘額同源（同一算子作用 n_q 次） | 常數虧損律要求 h_b/2 = h_t/69；實測 **15.092061** vs **0.36084169**（比 41.8246） | 🔴 **FAIL** |

**為何兩條都錯（自我批判）**

1. **R6-Q1** 之 86 係由 **t 之單一均值**（89.6392 ≈ 90 − 0.36）外推；把一個數之偶然接近 90 當成界。b 一測即破。
2. **R6-Q2** 預設「虧損對量子數線性」，即假設所有量子同構且損失常數——正正係 E 律之假設；用它去檢 F 律必然失敗。
   ⟹ 兩條預言皆**建基於未證之分配律**，屬循環；本輪已記錄，不刪原文。

## §4 結論

```
🔴 跨量子組合律 = no-go（不可識別）
   理由：① σ 連續 ⟹ 任何分配可表  ② n_q 不可觀測  ③ 六個量子含量全部無譜身份（ρ ≥ 19）
   結果：b、t 之質量檔「有編碼但無唯一化」——唔係未計好，係格式層不可判定
```

**新禁區**

- **D1**：不得由 b／t 質量值反解量子分配（等於在 10⁵–10⁶ 個等價分配中挑一個）
- **D2**：不得以 γ₁ 格點命中（整數倍）當結構（間距 0.0051 < 容差 0.0249 ⟹ 必然多重命中）

**M1 狀態**：維持 **partial**（格式層已完成、跨量子不可判定）。**唔 close** —— 按「推盡 ≠ 結論」原則：
close 觸發器 = 出現**獨立結構**提供量子分配機制（例如 M11 通道算子層，或未來 M5 束縛態給出多體合成律）。
