## §0 定義（本 M 凍結）

```
t ≡ m/M₀                                   （M₀ = 27.9009145112 MeV）
F0  ρ_bin(t; k, ε) = #{ S ⊆ {1..44} : |S| ≤ k, |Σ_S − t| ≤ ε·t }          純二值 σ
F1  ρ_1p (t; k)    = #{ (S, j) : |S| ≤ k−1, j ∉ S, 0 < t − Σ_S < γ_j }     恰 1 個 partial
                     〔σ_j = (t − Σ_S)/γ_j ∈ (0,1) 由目標唯一決定 ⟹ 每 (S,j) 恰一編碼〕
k*(t; ε)           = min{ k : ρ_bin ≥ 1 }
```

算法：meet-in-the-middle（44 模 → 22+22，按支撐分組）＋ `searchsorted` 精確計數；引擎以暴力枚舉在 k ≤ 2 對帳（自檢 3/3）。

## §4 兩個結構結論

**① 完備性 ⟹ 零預言力（M10 W5 之機制）**

```
σ ∈ [0,1]^44（連續） ⟹ 任何 t ≤ 90 皆可表（單 partial 即可）
二值 σ ∈ {0,1}^43  ⟹ 池密度：k ≤ 4 已覆蓋 17.0 %（ε=1e−3）、k ≤ 12 對 μ 有 953 個編碼
⟹ 質量值 m 唔可能係算子身份；身份只能來自「被強迫嘅低支撐編碼」
```
此即 M10 W5「質量值 dof = 0、零預言力」之格式層證明：**唔係計錯，係編碼太密**。

**② 重粒子支撐爆炸（與 M6 身份枯竭對帳）**

```
τ：t = 63.6847 > λ_max(18) = 63.5835 ⟹ 最小支撐恰 19（λ_max(19) = 66.1469）
c：t = 45.6257 > λ_max(12) = 45.5056 ⟹ 最小支撐恰 13
b：t = 149.8159 > Σγ = 90          ⟹ n_q ≥ 2（每量子均值 74.9079）
t：t = 6185.1019 > Σγ = 90         ⟹ n_q ≥ 69（每量子均值 89.6392）
```
⟹ M6「身份清晰止於 λ < 8」在編碼層得到**獨立第二證**：λ > 8 之後支撐數急升，簡併度跟隨爆炸（`docs/03` §2：τ 513、c 4285）。
