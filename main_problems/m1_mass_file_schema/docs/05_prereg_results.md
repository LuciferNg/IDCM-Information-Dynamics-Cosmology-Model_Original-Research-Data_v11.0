## §2 三處修正（本輪真正學到嘅嘢）

**① Q2 之錯在容量 ≠ 存在**
`λ_max(2) = 7.994904` ⟹ `t ≤ 7.99` 皆在容量區 ⟹ e（0.0183）、μ（3.7869）、s（3.3476）**三粒**，唔止兩粒。
「落入容量區」只表示理論上可容納，**唔保證有解**：e 之 `t = 0.0183148` 夾在 γ₁ = 0.0050958 與 γ₂ = 0.0203661 之間，而任何二值和 ≥ γ₁ + γ₂ = 0.0254621（+39 %）⟹ e 冇二值解。
⟹ **容量界（M6）與存在界（本 M）係兩個唔同嘅界**，兩者唔矛盾，但唔可以互推。

**② Q4 之錯在把「partial」當結構**
F1 對任何 `t < 4` 都有解且解係 `S = ∅, σ₄₄ = t/4`（`docs/03` §2 退化解定理）。
⟹ 「需一個 partial」唔係結構陳述，而係「目標 < 4M₀」之必然。
⟹ 輕扇區（e, u, d）之檔案內容 = **連續輸入**（3 個連續參數），唔係譜結構。
（此亦解釋 M4 `docs/16` 之標度約定問題：輕夸克質量本來就係 scheme-dependent 輸入。）

**③ Q1 後半之錯在假設「二值支撐爆炸」**
二值 ρ 只升到 μ k≤12 = 953（慢）；真正爆炸係 **partial**：μ ρ_1p（k≤2 → k≤5）= 796 → 285,784。
⟹ 判別力嘅敵人唔係「模數多」，而係「一個連續參數」。
