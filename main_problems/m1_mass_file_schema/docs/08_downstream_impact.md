## §2 重推結果（P1–P6，全 13 check PASS）

### P1 — `M₀` 兩義：**解除**（非矛盾）

```
M₀(v11 錨) = 27.9009145112 MeV      M₀(O239, v10) = 0.033331 MeV      ratio = 837.0860314
```

`0.033331` 出自 **v10.0 O239 之 `m = M₀|Δm|^φ²` 1 參數 fit**（`final_result.md` L16、`docs/43` L23、`scripts/47` L43）——標度被該式吸收，與 v11 錨值**不同物件**；且該式所屬路線已由 M9 判死（`|Δm|^φ²` 428.4σ）。比值 ≈ 837 = 27×31（dev 0.010 %）**屬單位制 artifact 之巧合**（O38：`M₀` 絕對值係單位 artifact），不作結構解讀。

⟹ M1 首輪 T1 之「上游未統一」記錄**降級為已解除**（append 附註，原文不刪）。

⟹ 對「零預言力」之結論**只有加强、不會減弱**；但下游引用**必須連慣例一併報**，否則三個池（M1 帳本／M4 比值／M10 F1）之數字互通即為錯用。

### P4 — 支撐閘（下游可用之作業規則）

```
covering(ε=1e−3) ≤ 0.1  ⟹  uniform 慣例：k ≤ 2（5.535%）；k=3 已 12.269% ⟹ 不合格
                              log-uniform 慣例：k = 1 唯一合格（0.882% / 0.617%）
「質量 = 某 mode 集」claim 需 (i) 報 coverage(k, ε) 與慣例、(ii) ρ=1（唯一編碼）
```

### P5 — M2 守恆式之多量子推廣

```
單量子（M2 §3）：m/M₀ + E_sync = Σγ = 90
多量子（本輪） ：m/M₀ + Σ_q E_sync^(q) = n_q·Σγ = 90·n_q
檢核 b：149.815877839 + (2·90 − 149.815877839) = 180 ✓      t：69 量子同理 ✓
```

⟹ M2 之式對 `m > 90 M₀` 之粒子（b、t 及全部核素）**不可直接套用**；若硬套，`E_sync` 會變成 `n_q·90 − m` 之偽量（b：30.1841、t：24.8981）。

### P6 — D2 之定量版：γ₁ 格點命中必然多重

```
目標 t = 30.1841222（b 之洞）  γ₁ = 0.0050958  容差 εt = 0.0301841
容差內 γ₁ 整數倍命中：12 個（k = 5918…5929）⟹ 格點命中率 ≈ 容差/γ₁ ≈ 5.9 個
```

⟹ 「整數倍 γ₁」型身份在任何合理容差下都必然多重命中 ⟹ 永久禁作結構證據（D2）。
