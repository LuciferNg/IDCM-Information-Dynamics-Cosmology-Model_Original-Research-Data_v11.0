| **d** | 0.167378026198 | 2 | 6 | 0 | **0.04184450655** | 🟡 退化 |

**退化解定理（本 M 第二結果）**

```
t < γ₄₄ = 4  ⟹  S = ∅, σ₄₄ = t/4 ∈ (0,1) 恆為合法 F1 編碼
⟹ 任何 t < 4 都有「編碼」，內容 = 一個純連續參數
⟹ 輕扇區（e, u, d）之檔案內容 = 連續輸入，唔係譜結構
```

同理，F1 對 t < 4 之解**與譜無關**（γ 只以 γ₄₄ = 4 之平凡方式出現）⟹
**partial 唔可以作為結構證據**；ρ_1p 之爆炸（`docs/02` §2）亦由此而來。

## §5 結果一句話
