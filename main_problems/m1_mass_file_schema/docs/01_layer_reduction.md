## §0 問題

原 schema（v10 O251）分五層：vertices / transform / operators / topology / labels。
問題：**邊幾層係真內容**？判準用 v11 L3 自由度閘之擾動測試 —— 改該層 ⟹ 預言（質量讀數）改變 ⟹ 有內容；不變 ⟹ 空層。

## §2 兩項結構副產品

**① 鏡射冗餘（新，記入本 M）**

```
γ_{44−n} = 4 − γ_n     （n = 1..43，精確至 4.2e−81）
⟹ 索引 n 只在等價類 {n, 44−n} 上有意義；固定點 n = 22 ⟹ γ₂₂ = 2
⟹ n = 22 = M8 之交接點（θ* = π/4、γ* = 2、t* = 0）
```

即：M8 用圖卡幾何獨立找到嘅交接點，在譜層係鏡射之唯一固定點。兩條路線在 n=22 / γ=2 匯合 —— 此為 M1 對 M8 之獨立旁證（非新推導）。

**② 環長敏感（新）**

N = 86 / 88 / 90 對 9 費米子最佳編碼**全部改變**（例：μ 之最佳偏差 8.62e−6 / 7.84e−5 / 5.69e−5；e 之 1.93e−2 / 2.65e−2 / 6.27e−2）⟹
**vertices 層唔係可調參數，N = 88 係硬約束**；任何「換環長都可解釋」嘅講法即刻被否證。

## §3 約化定理（本 M 第一結果）

```
五層  ⟹  三件 + 兩空層 + 三外部

  ✅ L1 vertices    譜表 γ_n（N=88；索引有 n ~ 44−n 冗餘，n=22 固定）
  ✅ L2 transform   M₀（只係單位 ⟹ 唔攜帶判別力）
  ✅ L3 operators   σ 編碼（唯一真內容）
  ⚫ L4 topology    空層 ⟹ 只可作等價結構，**不可作 flavour 指派**（與 O140 docs/19、M5 docs/07 一致）
  ⚫ L5 labels      空層 ⟹ 只可作註記（與 M4 docs/22 41.5σ 一致）
  ── 外部：M5 束縛態／重疊、M10 合法性、M11 em 通道算子
```

**判決**：原「五層格式規範」中被上游證成嘅只有三件；topology 與 labels 兩層之「內容」為零
⟹ 原 P2（拓撲／faces 攻堅）**結構上無對象可攻**，改為多重性／等價類（見 `docs/02`）。
