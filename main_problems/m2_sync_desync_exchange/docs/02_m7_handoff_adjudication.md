## 三、裁定 R2 — p 族完備性（回答 #3a）🔴 不完備

`docs/01 §7A` 測過嘅係 **可分族**：`m⁽ᵖ⁾ = M₀ Σ σ_n γ_nᵖ`（p = 0.5 / 1 / 2）。**未測非可分族**：

```
m = M₀ [ Σ σ_n γ_n + λ Σ_{n<m} σ_n σ_m w_nm ],   w_nm = γ_nγ_m/Σγ
```

`scripts/10` 五項實測（λ = −1）：

| # | 檢定 | 結果 |
|:-:|:--|:--|
| C1 | 單模態譜 | 對 λ 最大偏差 **0.0** ⟹ **單粒子譜完全盲** |
| C2 | 複合偏移（43+44 兩模） | **4.9538 MeV**（束縛尺度）；全 44 模 1213.4 MeV |
| C3 | 質量窗口 | `λ ∈ [−2.0695, 0]`：**吸引（束縛）容許**；排斥 λ>0 被 `Σγ` 封頂 |
| C4 | 互換律＋X 對合 | 恆等維持（`m/M₀ + E_sync' = Σγ`，`E_sync' = Σγ − m`） |
| C5 | 完備性 | **不成立** |

⟹ **非可分（束縛）族與 M2 全部既有約束相容**，而 M2 嘅測試（單粒子量子、總量、讀法比）**結構上分辨唔到** λ≠0。故「p 族淘汰完備」**不能宣稱**。

**框架內唯一排除途徑** = O237 逐模讀數（定義層），唔係 M2 定理。若要有束縛能項，就要換讀數算子 — 語料內冇。
