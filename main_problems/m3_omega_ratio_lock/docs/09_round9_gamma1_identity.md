## §0 問題

docs/08 觀察：gap 譜極端分層 `0 < γ₁ = 0.0050958 ≪ γ₂₂ = 2 < γ₄₄ = 4`。
問：**最輕 gap `γ₁` 有冇結構身份？**

## §1 ★ 結論先講

`γ₁` **唔係**額外輸入 —— 佢係**全譜之唯一代數種子**，而 M3 兩條數正是其初等對稱函數：

```
全譜 ∈ ℤ[γ₁]                     （Chebyshev，偏差 8.4e-60）
e₁(半譜) = Σ_{k=1..43} γ_k = 86   ⟹ Σγ = 86 + γ₄₄ = 90   （M3 約定）
e₄₃(半譜) = ∏_{k=1..43} γ_k = 44 = N_d  ★（精確至 1e-45）
```

## §2 乘積律（★ 本輪核心）

```
∏_{k=1..43} γ_k = N/2 = 44 = N_d        （N = 88）
∏ × γ₄₄ = 44 × 4 = 176 = 2N_d
```
來源：`∏_{k=1}^{n−1} 2sin(πk/n) = n`，`n=88`，成對 `k ↔ 88−k`，
餘下未配對項 `2sin(44π/88) = 2`：

```
(∏_{k=1}^{43} γ_k) × 2 = 88  ⟹  ∏ = 44
```

**⟹ 譜之和律與乘積律分別落在 `2N_d + 2` 與 `N_d`**：
M3 嘅預算數唔係外加，而係**譜本身之初等對稱函數**。

## §3 Chebyshev 生成：全譜由 `γ₁` 唯一決定

```
c = 1 − γ₁/2 = cos(π/44)
γ_n = 2 − 2T_n(c)          （T_n = Chebyshev）
```
`n = 0..44` 全驗（`max dev = 8.4e-60`）；`γ₀ = 0`、`γ₄₄ = 4 = B` 自動得出。
⟹ **44 個頻率並非 44 個獨立資料，而係一個代數數 `γ₁` 之 44 個多項式值。**

## §4 分形倍頻（精確，偏差 0）

```
γ_n^(88) = γ_{2n}^(176)          （全 n）
特別：γ₁^(88) = γ₂^(176)
```
鏈之 gap = 雙覆蓋（176 = 4N_d）之**第二諧波** —— 與分形張量重標定 `R` 一致。

```
γ₁ = 2 − α                    ⟹  deg γ₁ = 20

```

### ⚠️ 本輪自捉一錯（保留記錄）

初版誤用 `α = 2cos(π/88)`（degree 40）⟹ `q(γ₁) ≈ −1.04` **FAIL**。
因 `4sin²(π/88) = 2 − 2cos(2π/88) = 2 − 2cos(π/44)`，正確 `α = 2cos(π/44)`，degree **20**。
