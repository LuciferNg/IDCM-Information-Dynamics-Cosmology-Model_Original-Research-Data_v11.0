## §0 張力即一個 bit

```
Ω = ((B−1) : B² : N_d−B+1) / (N_d + B²)
N_d = 44 ⟹ (3:16:41)/60 ⟹ Ω_b = 0.05000   ⟹ +2.33σ
N_d = 45 ⟹ (3:16:42)/61 ⟹ Ω_b = 0.04918   ⟹ −0.40σ
```
`N_d = 44 ⟺ 鏈長 88 = F₁₁ − 1`；`N_d = 45 ⟺ 鏈長 90 = F₁₁ + 1`（`F₁₁ = 89`）。
**所以 Ω_b 2.33σ ≡ 「88 抑或 90」之 ±1 分歧。**

## §2 ★ 判決：`N_d = 45` 失敗 **8/8** 整數身份

| 身份 | N_d=44 | N_d=45 |
|:--|:--|:--|
| `L₅ = N_d/B ∈ ℤ` | 11 ✅ | 45/4 🔴 |
| `K_tree = N_gen·L₅ ∈ ℤ` | 33 ✅ | 135/4 🔴 |
| `2N_d = 8·L₅ , L₅ ∈ ℤ` | 88 = 8×11 ✅ | 45/4 🔴 |
| `N_d = N_gen·|A₂| − 1` | 44 ✅ | 44 ≠ 45 🔴 |
| `41 = N_d − N_gen` | 41 ✅ | 42 🔴 |
| `123 = K_tree + Σγ` | 33 + 90 ✅ | 125.75 🔴 |
| `61.5 = 123/2 = ⟨W⟩²` | ✅ | 62.875 🔴 |
| `88 = 2N_d = F₁₁ − 1` | 88 ✅ | 90 🔴 |

**⟹ 45 唔係「另一個結構解」，而係一個破壞 8 條整數身份之擬合值。**
（`L₅`、`K_tree` 係模式/深度計數，必須整數 —— 單此一條已足夠判死。）

## §3 ★ 新收穫：`N_d = B·L₅ = 4×11 = 44`（獨立於 |A₂| 路線）

```
路線 A（docs/05）: N_d = N_gen·|A₂| − 1 = 3×15 − 1 = 44   （−1 曾屬 🟡 殘餘）
路線 B（本輪）  : N_d = B·L₅ = 4×11 = 44                 （純乘積，無 ±1）
⟹ 44 有兩條獨立身份 ⟹ docs/05 之「−1 偏移」殘餘由路線 B 佐證，降級為 🟢
```

## §4 多面體數之角色分離（90 已用，唔可以兼任鏈長）

```
RH: V=60, E=120, F=62 ;  TI: V=60, E=90, F=32
88 = E(RH) − F(TI) = 120 − 32 = 2N_d      ← 鏈長
90 = E(TI) = Σγ(44-mode) = 2N_d + 2        ← 譜重
90 = E(RH) − V/2                           ← 同一角色之第二來源
```
⟹ **90 已以「Σγ 譜重」身份存在**；若同時做鏈長，`Σγ` 會變 92，`123 = 33 + 92` 即崩。
（此為結構一致性論證，級別 🟡，非獨立證明。）

## §5 統計判讀（誠實）

```
χ²(60) = 5.666 ; χ²(61) = 0.621 ; Δχ² = 5.046
χ²₁ 近似 ⟹ p = 0.0247（≈2.33σ，與 Ω_b 同源 —— 同一個 bit 數兩次）
```
**關鍵**：呢個 bit **並非自由**。若 61 係合法結構值，Δχ² 5.0 值得認真；
但 §2 證明它破壞 8 條整數身份 ⟹ 用 61 換 fit = 以結構換 2.3σ，屬**後驗擬合**，拒絕。
