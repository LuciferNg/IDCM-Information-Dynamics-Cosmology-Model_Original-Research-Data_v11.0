## §0 問題（O220 F2）

> 鏈之 **1D 性** —— 為何只有一條鏈？未由二十面體導出。

## §1 ★ 主答案：鏈係**相位扇區**，唔係空間晶格

```
O204 final_result: W-field = K_chain(形狀/相位) ⊗ K_tree(標度)
                   W = W₀ e^{iθ} , V = −μ²|W|² + λ|W|⁴ , 對稱 = U(1)_W
⟹ 相位空間 = S¹（單一角度）
⟹ 鏈維數 = 序參量獨立相位數 = rank(T^k) = 1
```

若序參量有 `k` 個獨立相位（`W ∈ ℂ^k`），鏈維數 = `k`（例如 `k=2` ⟹ 2D 環面 T²）。
**⟹ 1D 性 ⟸ 單一複純量。** 而「空間 3D」係另一回事（`N_gen = dim = 3`，O197 #11）——鏈係相位/時間方向，兩者唔衝突。

## §2 ★ 譜指紋：1D 環獨有嘅 Coxeter 配對

配對律 `γ_n + γ_{44−n} = B = 4`（O204 T4）係 1D 反射對稱 `n ↦ 44−n` 之產物。
測試：對每個特徵值 `λ`，問 `4−λ` 是否亦在譜內。

| 晶格 | 配對命中 | 相異特徵值 |
|:--|:--|:--|
| **1D C₈₈** | **88/88（100%）** | 45 |
| 2D C₂×C₄₄ | 47/88（53%） | 44 |
| 2D C₄×C₂₂ | 25/88（28%） | 35 |
| 2D C₈×C₁₁ | 8/88（9%） | 30 |

**只有 1D 環做到「全部模式」配對** ⟹ 配對律（進而 `μ²=2`、`γ₂₂=2`、`γ₄₄=4`）係 1D 之指紋。
另：1D 環每個相異特徵值重數 ≤ 2（`±n` 宇稱），**冇偏振自由度**（O221 docs/13 一致）——
3D 晶格需要 3 條分支，譜上唔符合。

## §3 🔴 否證：A₅ 群路線（原本以為「無秩-2 abelian 子群」）

實算 A₅ 全部 abelian 子群（由 120 個交換對閉包）：

```
abelian 子群 36 個；階集合 {2, 3, 4, 5}；最大階 5
★ 存在 V₄（Z₂×Z₂）：5 個 ⟹ 「A₅ 無秩-2」之假設【否證】
無 6 階元素（⟹ 無 Z₆）；無 4 階元素（⟹ 無 Z₄）
無 8 階 / 11 階 abelian 子群（⟹ 無 Z₈、Z₁₁）
88 ∤ 60 ⟹ Z₈₈ ⊄ A₅
```

**⟹ 群路線死**：A₅ 唔可能提供 88 位環面；亦唔可能解釋 88 位鏈之平移群。
1D 性**唔可以**用「二十面體無秩-2 abelian 子群」論證（該前提本身錯）。
記錄為 **FAIL-ROUTE**（禁止重推）。

## §4 Z₈₈ 自身：秩 1

```
單一生成元傳遞作用：88 位一條軌道
子群 8 個（τ(88)=8），全部循環

```
即：**鏈之平移群係循環群**，本身只承載一個週期方向。
