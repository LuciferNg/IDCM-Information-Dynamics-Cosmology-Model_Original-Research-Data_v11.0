## §0 問題

docs/06 得出：鏈維數 = 序參量相位秩 `k`；殘餘 = **為何 `k = 1`（單一複純量）**。

## §1 ★ 判據：`k = b₁(相位扇區)`（獨立相位數 = 環秩）

相位係 **holonomy**：圖上每個獨立環給一個相位，相位空間 = `(S¹)^{b₁}`。
所以序參量獨立分量數 `k = b₁`（前提：相位宿於圖之環，非頂點）。

實算（V/E 由建圖得，b₀ 用 union-find）：

| 圖 | V | E | b₀ | **b₁** | 意義 |
|:--|--:|--:|:--:|--:|:--|
| **C₈₈（世界鏈）** | 88 | 88 | 1 | **1** | ✅ 恰好一個獨立相位 ⟹ `k=1` |
| P₈₈（去一邊）| 88 | 87 | 1 | **0** | 冇環 ⟹ **冇相位**（鏈必須係環）|
| C₈×C₁₁（2D 環面）| 88 | 176 | 1 | **89** | 89 個相位 ⟹ 排除 |
| C₂×C₄₄（2D 環面）| 88 | 176 | 1 | **89** | 同上 |
| 2×C₈₈（兩斷開世界）| 176 | 176 | 2 | **2** | 兩分量 ⟹ `k=2` |

**★ 結論**：`k = b₁(C₈₈) = 1` ⟹ **序參量 = 單一複純量 `W ∈ ℂ`**。
而且 —— `b₁(P₈₈) = 0` 解釋咗**為何鏈係環（`K_chain ≡ L(C₈₈)`）而唔係路徑**：
路徑冇環 ⟹ 冇 Goldstone ⟹ 冇凝聚。第三輪 R3 之算子化（`K_chain ≡ L(C₈₈)`）由此獲得**理由**。

## §2 凝聚模唯一性（精確 ℚ）

```
rank L(C₈₈) = 87        ⟹ nullity = 1     （單一均勻凝聚模；合 O204 T1）
rank L(P₈₈) = 87        ⟹ nullity = 1     （控制組：連通即足，1D 唔關事）
rank L(2×C₈₈) = 174     ⟹ nullity = 2     （斷開 ⟹ 2 個凝聚 ⟹ k=2）

nullity(T − I) = 1                    （平移不變空間 = 均勻模）
nullity(R − I) = 45 = N/2 + 1         （反射不變：n=0,22,44 + 21 對）
nullity(T−I ∩ R−I) = 1                （同時不變 ⟹ 凝聚方向唯一）
```

## §3 兩個「1」是同一件事

| 說法 | 對象 | 值 |
|:--|:--|:--|
| 鏈維數 = 相位秩 | 場之內部自由度 | 1 |
| `k` = 獨立相位數 | 相位扇區拓撲 | `b₁ = 1` |

⟹ **「鏈 1D」同「場單分量」係同一個事實之兩面**：相位扇區 = **單一環**。

## §4 🔴 誠實負面（FAIL-ROUTE，禁重推）

試圖用預算比例 `(3:16:41)/60` 判 `k` —— **無效**：

```
k=1: (3,16,41)/60  = 1/20, 4/15, 41/60
k=2: (6,32,82)/120 = 1/20, 4/15, 41/60
k=3: (9,48,123)/180= 1/20, 4/15, 41/60   ⟹ 比例 projective，對 k 完全不變
```
⟹ 預算（任何齊次比例）**結構上不能**定 `k`；`k` 只能由拓撲定（§1）。
