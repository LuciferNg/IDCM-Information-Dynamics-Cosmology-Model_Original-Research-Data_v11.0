## §1 容量填充 ⟹ ℓ = 2

```
累積佔用:  cum(L) = Σ_{n=0}^{L} B^n   ⟹  1, 5, 21, 85, 341
ℓ = max{L : cum(L) ≤ C}
```

| 容量 C | 值 | L_max | 終端佔用 B^L |
|:--|--:|:-:|--:|
| **K_tree** | **33** | **2** | **16** |
| **N_d** | **44** | **2** | **16** |
| 60 | 60 | 2 | 16 |
| Σγ（能量）| 90 | 3 | 64 ✗ |

```
可接納容量區間：ℓ = 2 ⟺ 21 ≤ C < 85
⟹ K_tree (33)、N_d (44)、60 全部落區間 ⟹ 答案穩健（換容量不改）
⟹ Σγ = 90 給 ℓ = 3 ⟹ 排除 ⟹ 容量必須係【維度型】，唔可以係能量型
```

## §2 閘門邊界 ≡ 填充邊界

```
κ = B^{−ℓ} = 4^{−2} = 1/16 = γ_max⁻²   （B = γ_max 由 Nyquist 鎖死）
已填層      = [0, 1, 2]
通過閘門層  = {n : e^{−n} > κ} = [0, 1, 2]   ⟹ 兩集合相同
通過層數 = 3 = ⌈ℓ ln B⌉ = ⌈2.7726⌉ = 3 = B−1
```

**⟹ 「為何 κ⁻¹ = 16 就係暗份額」之答案：**
`κ⁻¹` 係**終端層佔用**（threshold 面），`16` 係**同一層嘅計數**（count 面）。
兩者係同一個物件 —— 閘門設在「終端層自己的佔用倒數」上，所以 `κ⁻¹ = B^ℓ = 16` 係**定義上必然**，
唔係巧合。
