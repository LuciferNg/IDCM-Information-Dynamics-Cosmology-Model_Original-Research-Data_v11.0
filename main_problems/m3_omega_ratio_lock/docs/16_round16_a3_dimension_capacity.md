## §1 判準：標度不變性

```
鏈 hopping t 係歸一化（場重定義／單位選擇），唔係物理參數
γ_n(t) = 4t sin²(πn/88)  ⟹  Σγ(t) = 90t      （實算：t=1/2→45, t=1→90, t=2→180）
dim(K_tree) = 33                              （純計數，與 t 無關）
```
任何 sector 計數（`ℓ`、`B^ℓ`、份額）必須對 `t` **不變**，否則同一宇宙會因單位選擇而改變物質比例。

## §3 維度型容量：ℓ 對 t 完全不變

```
ℓ_D = max{L : cum(L) ≤ dim K_tree} = max{L : cum(L) ≤ 33} = 2
⟹ Ω_dm = 16/60 = 0.26667，z = +0.44σ   （單一預言，無旋鈕）
```

## §4 維度界係定理，能量界唔係

```
第 L 層 ≅ (branch)^{⊗L}   ⟹  dim = B^L = 1, 4, 16, 64
層空間兩兩正交（不同次數之齊次分量）⟹ Σ_{L≤2} dim = 21 ≤ 33 < 85 = Σ_{L≤3} dim
```
- **維度界**：正交子空間維度之和 ≤ 全空間維度 —— 線性代數定理，無自由參數。
- **能量界**：`tr(H)` 隨算子歸一化任意縮放，冇任何定理限制其大小 —— 任何「能量容量」都要外部指定單位 ⟹ 偷加 1 個連續自由度。

## §5 容量之具體選擇

| 容量 | 值 | ℓ | |
|:--|--:|:-:|:--|
| **K_tree**（原則上）| **33** | **2** | ✅ 層空間所屬因子 |
| N_d | 44 | 2 | 同窗 [21,85) ⟹ 穩健 |
| 60 | 60 | 2 | 同窗 |
| dim(K_chain⊗K_tree) | 1452 | 5 | ✗ 層空間係 tree 因子內，非全張量積 |

⟹ **原則上 = K_tree**（層 = tree 之齊次分量）；N_d / 60 落同一窗口 [21, 85) ⟹ 結論對容量選擇穩健。
