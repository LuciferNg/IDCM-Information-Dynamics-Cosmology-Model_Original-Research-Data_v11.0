## §0 命題

```
3 + 16 + 41 = 60 = 3 × 4 × 5      （扇區和 = (B−1)·B·F₅）
```
問題：呢個「和 = 積」係咪扇區鎖定之**基準**（即宇宙以此為約束）？

## §1 「一般式」唔成立（先拆前提）

聲稱之一般式：對本原畢氏三元組 `(a,b,c)`，`a + 2b² + c² = abc`。

```
b ≤ 2000 全掃（本原三元組）：命中 = [(3,4,5)]  ⟹ 只有 1 個
反例 (5,12,13)：5 + 288 + 169 = 462 ≠ 780 = 5·12·13
```
⟹ **唔係一般律**，係 `(3,4,5)` 之專有性質。前提已錯。

## §2 方向性：係 B=4 ⟹ 和=積，唔係反之

```
S(B) − P(B) = (B−1 + B² + (B²+(B+1)²)) − (B−1)B(B+1) = −B(B−4)(B+1)
根 = {−1, 0, 4} ⟹ 唯一正根 B = 4
```
更精確定位（用 `N_d = B·L₅`）：

```
S − P = −B(B² − B − L₅ − 1)
⟹ 和 = 積 ⟺ L₅ = B² − B − 1
代入 B=4：11 = 16 − 4 − 1 ✓
```

**方向**：`B = γ_max = 4` 係 **Nyquist 定理**（任何週期環之 Laplacian 最大特徵值 = 4，與鏈長無關）
⟹ `B=4` 係定理 ⟹ 和=積係**算術殘影**。
反向不成立：唔可以「要求和=積」去定 B —— 因為和式 `S(B)` 本身已含 B，方程只係重述 B=4。

## §3 零指派力（決定性）

就算接受和積，佢只交**集合** `{3, 16, 41}`，唔講邊個數字屬邊個扇區。六個排列全掃：

| (Ω_b, Ω_dm, Ω_Λ) | χ² |
|:--|--:|
| **(3, 16, 41)** | **5.7** |
| (3, 41, 16) | 10 301.6 |
| (16, 3, 41) | 526 821.2 |
| 其餘三個 | > 5e5 |

⟹ 只有一個排列可行（次佳差 1800 倍）。
**扇區指派必須由算子身份供給**：`3 = B−1`（階 4 群非平凡特徵標）、`16 = B^ℓ`（容量終端佔用）、`41 = N_d − 3`（補集）。
和積在此之前完全無能 —— 佢係**數字集合**之描述，唔係**扇區物理**之約束。

## §4 真正嘅鎖定基準（三條，全部唔含畢氏結構）

| 扇區 | 基準 | 類型 |
|:--|:--|:--|
| Λ (41) | `⟨W⟩²/Σγ = 61.5/90` | 能量分割（凝聚 vs 譜跡）|
| 暗 (16) | `ℓ = max{L : Σ_{n≤L}B^n ≤ dim K_tree}` ⟹ `B^ℓ` | 容量界（維度，標度不變）|
| 可見 (3) | `B−1` = 階 4 群非平凡特徵標數 | 表示論 |

## §5 為何仍然「睇落似」

```
3, 4, 5 = (B−1, B, B+1)   ← 三個連續整數 ⟹ 積 = B³ − B = 60
16 = B²                   ；41 = B² + (B+1)² = 16 + 25
```
所以「和 = 積」實質只係一句：`L₅ = B² − B − 1`（兩邊都係 11）。
`L₅ = 11` 由二十面體導出、`B = 4` 由 Nyquist 導出 —— **兩個獨立結構數之算術相遇**，唔係第三條結構律。
