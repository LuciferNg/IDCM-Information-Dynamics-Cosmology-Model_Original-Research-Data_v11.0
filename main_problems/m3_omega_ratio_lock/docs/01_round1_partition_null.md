## §0 譜定義與約定（先釘死，避免跨約定污染）

```
44-mode 半譜 (本輪主用; O215/O163 預算約定):
    γ_n = 4 sin²(πn/88) = 2 − 2cos(πn/44),  n = 1..44
    Σγ = 90   Σγ_odd = 44   Σγ_even = 46   γ₄₄ = 4

88-mode 全譜 (O39/O163 求和約定):
    γ_k = 4 sin²(πk/176), k = 1..88
    Σγ = 178  Σγ_odd = 88    Σγ_even = 90
    關係: 88-mode 偶數子集 ≡ 44-mode (k=2n) ⟹ Σγ_even(88) = Σγ(44) = 90
```

⚠️ O215 寫「Σγ_odd = 44」(44-mode) 同 O163 寫「Σγ_odd = 88」(88-mode) **兩者都對**，
係約定不同。引用時必須標明約定，否則 60 份預算會計錯（88+16=104≠60）。

## §1 三條求和定理（本輪新證）

```
T-M1  Σ_{n=1}^{M} 4sin²(πn/2M) = 2M + 2
T-M2  Σ_{n odd}  = M = N_d          ← 關鍵
T-M3  Σ_{n even} = M + 2
T-M4  γ_M = 4 (Nyquist) — 與 M 無關
```

**證明**（手證，非只數值）：sin²x = (1−cos2x)/2；
奇部：n 與 M−n 配對（M 偶）⟹ Σcos(πn/M) 成對抵消 = 0 ⟹ 奇部 = M/4（sin²）= M/4；
偶部：只剩 cos(π)=−1 ⟹ M/4+½；總和 = (M+1)/2。乘 4 得上述三式。
數值核對：sympy 有理數，M ∈ {4,6,8,10,12,20,44} 全中。

**⟹ Σγ_odd = N_d 係半譜定理，唔係 88 特例。**
呢條係成個 60 份預算嘅地基：冇它，「44」唔可能同時做模數（count）同譜重（weight）。

## §2 身份鏈（EXACT，|Δ|<1e-49）

```
3  = γ_max − 1            = N_gen
16 = γ_max²               = B²         (B = γ_max = 4, Nyquist)
41 = Σγ_odd − γ_max + 1   = 44 − 4 + 1 = N_d − N_gen
60 = Σγ_odd + γ_max²      = 44 + 16
19 = 3 + 16 ;  123 = K_tree + Σγ = 33 + 90
```

**★ G4 關閉**：`41 = Σγ_odd − γ_max + 1` 同 `41 = N_d − N_gen` 唔係兩條要分別證嘅身份，
係同一條 —— 因為 `γ_max − 1 = N_gen`（4−1=3）。之前當「雙身份未證等價」係錯 framing。

## §5 60 身份普查（防雙重計數）

```
N_d + B² = 44+16   = 60   ★ 組合恆等（= 三份額之和）
|A₅| = 60                = 60   幾何來源（O223），非組合
5!/2, B·N_gen·F₅, 3×16+12, 2N_d−28  = 60   數值巧合
```

⚠️ **陷阱**：`|A₅|=60`（O223 手性判據）同預算分母 60 係兩個獨立 60。
若同時用作「分母 = 份額之和」同「60 = |A₅|」＝**雙重計數**，兩者必須分開引用，唔可以互證。
