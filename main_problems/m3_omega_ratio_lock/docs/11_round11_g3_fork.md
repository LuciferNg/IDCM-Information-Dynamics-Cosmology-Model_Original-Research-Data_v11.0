## §0 分叉與本輪新問

```
R1 閘門讀法 : 3 = ⌈ln B²⌉（通過 κ=B⁻² 之層數）; 16 = κ⁻¹（權重）
R2 樹層讀法 : 3 = B−1（深度-1 分枝減 identity）; 16 = B²（level-2 節點數）
```
**前幾輪未問之關鍵**：預算寫 `60 = 44 + 16`，而 `41 = N_d − 3` ⟹ **3 必須係鏈量**（3+41=44）。
但 docs/03 之 `P_κ` 用 `e^{−n}`（**層**權重）⟹ 其實係樹層量。
⟹ 若 3 屬樹層，「3+41=44」只係數值巧合，唔係鏈之分割。本輪硬檢此點。

## §1 3 之算子身份 = 樹層通過數

```
κ = B⁻² ;  L ≡ #{n ≥ 0 : e^{−n} > κ}
解析：e^{−n} > B⁻² ⟺ n < ln B² ⟹ L = ⌈ln B²⌉
實算（B=2..20）：L = ⌈ln B²⌉ 全部相等；B=4 ⟹ L = 3
```

## §2 「3 = B−1」係巧合，非律

| B | 2 | 3 | **4** | **5** | 6 | 7 | 8 |
|:--|--:|--:|--:|--:|--:|--:|--:|
| ⌈ln B²⌉ | 2 | 3 | **3** | **4** | 4 | 4 | 5 |
| B−1 | 1 | 2 | **3** | **4** | 5 | 6 | 7 |
| = ? | ✗ | ✗ | ✅ | ✅ | ✗ | ✗ | ✗ |

掃 B=2..20：命中只有 **B ∈ {4,5}**。
**且 `B ≡ 4` 係定理**（Nyquist：任何 cycle Laplacian 之 `γ_max = 4`，與鏈長無關）
⟹ 「R1 式本身 B-普遍」係**空優點**（宇宙只有一個 B）⟹ 分叉不可能由數據判，只能由算子身份判。

## §3 鏈可否自己供出 3？—— 唔可以（多重性審計）

```
#{γ_n < t} = 3  ⟺  t ∈ (γ₂, γ₃] = (0.0203571, 0.0457063]
```
| 門檻 | t | #{γ<t} |
|:--|--:|--:|
| κ = 1/16 | 0.0625 | **4**（唔係 3）|
| κ² = 1/256 | 0.003906 | 1 |
| γ_max/16 = 1/4 | 0.25 | 8 |
| 1/(2B²) = 1/32 | 0.03125 | 3 ★在窗 |
| B⁻³ = 1/64 | 0.015625 | 2 |

**★ 結構表達式多重性審計**（族 = 字典整數之 `a/b, a·b, 1/a, a², 2a, a/2, a²/b`，709 個值）：
落入窗 `(γ₂, γ₃]` 之候選 = **12 個**：
`1/45, 1/44, 1/41, 5/176, 1/33, 4/123, 1/30, 3/88, 1/29, 5/123, 2/45, 1/22`

**⟹ 「鏈門檻給 3」係從 12 個候選揀一個 = 擬合，不成立。**
（而且最自然嘅 `κ = B⁻²` 給 **4**，直接反駁鏈-閘門讀法。）

## §4 裁決

```
3 之唯一算子身份 = 樹層通過數 ⌈ln B²⌉
⟹ 「3 + 41 = 44」屬數值巧合，非鏈之分割（3 屬樹層空間、41 屬鏈空間）
⟹ 三份額 = 三個【唔同空間】之 rank：
     3  = dim(通過層子空間)
     16 = dim(level-2 節點空間)
     41 = dim(鏈之補空間)
⟹ 份額相加只能係 ⊕（直和）；⊗（同空間 dim 相乘）被排除
```

**★ 附帶收穫：第三輪 (d)「為何 ⊕ 而非 ⊗」獲得理由。**
⊗ 只在「三扇區係同一張量積之因子」時正確；實算顯示三者異空間 ⟹ ⊕ 係唯一一致嘅合成。
（仍屬「異空間 rank 相加」之建模選擇，非第一性原理，故 (d) 由 🔴 降 🟡。）

## §7 判決

| 項 | 級別 |
