## (a) 層/節點不對稱 → 一個閘門，兩個泛函

### 統一

```
閘門 κ = B⁻² = 1/16
可見 = ⌈ln κ⁻¹⌉ = 3      ← 讀【深度】（幾多層通過）
暗   = κ⁻¹     = 16      ← 讀【標度】（門檻倒數）
⟹ 物質 19 = ⌈ln κ⁻¹⌉ + κ⁻¹ = 3 + 16
```

**不對稱消失**：兩個分子係**同一個 κ** 之兩個泛函（深度 / 標度）。
「層 vs 節點」只係「讀深度」與「讀標度」之別，唔係兩個唔相干嘅規則。

### 殘餘（算術，非結構）

```
終端層節點數 = B^(L−1)，L = ⌈2 ln B⌉
B=3: 9  = κ⁻¹ ✓   B=4: 16 = κ⁻¹ ✓   B=5: 125 ≠ 25 ✗   B=6: 216 ≠ 36 ✗
```
⟹ `B^(L−1) = κ⁻¹` 只在 `⌈2 ln B⌉ − 1 = 2`（即 B = 3, 4）成立。
故 B=4 時「16 既係 κ⁻¹ 又係終端層節點數」屬**算術重疊區**，非額外結構律。
（呢個亦解釋了 G2「計數/權重混用」之疑：16 兩義之下，喺 B=4 恰好同一。）

## (b) P4 橋：M2 能量分割 ⟹ M3 份額（EXACT）

### M2 端（守恆帳本）

```
Σγ  = 90
E_sync = ⟨W⟩² = 123/2 = 61.5     （凝聚側錨: μ²/2λ）
E_proj = Σγ − E_sync = 57/2 = 28.5
K_tree = E_sync − E_proj = 33 = N_gen·L₅ ✓（與 M3 同一 K_tree）
```

### M3 端（份額）

```
E_sync/Σγ = 61.5/90 = 41/60  = Ω_Λ      （EXACT）
E_proj/Σγ = 28.5/90 = 19/60  = Ω_m      （EXACT）
E_sync/E_proj = 41/19        （EXACT）
量子 = E_sync/41 = E_proj/19 = 3/2      （= docs/04 測度等價之量子）
```

**⟹ P4 答案：`41 : (16+3)` 正是 M2 互換律之宏觀遺產。**
`41/19` 唔需要額外假設 —— 由「`Σγ = 90`（譜側）」＋「`⟨W⟩² = 61.5`（凝聚側）」兩錨夾定，
兩錨零共用輸入。

### ★ 結構簡化：分母 60 係【導出】，唔係前提

```
60 = Σγ / (3/2) = 90 / 1.5 = 60 = 2Σγ/3 = Σγ_odd + γ_max²
```

⟹ 邏輯次序可重排為 **兩層**，完全唔需要 `⊕` 直和：

```
第 1 層（能量）:  Ω_Λ = ⟨W⟩²/Σγ = 61.5/90 = 41/60
                  Ω_m = 1 − Ω_Λ  = 28.5/90 = 19/60
第 2 層（閘門）:  Ω_m 內分  Ω_b : Ω_dm = ⌈ln κ⁻¹⌉ : κ⁻¹ = 3 : 16
```

`⊕`（rank 相加得 60）只係「用秩測度書寫同一件事」之換算結果
⟹ 第三輪 (d) 之爭議**降級為寫法問題**（`🟡 → 🟢` 表述層）。
