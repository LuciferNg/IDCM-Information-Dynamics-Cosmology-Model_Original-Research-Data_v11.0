## §1 核心認同：K_chain ≅ Laplacian of C₈₈

```
K_chain ≡ L(C_88) = D − A        (88-cycle 之 Laplacian)
spec L = { 4 sin²(πk/88) : k = 0..87 }
半譜 k=1..44 ⟹ N_d = 44 modes
tr L = 2N = 176 ;  γ_max = γ₄₄ = 4 = B ;  zero mode 唯一（連通）
```

實算核對（numpy，88×88 顯式矩陣）：`max|spec − γ| = 4.0e-15`、`tr L = 176`、`γ₄₄ = 4.000000000000`。

**⟹ `γ_max = 4 = B` 唔再係「雙重錨定」口號，而係同一算子嘅兩面**：
chain 之 Nyquist 模態權重 ＝ tree 之分枝數。呢個就係 κ = B⁻² 嘅合法性來源。

## §2 半譜求和：算子形式（B-普遍）

```
Σγ(half) = ( tr L + γ_max ) / 2 = (176 + 4)/2 = 90 = 2N_d + 2
```

**⚠️ 順手拆一個陷阱**：O211 記「`Σγ = B(N_d+1)/2 = 90`」——兩式只喺 B=4 相等
（`4N_d+4 = B(N_d+1) ⟹ (B−4)(N_d+1) = 0`）⟹ 同 `(B−1)` 靚式同型，屬 **B=4 改寫**，非獨立律。
普遍式只可以寫 `2N_d + 2` 或 `(tr L + γ_max)/2`。

## §3 三份額 = 三個 rank

| 份額 | 算子 | 算子定義 | 值 |
|:--|:--|:--|:--|
| **N_gen = 3** | `P_κ`（chain 閘門投影）| `rank{n ≥ 0 : e^{−n} > κ = B⁻²}` | **3**（n=0,1,2）|
| **B² = 16** | `P_level2`（tree 二層投影）| `|level-2 節點| = B²` | **16** |
| **41** | `1 − P_κ` | `tr(1−P_κ) = N_d − N_gen` | **41** |
| **60** | `P_κ ⊕ P_level2 ⊕ (1−P_κ)` | 直和秩 | **60** |

`⌈ln B²⌉ = ⌈2.7726⌉ = 3` 同 `rank P_κ = 3` 兩條獨立算法同值（解析 vs 譜投影）。

**扇區來源分解（新）**：
- **物質兩扇區同源於 K_tree**：可見 = 閾值 `ln B²`、暗 = level-2 葉 `B²`
- **真空扇區源於 K_chain**：未投影模態 `N_d − N_gen = 41`

## §4 ★ 新預言：Ω_dm/Ω_b 係純 tree 量（chain-獨立）

```
Ω_dm/Ω_b = B² / ⌈ln B²⌉ = 16/3 = 5.3333        ← 式中完全冇 N_d
```

實測 N_d = 40…49：比值 **完全不變**（1e-15 內）。
⟹ 呢個係**真預言級結構**：暗/重子比只依賴 tree 分枝數，與鏈長無關。

**而 B 掃描（只用比值通道，唔碰 N_d）**：

| B | ⌈ln B²⌉ | 比值 | z |
|:--|:--|:--|:--|
| 3 | 3 | 9/3 = 3.0000 | **−22.2σ** |
| **4** | **3** | **16/3 = 5.3333** | **−0.3σ** ✅ |
| 5 | 4 | 25/4 = 6.2500 | +8.3σ |
| 6 | 4 | 36/4 = 9.0000 | +34.1σ |

**⟹ 單靠 Ω_dm/Ω_b 已可釘死 B=4**（唔需要 N_d、唔需要 Ω_b）。呢個係本 M 最乾淨嘅盲測通道。

## §5 殘餘：⊕ vs ⊗（(d) 之精確形式）

R3 已把三份額全部算子化，但**預算仍然係直和**：

```
60 = dim( H_chain ⊕ V^{⊗2} ) = 44 + 16
但 IDCM 核心對象係 K_chain ⊗ K_tree ⟹ dim = 44 × 4 = 176
```

**⟹ (d) 精確化**：為何份額用 `rank` 相加（⊕），而唔係 `dim` 相乘（⊗）？
呢個係唯一未解嘅建模選擇，亦係 O163 docs/04 (d) 嘅本體。
（本輪**不**主張已閉合；⊕ 之合法性仍缺第一性原理論證。）
