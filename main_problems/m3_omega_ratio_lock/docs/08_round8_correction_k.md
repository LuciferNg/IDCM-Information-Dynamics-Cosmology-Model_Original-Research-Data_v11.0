## §3 正確判據：`k = gapless 模式數`

**凝聚分量必有 VEV ⟹ 必無 gap**（有 gap 者唔可能凝聚）。故：

```
k = #{n : γ_n = 0}
```

精確結果（`mp.dps=40`）：

```
唯一零模 n = 0（γ_0 = 0）
γ_1  = 0.005095770779   ← 最輕有 gap 模式（唔係凝聚分量）
γ_22 = 2.0
γ_44 = 4.0 = B（Nyquist）
相異值 45 個（n=0..44 全異）
```

⟹ **`k = 1`**：序參量有**一個**凝聚分量 ⟹ `W ∈ ℂ`。
其餘 43 個模式係**有 gap 之激發**，各自帶相位，但唔係凝聚分量 —— 與「44 個頻率點」完全相容。
