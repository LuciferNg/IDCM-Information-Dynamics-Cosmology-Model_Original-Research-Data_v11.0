## §0 問題

而核心對象係 **K_chain ⊗ K_tree（dim = 44×4 = 176）**？

## §1 ★ 答案：兩本預算係同一個測度（逐扇區量子 = 3/2）

| 扇區 | 能量（90 制）| rank（60 制）| 量子 = 能量/rank |
|:--|:--|:--|:--|
| Λ | 123/2 = 61.5 | 41 | **3/2** |
| b | 9/2 = 4.5 | 3 | **3/2** |
| dm | 24 | 16 | **3/2** |
| Σ | 90 | 60 | 3/2 |

全部以 `Fraction` 精確核對，**零浮點容差**。

```
能量 = (3/2) × rank   逐扇區成立
⟹ 60 份預算 ≡ 90 能量預算 ÷ 均一量子
⟹ ⊕ 唔係額外嘅加法假設，而係【等分（equipartition）】之重述
```

## §2 兩條路線之獨立性（⊕ 之真正辯護）

| 路線 | 輸入 | 產出 |
|:--|:--|:--|
| **能量路線（O39）** | W-field 真空凝結：`⟨W⟩² = (Σγ + K_tree)/2 = 123/2` | Λ 能量 = 61.5 |
| **秩路線（本 M）** | chain rank `N_d−N_gen = 41`；tree rank `B² = 16`；閘門 `N_gen = 3` | 份額 41/3/16 |

兩條路線**冇共用輸入**（一條用 W-field 凝結值，一條用投影秩），卻在同一點重合：
`61.5/41 = 3/2` 且 `28.5/19 = 3/2`。
⟹ 呢個係**結構鎖**（兩個獨立結構相遇），唔係曲線擬合。

## §3 equipartition 之等價鏈

```
equipartition  ⟺  60 = 2Σγ/3  ⟺  N_d = N_gen·B² − B   (44 = 3·16 − 4 ✓)
再化（N_d = B·L₅ = 4×11）：  ⟺  L₅ = N_gen·B − 1      (11 = 12 − 1)
```
最後一式 = 語料已有之 **`12 = L₅ + 1`**（O116 §7 用過嘅同一關係）。

**⟹ ⊕ 之殘餘 = 一條算術身份（`12 = 11 + 1`），唔再係建模選擇。**

## §4 ★ B 掃描：只有 B=4 令兩路線重合

| B | N_gen=⌈ln B²⌉ | rank 總 | 量子 = 90/總 | Λ(秩×量子) | vs ⟨W⟩²=61.5 |
|:--|:--|:--|:--|:--|:--|
| 3 | 3 | 53 | 1.6981 | 69.623 | ✗ |
| **4** | **3** | **60** | **1.5000** | **61.500** | **✅** |
| 5 | 4 | 69 | 1.3043 | 52.174 | ✗ |
| 6 | 4 | 80 | 1.1250 | 45.000 | ✗ |

**⟹ equipartition 只喺 B=4 成立，而 B=4 由 Nyquist `γ_max=4` 獨立釘死**（docs/03 §1）。
即：⊕ 之合法性 ⇔ 「B=4 下兩條獨立路線重合」⇔ **一致性條件**（非自由參數）。

## §5 ⚠️ 自我修正：`B=4 only` 唔等於「後驗改寫」

docs/01 §4b、docs/02 §1 曾把 `3 = B−1`、`Σγ = B(N_d+1)/2` 判為「B=4 專用後驗改寫」。**需要修正其地位**：

- **B 並非自由參數**：`B ≡ γ_max`（Nyquist 定理，任何 cycle chain 皆 4），另加 4-ary tree 錨定。
- 既然 B 必然 = 4，凡「只喺 B=4 成立」之身份，喺 **IDCM 內即為定理**（前件必然滿足）。
- 該批評**只適用於**：把公式外推到假想 `B ≠ 4` 之宇宙（無觀測對應物）。

⟹ 正確講法：`3 = B−1` 係 IDCM 定理，但**唔係 B-普遍恆等式**；兩者要分開講。

## §9 生成閉包：整個預算塌縮到三個整數（2026-10-24 追加）

```
基礎整數:  B = 4 (≡ γ_max, Nyquist) ;  N_gen = 3 (⌈ln B²⌉) ;  L₅ = 11 (Lucas)
約束:      L₅ = N_gen·B − 1            (11 = 12 − 1)

導出:
  N_d    = B·L₅      = 44   =  88/2
  K_tree = N_gen·L₅  = 33
  Σγ     = 2B·L₅ + 2 = 90
  2⟨W⟩²  = Σγ+K_tree = 123
  60     = N_d + B²  ;  41 = N_d−N_gen  ;  19 = N_gen+B²
  123    = N_gen·(N_d−N_gen) = L₁₀
  量子   = Σγ/60 = 3/2
```

實算 16/16 PASS（`data/04_round4.out` §6）。
⟹ **所有預算數（3/16/41/60/90/123/61.5）都係 `(B, N_gen, L₅)` 之函數**，
唯一約束 `L₅ = N_gen·B − 1` 即語料既有之 `12 = L₅ + 1`。

**⟹ 全框架只剩一個非平凡輸入**：`L₅ = 11`（或等價：88 = 2B·L₅ = 8×11）。
若 88 位鏈長可由更深結構導出，則 ⊕ 之最後算術殘餘亦一併降級。
