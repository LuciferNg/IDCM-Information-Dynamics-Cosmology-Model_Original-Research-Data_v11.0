## §0 本輪要答嘅問題

G3 = 三扇區↔三區塊嘅賦值理由。經第一輪收窄後只剩兩條：
1. 暗份額為何 = `κ⁻¹ = B²`（而唔係隱藏模數 41）？
2. 三份額為何可以相加成一個預算（G2 嘅計數/權重混用）？

## §1 閉式（本輪推導）

```
Ω = ( ⌈ln B²⌉ : B² : N_d − ⌈ln B²⌉ ) / ( N_d + B² )
```

- `B = γ_max = 4`（Nyquist，半譜定理，與鏈長無關）
- `N_d = 44`（88-site 鏈半譜模數）
- `⌈ln B²⌉ = ⌈ln16⌉ = 3`（κ=B⁻² 閘門通過嘅代數數）
- B=4, N_d=44 ⟹ **(3 : 16 : 41)/60**，χ²=5.666（z = +2.33, +0.43, −0.18）

**⚠️ 寫法紀律（本輪最重要嘅方法論發現）**：
`3 = B−1` 呢個寫法**只在 B=4 成立**（第一輪 T2b：B=2,3,6,7,8 全部 MISMATCH）。
所以 `Ω = ((B−1), B², N_d−B+1)/(N_d+B²)` 呢個「靚式」係 **B=4 專用改寫**，
唔可以當結構強逼賣 —— 真正 B-普遍嘅式只可以寫 `⌈ln B²⌉`。
（同 φ-power 陷阱同型：事後改寫令巧合睇落似必然。）

## §5 語義分叉（本輪最深發現）

(3,16,41) 有**兩條**結構讀法，數值全同，但只在 B=4 時重合：

| | R1（閘門讀法）| R2（樹層讀法）|
|:--|:--|:--|
| 可見 3 | `⌈ln B²⌉`（κ 閘門通過數）| `B−1`（深度-1 分枝，減 identity）|
| 暗 16 | `κ⁻¹`（門檻倒數 = 權重）| `B²`（深度-2 葉數 = 計數）|
| Λ 41 | `N_d − ⌈ln B²⌉` | `N_d − (B−1)` |
| B-普遍？ | **✅ 式本身普遍** | 🔴 只喺 B=4 成立 |
| G2（計數/權重混用）| 🟡 仍在（16 係權重）| ✅ 消失（全部係計數）|

**裁決**：R2 睇落更「乾淨」（全計數、G2 消失），但佢用 `B−1` 呢個只在 B=4 命中嘅等式，
屬**後驗改寫**；R1 冇呢個問題（`⌈ln B²⌉` 就係定義），但要接受 16 係「權重當份額」。
⟹ **唔可以兩邊著數都要**：揀 R2 就必須解釋為何 `B−1 = ⌈ln B²⌉`（B=4 特例）；
揀 R1 就必須解釋為何門檻倒數可以做份額。此為 G3 之真正核心。

## §6 張力歸因（比值通道 vs 標度通道）

```
Ω_dm/Ω_b = B²/(B−1) = 16/3 = 5.3333
觀測     = 5.3651 ± 0.1065        z = −0.30σ   ✅
Ω_b = 3/D 反解 D = 60.85（結構 60）⟹ 標度差 +0.85 份
```

**⟹ 結構式嘅「比值部分」−0.3σ 命中；全部張力落喺標度（分母）**。
呢個係重要診斷：如果將來 CMB-S4 把 Ω_b 拉低到 0.0490，分母會要求 61.2 ⟹ 60 會死；反之 60 生。
