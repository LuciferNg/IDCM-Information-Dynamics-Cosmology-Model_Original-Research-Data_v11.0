## §1 獨立重算（本輪自建，24/24 PASS）

### (a) 群論路線

```
icosahedron: 12 頂點、30 邊（實算最短距）
旋轉群 I（由 12 頂點置換暴力建構，det=+1，60 個相異矩陣）
階分佈: {1: 1, 2: 15, 3: 20, 5: 24}
  ⟹ |A₂| = 15（二階元素 = 2-fold 軸）
  ⟹ e = 24/4 = 6（5-fold 軸）; 三階 20/2 = 10（3-fold 軸）
N_gen = (e + o − 3)/(F₅ + 1) = (6+15−3)/6 = 18/6 = 3
N_d   = N_gen·|A₂| − 1 = 3×15 − 1 = 44   ⟹  88 = 2N_d , 176 = 4N_d
```

### (b) 多面體計數路線（唔用群表示論）

```
RH（rhombicosidodecahedron）: V=60, 每點度數 4 ⟹ E = 60×4/2 = 120 ; F = 20△+30□+12⬠ = 62（Euler ✓）
TI（truncated icosahedron）  : V=60, E=90, F = 12⬠+20⬡ = 32（Euler ✓）
★ 88 = E(RH) − F(TI) = 120 − 32
★ 兩路線一致：2N_d = 88
```

兩條路線**零共用輸入**（群元素計數 vs 多面體面/邊計數）⟹ 互證。

## §3 ★ 新增結構聯繫：`|A₂| = B² − 1`（群 ↔ 樹之橋）

```
|A₂| = 15   （icosahedral，二階元素）
B² − 1 = 15 （B = γ_max = 4）
⟹ N_d = N_gen(|A₂|) − 1 = N_gen(B²−1) − 1 = N_gen·B² − B
⟹ 兩式等價 ⟺ B = N_gen + 1        （4 = 3 + 1）
```

**意義**：docs/04 §3 之 equipartition 算術節點 `N_d = N_gen·B² − B`，
原來**等價於 `B = N_gen+1`**，而後者 = Nyquist(4) 與 Coxeter(3) 之鎖。
即：equipartition 唔係額外身份，而係「鏈之 Nyquist 權重」與「二十面體世代數」相遇嘅結果。
