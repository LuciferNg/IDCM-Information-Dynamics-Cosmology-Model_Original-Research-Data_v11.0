## 二、P-a：CAP 結構排除（先驗、零 dof、已成立）

```
單模 γ-ratio 讀法之比值上限 CAP = γ₄₄/γ₁ = 4/(4sin²(π/88)) = 784.9646644
```

**預言**：任何質量比 `> 784.9646644` **不可能**係單模 γ-ratio 讀數；任何聲稱「`m_A/m_B = γ_a/γ_b` 且比值 > CAP」者，**無需核數即可判錯**。

**已應用**：`m_τ/m_e = 3477.23 = 4.43× CAP` ⟹ 跨代輕子比**必然**要多模／多因子。此預言**永久可證偽**（若有人給出合法單模讀法且比值 > CAP ⟹ 本 M 判決錯）。

## 三、P-b：φ-ladder 唔會被未來精度救回（已可判）

`φ^(11+7/88)` 之 dev = `9.53e−6` 相對；5σ 相容需 `≤ 1.11e−7`。差距 **86×**。
