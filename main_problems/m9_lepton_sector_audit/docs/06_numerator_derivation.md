## 一、域分離定理（本 session 最強結果，✅ 定理）

**定理**：`∀x ∈ ℚ\{0}`：`φ^x ∉ ℚ(ζ₈₈)`。而 `∀a,b`：`γ_a/γ_b ∈ ℚ(ζ₈₈)`。
⟹ **`φ^x ≠ γ_a/γ_b` 恆成立** —— 唔可以有任何數同時係「φ-冪」同「譜讀數」。

**證明**（四步，全部可由機器核）：

1. `γ_n = 4sin²(πn/88) = 2 − (ζ^n + ζ^{−n}) ∈ ℚ(ζ₈₈)` ⟹ 任何 γ 比值 ∈ `ℚ(ζ₈₈)`（域對乘除封閉）。
2. 設 `x = p/q`（既約，`p ≠ 0`），`α = φ^x`。若 `α ∈ ℚ(ζ₈₈)`，則 `α^q = φ^p ∈ ℚ(ζ₈₈)`。
3. 但 `φ^p = F_p·φ + F_{p−1}`，`F_p ≠ 0` ⟹ `φ^p ∉ ℚ`，且 `φ^p ∈ ℚ(√5)`。
4. `disc(ℚ(√5)) = 5`（域判別式；多項式判別式 20）⟹ 5 在 `ℚ(√5)` 分歧；`ℚ(ζ₈₈)` 只在 `{2,11}` 分歧（`88 = 2³·11`，`5 ∤ 88`）⟹ `ℚ(√5) ∩ ℚ(ζ₈₈) = ℚ` ⟹ `φ^p ∉ ℚ(ζ₈₈)`，矛盾。∎

1. **Q1 定論**：同一量**唔可能**同時有「譜讀數」同「φ-冪」兩個合法身份 —— 唔係判據約定，係域論不可能性。所以「三聲稱邊個係身份」呢個問法本身**只有一個可能答案類**：最多一個，且兩者互相排斥。
2. **φ 階梯唔可能係 K_chain 譜嘅輸出**（反之亦然）：`φ ∉ ℚ(ζ₈₈)`。⟹ O34/O35 之階梯屬**獨立描述層**，唔屬譜層，兩者必須分開記賬。
