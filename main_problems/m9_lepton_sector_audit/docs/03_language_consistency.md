## 三、判準（Q1 之正式答案）

| | 插值族（φ-ladder） | 離散族（γ-ratio） |
|:--|:--|:--|
| 覆蓋 | 任何目標都在半格內 ⟹ 命中率 **100 %**（τ ≥ 半格） | 1 892 值；可以完全落空 |
| 可證偽性 | **零** | **有**（實測三個比值全部落空 ≥1 %） |
| 每次檢定之淨資訊 | **0 bit**（構造上必然命中） | 見 docs/04 位元預算 |

**⟹ Q1 答案：同一量唔可以有「兩個合法身份」，判準唔係「邊個準」，而係——**

1. **事前性**：參數必須在見目標前凍結（docs/02 §四：C1 失敗）。
2. **可證偽性／族密度**：族必須有能力落空（插值族 0 能力 ⟹ 無資格做身份）。
3. **dof 成本**：每個反解因子 / 每次取整都係 1 dof（C2 = 1 dof tautology）。

三者任一不過 ⟹ 該形式**唔係身份**，只係**近似式**。同一量可以有任意多條近似式，所以「唯一化」唔係揀一條，而係判定**有冇**合法者。

**T3 判**：φ-ladder 對三個輕子比值「全部命中」係插值族之必然（P ≈ 1），**唔構成同語言證據**；γ-ratio 離散族對三個比值**全部落空**（≥1 %）⟹ **輕子扇區在 σ 級無結構比值**。
