# M9 — 輕子扇區獨立攻：比值算子身份唯一化

## 狀態: 🔴 已註冊（只開不推）

**問題**：同一個觀測量 `m_μ/m_e = 206.768282988`，三個互斥聲稱同時掛住 🟢：

| 公式 | 值 | 值偏差 | 出處 |
|:--|--:|--:|:--|
| `φ^(11+7/88)` | 206.770253211 | +0.000952865 %（`9.53e−6`） | O34／O35 |
| `(γ₇/γ₁)(F_μ/F_e)` | 206.705 | 0.031 % | memory 式（M4 L58 已判 **後驗 permissive**） |
| 「界內可達」 | 206.77 | — | M4 `docs/19`（單模可達清單） |

## 核心方法論（本 M 唯一新東西）

**判輕子扇區唔可以用 % 門檻，必須用 σ。**
`9.53e−6` 相對偏差，分母取 `1e−3`（%級標準）睇落「極準」；分母取觀測不確定度（`m_μ` 相對 ~`2.2e−8`）⟹ **~430σ**。
三個「🟢」能並存，正因為各自用了不同門檻。

⚠️ 觀測不確定度數值本身 🟡 **未權威核**（本 M P1 第一件事）。

## 待證（全 🔴）

- T1 三聲稱中最多一個係結構身份
- T2 φ 指數 `11 + 7/88` 過 φ-lock 閘（`log_φ(obs) = 11.07952565` vs `11+7/88 = 11.07954545`，差 `1.98e−5` = 先取 log 再湊分母之指紋）
- T3 `τ/μ` 同語言（`log_φ(16.8170293324) = 5.865175951`，非整數非半整數）
- T4 至少一個樣本外零參數預言
