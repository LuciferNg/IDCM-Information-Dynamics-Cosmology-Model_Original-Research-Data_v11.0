## 一、問題形式化

本 M 之註冊質量形式（`docs/19`／M6 線）：`m_f = M₀·γ_{n_f}·C_f` ⟹

```
Δ ≡ m_d − m_u = M₀ ( γ_{n_d}·C_d − γ_{n_u}·C_u )
```

味分裂要非零，**只能**由兩處進入：① 味→模指派 `n_f` 不同；② 係數 `C_f` 不同。以下逐路封死。

## 二、路線 (a)：`C_u = C_d`（零新常數）

`Δ = M₀C(γ_{n_d} − γ_{n_u})`。本檔以 3 味 → 3 模（`u@3, d@11, s@27`）窮舉 **S₃ 全 6 置換**：

| 置換下之 Δ（MeV，`C = 1`） |
|:--|
| `+15.0687`、`+74.0273`、`−15.0687`、`+58.9586`、`−74.0273`、`−58.9586` |

- **6 個相異值、含 ±** ⟹ 同一物理內容可有**相反**預言 ⟹ 預言未良定義；
- 指派軌道 = `6`、穩定子平凡 ⟹ **註冊結構中無不變量可選代表**；
- 選定代表所需外部信息 ≥ `log₂6 = 2.5849625 bit` ⟹ **離散 dof ≥ 1**；
- 實證已死：`docs/20` §七 —— 內容型指派樣本外 `z = +7.56`；排序型指派恆真（`0 bit`）。

## 三、路線 (b)：`C_d ≠ C_u`（新係數）

`Δ = M₀(γ_{n_d}C_d − γ_{n_u}C_u)`，係數比只能**反解**：

| 欲命中 | 需 `C_d/C_u` |
|:--|--:|
| `Δ0 = 4.4492 MeV`（M5 `A_eff`） | `1 + 4.4492/M₀ = 1.159` |
| `X = 2.5461523 MeV`（γ 載體分支，已 NO-GO） | `1 + 2.5461/M₀ = 1.091` |

⟹ **1 個新有量綱常數、零預言力**；且 M2 唯一性（`docs/15` §九）禁獨立新項 ⟹ 雙重禁止（同 `docs/28` §四）。

## 四、路線窮舉完備性

註冊詞彙逐項檢（S₃ 全 6 置換、5 類量）：`Σγ`、`Σγ²`、`Σγ^p`、`g`-pairs、計數 —— `max dev = 3.67e−40` ⟹ **全部 label-blind**。
