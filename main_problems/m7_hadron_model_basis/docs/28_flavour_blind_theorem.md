## 一、定理

**𝒜 之生成元**

- ① 一體：`E₁(σ) = M₀ Σ_n σ_n γ_n`，`γ_n = 4sin²(nπ/88)`，`n = 1..44`
- ② 兩體：`E₂ = Σ_{i<j} g(|n_i − n_j|)`，`g(d) = g(88−d)`（M6 註冊核）

**陳述**：①、② 之式中**皆無味指標**；`E₁` 只依佔用模之**多重集**，`E₂` 只依模距之**多重集**。
故對任何「只差味標籤置換」之伴侶（`π±`、`K±`、`p/n`、`D±`…），`E = E₁ + E₂` **精確相等**。

**推論**：`Δ0 ≡ 0`、`s/d` 細分 ≡ 0、`u/c` 細分 ≡ 0 —— **一體與兩體皆然**，與 `M₀` 及核之具體形式**無關**（純結構，不需數值）。
